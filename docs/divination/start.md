# 五术之卜

- 所谓"卜"，它包括占卜、选吉、测局三种，其目的在于预测及处理事情，其中占卜的种类又可分为"易断"及"六壬神课"。
- 在"山、医、命、相、卜"五术中，"卜"是对"未知之事"发问的学问：当人对前路吉凶、事态走向难以决断时，借一定的推算工具与规则来寻求参考。它既有一套仪式化的起卦占验方法，也沉淀了深厚的典籍与理论传统。

## "卜"字何意与范畴

- "卜"在古汉语中本指灼烧龟甲兽骨、观其裂纹以断吉凶的行为（甲骨文之"卜"即裂纹之象），后泛指一切预测吉凶的方术。
- 传统上把"卜"的范畴概括为三事：**占卜、选吉、测局**。三者对象与规模不同：
    - **占卜**——针对个人或具体事件推断吉凶，如问病、问事、问失物等；
    - **选吉**——为即将进行的事务择定吉时、吉方、吉日，重在"择"；
    - **测局**——面向更大格局（国运、气数、天下大势）的推演，重在"测"。

## 占卜一系

- **以《周易》为宗：** 传统说法认为占卜以大衍筮法（用蓍草推演）起卦，以卦象、卦辞、爻辞为断；《周易》因兼具占筮与哲理，成为占卜体系中最核心的经典。
- **易断：** 指以《易》理推演的占断方法，含卦象取义、爻位生克、变卦互卦等解读路径；后世又发展出六爻（纳甲筮法）、梅花易数等各具特色的易占流派。
- **六壬神课：** 又称大六壬、六壬式占，传统"三式"（太乙、奇门、六壬）之一，以天盘、地盘配合干支五行推演，多用于占人事之吉凶，与《周易》占法并称。
- 本站卜部所收录的《周易》经传原文及六爻、梅花易数基础，均属占卜一系的文献整理。

## 选吉一系

- **奇门遁甲：** 传统三式之一，被描述为"由布局、布斗、符咒相结合"的术数体系，讲究天时（九星）、地利（九宫）、人和（八门）的配合。民间传说其盛于军事运筹，故有"帝王之学"的称号（传统说法）。
- 选吉体系的实际运用多与历法结合，如选择动土、婚嫁、出行等的吉日良辰，在民俗生活中影响深远。
- 需说明：奇门遁甲典籍庞杂、门派繁多、术语晦涩，民间传说成分亦重，宜以文献研究的眼光看待。

## 测局一系

- **太乙神数：** 传统三式之一，相传以十二运卦象之术推演，常被用于推算国家政治命运、气数与历史变化规律，是面向大格局的术数（传统说法）。
- 测局之术因其对象宏大、涉及政事，历史上多在特定圈层流传，民间少见；相关古籍多古奥难读，真伪杂糅。

## 卜术的经典背景

- 卜部的核心经典是《周易》。《周易》由"经"（六十四卦卦爻辞）与"传"（十翼）组成，既是占筮之书，更是阐述变易之道的哲学典籍，被尊为"群经之首"。
- 理解卜术，宜先读《周易》原文以明其象数与义理，再涉猎六爻、梅花等流派，方不致迷失于枝节口诀。
- 卜部章节结构：
    - 《[周易导读](/divination/zhouyi/what)》——经传构成、八卦基础与阅读路径；
    - 《[六十四卦](/divination/zhouyi/what)》——逐卦经文整理；
    - 《[十翼导读](/divination/shiyi/what)》——七种十篇《易传》的说明；
    - 命部另收《[六爻](/fate/liuyao)》《[梅花易数](/fate/meihua)》两篇基础文。

## 理性看待

- 占卜之术属于传统方术文化：它承载了古人在不确定面前寻求参照的心理需求，也凝聚了一套观察事物变化、权衡进退的思维框架（如"潜龙勿用""亢龙有悔"所提示的进退之道）。
- 从现代视角看，占卜结果不宜作为决策依据，重大事务应依据事实、理性与专业意见判断；了解卜术宜取其文化与思维价值，而不迷信其断语。
- 本站以整理经传原文与文化知识为务，不提供占断服务，亦不主张以此干预医疗、法律等专业事务。
