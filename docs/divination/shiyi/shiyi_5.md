# 文言传
- 《文言传》是《十翼》之一，专门用来解释《乾》《坤》两卦的传文。六十四卦之中，唯《乾》《坤》两卦另配《文言》，可见其在全经中的特殊地位。
- 《乾》《坤》为《易》之门户：乾为纯阳以象天，坤为纯阴以象地。天地之道立，六十四卦之义才有所统摄，因此《文言传》被视为理解整部经典的钥匙。
- 全篇分为「乾文言」与「坤文言」两部分：乾文言先以「元、亨、利、贞」四德立纲，再逐爻设问，申说君子进德修业之道；坤文言则阐发坤道柔顺承天、积善成德、敬义直方之理。

## 乾文言
- 文言曰：「元者，善之长也，亨者，嘉之会也，利者，义之和也，贞者，事之干也。君子体仁，足以长人；嘉会，足以合礼；利物，足以和义；贞固，足以干事。君子行此四者，故曰：乾：元亨利贞。」

- 初九曰：「潜龙勿用。」何谓也？子曰：「龙德而隐者也。不易乎世，不成乎名；遯世而无闷，不见是而无闷；乐则行之，忧则违之；确乎其不可拔，乾龙也。」
- 九二曰：「见龙在田，利见大人。」何谓也？子曰：「龙德而正中者也。庸言之信，庸行之谨，闲邪存其诚，善世而不伐，德博而化。易曰：「见龙在田，利见大人。」君德也。」
- 九三曰：「君子终日乾乾，夕惕若，厉无咎。」何谓也？子曰：「君子进德修业，忠信，所以进德也。修辞立其诚，所以居业也。知至至之，可与几也。知终终之，可与存义也。是故，居上位而不骄，在下位而不忧。故乾乾，因其时而惕，虽危而无咎矣。」
- 九四：「或跃在渊，无咎。」何谓也？子曰：「上下无常，非为邪也。进退无恒，非离群也。君子进德修业，欲及时也，故无咎。」
- 九五曰：「飞龙在天，利见大人。」何谓也？子曰：「同声相应，同气相求；水流湿，火就燥；云从龙，风从虎。圣人作，而万物覩，本乎天者亲上，本乎地者亲下，则各从其类也。
- 上九曰：「亢龙有悔。」何谓也？子曰：「贵而无位，高而无民，贤人在下而无辅，是以动而有悔也。」

- 乾龙勿用，下也。见龙在田，时舍也。终日乾乾，行事也。或跃在渊，自试也。飞龙在天，上治也。亢龙有悔，穷之灾也。乾元用九，天下治也。
- 乾龙勿用，阳气潜藏。见龙在田，天下文明。终日乾乾，与时偕行。或跃在渊，乾道乃革。飞龙在天，乃位乎天德。亢龙有悔，与时偕极。乾元用九，乃见天则。
- 乾元者，始而亨者也。利贞者，性情也。乾始能以美利利天下，不言所利。大矣哉！大哉乾乎？刚健中正，纯粹精也。六爻发挥，旁通情也。时乘六龙，以御天也。云行雨施，天下平也。
- 君子以成德为行，日可见之行也。潜之为言也，隐而未见，行而未成，是以君子弗用也。
- 君子学以聚之，问以辩之，宽以居之，仁以行之。易曰：「见龙在田，利见大人。」君德也。
- 九三，重刚而不中，上不在天，下不在田。故乾乾，因其时而惕，虽危无咎矣。
- 九四，重刚而不中，上不在天，下不在田，中不在人，故或之。或之者，疑之也，故无咎。
- 夫大人者，与天地合其德，与日月合其明，与四时合其序，与鬼神合其吉凶。先天下而天弗违，后天而奉天时。天且弗违，而况於人乎？况於鬼神乎？
- 亢之为言也，知进而不知退，知存而不知亡，知得而不知丧。其唯圣人乎？知进退存亡，而不失其正者，其为圣人乎？

##### 白话
- 【释四德】「元」是众善之首，「亨」是嘉美之会合，「利」是义理的和谐，「贞」是办事的骨干。君子以仁为体，足以领导众人；会合众美，足以合乎礼义；利济万物，足以谐和于义；坚守正道，足以办成事业。君子能行这四德，所以说「乾：元亨利贞」。
- 【逐爻问答】初九讲「潜龙勿用」，是比喻身怀龙德而隐居的人：不为世俗所移，不追求虚名，避世而无苦闷，不被世人认可也无苦闷；乐意之事就去做，可忧之事就避开，意志坚定而不可动摇。九二居中得正，言谈守信、行事谨慎，防止邪念而保持诚心，有益于世却不自夸，德行广博而能感化人，这就是「君德」。九三讲君子进德修业：忠信用以增进德行，修饰言辞、确立诚心以安顿功业；知所至而往赴，可与之共察几微；知所终而努力完成，可与之共守道义，所以居上不骄、处下不忧，终日乾乾、随时警惕，虽危而无咎。九四可上可下、可进可退，并非行邪离群，只是急于把握时机，所以无咎。九五言同声相应、同气相求，水向湿处流、火向燥处生，云随龙、风从虎；圣人兴起，则万物仰见，本于天者亲附于上，本于地者亲附于下，各从其类。上九「亢龙有悔」，是尊贵而失去实位、高踞而脱离民众、贤人在下却无人辅助，所以一行动便有悔。
- 【爻位与时用】「潜龙勿用」是说处于卑下之位；「见龙在田」是说暂居其时；「终日乾乾」是有所行事；「或跃在渊」是自我试炼；「飞龙在天」是居上位而治世；「亢龙有悔」是穷极之灾；「乾元用九」则天下大治。又从阳气消息而言：潜藏之时阳气深藏于下；见龙在田，天下文教光明；乾乾行事，与时并进；或跃在渊，乾道正在变革；飞龙在天，位当天德；亢龙有悔，与时一同穷极；乾元用九，乃见天道法则。所谓乾元，是万物之始而亨通者；利贞，说的是乾的性情。乾一开始即以美利利济天下，却不言所利之事，伟大啊！乾之所以伟大，在于刚健中正、纯粹精一；六爻发动变化，旁通万物之情；依时驾乘六龙以御天道；云行雨施，天下太平。
- 【成德与大人、圣人】君子以成就德行为本，须落实于日常可见的行为之中；「潜」是说隐而未现、行而未成，所以君子此时不轻举妄动。君子靠学习积累知识，靠发问辨析疑难，以宽厚自处，以仁爱行事。九三重刚而不居中，上不着天、下不临地，故乾乾惕厉而无咎；九四亦重刚不中，进退未定、疑虑未决，故能免咎。所谓大人，德行与天地相合，明察与日月相合，秩序与四时相合，吉凶与鬼神相合：先于天而动，天不违逆他；后于天而动，则奉行天时。天尚且不违逆他，何况于人、于鬼神呢？「亢」是只知进而不知退、只知存而不知亡、只知得而不知丧；懂得进退存亡而不失正道的，大概只有圣人吧！

## 坤文言
- 文言曰：坤至柔，而动也刚，至静而德方，后得主而有常，含万物而化光。坤其道顺乎？承天而时行。
- 积善之家，必有馀庆；积不善之家，必有馀殃。臣弑其君，子弑其父，非一朝一夕之故，其所由来者渐矣，由辩之不早辩也。
- 易曰：「履霜坚冰至。」盖言顺也。直其正也，方其义也。君子敬以直内，义以方外，敬义立，而德不孤。「直，方，大，不习无不利」；则不疑其所行也。
- 阴虽有美，含之；以从王事，弗敢成也。地道也，妻道也，臣道也。地道无成，而代有终也。
- 天地变化，草木蕃；天地闭，贤人隐。易曰：「括囊；无咎，无誉。」盖言谨也。
- 君子黄中通理，正位居体，美在其中，而畅於四支，发於事业，美之至也。
- 阴疑於阳，必战。为其嫌於无阳也，故称龙焉。犹未离其类也，故称血焉。夫玄黄者，天地之杂也，天玄而地黄。

##### 白话
- 【坤道之体】坤体至为柔顺，可一旦发动却显出刚健；至为安静，而德行端正有方；居后顺承、得到主导者，故能恒常；它包容万物而化育光大。坤的道，不就是「顺」吗？承受天道而依时运行。
- 【积善履霜与敬义】积善之家必有余庆，积不善之家必有余殃。臣弑君、子弑父，不是一朝一夕的缘故，而是逐渐积累而成，只因未能及早辨明罢了。《易》说「履霜，坚冰至」，是说顺着趋势预先察觉。直是内心之正，方是行事之义；君子用敬使内心正直，用义使言行方正，敬与义立起来了，德行就不会孤立无援。「直、方、大，不习无不利」，是说自己的所作所为不必疑虑。
- 【含章从王与括囊谨言】阴柔虽具美德，也要含藏不露；以此辅助君王行事，不敢自居其成。这是地道、妻道、臣道——地道不自己成就事功，而是代天行事、终而有成。天地之气变化，草木就繁茂；天地闭塞，贤人就隐退。《易》说「括囊，无咎无誉」，是说谨慎啊。
- 【黄中通理与阴阳之辨】君子胸怀中和之美、通达事理，端正居位、安顿自身，美蕴于内心，而畅达于四肢、施展于事业，这才是美到了极点。阴气发展到与阳势均力敌、互相猜疑时，必然交战；因为忌讳显得没有阳气，所以爻辞里称它为「龙」；又因它尚未脱离阴类，所以称流出的血为「血」。所谓玄黄，是天地之色相混杂——天色玄，地色黄。
