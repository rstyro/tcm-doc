# 十翼

- 《十翼》是《易传》的别称，指解释《周易》经文（卦爻辞）的十篇传文。翼者，辅翼之意——谓其如鸟之双翼，辅佐经义而使之显明。
- 《周易》由"经""传"两部分组成："经"即六十四卦的卦象、卦辞与爻辞；"传"即《十翼》，相传为孔子及其后学整理阐发（成于先秦，学界认为非一时一人之作）。

## 《十翼》的构成

- 《十翼》共七种十篇。通行说法将它们对应《周易》经文的次序，如下表：

| 篇名 | 分篇 | 性质与作用 |
| --- | --- | --- |
| 彖传 | 上、下 | 解释卦辞，每卦一条，阐发一卦之大义 |
| 象传 | 大象、小象（各随卦爻而分上下） | 大象释全卦之象，小象逐爻释爻辞 |
| 文言传 | （一篇） | 专释乾、坤两卦 |
| 系辞传 | 上、下 | 通论《易》理，谈象数、占筮与义理 |
| 说卦传 | （一篇） | 阐述八卦的取象与德性 |
| 序卦传 | （一篇） | 解说六十四卦排列顺序的理由 |
| 杂卦传 | （一篇） | 以对举方式概括各卦要义 |

- 需要注意：古书"传"常随经文而传抄，《十翼》在长期流传中或独立成篇、或附于经下，今日所见通行本多将《彖》《象》等散附于各卦之下，独立阅读时则按篇编排。

## 各篇细说

### 彖传

- 彖，本指断定一卦之义的断语。《彖传》逐卦解释卦辞，说明卦名、卦象与卦辞之间的关联，往往先言上下卦的组成与取象，再申明一卦的核心义理。
- 作用：读者借《彖传》可明白"为什么此卦作如此判断"，是理解六十四卦纲领的钥匙。

### 象传

- 《象传》分两部分："大象"就一卦六爻的整体取象立说，常以"×××，君子以……"的句式推阐修身治世之道（如乾卦"天行健，君子以自强不息"）；"小象"则逐爻解释爻辞的根据。
- 作用：大象把自然之象转为人事法则，是《易》由天道贯通人事的典型体现；小象帮助理解每一爻的吉凶由来。

### 文言传

- 《文言》专释乾、坤两卦，因乾坤为《易》之门、六十四卦之基，故特为文以详说之。
- 乾卦《文言》多引"子曰"阐发"元亨利贞"与各爻义蕴，文字精醇，是研读乾卦不可少的参考；坤卦《文言》则发挥坤德柔顺载物之义。

### 系辞传

- 《系辞传》是《十翼》中篇幅最长、义理最丰的一篇，通论《易》之为书：论卦爻的生成（"易有太极，是生两仪"）、阴阳刚柔的变化、圣人设卦观象之意，以及占筮的哲理依据。
- 其中许多命题（如"一阴一阳之谓道""穷则变，变则通，通则久""天行健"等）已成为中国哲学的核心表述；了解《周易》思想，《系辞》是最重要的入口。

### 说卦传

- 《说卦传》集中阐述八卦的性质、取象与方位：既述"天地定位"的先天之象，也述"帝出乎震"的后天方位，并罗列八卦广泛取象（如乾为天、为君、为父、为马等）。
- 作用：它是理解卦象象征系统的基础文献，读卦与用卦皆需参考此篇。

### 序卦传

- 《序卦传》解释六十四卦的排列次序：从"有天地然后万物生焉"起，说明乾坤居首、既济未济殿后的理由，把每两卦之间的承接关系串成一条条理由链。
- 作用：它体现古人"观其序而知变化之理"的思路，是理解卦序编排与事物发展逻辑的引导。

### 杂卦传

- 《杂卦传》不按卦序，而是把意义相反或相对的卦两两对举（如"乾刚坤柔""比乐师忧"），以极简之语点出各卦要旨。
- 作用：以对反相形的方式提纲挈领，便于记忆各卦性格，与《序卦》合观可收互证之效。

## 阅读顺序建议

- **初读《周易》者：** 可先读《系辞传》以了解全书宗旨，再回头通读经文；或先随卦读《彖》《象》，逐步建立对卦爻辞的理解。
- **细读六十四卦时：** 建议按"卦辞→《彖传》→《大象》→各爻爻辞→《小象》"的顺序，一则原文一则传解，两相对照。
- **专研乾、坤时：** 补读《文言传》，其文字与义理都值得反复涵泳。
- **理解卦象系统：** 先读《说卦传》；理解卦序逻辑，读《序卦传》；快速把握各卦要点，读《杂卦传》。
- 本站十翼各篇原文可自《[十翼导读](/divination/shiyi/what)》下的分篇进入逐篇研读。

## 十翼的思想价值

- 《十翼》把一部占筮之书提升为系统的哲学文本：它提出"一阴一阳之谓道"的变化观、"易与天地准"的宇宙图景，以及"自强不息""厚德载物"的人生理想，奠定了《易》在中国思想与文化中的根本地位。
- 对现代读者而言，《十翼》的价值主要在于提供了一套观察变化、安顿身心、明辨进退的思想资源；至于占验之用，则属于传统方术范畴，宜以文化知识视之。
