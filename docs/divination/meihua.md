# 梅花易数

- 梅花易数，相传为北宋邵雍（康节）所传、以「观梅占」而得名的一种易占方法，属传统「以象起卦、以数断事」的简易占卜术。
- 其特点是「万物皆数、数皆成卦」：凡所见字数、声音、方位、时间、器物等皆可转化为卦象，不必借助铜钱，随时随地可占。
- 与六爻的「纳甲装卦、干支生克」体系不同，梅花易数更多运用「先天卦数 + 体用生克 + 卦象比类」断事，入门轻巧而深究无穷。本页仅作知识性整理，与命部《[命理师](/fate/what)》所述「命」与「卜」的分野一致，本篇属**卜**。
- 本页按**起卦 → 成卦 → 断卦**三步讲：起卦重在「取数」，成卦重在「本卦·变卦·互卦」，断卦重在「体用生克 + 卦气旺衰 + 卦象取义 + 外应」。

## 一、起卦：万物皆可成卦

### 先天八卦数

- 梅花起卦用的是**先天八卦数**（通行口诀）：**乾一、兑二、离三、震四、巽五、坎六、艮七、坤八**。
- 这八个数与先天八卦图相配，起卦就是把取到的「数」按除以 8 的余数换成卦：余 1 为乾、余 2 为兑……**余 0 则取 8 为坤**。方位与符号详《[八卦基础](/divination/zhouyi/bagua)》。

### 时间起卦法

- 最常用的一法：以农历**年支数、月数、日数、时数**起卦。

| 步骤 | 算法 | 说明 |
| --- | --- | --- |
| 上卦 | （年支数 + 月数 + 日数）÷ 8，取余数 | 余 0 作 8 |
| 下卦 | （年支数 + 月数 + 日数 + 时数）÷ 8，取余数 | 余 0 作 8 |
| 动爻 | （年支数 + 月数 + 日数 + 时数）÷ 6，取余数 | 余 0 作 6 |

- 各数取法：**年支数**按地支序（子 1、丑 2、寅 3、卯 4、辰 5、巳 6、午 7、未 8、申 9、酉 10、戌 11、亥 12）；**月数**用农历月份（正月 1、二月 2……十二月 12）；**日数**用农历日（初一 1……三十 30）；**时数**用时辰地支序（子时 1……亥时 12）。
- **经典示例（《梅花易数》「观梅占」）**：辰年（辰 = 5）十二月（12）十七日（17）申时（申 = 9）。
    - 上卦：（5 + 12 + 17）÷ 8 = 34 ÷ 8 余 **2** → 兑 ☱
    - 下卦：（34 + 9）÷ 8 = 43 ÷ 8 余 **3** → 离 ☲
    - 动爻：43 ÷ 6 余 **1** → **初爻**动
    - 上兑下离，得本卦**泽火革**，初爻动，变**泽山咸**。

### 其他起卦法

- **数字起卦**：心中报两数（或取所见两组数），前数为上卦、后数为下卦，两数之和定动爻；数小于 8 者直接用，大于 8 者除 8 取余。
- **字占**：以字数或笔画数分上下卦。
    - **二字占**：前一字取上卦、后一字取下卦，二字笔画之和定动爻；
    - **三字及以上**：或以字数分（前半字为上卦、后半字为下卦），或以笔画数分，总笔画定动爻；
    - **一字占**：取该字笔画数（或拆其左右、上下各取笔画）分上下卦，各家取法不一；
    - 另有「以字义取象」的一路（如见「火」字取离、见「水」字取坎），属卦象取象的延伸。
- **物数 / 声音 / 方位**：见物之数、闻声之数、所处方位（按后天八卦方位取数）皆可起卦——所谓「万物皆数」，正是梅花易数区别于六爻的用意所在。
- 起卦须心诚、所问明确；取数讲求「当下相应」，不必外加推敲。

## 二、成卦：本卦、变卦、互卦

- 上下两卦相重，得**本卦**（又称正卦）——代表事情的当前状态。
- 动爻所在的爻阴阳一变，即得**变卦**——代表事情的发展趋势。
- 取本卦的**二、三、四爻**作下卦，**三、四、五爻**作上卦，相重得**互卦**——代表事情过程中的隐含因素或中间变化。
- 三者合看：本卦看「现在」，互卦看「过程」，变卦看「结果」。这是梅花与六爻在结构上的共同点（都要看动变），但**梅花不装干支六亲，只从卦象与五行生克取义**。

## 三、断卦：体用生克

- 断卦的通用次序大体如下，本节的各小节即按此展开：

| 次序 | 看什么 | 产出 |
| --- | --- | --- |
| ① | 定体用 | 哪一卦是「我」、哪一卦是「事」 |
| ② | 看体用生克 | 大方向：助、耗、克、制、和 |
| ③ | 看卦气旺衰 | 为生克加上轻重 |
| ④ | 看互卦与变卦 | 过程与结果 |
| ⑤ | 取卦象、所问之事 | 落到具体人事 |
| ⑥ | 参外应 | 佐证 |

### 体卦与用卦

- **动爻所在的那一卦为「用卦」，另一卦（不动者）为「体卦」**。
- 体卦代表**占者自身**（或所问之事的主体），用卦代表**对方、环境、所测之事**。体用一定，断卦就以二者的生克为纲。

### 体用五种关系（核心简则）

| 关系 | 含义 | 传统取象 |
| --- | --- | --- |
| **用生体** | 外来生助 | 吉——有助益，事易成 |
| **体生用** | 自家泄气 | 主费心耗力、事有迟滞（耗而非凶） |
| **用克体** | 外来克制 | 凶——受阻妨碍，宜谨慎 |
| **体克用** | 我能制彼 | 主可制物、事虽费力而可成 |
| **体用比和** | 同气相求 | 吉——顺遂相合 |

### 卦气旺衰：不能只看生克

- 只看体用生克会失之粗率，还要看**体用两卦当下的旺衰**。传统以「旺相休囚死」配四时与月令：

| 季节 / 月令 | 旺 | 相 | 休 | 囚 | 死 |
| --- | --- | --- | --- | --- | --- |
| 春（寅卯月） | 木（震巽） | 火 | 水 | 金 | 土 |
| 夏（巳午月） | 火（离） | 土 | 木 | 水 | 金 |
| 秋（申酉月） | 金（乾兑） | 水 | 土 | 火 | 木 |
| 冬（亥子月） | 水（坎） | 木 | 金 | 土 | 火 |
| 四季（辰戌丑未月） | 土（坤艮） | 金 | 火 | 木 | 水 |

- 读法：**当令者「旺」、当令者所生者「相」、生当令者「休」、克当令者「囚」、当令者所克「死」**。旺相为有力，休囚死为无力。
- 于是同是「用克体」，**用衰体旺则克力不足，用旺体衰则受制明显**——这一步是把「生克」与「时令」两层合起来，梅花的断法才算完整。
- 卦气之义与五行配属，另见《[八卦基础](/divination/zhouyi/bagua)》与命部《[五行](/fate/wuxing)》。

### 卦象取义

- 生克定「势」，卦象定「事」。须结合八卦本义取象：
    - 乾为刚健、坤为顺载、离为明丽（附丽）、坎为险陷、震为动、巽为入、艮为止、兑为悦；
    - 再落到所问之事：如问财见离，可取「明丽、虚华」；问病见坎，可取「险陷、沉滞」。
- 更细的取象（卦配身体、方位、器物、人伦）见《[说卦传](/divination/shiyi/shiyi_8)》与《[八卦基础](/divination/zhouyi/bagua)》。**梅花断卦，象与数、生克与取象要并看**。

### 外应

- 梅花易数讲究「外应」：起卦或断卦当下，周围出现的动静（声响、来人、物象变化、方位）可作附加取象佐证，属传统「天人相应」思想的体现，是进阶运用。
- 外应之说主观成分较重，各人取法差异极大，宜作参考而非定式。

## 四、一个完整的例子

下面把起卦到断卦走一遍。**演示的是「怎么看」，不是给谁算命**。

**起卦**：农历辰年（5）六月初六（6 与 6）午时（7）。

- 上卦：（5 + 6 + 6）÷ 8 = 17 ÷ 8 余 **1** → 乾 ☰
- 下卦：（17 + 7）÷ 8 = 24 ÷ 8 余 **0** → 作 8 → 坤 ☷
- 动爻：24 ÷ 6 余 **0** → 作 **6** → **上爻**动
- 上乾下坤，得本卦**天地否**；上爻动，上卦乾（三阳）最上爻由阳变阴，成兑 ☱，得变卦**泽地萃**。

**成卦**：

| 项 | 算法 | 结果 |
| --- | --- | --- |
| 本卦 | 上乾下坤 | 天地否 |
| 互卦 | 取二三四爻（艮）与三四五爻（巽） | 风山渐 |
| 变卦 | 上卦乾变兑 | 泽地萃 |

**体用**：动爻在上卦，故**上卦乾为用、下卦坤为体**。

**断卦推演**：

- **生克**：乾兑皆金，坤为土。**土生金**，即**体生用**——传统主「我付出、我泄气」，费心耗力而事有迟滞，非凶，但不利求进。
- **卦气**：六月属未月，四季土旺。体卦坤土当令而**旺**，用卦乾金为土所生而**相**。体旺于用，泄气虽实，但本体有力，不至于因耗而衰。
- **卦象**：否卦为「天地不交、闭塞不通」之象（阳在上、阴在下，二者不交）；变卦萃为「聚」——传统读法是**先闭后聚**：眼前阻隔，须待时而后成聚。
- **互卦参看**：互卦风山渐，渐为「循序渐进」之象，多主过程中宜缓不宜急、须次第而成，与「体生用」的耗力迟滞之说相合。
- **综合表述**（传统口吻）：「此事眼前闭塞、须自出力，且过程有耗；但本体当令有力，耗而不伤，若待时令转，有聚而成之望。」——按站内《[八字怎么批](/fate/piming)》「断语怎么讲」的分寸，这类话只能说到「偏向」，不宜说成定论。

再次说明：以上只是**把梅花易数的读卦步骤走一遍**，不是真实占断，也不构成任何建议。

## 五、与六爻的比较

| 比较项 | 六爻（纳甲筮法） | 梅花易数 |

| 断法特点 | 重干支生克与旺衰 | 重生克 + 卦象取义 + 外应 |

## 六、常见误区

- **先天数与后天方位混用**：起卦取数用**先天八卦数**（乾一……坤八），取方位取象才用**后天八卦**（离南坎北）。把后天方位序数当起卦数用，卦就起错了。
- **体用判反**：口诀是「**动者为用、静者为体**」。体卦永远是不动的那一卦、代表自己；把它当成对方，整条推理链就反了。
- **只看生克、不看卦气**：用克体未必凶到底——用衰体旺则克力有限；体旺而自泄（体生用）也未必坏。生克与旺衰必须合看。
- **只论卦名吉凶**：卦名（如「否」「剥」）只是符号，梅花断的是**这一体这一用**的关系与卦象取义。见「吉」字卦名就说吉、见「凶」字卦名就说凶，是最常见的外行读法；同一卦问不同事，取象也不同。
- **互卦、变卦乱用**：本卦看现在、互卦看过程、变卦看结果，各有分工；三者混成一锅，论断就失去了层次。
- **滥用外应**：外应本是佐证；若起卦之后到处找「应」，等于事后附会，反而失去取卦当下的本意。
- **与六爻混用**：梅花不装干支六亲，六爻不用体用。两套体系各有边界，混着用往往两边都不成立。

## 七、源流与文献

- 梅花易数**托名北宋邵雍**。邵雍字尧夫、谥康节，是理学「北宋五子」之一，著《皇极经世》，以象数之学推演宇宙运数；后世术家遂把「以数起卦」这一路挂在他的名下。
- 今本《梅花易数》一般认为是**明清间辑录而成，并非邵雍手著**——书中「观梅占」「牡丹占」「老人有忧色占」诸例，都是后出的示范，不必当作北宋实录来读。
- 明以后另有《邵子神数》等托名邵雍之作，与本书并非一路。研读时宜分清两件事：**邵雍本人的象数之学**，与**托名邵雍的占法**。
- 因此本页谈的是一套传统术数的通行说法，不是某位作者的定论。

## 学习建议

- 入门顺序：记熟先天八卦与配数 → 学会时间 / 数字起卦 → 掌握本卦、变卦、互卦 → 习体用生克 → 加卦气旺衰 → 再练象意解读与外应。
- 本页为入门导览；梅花易数古籍以《梅花易数》一书为代表，历代注家说法小有出入，宜以通行本为准。
