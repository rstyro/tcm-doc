# 八字命理

- 八字命理，又称四柱命理或子平命理，是中国传统命理学中的一个重要分支，属传统文化中的经验学说。
- 它依据一个人出生的年、月、日、时四个时间点起盘：每个时间点由一个天干与一个地支相配，合共“八个字”，故称“八字”；四组干支分别组成年柱、月柱、日柱、时柱，故又称“四柱”。
- 传统认为，通过分析这八个字所蕴含的天干地支五行信息及其相互关系，可推测一个人的性格特点，以及健康、婚姻、财运、事业等人生运势的走向；此处仅作知识性整理，不作预测结论。

如需亲自排盘，可先使用本站的[八字查询工具](/fate/query/baziQuery)排出四柱，再对照本页理解各柱、各字的意义。

若对天干地支、六十甲子等基础概念尚不熟悉，可先阅读[天干地支](/fate/ganzhi)、[五行](/fate/wuxing)两篇基础页，再进入本页研习。

## 时间表示与示例

同一时刻，可用三种历法记法表示（以下示例取同一出生时刻）：

- 阳历：2024年7月21日15时
- 阴历（农历）：2024年六月十六日申时
- 干支历：甲辰年 辛未月 丙戌日 丙申时

干支历不按正月初一换年，而是由“年、月、日、时”四组干支（即四柱）依序编排，是八字的直接来源。上例四柱分别为：年柱甲辰、月柱辛未、日柱丙戌、时柱丙申，逐字写下即得“甲辰 辛未 丙戌 丙申”八个字；其中日柱的日干丙火，传统上被视为命主本人。

## 八字的构成（四柱）

- **年柱：** 出生年的天干和地支。
- **月柱：** 出生月的天干和地支。
- **日柱：** 出生日的天干和地支，其中日干被视为命主本人。
- **时柱：** 出生时辰的天干和地支。

四柱把一个人出生时刻的“时间坐标”以干支定格，构成论命所称的“原局”。至于每一柱的天干地支从何而来，见下节排盘说明。

### 排盘：一步得到四柱

初学者不必逐字手算，只需弄清四柱各自的来历即可。

**年柱——按“立春”换年：** 传统说法以二十四节气的立春为一年的分界。出生在立春交节时刻之后，年柱即换入新的干支；立春一般在公历每年 2 月 3 日至 5 日之间，故传统上“过立春才换年”，而不是以正月初一为界。个别流派对换年另有取法，属一般分歧。

**月柱——按“节令”换月：** 干支纪月以十二个“节”（节令）为每月的起始，每过一个节令，月的地支便递进一位，故地支月又称“月建”。十二节令与地支月的对应如下：

| 节令（该月起于此节） | 地支月（月建） | 约合农历 |
| --- | --- | --- |
| 立春 | 寅月 | 正月 |
| 惊蛰 | 卯月 | 二月 |
| 清明 | 辰月 | 三月 |
| 立夏 | 巳月 | 四月 |
| 芒种 | 午月 | 五月 |
| 小暑 | 未月 | 六月 |
| 立秋 | 申月 | 七月 |
| 白露 | 酉月 | 八月 |
| 寒露 | 戌月 | 九月 |
| 立冬 | 亥月 | 十月 |
| 大雪 | 子月 | 十一月 |
| 小寒 | 丑月 | 十二月 |

以“节”为月界，故节令前后出生的月份归属，会与以农历初一为界的记法有所出入。各节令交节的公历日期大多在当月上旬，确切时刻以万年历或排盘工具为准。

**日柱——查历推算：** 日柱干支由历法逐日连续排出，无法以口诀硬算，须查万年历或借助工具。日柱的日干又称“日主”“日元”，传统上代表命主本人，是后续分析的核心参照。

**时柱——先定“时辰”，再起时干：** 先将出生钟点折算为十二时辰（每两小时一个时辰，见后文地支时辰对照表），再由日干按“五鼠遁（日上起时）”的规则推出时干。口诀为：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途（传统口诀，仅作了解）。其意为：日干为甲或己者，子时从甲子起；日干为乙或庚者，子时从丙子起；日干为丙或辛者，子时从戊子起；日干为丁或壬者，子时从庚子起；日干为戊或癸者，子时从壬子起。自子时定下后，其后各时逐位顺推即可。

需留意的是，子时（23 点前后）跨越前一日与后一日，“早子时、晚子时”如何归属前后两日，各派取法不一；时辰换算亦有主张按出生地真太阳时修正的说法。二者均属流派分歧，此处不作展开。

现代排盘几乎都借助工具完成。本站提供[八字查询工具](/fate/query/baziQuery)，输入出生年月日时即可得到四柱及后续进阶参数，可与本页各表互相对照。

## 五行与生克

- 五行指木、火、土、金、水五种基本属性。天干地支各有所属五行（见前两表），因此五行关系是理解干支生克的基础。
- **相生：** 木生火、火生土、土生金、金生水、水生木，按“木火土金水”的顺序循环相生，如环无端。
- **相克：** 木克土、土克水、水克火、火克金、金克木，按“木土水火金”的顺序循环相克（与“金木土水火”是同一循环、起点不同而已）。

本站另有[五行](/fate/wuxing)页整理基本关系，可与本页对照阅读。

## 六十甲子与旬空

- 甲子 乙丑 丙寅 丁卯 戊辰 己巳 庚午 辛未 壬申 癸酉
- 甲戌 乙亥 丙子 丁丑 戊寅 己卯 庚辰 辛巳 壬午 癸未
- 甲申 乙酉 丙戌 丁亥 戊子 己丑 庚寅 辛卯 壬辰 癸巳
- 甲午 乙未 丙申 丁酉 戊戌 己亥 庚子 辛丑 壬寅 癸卯
- 甲辰 乙巳 丙午 丁未 戊申 己酉 庚戌 辛亥 壬子 癸丑
- 甲寅 乙卯 丙辰 丁巳 戊午 己未 庚申 辛酉 壬戌 癸亥

- 每个组合由一个天干（甲、乙、丙、丁、戊、己、庚、辛、壬、癸）与一个地支（子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥）组成，天干和地支的组合顺序固定不变，六十个组合循环一次后重复，因此称为“六十甲子”。
- 六十甲子由十个天干与十二地支按固定顺序相配而成，因 10 与 12 的最小公倍数为 60，故六十组一循环。
- 在古代，六十甲子不仅用于纪年，也用于纪月、纪日和纪时，是古代历法与干支历的重要组成部分。

以十天干领起，每十组为一旬：自甲子至癸酉为“甲子旬”，甲戌至癸未为“甲戌旬”，依此类推共六旬。每旬十组用尽十个天干后，仍余下两个地支无处相配，命理中称该两支为该旬的“旬空”（亦称空亡）。例如甲子旬自甲子至癸酉，所余戌、亥两支即属空亡。旬空的吉凶含义须结合命局整体讨论，此处仅作概念提示（传统说法）。

## 进阶体系（简览与站内链接）

排好四柱、认得干支五行之后，八字论命还有一串常用进阶概念。本站相关主题均已单独成页，此处各作一句话简介：

- **十神：** 以日主为“我”，把命局各干支按五行生克与阴阳异同归类为十种关系称谓，是传统论命的通用分析语言。详见[十神](/fate/shishen)。
- **十二长生：** 把天干之气落在十二地支上的旺衰状态分为十二个阶段，用以衡量某字之气的强弱进退。详见[十二长生](/fate/changsheng)。
- **大运与流年：** 原局是静态结构，大运（十年一步）与流年干支则描述后天时运的逐年推移。详见[大运与流年](/fate/dayun)。
- **格局：** 以月令（月支）为提纲、结合与日主的关系，把命局归纳为若干类型（如八格与外格），是命局定性的一种框架。详见[格局](/fate/geju)。
- **用神：** 从旺衰、寒暖、生克中为命局选定一个平衡枢纽，是“排盘之后论喜忌吉凶”的关键一步。详见[用神](/fate/yongshen)。
- **太岁：** 干支纪年中执掌当年干支的“值岁”，民俗中“犯太岁”等说法即由此衍生。详见[太岁](/fate/taisui)。
