# 十二长生

- 十二长生，又称“十二运”“长生十二宫”“寄生十二宫”，是八字（子平）命理中描述天干所代表的五行之气在十二地支上所处旺衰状态的一组概念（传统说法）。
- 它借人从受孕、出生、成长、鼎盛到衰老、收藏、再生的过程作比喻，把五行之气的消长划分为十二个阶段：长生、沐浴、冠带、临官（又名建禄）、帝旺、衰、病、死、墓（又名库）、绝、胎、养。
- 在排盘中查看某一干支或十神之气落在哪个阶段，是判断旺衰轻重的参考依据之一。本页仅作知识性整理。

## 十二状态含义

- **长生**：如婴儿初生，主生机萌发、事情起头，传统认为多主开端有力。
- **沐浴**：如婴儿初生后洗浴，主初成而未固；传统亦称之为“败地”，喻人尚青涩、易受诱惑（亦常与桃花之事相联想，属一般说法）。
- **冠带**：如少年行加冠之礼，主渐已自立、名誉渐立。
- **临官（建禄）**：如壮年入仕食禄，主就位立业、有名有位；此位即天干之禄，故又名建禄。
- **帝旺**：如壮年极盛，主力量、气势达于顶点；传统认为旺极则反，盛时须知防衰。
- **衰**：盛极而转衰，主力量渐减、诸事渐走下坡。
- **病**：如人之病，主气力不支、事多牵绊，进退维艰。
- **死**：如人之死，主该气生机近乎枯竭，事难强求；传统认为亦非全无回旋，须看全局组合。
- **墓（库）**：如人死后入墓，主气收藏入库、暂时蓄积；传统有“墓库逢冲则开、冲开可用”一类说法，吉凶须随命局喜忌而论。
- **绝**：如生机断绝，为该气的最低点；传统认为绝处又藏生机，正是下一轮循环的开始。
- **胎**：如受孕结胎，主新机开始酝酿于无形。
- **养**：如胎中养育待生，主元气渐复、蓄势待发。

## 十天干的十二长生（传统表）

- 本页采用较通行的“阳干顺行、阴干逆行”排法：自该干的长生位起，阳干沿十二支顺序一位一位排布，阴干则沿十二支逆序排布。
- 十天干的长生位（通行口诀，传统说法）：
    - 阳干：甲长生于亥，丙、戊长生于寅，庚长生于巳，壬长生于申。
    - 阴干：乙长生于午，丁、己长生于酉，辛长生于子，癸长生于卯。
- 排布示例：甲（阳木）长生于亥，其后顺排为沐浴子、冠带丑、临官寅、帝旺卯、衰辰、病巳、死午、墓未、绝申、胎酉、养戌；乙（阴木）长生于午，其后逆排为沐浴巳、冠带辰、临官卯、帝旺寅、衰丑、病子、死亥、墓戌、绝酉、胎申、养未。其余各干依“阳顺阴逆”类推。

## 五行旺衰的另一种表达

- 十二长生与五行的“旺相休囚死”是两套角度不同的旺衰概念：后者按季节月令看某一五行是否当令得时（可参看本站五行页），前者则按天干落到十二地支的哪一位，逐一判断该干之气进退消长的程度。
- 传统说法认为二者角度互补，常配合使用；论格局、取用神时以哪套为主，亦随流派而异。

## 提示

- 十二长生的排布在不同流派中存在分歧：本页所录为较通行的“阳干顺行、阴干逆行”一系；另有流派主张阴干与阳干同进退（按五行整体论旺衰，同属一五行的两干长生、墓库相同），或采用“阴生阳死”等其它口诀，其位置与本页表格会有出入。
- 旺衰判断还应结合月令、得地通根、透干与否等综合考量，十二长生只是其中一项参考（传统说法）。
