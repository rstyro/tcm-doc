# 八字怎么批

- **八字批命**（又称论命、推命），是把一张排好的四柱盘按一定次序拆解分析，最后落到「某方面运势如何、什么时段顺、什么时段阻」的传统方法。整个过程可概括为：**先「排」后「看」，定「主」分「喜」**。
- 传统子平命理把这一过程归纳为七个步骤：**排盘 → 立极 → 察旺衰 → 定格 → 取用 → 看组合 → 推岁运**。本页讲的是这七步**怎么走、怎么衔接**：每一步要得出什么结论才能进入下一步，哪里最容易走偏，各派在哪里分歧。
- 每一步内部的判据细节（旺衰怎么定、用神怎么取、格局怎么分）各有专页，本页不重复。**本页与专页的分工**如下：

| 环节 | 判据细节看 | 本页讲的是 |
| --- | --- | --- |
| 一、排盘 | 《[八字基础](/fate/bazi)》 | 必须一并记下哪些附属信息 |
| 二、立极 | 《[十神](/fate/shishen)》 | 为什么要先立起参照系 |
| 三、察旺衰 | 《[日主旺衰](/fate/wangshuai)》《[五行](/fate/wuxing)》《[十二长生](/fate/changsheng)》 | 三得的权重次序与常见误判 |
| 四、定格 | 《[格局](/fate/geju)》 | 三种取格法与成破之辨 |
| 五、取用 | 《[用神](/fate/yongshen)》 | 诸法不同向时怎么取舍 |
| 六、看组合 | 《[地支关系](/fate/dizhi-relation)》 | 宫位、十神、五行怎么互相印证 |
| 七、推岁运 | 《[大运与流年](/fate/dayun)》 | 「应期」是怎么被引动的 |

- 以下均为传统文化中的经验学说与传统说法，各派细节分歧颇多，本页取较通行的框架作知识整理，**不作人生预测**。七步在一张具体命盘上走通的示范，见《[命盘实例](/fate/shili)》。

## 批命的两条总原则

- 在进入七个步骤之前，先要记住两条贯穿始终的原则。传统论命的「功夫」，多半就在这两条的分寸上：

- **其一：先看结构，后论吉凶。** 命局的旺衰、格局是「体」，喜忌吉凶、具体事象是「用」。传统所忌的是**跳过结构直接断事**——见到一个冲就说凶、见到一个吉神就说好，都属「只见一斑」。次序必须是从结构推出喜忌，再从喜忌落到事象。
- **其二：命局为主，岁运为辅。** 原局是「种子」，大运流年是「季节」。同一颗种子在不同季节里表现不同，但季节改变不了它是什么种子。所以**论运必先论命**：脱离原局喜忌去看大运流年，是传统论命的另一大忌。
- 换一个说法：**看盘看全局，断事看一路**。判定命局时要八方兼顾，落到某一件事时则要顺着一条线索走到底（见第六节「四路印证」）。

## 一、排盘：把生日时辰换成四柱

批命的第一步，是把出生时间换成干支，得到四柱八字。四个字的来历各有讲究：

- **年柱**：以「立春」为一年的换年界线（不是正月初一）。
- **月柱**：以「节令」换月——立春入寅月、惊蛰入卯月、清明入辰月……小寒入丑月。
- **日柱**：由历法逐日连续排出，须查万年历或借助工具。
- **时柱**：先定「时辰」，再由日干按「五鼠遁」口诀起出时干。

**排盘是七步中唯一有「对错」的一步。** 后六步都是判断，判断可以各执一词；排盘却是事实——排错一个字，后面全盘皆错。因此批命之前先要核两件事：**时辰准不准**、**出生地在哪**（是否需换算真太阳时）。旧时说「时辰不明，不批八字」，讲的就是这个前提。

排定四柱后，还要**同时记下四样附属信息**，它们各自服务于后面不同的步骤：

| 附属信息 | 是什么 | 后面谁会用到 |
| --- | --- | --- |
| **藏干** | 每个地支内部所藏的天干（如子藏癸、丑藏己辛癸、寅藏甲丙戊） | 第三步找「根」、第四步取格、第六步看十神 |
| **旬空** | 日柱所属之旬中空亡的两个地支 | 第六步判某支之力虚实 |
| **纳音** | 六十甲子另一套五行对应（如甲子乙丑「海中金」） | 民俗论断与合婚（见《[纳音](/fate/nayin)》） |
| **神煞** | 依干支组合附会出的吉凶名目（如天乙贵人、桃花） | 第六步辅助参考（见《[神煞](/fate/shensha)》） |

- 前两项是**结构必需**，后两项是**论断参考**——这是初学者最容易混淆的分量差别。另外，旬空只提示「该支之力偏虚」，**不等于「有这个字就当没有」**。

> 示例（与[八字基础](/fate/bazi)页一致）：某人生于 2024 年 7 月 21 日 15 时，四柱为 **甲辰　辛未　丙戌　丙申**；后文各步均以此盘说明。

- 排盘的操作细节见《[八字基础](/fate/bazi)》；若要快速得到四柱，可直接使用本站[八字查询工具](/fate/query/baziQuery)。

## 二、立极：先找「日主」

- 「立极」就是**建立参照系**。八字中，**日柱的天干（日干）代表命主本人**，传统称「日主」「日元」「我」。
- 日主一立，其余七个字的关系才有意义：生它的为印、它生的为食伤、它克的为财、克它的为官杀、同类的为比劫。**同一张盘，换一个日主，十个十神全变**——这正是必须先在八个字里「立」出那一个「极」的原因。
- 立极的同时，还要把**月令**（月柱地支）标出来。传统称月令为「提纲」：它既是第四步定格的依据，又是第三步权重最高的一项。所以在读盘的次序上，**日主是中心，月令是提纲，两个「极」并立**。
- 上例日干为 **丙火**，则整个命局围绕「丙火日主」展开；月令为未。十神的推算原则见《[十神](/fate/shishen)》。

## 三、察旺衰：判断日主强不强

- 定了「我」之后，先看「我」自身的力量强弱。传统从三个角度入手，合称「三得」：

| 判据 | 看的是 | 权重 |
| --- | --- | --- |
| **得令** | 日主五行在月令是否当令（旺相休囚死） | 最高——月令为提纲 |
| **得地** | 地支藏干中有无日主的同类之气（即有无「根」） | 次之——力量的根基 |
| **得势** | 天干中有无生助日主的印星、比劫 | 再次——外援 |

- 三得合看，结论落到 **身强 / 身弱 / 中和** 三档之一。详细的判据（旺相休囚死表、本气中气余气之别、通根透干、十二长生）见《[日主旺衰](/fate/wangshuai)》《[五行](/fate/wuxing)》《[十二长生](/fate/changsheng)》，本页不重复。
- **这一步要产出什么**：一句能写下来的话——「日主偏强」「日主偏弱」「中和偏旺」之类，且要与理由一起记。因为下一节取用神的方向全由这句话决定：偏强宜泄、克、耗，偏弱宜生扶。
- **最容易走偏的三处**：
    - **只看得令，不看地、势**——月令虽重，但失令而有强根者未必弱，得令而无根者未必强。
    - **只数帮身的字数，不看那个字有没有力**——天干上的帮手若地支无根，传统称为「虚浮」，帮助有限；地支的根若被冲、被合去，也要减等。
    - **把旺衰当结论**——旺衰只是「体质描述」。**身强不等于命好，身弱不等于命差**；它是为取用神服务的中继站，不是终点。

## 四、定格：以月令立格局

- 格局以 **月支（月令）**为主要依据，这是各家比较一致的一点。格局回答的是「这张盘属于哪一类结构」。
- 但**取格的具体走法有三条，常常得出不同答案**，这是第四步最主要的分歧来源：

| 取法 | 怎么取 | 分歧点 |
| --- | --- | --- |
| **月令透干取格** | 看月令所藏之气哪个透出天干，取那个十神立格 | 月令藏干多、皆透出时，取哪一个有争议 |
| **月令本气取格** | 不论透与不透，径取月令**本气**的十神立格 | 本气不显时，取出的格容易名不副实 |
| **司权取格（人元用事）** | 按当月「司令」的那个人元（人元分野）取格 | 分野日数各家不一，跨日者取法不一 |

- 同一个月令，三种走法可能得出三个不同的格，也可能三者归一。**三法不同并非哪家算错，而是着眼点本就不同**（三法各自的着眼与争议，详见《[格局](/fate/geju)》）——一张盘三种取法各异的实例，见《[实例一](/fate/shili/example1)》。
- 取格之后还有一层：**成格与破格**。格是否被刑冲克害所伤、有无救应，决定它「成」还是「破」——格成而破，比格不成更需留意。详见《[格局](/fate/geju)》。
- **这一步要产出什么**：一句话——「某格，成 / 破，纯粹度如何」。**不要只写格名，要连成破一起看。**
- **常见错法**：拿日主的十神当格（格从月令出，不从日主出）；见八字有点特别就套「外格」——专旺、从格一类外格的成立条件很严，各派标准分歧极大。

## 五、取用：定用神、分喜忌

- 在旺衰与格局的基础上，为命局选定一个「枢纽」——**用神**。传统常见取法有四：

| 取法 | 着眼点 | 何时优先 |
| --- | --- | --- |
| **扶抑** | 日主的强弱平衡 | 通则，多数情况先用它 |
| **调候** | 命局的寒暖燥湿 | 生于严冬盛夏、气候明显偏于一端时 |
| **通关** | 两股力量相战不通 | 命局出现两行对峙时 |
| **病药** | 全盘最明显的「病」处 | 失衡点极明确时 |

- **诸法结论不一致是常态，而非例外。** 取舍的通例是：**以扶抑为主纲**（它直接服务于日主能否「任」得起全局），**调候为重要参考**（冬夏之命尤其要顾），通关、病药再看具体情形。
    - 举例：若某盘扶抑取土金、调候却取火水，而全局火势已成——此时火虽能暖局，却也直接攻身，按「扶抑为纲」仍取土金为用。
    - 反过来，若生于严冬、全局水旺而日主又有相当之根，则调候的分量会压过扶抑。
- 用神一定，整盘的字便按与它的关系分层：**生扶用神者为喜，克害用神者为忌**；另有「闲神」（关系不大）「仇神」（助忌神以害用神）等更细的分法，各派不一，宜作参考而非铁律。
- **这一步要产出什么**：一张喜忌表——用、喜、忌各落在哪些五行与十神上。喜忌一分，后面看大运流年的顺逆才有标尺。
- **常见错法**：**把用神当万能药**（以为找到一个吉神就能解全局）；**取用与格局割裂**（格与用相背时，须说明两者是如何调和的）；**滥用调候**（自有其前提，不是任何命都要先讲寒暖）。

## 六、看组合：刑冲合害与宫位、十神

结构定好之后，还要把命局「看活」。这一节是三套系统叠在一起看。

### 刑冲合害：命局里的变数

- **地支六合、三合、三会、六冲、相刑、六害、六破**等关系，会改变原有的生克关系，传统称命局里的「变数」。完整对照表与判断要点见《[地支关系：合冲刑害](/fate/dizhi-relation)》。
- 几条口诀式的常用规则：**贪合忘冲 / 贪合忘克**（有合的关系时，冲与克的力量可能被牵制）；**合而不化**（合了却化不成那一行，关系暧昧）；**冲开**（原被合住者，遇冲则解开）。
- 注意**关系是多对多的**：一对地支可能同时既六合又相破，既相冲又相刑，读盘时不能只认一种。

### 宫位对应人生领域（传统说法）

| 四柱 | 宫位 | 所主 |
| --- | --- | --- |
| 年柱 | 祖上 / 早年 | 祖上、长辈与童年境遇 |
| 月柱 | 父母 / 事业根基 | 父母、兄弟，亦主事业根基与中年 |
| 日柱 | 自身 / 夫妻宫 | 日干为命主本人；日支为「婚姻宫」，主配偶 |
| 时柱 | 子女 / 晚年 | 子女与晚年归宿 |

- 宫位是**「事的位置」**：同一件事落在哪一柱，就带哪一柱的色彩——早年得助与晚年得助，是两回事。

### 十神管人事

- 以日主定十神后，十神各有所主：正官主事业约束与贵气、正财主正妻与财帛、正印主母亲与学业、食神伤官主才华与子女、比劫主同辈与竞争等，详见《[十神](/fate/shishen)》。
- 十神是**「事的性质」**：官主约束、财主资源、印主庇护、食伤主表达、比劫主争夺。取象时先认性质，再落到具体人事。

### 四路印证：一件问事怎么落到盘上

- 宫位、十神、五行、岁运这四路要**互相印证，而非单取一点**。以「问某一方面的事」为例：

| 一路 | 问什么 | 以「婚姻」为例（传统说法） |
| --- | --- | --- |
| **宫位** | 这件事落在哪一柱 | 日支「夫妻宫」本身的安稳度：有无冲、刑、被合去 |
| **星** | 这件事由哪个十神主 | 配偶星——男看财星、女看官星（此为传统分工） |
| **五行** | 喜忌上顺不顺 | 配偶星与夫妻宫是喜用，还是忌神 |
| **岁运** | 什么时候被引动 | 行运是否合动、冲动夫妻宫或配偶星 |

- 四路若同向，传统上视为「这一点在命局里是明确的」；若互相打架，说明这一问在原局中本就没有唯一答案，断语宜留余地。
- **这一步要产出什么**：一份**变数清单**——原局里有哪些冲、合、刑、害，各自落在哪一柱、影响哪一件事。

## 七、推岁运：用大运流年把命局「动」起来

- 原局是静态的「种子」，**大运**（从月柱起排，阳男阴女顺行、阴男阳女逆行，十年一步）与**流年**（逐年干支）是动态的「季节」。排法与起运岁数的算法见《[大运与流年](/fate/dayun)》。
- 岁运干支进入命局后，与原局（并与运、年彼此之间）发生生克冲合，从而**「引动」**原局中的某一方。引动喜用、忌神受制，传统视为顺遂之时；反之则多阻碍。
- **应期是怎么被「引动」的**——这是第七步的实操核心，常见的引动方式有五种：

| 方式 | 机制 | 传统读法 |
| --- | --- | --- |
| **值（伏吟）** | 岁运干支与原局某字相同 | 那个字所主之事被「激活」，多主变动明显 |
| **冲（反吟）** | 岁运与某柱天克地冲 | 冲则动，原有结构被搅动 |
| **合** | 岁运与原局某字成合 | 合则牵动，也可能会把原局之力「合去」 |
| **填实** | 原局有拱、半合而缺一字，岁运补上 | 缺的那一字到齐，格局与六亲关系随之成形 |
| **并临** | 流年与大运干支相同 | 传统有夸张说法，实须结合喜忌看 |

- 用法上，**大运看「十年的主题」，流年看「当年引动哪一点」**：大运是背景与方向，流年是那一年扣动的扳机。
- **最要紧的一条**：岁运的作用必须放回原局喜忌中判断，**不能脱离命局只看流年**——这也是《[用神](/fate/yongshen)》所说「见到某五行就定吉凶」式的简单对应之所以不可取。
- **常见错法**：把大运当「好年份 / 坏年份」的开关；只看流年不看原局；把「岁运并临」「天克地冲」这类术语直接当凶兆。

## 一张盘要回答的六个问题

- 七步走完，接下来是「用起来」。传统论命落到具体事项，通常不外以下几个方面；每个方面各有所属的要素：

| 问什么 | 主要看 | 辅助看 |
| --- | --- | --- |
| **性情** | 日主五行与强弱、月令 | 十神配置、格局 |
| **六亲** | 各柱宫位 + 对应十神（父母、配偶、子女） | 该星与宫的冲合、喜忌 |
| **事业与财官** | 官杀（约束与位置）、财星（资源） | 月柱（事业根基）、格局层次 |
| **婚姻** | 日支夫妻宫 + 配偶星 | 冲合、喜忌、行运 |
| **健康** | 五行偏枯、冲刑落在哪一柱 | 传统「五行—脏腑」对应（见《[五行](/fate/wuxing)》） |
| **时运** | 原局喜忌 | 大运流年如何引动（见第七节） |

- 表中每一项都要求**至少两路印证**。只凭一个星或一个宫就断一件事，是传统论命所忌。

## 批命十忌

把前面各节提到的坑归拢成一份自查清单：

1. **跳过结构直接断事**——不先定旺衰与格局，看到冲就说凶。
2. **只看得令，不看地、势**——三得只看了一项。
3. **把旺衰当结论**——忘了它只是取用神的前提。
4. **以日主的十神当格**——格从月令出，不从日主出。
5. **见「外格」就套**——从格、专旺的成立条件极严。
6. **取用一法定死**——忘了扶抑、调候、通关之间可能打架，取舍须说明。
7. **把用神当万能药**——指望一个吉神包打全盘。
8. **只认一种地支关系**——忘了关系是多对多的。
9. **脱离原局只看流年**——把岁运从命局里摘出来论吉凶。
10. **术语当断语**——「岁运并临」「天克地冲」只是描述，不是判决。

## 断语怎么讲：语气与分寸

- 传统论命讲**「说趋势，不说定数」**。同一件事，按把握大小分档表述：

| 把握 | 说法 | 用在什么情形 |
| --- | --- | --- |
| 高 | 「传统认为此处偏向……」 | 四路印证一致，结构与喜忌都指向同一处 |
| 中 | 「此点可能偏……」 | 有一路相左，或落在旺衰的中间地带 |
| 低 | 「这一点留待行运再看」 | 宫、星、喜忌互相打架，原局本无定论 |

- 三条底线：**不制造焦虑**（凡以「大凶」「血光之灾」劝人破财消灾者，已背离传统命理的本意）；**不以命理替代专业意见**（健康就医、心理困扰求询、法律财务问专业人士）；**不替人做人生重大决策**。
- 传统论命的最后一步从来不是「判死」，而是「安顿」——了解命局的特点，是为了更清醒地安排自己的取舍。这一分寸，《[命理师](/fate/what)》一篇另有申说。

## 结语：综合论断

- 批命的收束，是把以上信息**叠在一起**得出结论，而不是拿单一要素下断语。借第六节的四路印证表，可以把一件问事写成一条推理链：

| 步骤 | 以「问婚姻」为例 |
| --- | --- |
| ① 立结构 | 旺衰偏强还是偏弱？什么格？喜忌落在哪几行？ |
| ② 看宫与星 | 日支夫妻宫安稳否？配偶星（男财女官）有无、旺否、是否被冲合？ |
| ③ 看喜忌 | 配偶星与夫妻宫在喜忌中站哪一边？ |
| ④ 看岁运 | 当前所行大运、流年是否引动了夫妻宫或配偶星？ |
| ⑤ 合成断语 | 按上表三档语气，给出趋势性的传统分析 |

- 同一张盘在不同体系下结论可能不同（取格、取用皆有分歧），这是命理作为经验学问的固有特征，不必视为错误；本站整理这些内容，**只为帮助读者读懂传统著作与术语，不对任何命局作吉凶承诺**。
- 想把七步真正走一遍，见《[命盘实例](/fate/shili)》——那里有两张完整命盘（同一辛金日元、一强一弱），从排盘一路推到岁运。

- 本站各页所载均为较通行的传统说法；排盘换年、子时归属、藏干次序、取格取用方式等细节流派不一，本页取其一，并非唯一答案。
- 内容供了解传统文化与命理术语之用，**不构成预测、医疗或现实决策建议**，不承诺任何预测功效。
