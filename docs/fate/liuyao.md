# 六爻

- 六爻，又名“六爻预测”“纳甲筮法”“火珠林法”，是传统占卜中流传较广的一支。它以《周易》卦象为基础，用三枚铜钱摇卦成卦后，依“纳甲”体系装卦断事。
- 与《周易》经传侧重“义理、象辞”的研读不同，六爻侧重“以卦为器、据干支生克断吉凶”的实用占断，两者同源而异流。本页仅作知识性整理。

## 起卦方法

- 传统以三枚铜钱（或用硬币代替）于心中默念所问之事，双手合摇后掷出，记录每次正反面：
    - 一个背面（少阳）记“—”（单）；
    - 两个背面（少阴）记“--”（拆）；
    - 三个背面（老阳）记“○”（重，动爻）；
    - 三个字面（老阴）记“×”（交，动爻）。
- 自下而上共摇六次，成一卦；老阳、老阴为“动爻”，动则本卦变出“变卦”。
- 现代亦常见以“报数、时间、字占”等方式起卦，但六爻传统仍以钱摇为正。

## 装卦（纳甲）要点

- **定世应**：依卦宫与卦序定“世爻”与“应爻”（世为自己、应为对方或所测之事），口诀如“天同二世天变五，地同四世地变初”等，属传统排法。
- **纳甲装卦**：将天干地支纳入各爻（乾纳甲壬、坤纳乙癸、震纳庚、巽纳辛、坎纳戊、离纳己、艮纳丙、兑纳丁），每爻配一支，是后续生克判断的基础。
- **安六亲**：以本宫五行属性为我，生我者为父母、我生者为子孙、克我者为官鬼、我克者为妻财、比和者为兄弟；六亲定用神所依。
- **配六神**：依起卦日干起青龙、朱雀、勾陈、腾蛇、白虎、玄武，顺序安置六爻，供取象参考。

## 断卦要领（概述）

- 先定“用神”（占财看妻财、占官看官鬼、占父母长辈看父母、占子女小辈看子孙、占同辈朋友看兄弟等），再查其旺衰、动静、空亡。
- 核心生克：日辰、月建对用神有生扶或克泄之权；动爻可生克静爻；爻与爻之间论生克冲合、刑害墓绝。
- 常用概念：旬空（旬内空亡）、月破、入墓、伏神飞神、进神退神、回头生克等，均为断应期与吉凶的参考依据。
- 断语应结合所问之事灵活取舍，切忌单凭一爻定论。

## 学习建议

- 入门顺序建议：先会起卦成卦 → 学会装卦（世应、纳甲、六亲、六神）→ 熟记干支五行生克 → 再练断卦取象。
- 本页为入门导览，涉及大量口诀细节（六十甲子纳音、卦宫次序等）宜配合专业教材逐步掌握，本页不作详表罗列。
