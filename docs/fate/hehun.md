# 合婚

- **合婚**，指传统婚配习俗中，把男女双方的生辰八字（或生肖）摆在一起逐项比对，看两者「相合」还是「相冲」，以判断这门婚事在术数意义上的宜忌。属「[命](/fate/what)」部的一支应用，源头与「[卜](/divination/start)」也有交叉——旧时多由命理师或择日师一并承办。
- 需要先说清楚：**合婚是传统民俗与术数经验，不是现代意义上的科学判断**。它的比对规则自有一套内部逻辑，但缺乏可验证的依据；同一对八字在不同流派、不同项目权重下，结论可以完全相反。
- 本页整理传统合婚的**通行判据**与常见说法，目的是帮读者读懂旧小说、旧戏文与老一辈口中的「属相不合」「纳音相克」到底在讲什么，**不构成任何婚恋决策建议**。
- 想直接比对两个人的八字，可用本站的[八字合婚查询](/fate/query/hehunQuery)：输入双方生辰后，会把下列各项逐条列出并给出传统倾向。

## 合婚的来路

- **早期形态是「问名」与「卜婚」。** 《周礼》所记「六礼」中，「问名」之后要「纳吉」，即把女方名字与生辰取回，在宗庙占卜吉凶。这是合婚最早的原型，属[卜](/divination/start)的范畴，还不是后来按干支推算的做法。
- **干支体系成熟后，才形成「以八字论婚」的细密规则。** 唐宋以后，子平术与纳音术并行，合婚从「占卜一次」变成「逐项比对」，项目越加越多，明清命书里已成一套繁复的门类。
- **生肖层面另有一套民间说法。** 与命理师的细算不同，市井流传的是简化的生肖歌诀（如「白马怕青牛」），好记好用，流传反而更广。二者层次不同，本页分节说明。

## 传统合婚比哪几项

传统合婚的项目各家出入很大，本站工具归纳的是其中较通行的六项。理解这六项，也就理解了旧时合婚的取舍逻辑：

### 一、年支关系（生肖）

- 年柱的地支即生肖，是最省事也最常用的一项。看两人年支之间是**六合、三合**，还是**相冲、相刑、相害、相破**。
- 民间把六合与三合称为「**上等婚**」，把相冲、相害视为不利。下表是十二生肖的对照速查：

| 生肖 | 地支 | 六合 | 三合 | 相冲 | 相害 |
| --- | --- | --- | --- | --- | --- |
| 鼠 | 子 | 牛 | 猴 · 龙 | 马 | 羊 |
| 牛 | 丑 | 鼠 | 蛇 · 鸡 | 羊 | 马 |
| 虎 | 寅 | 猪 | 马 · 狗 | 猴 | 蛇 |
| 兔 | 卯 | 狗 | 猪 · 羊 | 鸡 | 龙 |
| 龙 | 辰 | 鸡 | 鼠 · 猴 | 狗 | 兔 |
| 蛇 | 巳 | 猴 | 鸡 · 牛 | 猪 | 虎 |
| 马 | 午 | 羊 | 虎 · 狗 | 鼠 | 牛 |
| 羊 | 未 | 马 | 猪 · 兔 | 牛 | 鼠 |
| 猴 | 申 | 蛇 | 鼠 · 龙 | 虎 | 猪 |
| 鸡 | 酉 | 龙 | 蛇 · 牛 | 兔 | 狗 |
| 狗 | 戌 | 兔 | 虎 · 马 | 龙 | 鸡 |
| 猪 | 亥 | 虎 | 兔 · 羊 | 蛇 | 猴 |

- 各项关系的完整定义与判断要点，见专页《[地支关系：合冲刑害](/fate/dizhi-relation)》。

### 二、日柱关系

- 传统命理认为**日柱**最要紧：日干代表命主本人，日支是夫妻宫，所以看两人合与不合，**光看生肖不够，重点在日柱**。
- 常看的三种：
    - **日干五合**——甲己合、乙庚合、丙辛合、丁壬合、戊癸合。日干相合，传统视为情意相投、关系紧密的一项（详见《[天干地支](/fate/ganzhi)》）。
    - **日支关系**——两人的日支之间是合是冲，直接影响「夫妻宫」的状态。
    - **天克地冲**——一方日柱的天干克另一方的天干，同时地支又相冲（如甲子对庚午），传统视为摩擦较大的一种组合。
- 生肖只取年支一个字，日柱却取两个字，且被赋予了「本人」与「配偶」的象征，这就是为什么老话说「属相只是粗看，八字才见真章」。

### 三、夫妻宫（日支）比对

- 日支在传统宫位体系中称「**夫妻宫**」，主配偶（宫位对应见《[八字怎么批](/fate/piming)》第六节）。
- 合婚时先看两人各自的夫妻宫本身是否安稳（是否被冲、被刑），再看两宫之间是合是冲。两宫相合，传统视为相处顺遂的一项；相冲则视为聚少离多或易生口角的一项。
- 这一项与第二项共用日支，但着眼点不同：第二项看「两人之间的关系」，本项看「各自婚姻宫的状态」，传统上要合起来看，不能只取一端。

### 四、五行互补

- 把两人八字各自的五行分布分别统计出来，看是否**互济**：一方所缺或偏弱的五行，恰是另一方偏多的，传统视为可以补益。
- 反过来，若两人同一种五行都过旺、或都缺同一行，传统视为难以互济。
- 这一项的完整原理见《[五行](/fate/wuxing)》，五行偏枯的判读原理同于个人的命局分析。

### 五、纳音五行生克

- **纳音**是六十甲子另一套五行对应法（如甲子乙丑「海中金」），与天干地支本身的五行不是一回事（详见《[纳音](/fate/nayin)》）。
- 纳音合婚是较老的一路方法：把两人**年柱（或日柱）的纳音五行**取出来，看是相生、比和，还是相克。
- 因纳音一名一义、好记好断，旧时民间极流行，甚至只看纳音就下结论。但纳音一路与子平一路的理论基础不同，命理界内部亦有批评，宜视为一家之言。

### 六、用神喜忌参考

- 更深一层的做法，是把两人各自的[旺衰](/fate/wangshuai)与[用神](/fate/yongshen)取出来，看一方的喜用五行是否正是另一方命局所多的五行。
- 这是六项中**最依赖前提**的一项：用神本身要先定旺衰，而旺衰的判法与用神的取法各派分歧极大。因此本站工具只在这一项上作提示，不下硬判。
- 传统上把这一项看作「合婚的进阶版」——前五项多可一眼看出，本项要真懂命局才谈得上。

## 民俗层面的生肖说法

- 市井流传的生肖歌诀，讲的其实都是地支「**相害**」（兼有相刑）的组合，只是被编成了顺口溜。常见六句如下：

| 歌诀 | 对应关系 |
| --- | --- |
| 白马怕青牛 | 午丑相害 |
| 羊鼠相逢一旦休 | 未子相害 |
| 蛇虎如刀错 | 巳寅相害又相刑 |
| 龙兔泪交流 | 辰卯相害 |
| 金鸡怕玉犬 | 酉戌相害 |
| 猪猴不到头 | 亥申相害 |

- 不必把这六句当成独立的「第六害」——它们与上表「相害」一栏是同一回事，只是挑了害得比较整齐的六组编成韵语。
- 民间说法中，六合与三合叫「上等婚」，相冲、相害则被说成不合。这类说法**把十二生肖分成六组对立面，等于用年支一个字代表整个人**，简化到失真，学理上站不住。它流行是因为好记，不是因为准。
- 值得留意的是：同一对夫妻，生肖若相冲，纳音却可能相生，日柱又可能五合。**传统项目之间经常互相矛盾**，这本身就是传统合婚不具科学性的直接证据。

## 三处常见误解

- **「属相不合就一定不能成」**——生肖只取年支一个字，是六项里最粗的一项。旧时真正细算的命理师，从不会只看生肖下断语。
- **「合婚是古礼，所以是正统」**——合婚确实源出古礼的「纳吉」，但那是**占卜**，不是后来这套干支比对法。明清命书里那些细密规则，是后起的术数构造。
- **「有工具算出来就准」**——工具只是把传统规则替你算完，规则本身的分歧与局限并不因此消失。看到「不利」字样，宜当作「传统认为此处有冲突」，而不是「事情会不好」。

## 一份结果该怎么读

- **先看时辰是否可靠。** 传统批命以时辰准确为前提。若有一方未填具体时辰，时柱就是默认值，凡与时支、时干相关的判断都只能参考。本站工具会在这一项上给出提示。
- **再看项目之间是否一致。** 若六项大都指向和合，传统上视为较顺；若几项互相打架，说明这盘八字在传统框架内本就「没有唯一答案」，不必强行挑一项去相信。
- **最后看结论的语气。** 传统合婚说的是**倾向**，不是判决。任何把合婚结论当成现实依据、乃至据以施压的做法，都已超出这门学问的本分。

## 提示

- 本站合婚内容与[查询工具](/fate/query/hehunQuery)均属传统术数与民俗的知识整理，**不是现代科学结论，也不构成婚恋决策建议**。
- 婚姻是否合适，取决于双方的相处、价值观与共同经营，非任何术数所能判定。请勿据此评价他人，更勿据此作出人生重大决定。
- 命理与合婚的流派分歧极大，同一对八字在不同体系下结论可能完全相反；本站只作客观罗列与说明，不保证任何预测功效。
