# 紫微斗数

- 紫微斗数，简称“紫微斗数”“斗数”，是中国传统命理学的一个门类。它以人出生时的年、月、日、时推排命盘，再以盘上星曜分布与宫位组合来论断一生格局与运势起伏。
- 相传斗数之学托名于宋初道家陈抟（希夷），经后世辗转流传形成不同派系（如“三合派”“飞星派”“四化派”等），属传统说法；其体系成熟期与流行情况以明清以后为著。
- 与八字命理偏重“五行旺衰、十神生克”不同，紫微斗数更偏重“星曜性质 + 宫位环境 + 四化牵引”的组合解读。二者可互相参看，本页仅作知识性整理。

## 核心组成

- **十二宫**：命宫、兄弟、夫妻、子女、财帛、疾厄、迁移、仆役（交友）、官禄、田宅、福德、父母，加上身宫，构成观察人生的十二个侧面。
- **星曜**：一般分十四主星——紫微、天机、太阳、武曲、天同、廉贞、天府、太阴、贪狼、巨门、天相、天梁、七杀、破军；另有辅佐星（左辅右弼、文昌文曲、天魁天钺等）、煞星（擎羊、陀罗、火星、铃星、地空、地劫等）、杂曜与四化星等，合称格局星曜（一百零八颗为通行说法）。
- **三方四正**：命宫与财帛、官禄三宫合成“三方”，再加对宫（迁移）为“四正”；论断某宫吉凶常须合看其三方四正，而非只看单宫。
- **四化**：化禄、化权、化科、化忌。由出生年干（或以盘式所定）引出，化禄主财喜、化权主掌权、化科主名声、化忌主牵绊与缺失，是斗数论断吉凶的关键枢纽之一。
- **五行局**：依生年干支与命宫纳音所属（水二局、木三局、金四局、土五局、火六局）确定起运起点，据此安“大限”。

## 排盘流程（概述）

- 起盘需四要素：农历生年、生月、生日、生时（子时前须注意日夜分之别）。
- 先安命宫、身宫 → 布十二宫 → 定五行局 → 安紫微星与十四主星 → 安辅星、煞星 → 依生年干化四化 → 定大限起始 → 即可得一张完整的紫微命盘。
- 现代常用排盘软件即时生成，手排主要用以理解盘面构造原理。

## 阅读建议

- 看盘一般“先观命宫与身宫、次察三方四正、再参四化与煞忌”，并注意星曜庙旺利陷（亮度）的影响。
- 初学者建议：先识十四主星性质 → 再学宫位含义 → 后习四化与三方四正，循序渐进。
- 本页为入门导览；具体论断方法流派繁多、深浅差异大，宜以经典教材（如紫微斗数全书、诸家讲义）为师，本页不代论断吉凶。
