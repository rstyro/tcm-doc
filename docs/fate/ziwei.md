# 紫微斗数

- 紫微斗数，简称「斗数」，是中国传统禄命术（推命之术）的一个门类，与子平八字并称近现代命理学的两大体系。
- 它的做法是：以农历出生的年、月、日、时四个要素排出一张**命盘**，把一批星曜安置进十二个**宫位**，再按「星曜性质 + 宫位环境 + 四化牵引」的组合去解读。
- 与八字偏重「五行旺衰、十神生克」不同，斗数偏重「星曜的组合与位置」。两者切入路径不同，传统上常互相参看。
- 本组是站内「命」部的斗数专区，共 7 页：先讲这一类术数的来路与文献，再拆开宫位、星曜、四化三块零件，然后给排盘步骤，最后讲读盘的次序与常见格局。
- 需先说明：斗数是一套**传统术数模型**，取材于古代星占、阴阳五行与干支历法，不是现代天文学意义上的星象观测。它有自洽的推演规则和相当丰富的术语体系，值得作为传统文化与文献来了解，但**不具备现代科学意义上的预测效力**。本组不做吉凶判断，也不提供任何人生决策建议。

## 与八字的差别

- 输入相同，切法不同。
    - 八字把出生时刻换算成四组干支（年柱、月柱、日柱、时柱），看的是八个字之间的五行生克与十神关系，可参考《[八字基础](/fate/bazi)》。
    - 斗数把出生时刻换算成一张十二宫盘，看的是星曜落在哪个宫、与哪些星同宫、被哪几个天干化出禄权科忌。
- 术语体系几乎不重叠。八字的十神、格局、用神（见《[十神](/fate/shishen)》《[格局](/fate/geju)》《[用神](/fate/yongshen)》）在斗数里没有对应位置；斗数的十四主星、宫干飞星，在八字里也找不到。
- 唯一的共用底子是干支与纳音：斗数定「五行局」要用命宫干支的纳音（见《[纳音](/fate/nayin)》）；安禄存、天魁天钺、天马、华盖、咸池等星曜的口诀，与八字神煞的取法基本相同（见《[神煞](/fate/shensha)》）。
- 传统上两套常合看：一边看五行气机的旺衰，一边看星曜落宫的组合。这属于命理从业者的习惯做法，本组只作知识性整理，不主张任何一端的效力。

## 几个常见的误解

- **不是「看星座」**。「紫微」在古代指紫微垣（北极星附近的天区），斗数的星曜名取自中、南、北三斗的星官体系，但排盘**不查星历、不看真实天象**，纯粹由农历生辰按固定规则推算。同一时刻出生的人，盘完全相同。
- **不是「一百零八颗星都要背」**。通行说法的一百零八颗里，真正进入论断主线的通常只有十四主星、六吉、六煞、禄存天马与四化，其余杂曜多按规定动作安好之后仅供参考。
- **不是「古书一脉相传」**。「紫微斗数」这个名称在明代中期以后才见于文献，成术过程融合了五星术、十八飞星、干支历法等多种来源；托名陈抟（希夷）属传统说法，可考的早期刻本都出在明代。详见《[源流与文献](/fate/ziwei/origin)》。
- **不是「宫名就是字面意思」**。命宫、财帛宫、官禄宫这些名称是**观察角度**，不等于「旺不旺财」「当不当官」。宫名只回答「从哪个侧面看」，吉凶仍要由宫内星曜与四化决定。

## 提醒

- 本组内容属传统术数与民俗文化的知识整理。斗数典籍来源复杂、流派分歧不小，同一张盘在不同师承下的解读可能相差很远，本组遇分歧处一般并列各家说法，不做独断。
- 命理类内容有一个固有的难处：论断含糊到无法证伪时，听者容易自行对号入座。请把本组当作术语与文献的索引来用，不要据此判断自己或他人的命运、婚姻、健康与事业。
- 斗数有「疾厄宫」一说，涉及健康的部分尤其不可当真。身体不适请到正规医疗机构就诊。
