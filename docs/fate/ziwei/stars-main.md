# 十四主星

- 斗数命盘上的星曜数以百计，但真正担当「主角」的只有十四颗，称**十四主星**（又称十四正曜）。
- 十四主星分两个星系：
    - **紫微星系**（六颗）：紫微、天机、太阳、武曲、天同、廉贞。
    - **天府星系**（八颗）：天府、太阴、贪狼、巨门、天相、天梁、七杀、破军。
- 六加八正好十四。两个星系的**排布方向相反**：紫微星系逆行，天府星系顺行（安星方法见《[排盘方法](/fate/ziwei/paipan)》）。
- 传统上还有「分属北斗、南斗、中天」的说法：紫微星系多属北斗，天府星系多属南斗，太阳与太阴另属中天。这一划分各家出入不小，本页只作备注。

## 一、十四主星总表

- 「化气」是古籍对每颗星核心性质的一句概括（见《紫微斗数全书》各星问答），下表的「主要意象」是据此展开的常见理解。

| 主星 | 所属星系 | 传统五行 | 化气 | 主要意象 |
| --- | --- | --- | --- | --- |
| 紫微 | 紫微系 | 土 | 尊（一说权） | 尊贵、统御、领导、重视体面 |
| 天机 | 紫微系 | 木 | 善 | 智慧、谋略、机变、多思 |
| 太阳 | 紫微系 | 火 | 贵 | 光明、博爱、付出、名声 |
| 武曲 | 紫微系 | 金 | 财 | 财帛、刚毅、果决、执行 |
| 天同 | 紫微系 | 水 | 福 | 福泽、安逸、仁慈、情绪化 |
| 廉贞 | 紫微系 | 火 | 囚 | 是非、权术、纪律、桃花的另一面 |
| 天府 | 天府系 | 土 | 库（南斗令星） | 库藏、稳重、保守、包容 |
| 太阴 | 天府系 | 水 | 富 | 财富、柔顺、母性、内敛 |
| 贪狼 | 天府系 | 木（一说水） | 桃花 | 欲望、才艺、交际、酒色财气 |
| 巨门 | 天府系 | 水 | 暗 | 口舌、是非、疑虑、钻研 |
| 天相 | 天府系 | 水 | 印 | 辅佐、文书、印信、谨慎 |
| 天梁 | 天府系 | 土 | 荫 | 荫庇、长辈、清高、承担 |
| 七杀 | 天府系 | 金 | 将（一说权） | 肃杀、冲劲、开创、竞争 |
| 破军 | 天府系 | 水（一说土） | 耗 | 破耗、变革、求新、波涛 |

- **关于五行一列**：十四主星的五行归属，各家用字并不统一（同一颗星可能标作阳土或阴土，个别星甚至有两种说法）。上表取较通行的一种，仅供对照，不必当成定论。

## 二、十四主星的性情

- 以下描述取自命书对星曜性质的常规概括，属于**性格原型**，不是判词。传统上每颗星都有「正面表现」与「失度之后的表现」两面，本页两面都写。

### 紫微

- 帝星。传统上象征统御与中心位置，重视体面、有主导欲，处事倾向于从全局考虑。
- 失度时表现为刚愎、好面子、不喜被指挥。
- 紫微本身不主具体事务，须与同宫的主星配合才见其用，所以古书极重「紫微与谁同宫」。

### 天机

- 主智慧与机变，善分析、善谋划，反应快，对信息的敏感度高。
- 失度时表现为思虑过重、多疑、主意反复、想得多做得少。
- 传统上与「变动」有关，命宫坐天机者多不喜长期一成不变的处境，属经验性的联想。

### 太阳

- 主光明与施与，性格外放、热心、愿意承担，重视名声与公开的形象。
- 失度时表现为过刚、好出头、锋芒太露。
- 传统上太阳亦作「男性长辈」「丈夫」的星系象征之一，女命资料中尤其常提。这类对应属象征性归类。

### 武曲

- 主财，也主刚毅果决，执行力和独立性都强，做事偏向实务。
- 失度时表现为固执、不通融、只认结果。
- 传统上与「金属」「财务」相联，是斗数里最典型的财星。

### 天同

- 主福，性情温和、随和、懂得自得其乐，不喜冲突。
- 失度时表现为懒散、畏难、情绪起伏大。
- 是十四星中「福星」的代表，古书常以「福星不化忌」之类的说法来支持自己的四化主张（见《[四化](/fate/ziwei/sihua)》）。

### 廉贞

- 主是非与权术，也主才情与吸引力。管理、纪律、制度类的角色常见此星。
- 失度时表现为心机重、易招是非、感情上纠缠。
- 廉贞与贪狼同为斗数中最常被提到的「桃花」相关主星，但廉贞的桃花偏向「纠缠」而非「欢愉」。

### 天府

- 主库藏，稳重、保守、重积累，善于经营既有的局面。
- 失度时表现为贪图安逸、缺乏开创。
- 天府是南斗令星，古书有「府库」之喻，长于守而不长于攻。

### 太阴

- 主富，也主柔顺、内敛、细致，对环境的感受力强。
- 失度时表现为多愁善感、犹疑、依赖心重。
- 与太阳对称，常被用作女性长辈、妻子的星系象征之一。

### 贪狼

- 主欲望与才艺，交际能力强，兴趣广，擅于把握机会。
- 失度时表现为贪多、纵情、难以收束。
- 是斗数里最具「多才多艺」色彩的一颗星，也最常出现在各种桃花格局的名称里。

### 巨门

- 主口舌与是非，也主钻研。说话直、爱追问、不轻易接受现成结论。
- 失度时表现为多疑、辩争、因言招怨。
- 传统上巨门喜与「禄」同宫（古称「石中隐玉」），意即把口才用在能生利的地方。

### 天相

- 主印信文书，谨慎、周密、讲程序、善于辅佐，常被比作「宰相」。
- 失度时表现为过分拘谨、易被牵连。
- 天相不参与四化（多数流派如此主张），它的吉凶很依赖邻宫与对宫——故有「刑忌夹印」这类格局名目。

### 天梁

- 主荫庇，有长辈缘，性格偏清高，愿意承担与照顾他人。
- 失度时表现为爱操心、管得太多、把责任揽成负担。
- 传统上又称「寿星」，与「老人」「医药」「宗教」等意象相联。

### 七杀

- 主肃杀与征战，勇于开创、敢于承担风险、行事利落。
- 失度时表现为冲动、不计后果、不留余地。
- 七杀与贪狼、破军并称「杀破狼」，这一组在传统上专门对应「变动与转折」。

### 破军

- 主破与耗，长于变革、打破旧局、从头再来。
- 失度时表现为消耗、反复、难以守成。
- 「破军」之名容易被误读为「破坏」，其实它的核心是「旧的不去新的不来」这一类变动意象。

## 三、常见的主星组合

- 星曜的含意有相当一部分来自「与谁同宫」。十四主星在盘上形成若干**固定组合**，这是读盘时最先要看的东西：

| 紫微所在宫 | 同宫主星 | 组合的简称 |
| --- | --- | --- |
| 子、午 | 无（紫微独坐） | 紫微独坐 |
| 丑、未 | 破军 | 紫破 |
| 寅、申 | 天府 | 紫府 |
| 卯、酉 | 贪狼 | 紫贪 |
| 辰、戌 | 天相 | 紫相 |
| 巳、亥 | 七杀 | 紫杀 |

- 除了紫微，另有几组固定的同宫或对宫关系常被提到：
    - **日月同宫**：太阳与太阴在丑宫或未宫同宫。
    - **日月对照**：太阳与太阴分居对宫（如卯与酉）。
    - **机月同梁**：天机、太阴、天同、天梁四星分居三方四正之内。
    - **杀破狼**：七杀、破军、贪狼三星分居三方四正之内。
    - **武曲与天府**：同为财星，居子午丑未一带常见相邻或三方之会。
- 「机月同梁」与「杀破狼」这两组尤其常被引用：前者传统上对应守成、稳定的取向，后者对应变动、开创的取向。这属于成组的象义对照，不是判词。

## 四、庙旺利陷

- 同一颗主星落在不同的地支宫，传统认为表现强弱不同，分成若干等级，通称「**庙、旺、得地、利、平、陷**」，合称**亮度**或**庙旺利陷**。
- 大致的意思是：庙是「最得地」，陷是「最不得地」。星曜落入「庙旺」之宫，其正面的性质容易显现；落入「陷」宫，则较易显出失度的一面。
- 但有两点必须说清楚：
    - **各家的亮度表出入不小**。同一颗星在同一个宫，不同书里标为庙、旺或平的情况很常见，原因是这套等级本来就没有统一定义，各派按自己的经验填表。
    - **亮度只是参考项之一**。传统讲法里，四化的影响力往往被认为高于亮度；某星虽在陷宫，若得化禄、化权，或与吉星同宫，结论就可能反过来。古书里也有类似的提醒，大意是不可只凭亮度定吉凶。

## 五、空宫与借星

- 十四主星要放进十二宫，必然有宫位容纳两颗主星，也就会有**空宫**（没有主星的宫位）。但空宫的数目随紫微落宫而变——紫微在寅或申时（紫府同宫）一个空宫也没有，紫微在巳或亥时则有四个。详见《[十二宫与身宫](/fate/ziwei/palaces)》。
- 通行的处理是**借对宫主星**来看，并认为借来的力量要打折。也有流派主张借三方四正的主星，或另作别论。详见《[十二宫与身宫](/fate/ziwei/palaces)》。

## 六、提醒

- 本页对十四主星的所有描述，都是命书里**形容性格与倾向**的传统用语。它们有两个特点：一是两面性（正面与失度并存，几乎任何判断都能自圆其说），二是组合依赖（单星几乎说明不了什么，必须看同宫、三方四正与四化）。
- 因此，把「命宫是某某星」直接翻译成对一个人性格或命运的断定，是逻辑上不成立的用法。真正可核对的是**星曜的位置与排列规则**；至于这些位置「意味着什么」，属于历代经验的引申，各派差异很大。
- 本页仅供了解术语与古籍原文之用，不构成对任何人的性格、能力或人生走向的评价。
