# 格局与看盘

- 前面几页把零件拆开了：宫位、主星、辅煞、四化。本页讲怎么把它们组装起来看——也就是传统的「读盘次序」，以及「格局」这个概念到底是怎么用的。
- 先说一个贯穿全页的原则：斗数里**可以逐项核验的规则基本上到排盘为止**。从「这张盘意味着什么」开始，就进入了历代经验的引申，各派差异大、也难以证伪。本页把这一层如实标注。

## 一、传统的读盘次序

命书里讲看盘，一般遵循由主到次、由静到动的顺序：

1. **先看命宫与身宫**。命宫定基调，身宫看一生着力处。两者是否同宫，也是最先要记下的事。
2. **次看命宫的三方四正**。命、财帛、官禄三方，加迁移宫。这一步是为了避免「只看一格」——单宫的星曜几乎说明不了什么。
3. **再看主星的亮度（庙旺利陷）**。同一颗星在庙宫与在陷宫，传统认为表现强弱不同（见下）。
4. **然后看四化的落点**。生年四化的四颗星各落在哪一宫，这几个宫就是这张盘的「重点区」。四化的分量通常被认为高于亮度。
5. **参看煞忌的分布**。哪些宫被擎羊、陀罗、火星、铃星、地空、地劫占据，哪几宫的星被化忌牵住。
6. **最后才进入动态**：大限落在哪一宫、该宫的星曜与四化如何，再看流年。
7. 全过程都要合看三方四正——不是只看本宫。

- 传统上也有一句简括的说法：「**先观命身，次察三方，再参四化与煞忌**」。次序本身没有强制规定，但「先静后动、先主后次」是通例。

## 二、庙旺利陷与空宫

- **庙旺利陷**（亮度）把主星在各宫的得地程度分成若干级，通行的写法是「庙、旺、得地、利、平、陷」六级，也有只分四级的。
- 大致含意：庙为最得地，陷为最不得地。星在庙旺之宫，正面的性质容易显现；在陷宫则较易显出失度的一面。
- 三点必须说明：
    - **各家的亮度表出入不小**。同一颗星在同一宫，不同资料标为庙、旺或平的情况很常见。这套等级本来就没有统一定义。
    - **亮度不是决定项**。四化的影响传统上被认为高于亮度；得化禄、化权，或与吉星同宫，往往能改变结论。古书里也有类似的提醒，大意是不可只凭庙陷定吉凶。
    - **空宫另有处理**。没有主星的宫位借对宫主星来看，并认为借来的力量要打折。见《[十二宫与身宫](/fate/ziwei/palaces)》。

## 三、格局是什么

- **格局**是古人对「成组的星曜配置」起的名字。它不是额外的规则，而是给常见组合取的一个便于称呼的代号。
- 例如「紫府同宫」这个名称，本身只说明「紫微与天府落在同一个宫」，至于这个组合意味着什么，各书所论详略不同。
- 格局名目极多。各种资料里罗列的常见格局有数十条之多，且**同名不同义、同义不同名的情况很普遍**——同一组星曜在不同书里可能被归入不同格局，甚至给出相反的评价。这是读斗数资料时最需要留神的一点。

## 四、常见格局选列

- 下表只取**构成方式相对一致**的若干条。凡各家定义有出入者，均已注明。

| 格局 | 构成（按较通行的定义） | 传统的取意 |
| --- | --- | --- |
| 紫府同宫 | 紫微与天府同宫（寅宫或申宫） | 统御与库藏相合，主稳 |
| 紫府朝垣 | 紫微、天府分居三方四正 | 同上，取会照之意 |
| 君臣庆会 | 紫微与左辅、右弼同宫或三方会照 | 主得辅佐之力 |
| 府相朝垣 | 天府、天相分居三方四正 | 主保守、周全 |
| 日月同宫 | 太阳与太阴同宫（丑宫或未宫） | 阴阳兼具 |
| 月朗天门 | 太阴在亥宫（亥为「天门」） | 主清朗、内敛之富 |
| 日出扶桑 | 太阳在卯宫（卯为「扶桑」） | 主光明、外显 |
| 明珠出海 | 一说命宫在未，太阳在卯、太阴在亥 | 各家定义不一，仅供参考 |
| 石中隐玉 | 巨门在子宫或午宫，多与禄存或化禄相配 | 口才用于生利 |
| 火贪格 · 铃贪格 | 贪狼与火星（或铃星）同宫，又称「雄宿乾元」 | 主突发、骤起 |
| 禄马交驰 | 禄存与天马同宫，或分居对宫 | 取「财随动而增」之意 |
| 双禄交流 | 禄存与化禄相会 | 主财源叠加 |
| 三奇加会 | 化禄、化权、化科三星会于三方四正 | 主禄权科齐备 |
| 科权禄夹命 | 命宫两侧的邻宫分别被禄、权、科所夹 | 取「左右扶持」之意 |
| 羊陀夹忌 | 化忌之宫被擎羊、陀罗相夹 | 主牵制、受困 |
| 火铃夹命 | 命宫两侧分别为火星与铃星 | 主躁动、突发 |
| 杀破狼 | 七杀、破军、贪狼分居三方四正之内 | 主变动、开创 |
| 机月同梁 | 天机、太阴、天同、天梁分居三方四正之内 | 主守成、稳健 |
| 巨铃陀 | 巨门与铃星、陀罗成组（各家组合不一） | 主口舌纠缠 |

- 从表中可以看出两类常见做法：一类是**看主星与吉星的会照**（三奇加会、君臣庆会），一类是**看煞忌如何被夹住**（羊陀夹忌、火铃夹命）。传统的「夹」是很受重视的一种结构，因为它把相邻两宫的关系也算进来了。
- 「杀破狼」与「机月同梁」是两组流传最广的说法，常被用作两种取向的对照：一组对应变动与开创，一组对应守成与稳定——它们更像是两套性格原型，而不是好坏的分级。

## 五、关于「四大类型」

- 近数十年，中国香港、中国台湾地区的一些研习者把十四主星归纳为四组性格类型：
    - **开创型**：七杀、破军、廉贞、贪狼。
    - **领导型**：紫微、天府、武曲、天相。
    - **支援型**：太阳、巨门、天机。
    - **合作型**：太阴、天梁、天同。
- 这种归纳的好处是便于初学者建立印象，也有与西洋占星四象（火、土、风、水）作类比的尝试。
- 但需明确：**这是近人的通俗整理，不见于古籍**。传统命书里没有「四大类型」这个说法，十四主星的归组方式也不止这一种。把它当作入门时的记忆辅助即可，不宜当成斗数体系的一部分。

## 六、格局这一层的限度

- 格局的用法在传统上是「快速归类」：看到某个组合，就能联想到一批前人写下的判断，不必从零推起。这是它在经验传承上的便利。
- 但它的限度也很清楚：
    - **同一个格局，因四化、煞忌、大限流年的不同，解读可以差得很远**。古书中也常见类似的提醒，大意是格局须结合四化来看，不可执一而论。
    - **格局没有统一的分级**。什么算「成格」、什么算「破格」，各书标准不同；把格局当成「命好命坏」的等级表来用，是对它的误读。
    - **可证伪性低**。同一张盘，既可以说「因有煞星所以应了挫折」，也可以说「因有吉星所以化解了挫折」——两种说法都不违背体系。
- 综合起来，本页把格局归入**传统术语与文献材料**，而不是可以据此判断人生的工具。

## 七、几个常见的误解

- **「命宫好就一切都好」**。斗数的基本约定是要合看三方四正与大限流年。单看一格，几乎必然得出片面的印象。
- **「煞星一定不好」**。命书里同样有「煞有煞用」的说法，认为煞星能带来冲劲与突破。能两说的东西，不适合当结论用。
- **「化忌一定倒霉」**。传统上更多的是把化忌解为「牵住、放不下、特别费心」，未必是损失。
- **「软件排出来的就是事实」**。软件排的只是星曜位置；位置是确定的，「位置意味什么」不是。
- **「某个格局的人我见过，很准」**。这类印象往往来自事后挑选——记得住应验的，忘了其余的大部分。这是人脑的常态，不是斗数的效力。

## 八、提醒

- 本组七页内容属传统术数与民俗文化的知识整理。斗数体系自洽、术语丰富、文献也有其研究价值，但它并非基于现代意义上的观测与验证：排盘不查星历，论断不设可证伪的边界，同一张盘的解读可以随解释者的立场而变。
- 请勿依据本组内容判断自己或他人的性格、婚姻、事业、健康与人生走向。若有人以斗数结论劝你作出涉及金钱、医疗、婚姻的重大决定，请格外警惕。
- 涉及健康的部分（斗数有疾厄宫一说）尤其不可当真。身体不适请到正规医疗机构就诊。
- 命理类内容最容易被用来制造焦虑，也最容易被用来自我安慰。把它当文化来读，是安全的；把它当判词来听，就不是了。
