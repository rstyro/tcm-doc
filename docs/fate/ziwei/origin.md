# 源流与文献

- 在五术的各类术数里，紫微斗数是**成术最晚**的一套，也是古籍存世最少的一套之一。
- 它的难办之处在于：传说讲得极其完整（祖师、授受、秘传谱系一应俱全），可考的文献却晚到明代中期才出现。传说的部分无法证实，文献的部分又稀薄，所以谈斗数源流必须把两者分开说。
- 本页先记传说，再列可考文献，最后讲义理层面的来源推测与近现代流传。凡属传说或推测处，本页均予标明。

## 一、传说：托名陈抟

- 通行说法是：斗数为五代末宋初的道家人物**陈抟**（字图南，号希夷先生，872—989）所创。
- 更完整的传说版本是：吕洞宾将一套「以二十八宿配合九宫」的星命术授予陈抟，陈抟加以改良，定名「紫微斗数」；此后陈抟又传给自己的儿子与弟子，几百年间以孤本的形式在门内秘传，因此外界文献极少。这被用来解释斗数古籍为何如此稀少。
- 另一层说法是：斗数长期被视为「帝王之学」，明清钦天监垄断天文术数，能接触到的只限皇族与重臣，所以民间流传远不如八字广；直到清末民初钦天监解散，术数家流落民间，斗数才逐渐公开。
- 需要说明的是：**这些都属于传统说法与民间叙述**。陈抟授受之事不见于可考的早期文献；「钦天监垄断导致不传」也缺乏直接证据——八字同样与官方历法有关，却流传极广。本页按传统说法转述，并标明其性质，不作事实认定。

## 二、名称的最早出处

- 目前可考的、「紫微斗数」四字见于文献的最早年份是**明万历九年（1581）**，金陵书坊刻印的《**紫微斗数捷览**》（据称今藏苏州博物馆）。
- 稍后是**明万历三十五年（1607）**，第五十代正一道天师张国祥辑成《万历续道藏》，其中收录《紫微斗数》三卷，作者佚名。
- 这里有一个常被忽略的关键点：**《万历续道藏》里那三卷《紫微斗数》，内容并不是今天流通的斗数**。据研究者比对，它的星曜名称与排盘方式都与后世不同，实为「十八飞星」之术。所以不能简单地说「现代斗数就是《续道藏》里那三卷」。
- 反过来看，明代以前的官方与私家书目——宋代《直斋书录解题》、元代《宋史·艺文志》、明代《明史·艺文志》等——所录方术数以百计，**都没有「紫微斗数」之名**。这是学界判断其成术较晚的主要依据。

## 三、《紫微斗数全书》与罗洪先

- 今传《紫微斗数全书》一书**托名陈抟所著**，书前有一篇署「罗洪先」的序。
- 罗洪先（1504—1564）是江西吉水人，明嘉靖年间的学者，属阳明后学一系，也是地理学家（《广舆图》的作者）。
- 该序的落款时间为**嘉靖庚戌（1550）**，比《紫微斗数捷览》的 1581 年还早。但问题在于：现存《紫微斗数全书》的**刻本**反而晚于《紫微斗数捷览》出现，所以两者的先后关系至今尚待考订。
- 有研究认为，罗洪先可能只是**托陈抟之名、为本书作序**，而非作者本人；也就是说，这部书的成书过程可能比序言所署的年代复杂得多。
- 另一个证据是：现存《紫微斗数全书》的内页可见多家署名（后世补辑者、添阅者），说明它**不是一时一人一地之作**，而是在流传中不断被增补而成的。

## 四、南北两派之说

- 传统上把斗数的早期流传分为两系：
    - **北派**：三卷本《紫微斗数》，后被道教典籍《万历续道藏》收录。
    - **南派**：四卷本《紫微斗数》，明代嘉靖年间经罗洪先刊刻流传，即后来的《紫微斗数全集》与《紫微斗数全书》两个本子。
- 这个「南北两派」的说法流传很广，但需要注意：它讲的是**版本谱系**，与今天讲的「三合派」「飞星派」等**论断方法流派**不是一回事，不要混为一谈。

## 五、存世文献清单

斗数古籍数量确实很少，大致可分四类：

- **刻本三种**：
    - 《紫微斗数捷览》（明万历九年，1581）
    - 《紫微斗数全集》——坊间最通行者为晚清木刻翻刻本
    - 《紫微斗数全书》——通行者为民国石印本
    - 后两种的现存版本多出自清同治时期的刻版。
- **钞本（抄本）**：《斗数纲要》《斗数秘钞》《斗数演例》《紫微斗数之捷径》等。
- **民国著述**：王裁珊《斗数宣微》《斗数观测录》。
- **赋文**：《太微赋》《骨髓赋》等，通常附于《全书》《全集》之内，是古人对星曜与格局的精炼概括，也是后世引用最多、争议也最多的一类文字。
- 对比一下就很清楚：八字一路仅宋代以后就有《渊海子平》《三命通会》《滴天髓》《子平真诠》等成体系的著作传世，斗数可考的刻本却只有三种。所谓「古籍稀少」，是字面意义上的少。

## 六、来源推测：它不是凭空出现的

学界通行的看法是，斗数是一套**晚成而来源驳杂**的术数，由多种方术长期融合而成。常被提到的几条线索：

- **星占与道教斗经**。道教有《北斗经》《南斗经》一系经典，其中已有「本命星」「身主星」之类的观念，并有「祈安礼斗」的祈禳科仪。斗数里的「命主星」「身主星」（见《[辅佐煞杂曜](/fate/ziwei/stars-minor)》）与这套观念是否有直接承袭关系，属推测，尚无硬证。
- **唐代五星术**。又称五星禄命术、琴堂五星术，以日、月与金木水火土五星（合称七曜）为推命核心，配合甲子周期推算。这一路在唐代颇盛，后因历法久用失准而逐渐式微。
- **十八飞星**。宋代以后，十八飞星之术与五星禄命术相互融合，初步形成了「十二宫位 + 星曜组合」的推命模型，但体系尚不完整。
- **明清的成熟**。在吸收了干支历法、阴阳五行、易卦、择日乃至中医脏腑观念之后，斗数的完整架构大致到清代才真正齐备——这也是它「名晚而体全」的原因。

## 七、近现代的流传

- 明清至民国，命理学中一直是八字独大，斗数的研习者相对少，著作也少。
- **1980 年代之后**，斗数在中国香港、中国台湾地区迅速发展，与八字并称命理学的两大显学。现代有代表性的师承与派系大致包括：
    - **三合派**：以三方四正、星曜性质与格局为主要断法。
    - **飞星派**：以各宫宫干的四化飞星为主要断法，代表如梁若瑜一系。
    - **中州派**：王亭之一系，对星曜性质与四化表有系统整理，影响很大。
    - **钦天四化**：蔡明宏一系，以四化为核心。
- 现代还有一个明显变化：不少研习者尝试把斗数与心理学、统计方法乃至西洋占星作对照，并归纳出通俗的分类（如把十四主星归为「开创型、领导型、支援型、合作型」四类）。这类归纳属于**近人的通俗整理**，并非古籍原有内容，见《[格局与看盘](/fate/ziwei/geju)》。

## 八、关于源流研究的两点提醒

- 斗数的文献考订本身还有不少空白（如《全书》与《捷览》孰先、罗洪先序的真伪、南北两派的版本关系），本页所列只是一般共识，不是定论。
- 「托名」在古代术数文献中极为常见：借一位名人署名以提高分量，是当时的出版惯例，不必因此判定全书无价值，也不应反过来把托名的内容当作真实历史。读这类书时，把**文献事实**与**术数理论**分开对待，会更清楚。
