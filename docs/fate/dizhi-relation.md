# 地支关系：合冲刑害

- 十二地支并非各不相干的独立符号，彼此之间存在一套固定的关系网络：**合、冲、刑、害、破、会**。
- 这套关系是命理、六爻、择日、风水共用的工具语言。论八字时，它用来判断命局是否"被引动"；论六爻时，它用来定应期与吉凶；论择日风水时，它用来避开不利的干支组合。
- 本页把六组关系逐一展开，给出完整的对照表与判断要点。《[天干地支](/fate/ganzhi)》页侧重干支的来历与属性，本页专讲相互关系。

## 为什么要单独讲这组关系

- 在八字里，干支的生克只是**静态**属性：木克土、金克木，是谁都看得见的一层。而合冲刑害是**动态**的：它会改变原有的生克关系——本该相克的，可能因为相合而"贪合忘克"；本该有力的，可能因为被冲而动摇。
- 传统论命的次序，是**先看生克旺衰定强弱，再看合冲刑害看变数**（参见《[八字怎么批](/fate/piming)》第六步）。
- 因此有"合冲为先"的说法：排出四柱之后，先把地支之间的关系梳理一遍，命局的"动点"在哪里就清楚了。
- 需要说明，以下全部为传统术数的通行说法，各流派在细节（如合化的成立条件、刑的顺序）上分歧不少，本页尽量标注。

## 六合

- **六合**指十二地支两两相合，共六组，故称六合。
- 六合主"亲近、结合、羁绊"：合则相牵，既可以是助力（如合来贵人），也可以是牵绊（如把该动的字合住不动）。

| 组合 | 合化（通行说法） | 备注 |
| --- | --- | --- |
| 子丑 | 合化土 | 合中带克，传统有"合而不化"之说 |
| 寅亥 | 合化木 | 亥水生寅木，合得顺畅 |
| 卯戌 | 合化火 | 戌土中的丁火得卯木之助 |
| 辰酉 | 合化金 | 辰土生酉金 |
| 巳申 | 合化水 | 巳申既合又刑，关系复杂 |
| 午未 | 合化土 | 午火生未土 |

- **生合与克合**：六合中有的相生（如寅亥、辰酉），有的相克（如子丑、午未），传统认为生合较顺、克合较别扭，须结合命局喜忌看。
- **合化与合而不化**：两个地支相合后是否真的"化"成另一种五行，取决于月令、条件是否具备。多数情况下只是"合住"而非"化掉"，传统对此非常讲究。
- **贪合忘克**：一个本该去克别人的字，如果同时与另一字相合，传统认为它会被合住而"忘记"克，这在判断用神是否得力时很关键。

## 三合局

- **三合局**是三个地支相合成一个完整五行局，力量比六合更强，共四组。
- 三合局的构成有规律：每组由一个"长生"、一个"帝旺"、一个"墓库"组成（可与《[十二长生](/fate/changsheng)》对照理解）。

| 三合局 | 组合 | 旺神（中神） | 成局条件 |
| --- | --- | --- | --- |
| 水局 | 申子辰 | 子 | 三字全见力最强 |
| 木局 | 亥卯未 | 卯 | 同上 |
| 火局 | 寅午戌 | 午 | 同上 |
| 金局 | 巳酉丑 | 酉 | 同上 |

- **半合**：只有其中两字，通常必须有那个"旺神"（子、卯、午、酉）才算半合成立，力量次于三字全。
- **拱合**：失掉旺神、只有长生与墓库两字（如申辰），传统认为二者"拱"着中间的旺神，条件齐备时也可成局，说法分歧较大。
- 三合局成立后，整组的力量方向统一，会显著改变命局的五行格局，是判断旺衰的重要依据之一。

## 三会方（会局）

- **三会**指三个地支会合成一个方位之气，力量最强，共四组，比三合局更"专"。

| 三会方 | 组合 | 方位与五行 |
| --- | --- | --- |
| 东方木 | 寅卯辰 | 春季木气 |
| 南方火 | 巳午未 | 夏季火气 |
| 西方金 | 申酉戌 | 秋季金气 |
| 北方水 | 亥子丑 | 冬季水气 |

- 三会的道理来自季节方位：寅卯辰正是春季三个月，木气最盛，故会成木。这也是为什么传统把三会视为"方局"——它取的是时令的旺势，而非人为配合。
- **力量次序**（通行说法）：三会 > 三合 > 六合。但实际论命须看是否当令、有无冲破坏局，不能只按强度表套用。

## 六冲

- **六冲**指十二地支中位置相对（相隔六位）的两字相冲，共六组。
- 冲主"动摇、冲突、分离、变动"：冲可以冲开（如冲开墓库使收藏之气得以透出），也可以冲动（使静态的字活跃起来），还可以冲破（使原本成局的结构散掉）。吉凶须结合喜忌——**冲忌神为吉，冲喜用神则不利**。

| 六冲 | 对应生肖 | 含义提要 |
| --- | --- | --- |
| 子午 | 鼠—马 | 水火相战，南北相冲 |
| 丑未 | 牛—羊 | 土土相冲，多在库与库之间 |
| 寅申 | 虎—猴 | 金木相冲 |
| 卯酉 | 兔—鸡 | 金木相冲，主分离 |
| 辰戌 | 龙—狗 | 土库相冲 |
| 巳亥 | 蛇—猪 | 水火相冲 |

- **天克地冲**：天干相克、地支相冲同时出现（如甲子 vs 庚午），传统视为变动较激烈的组合。
- **墓库逢冲**：辰戌丑未四库，传统有"逢冲则开、冲开可用"的说法，即收藏在库中的力量因冲而被激发。这是冲的一种正面用法。
- **邻近之冲与遥远之冲**：相邻两柱相冲力较直接，隔柱相冲力较缓，各派对此权重说法不一。

## 三刑与自刑

- **相刑**是地支关系中道理最晦涩的一组，古人配以人事伦常来解释，故有"无恩""恃势""无礼"之名。共分四类：

| 刑的类型 | 组合 | 传统解释（取象） |
| --- | --- | --- |
| 无恩之刑 | 寅、巳、申 | 三者中任意两字相见即刑，主恩怨、伤害 |
| 恃势之刑 | 丑、戌、未 | 三字相刑，主仗势、争斗 |
| 无礼之刑 | 子、卯 | 二字相刑，主礼节、情感纠葛 |
| 自刑 | 辰、午、酉、亥 | 两字相同（如辰见辰）即刑，主自我消耗 |

- **寅巳申三刑**与**丑戌未三刑**须三字会齐方成"三刑"；只出现两字，传统也论刑，但力量较轻。
- **自刑**的用法是：命局中出现两个相同的地支（如两个午），传统认为反而构成刑，主内耗、反复。这一点与"同类相帮"的直觉相反，是初学者容易忽略处。
- 相刑的含义在诸家中分歧最大：有重在论是非官非的，有重在论健康情绪的，也有主张刑的力度远不如冲合、不必深究的。本页只作概念梳理。

## 六害（穿）与六破

- **六害**，又称**六穿**，指六组互相妨害的组合，共六组。害主"暗中干扰、相互拆台、好事多磨"，比起冲的明朗，害更偏向暗损。

| 六害 | 组合 |
| --- | --- |
| 子未 | 子未害 |
| 丑午 | 丑午害 |
| 寅巳 | 寅巳害 |
| 卯辰 | 卯辰害 |
| 申亥 | 申亥害 |
| 酉戌 | 酉戌害 |

- **六破**指六组互相破损的组合，是程度最轻的一组关系，多主计划落空、小事不顺。

| 六破 | 组合 |
| --- | --- |
| 子酉 | 子酉破 |
| 午卯 | 午卯破 |
| 辰丑 | 辰丑破 |
| 戌未 | 戌未破 |
| 寅亥 | 寅亥破 |
| 巳申 | 巳申破 |

- 注意**寅亥既合又破**、**巳申既合又刑又破**：同一个地支组合可能同时具备多重关系。这正是地支关系的复杂处——不能只查一种表就下结论，须把该组合在所有关系表中的出现都看一遍。
- 实务中，破的权重最低，许多流派几乎不单独用破论事；害则常与刑配合参看。

## 多重关系示例

- 以 2026 年丙午年为例，十二生肖与当年太岁（午）的关系分布如下（这一组恰是《[太岁](/fate/taisui)》篇判"犯太岁"的依据）：

| 生肖 | 地支 | 与午的关系 |
| --- | --- | --- |
| 马 | 午 | 值太岁（同支）、自刑（午午自刑） |
| 鼠 | 子 | 冲太岁（子午冲） |
| 牛 | 丑 | 害太岁（丑午害） |
| 兔 | 卯 | 破太岁（卯午破） |
| 羊 | 未 | 合太岁（午未六合） |
| 虎 | 寅 | 合太岁（寅午戌半合火） |
| 狗 | 戌 | 合太岁（寅午戌半合火） |

- 同一张表就能看出：属马者"值太岁 + 自刑"叠加，属虎狗者反而得合。这说明**合冲刑害读的是关系本身，吉凶则要看这股关系对命局是好是坏**，与"犯太岁必倒霉"的通俗印象并不一致。

## 天干的合与冲

- 地支之外，天干也有两组关系，常与地支关系配合使用：
    - **十干五合**：甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火。
    - **十干相冲**：甲庚冲、乙辛冲、丙壬冲、丁癸冲（戊己居中，不参与相冲）。
- 详见《[天干地支](/fate/ganzhi)》页。合冲同现时（如天干相冲而地支相合），传统称"合冲并见"，吉凶看何者为主。

## 使用要点与提示

- **先立旺衰，再论合冲**。日主强弱未定之前，谈合冲刑害意义不大；定强弱可参考《[日主旺衰](/fate/wangshuai)》。
- **合冲有优先次序**（通行说法）：一般先看三会、三合这类"成局"关系，再看六合六冲，最后看刑害破。但各派权重不同，不必拘泥。
- **忌只查表不分析**。合冲刑害给的是"命局哪里在动"，不直接等于吉凶；同一个子午冲，在不同的命局里可以是伤病，也可以是变动迁居。
- **术语流派分歧较多**：合化条件、刑的效力、破是否可用、隔位算不算冲，各家说法不一，本页所录为较通行的一系。
- **想看实际比对**：可用本站[八字合婚查询](/fate/query/hehunQuery)，输入两人出生信息，即按本页各类关系（六合、三合、六冲、相刑、六害、六破）逐条列出比对结果。
