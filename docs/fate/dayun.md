# 大运与流年

- 八字（四柱）以出生年、月、日、时排出，构成一个人的“原局”，传统视为先天禀赋的部分。
- 原局只是静态结构，人生各阶段的际遇起伏，要靠“大运”与“流年”逐年逐段地推行出来，二者共同描述后天时运的推移。
- 大运主管较长的时间段，传统以十年为一运，实为以一组干支管十年，俗称“一步大运十年”。
- 流年即逐年的干支纪年，传统也称该年的“太岁”。本站“太岁”篇侧重民俗与犯太岁的关系，本篇则从命理排盘与干支作用的角度作介绍，两篇可互为参照。
- 以下按传统子平框架的通行说法简述；不同流派在排法细则与论断侧重上存在差异，文中会相应注明。

## 大运的起排

- 大运从月柱干支起排，先确定顺行还是逆行，再逐位推排，故月柱在排大运中处于枢纽位置。
- 顺逆依年干的阴阳与命主性别而定，通行说法是：阳年生男、阴年生女顺排；阴年生男、阳年生女逆排，简言为“阳男阴女顺、阴男阳女逆”。
- 所谓“阳年”“阴年”，指的是年柱天干的阴阳（甲、丙、戊、庚、壬为阳，乙、丁、己、辛、癸为阴），与生肖、方位无关。
- 顺排即按六十甲子自月柱干支向后顺推（如月柱为甲子，则其后为乙丑、丙寅、丁卯……）；逆排则向前倒推（如月柱甲子，前为癸亥、壬戌、辛酉……）。
- 示例性说明：假设某男命生于甲年（阳年）、月柱为庚午，则大运自辛未顺排，其后壬申、癸酉、甲戌……依次接续；若同为庚午月而生于乙年（阴年）的男命，则大运自庚午前一位己巳起逆排，再戊辰、丁卯……。此处仅为说明推排方向，不涉及具体吉凶。
- 每步大运由天干、地支两个字组成，传统有“天干主前半五年、地支主后半五年”的说法，也有流派不分主次而将十年一体论断，属于论运方式的分歧。

## 起运岁数

- 大运虽以十年一步，但第一步大运并非出生即开始，命主需先度过一段“未上运”的时段，故要先推算“几岁起运”。
- 通行做法是：以出生日到相邻节气（顺排取下个节气、逆排取上个节气）的间隔天数折算起运岁数，约以三天折合一岁的方式取整定岁。
- 各派对节气间隔的取法、折算的精细规则（如余数如何折算月数）并不完全一致，同一命例在不同流派下起运岁数可能略有出入。
- 需注意月令以二十四节气为界，起运推算也以节气的交节时刻为基准，而非阴历的初一。
- 起运的早晚只影响第一步运来临的时间，每步大运本身仍是十年。

## 大运与命局的作用

- 大运干支如同外部进入的环境，会与原局干支发生生、克、冲、合、刑、害等关系，从而“引动”原局中的十神与结构。
- 一个常见的比喻是：原局是“种子”，决定了这株植株的天性与潜能；大运与流年是“季节”，决定种子在哪个阶段发芽、生长还是蛰伏。
- 因此同样的好运或坏运，落在不同命局上效果不同；同一命局走不同的大运，取向与吉凶也不同，必须把原局与大运放到一起整体看。
- 传统论运还讲究大运所临的五行方向与命局喜忌是否相合，能助起原局所喜者为顺遂之时，反之则易多阻碍。

## 流年（岁运）

- 流年指具体某一年的干支，干支纪年一年一换，故称“流年”；因为这一年的干支被看作当年当值，传统上也称“太岁”。
- 论一年之事，通行思路是“大运为纲、流年为目”：先看流年干支与大运、原局之间发生的关系，再看它引动的是喜用还是忌神，结合具体事象作综合判断。
- 流年、大运与原局三者叠加，构成岁运分析的常用框架；只看流年单柱、脱离原局与大运来断吉凶，是传统论命所忌。
- 本篇所述流年侧重干支生克合冲的命理视角，与“犯太岁”（生肖与当年太岁地支的值、冲、刑、害、破关系）的民俗说法角度不同，后者详见本站“太岁”篇。

## 岁运并临等术语

- 岁运并临：指流年干支与大运干支完全相同（如同为甲子），两者同时出现。传统有“岁运并临，灾殃立至”一类夸张说法，也有解作变动剧烈者；实际吉凶须结合原局喜忌而定，不能单凭这一现象断语。
- 其他常用提法还有“岁运天克地冲”（流年与大运天干相克、地支相冲）、“运逢喜用”（大运临喜用神之地）等，均只是对干支关系的一种概括称呼。
- 这些术语在传统命书中出现频繁，但都属于论断时的描述性语言，其实际意义需放回具体命局中检验。

## 提示

- 大运流年的论法流派繁多：管运年限的分配方式、岁运与原局关系的主次安排、神煞的取舍标准等，各家细则并不一致，不可只凭单一关系（如只看冲合或只看神煞）下结论。
- 本文仅属术语与框架层面的知识整理，不涉及具体命例的判断方法；实际运用须以完整命局为依据，结合喜忌整体分析。
- 命理内容是传统文化知识的整理介绍，不作人生预测承诺。
