# 五行

## 什么是五行

- 五行指木、火、土、金、水五种基本属性，是古人认识世界的基本框架之一，命理、中医等传统学问均以其为理论基础。
- 五行不是指五种具体物质，而是五种属性、五种“气化状态”：木主生发、火主炎上、土主承载、金主肃降、水主润下，古人借其归类万物、比象人事。
- 天干与地支各有所属五行，其完整属性表见[八字命理](/fate/bazi)页；明白各字所属五行，是理解干支生克的第一步。

## 五行相生

- 相生即“相互滋生、助长”：木生火、火生土、土生金、金生水、水生木，循环不息、如环无端。
- 助记：按“木火土金水”顺次相生，每一位都滋生其后一位，末位又回头滋生首位。

## 五行相克

- 相克即“相互制约、克制”：木克土、土克水、水克火、火克金、金克木，亦成一循环。
- 同一循环亦可换个起点写作“金木土水火”，只是写法起点不同，含义并不矛盾。

## 五行与方位、季节

- 五行配五方：木居东、火居南、土居中、金居西、水居北。
- 五行应四季旺衰：春木旺、夏火旺、四季末月（辰、戌、丑、未）土旺、秋金旺、冬水旺。更细的旺衰进退，可参考[十二长生](/fate/changsheng)页。

## 五行与身体（传统歌诀）

传统中医与命理有以天干配人体脏腑的取象习惯，通行歌诀为：

> 甲胆乙肝丙小肠，丁心戊胃己脾乡；庚是大肠辛属肺，壬系膀胱癸肾藏。

- 甲木应胆，乙木应肝：甲乙同属木，甲为阳木应胆，乙为阴木应肝。
- 丙火应小肠，丁火应心：丙丁同属火，丙为阳火应小肠，丁为阴火应心。
- 戊土应胃，己土应脾：戊己同属土，戊为阳土应胃，己为阴土应脾。
- 庚金应大肠，辛金应肺：庚辛同属金，庚为阳金应大肠，辛为阴金应肺。
- 壬水应膀胱，癸水应肾：壬癸同属水，壬为阳水应膀胱，癸为阴水应肾。

此歌诀为传统取象记诵口诀（传统说法）。五行生克也可类比到脏腑关系，如肝木与脾土之间的“木克土”，中医传统称“木乘土”；此处点到即止，不作展开。
