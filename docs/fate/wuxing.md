# 五行

## 什么是五行

- 五行指木、火、土、金、水五种基本属性，是古人认识世界的基本框架之一，命理、中医等传统学问均以其为理论基础。
- 五行不是指五种具体物质，而是五种属性、五种"气化状态"：木主生发、火主炎上、土主承载、金主肃降、水主润下，古人借其归类万物、比象人事。
- 五行是"山、医、命、相、卜"五术共用的底层符号系统之一：命理以五行论日主旺衰，中医以五行配五脏，风水以五行论方位生克，八卦亦各配五行。故本页属跨栏目的公共基础内容。
- 天干与地支各有所属五行，其完整属性表见[八字命理](/fate/bazi)页；明白各字所属五行，是理解干支生克的第一步。干支体系总论另见[天干地支](/fate/ganzhi)页。

## 阴阳与五行

- 阴阳与五行是两套互补的框架：阴阳讲"对立统一、消长转化"，五行讲"五种属性的生克制化"。传统学问往往先立阴阳，再以五行分疏万物。
- 五行各分阴阳：如木有阳木（甲）、阴木（乙），火有丙阳丁阴等；同一五行因阴阳不同，性质与喜忌亦有差异。
- 阴阳五行结合，构成理解中医藏象、命理旺衰、易卦变化的基础。阴阳本身的哲学展开，可参见医部《[黄帝内经](/tcm/huangdi/what)》与《[周易](/divination/zhouyi/what)》相关论述。

## 五行相生

- 相生即“相互滋生、助长”：木生火、火生土、土生金、金生水、水生木，循环不息、如环无端。
- 助记：按“木火土金水”顺次相生，每一位都滋生其后一位，末位又回头滋生首位。

## 五行相克

- 相克即“相互制约、克制”：木克土、土克水、水克火、火克金、金克木，亦成一循环。
- 同一循环亦可换个起点写作"金木土水火"，只是写法起点不同，含义并不矛盾。

## 生克不是吉凶：命理怎么读生克

- 相生相克讲的是**关系**，不是**吉凶**。这是初学命理最容易走偏的一处：以为「生」就是好、「克」就是坏。
- 在命理里，某一行对日主是生是克，只说明它是「哪一类」力量；至于这类力量对这张盘好还是坏，要看**日主需不需要它**：
    - 日主偏弱时，生扶它的（印、比劫）为喜，克制、耗泄它的（官杀、财、食伤）为忌；
    - 日主偏强时，反过来——泄它、克它、耗它的为喜，再生扶反而是负担。
- 所以同一对五行关系，在不同的盘上吉凶可以完全颠倒。这一点详见《[八字怎么批](/fate/piming)》「取用」一节，也正是《[命盘实例](/fate/shili)》两张对照盘要演示的核心：同一个「火」，在身强的盘里是制金的用神，在身弱的盘里却是攻身的忌神。
- 另一层要留意的是**生克并非只按字面直推**：
    - **生多为克**：生得太过反成害。如水多木漂、土多金埋、火多木焚——生我者太旺，我反受其困。
    - **贪生忘克**：一方正在生另一方时，对第三方的克制会被牵制。如金本克木，但金若忙于生水，克木之力就减。
    - **反克（反侮）**：被克者过旺，会反过来欺侮克它的一方。机制与中医共用，详《[五行学说](/tcm/jichu/wuxing)》。
- 记住一句：**生克是「势」，喜忌是「用」**——先算势，再据日主所需定用。

## 五行与十神：从五行到八字的桥

- 五行要落到八字上，中间要经过一层翻译：把「某一行与日主的关系」换成**十神**。这一步是五行在命理中真正的用法：

| 与日主的关系 | 十神 | 五行上的说法 |
| --- | --- | --- |
| 生我者 | 正印 / 偏印 | 日主的「母」 |
| 我生者 | 食神 / 伤官 | 日主所生 |
| 克我者 | 正官 / 七杀 | 制日主者 |
| 我克者 | 正财 / 偏财 | 日主所制 |
| 同我者 | 比肩 / 劫财 | 与日主同类 |

- 同一行的阴阳之别又把它一分为二：生我者为印，异性相生为正印、同性为偏印；克我者为官杀，异性为正官、同性为七杀。十神的完整推法与性质见《[十神](/fate/shishen)》，本页只交代这层对应。
- 这层对应一通，五行就有了人事内容：印主学业、母亲与庇护，食伤主才华、表达与子女，官杀主事业、约束与责任，财主资源与经营（男命亦主妻），比劫主同辈、竞争与助力。
- **同一个五行，对不同日主是不同的十神**。例如金——对木日主是官杀（克我），对水日主是印（生我），对土日主是食伤（我生），对火日主是财（我克）。所以「金好不好」这个问题，在命理里必须连「哪一个日主」一起问，单看五行是答不了的。
- 反过来说，**一张盘的五行分布，也就是它的十神分布**；旺衰算完、喜忌定了，十神才好用。


## 五行的旺相休囚死（四季旺衰）

- 五行在四季中有旺衰变化，传统以"旺、相、休、囚、死"描述某行在当令时的势力消长：
    - **旺：** 当令者旺。如春季木当令，木为旺。
    - **相：** 旺所生者为相。春木旺，木生火，火为相。
    - **休：** 生旺者退而休息。水生木，春木旺则水为休。
    - **囚：** 克旺者被困。金克木，春木旺则金为囚。
    - **死：** 被旺所克者无气。木克土，春木旺则土为死。
- 各季对应：春木旺、夏火旺、秋金旺、冬水旺；土旺于四季之末（辰、戌、丑、未月）。
- 此旺衰框架与[十二长生](/fate/changsheng)一脉相承，都是判断某行"是否有气、有力无力"的参考；论命时旺衰须结合日主喜忌，不能单凭旺衰定吉凶。

## 五行的势力：不数个数，看有没有根

- 初学最省事的做法是「数一数盘里几个木、几个金」，但传统命理不用这个方法。原因是：**天干与地支的分量不同，得令与失令的分量也不同**。
- 大体的轻重层次如下（判据细节见《[日主旺衰](/fate/wangshuai)》）：
    - **月令最重**：月支所主的五行是一月之令，力量最大，故称「提纲」；
    - **地支重于天干**：天干上的同类若无地支为根，传统称「虚浮」，帮助有限；
    - **通根与透干**：地支藏干里有同类的气叫有根（通根），天干上透出同类叫透干——有根才算有力；
    - **行运补足**：原局所缺、或有根无透的，得大运流年补上，力量才现。
- 所以同样「三个火」，落在月令、地支有根，与落在天干无根，是两回事；同样，**五行缺一行，不等于这行就弱到需要补**——它可能只是不显。
- 这也解释了为什么命理看「势」重于看「数」：**五行是活的，字面数量只是静态统计**。

## 五行与方位、季节

- 五行配五方：木居东、火居南、土居中、金居西、水居北。
- 五行应四季旺衰：春木旺、夏火旺、四季末月（辰、戌、丑、未）土旺、秋金旺、冬水旺。更细的旺衰进退，可参考[十二长生](/fate/changsheng)页。

## 五行与身体（传统歌诀）

传统中医与命理有以天干配人体脏腑的取象习惯，通行歌诀为：

> 甲胆乙肝丙小肠，丁心戊胃己脾乡；庚是大肠辛属肺，壬系膀胱癸肾藏。

- 甲木应胆，乙木应肝：甲乙同属木，甲为阳木应胆，乙为阴木应肝。
- 丙火应小肠，丁火应心：丙丁同属火，丙为阳火应小肠，丁为阴火应心。
- 戊土应胃，己土应脾：戊己同属土，戊为阳土应胃，己为阴土应脾。
- 庚金应大肠，辛金应肺：庚辛同属金，庚为阳金应大肠，辛为阴金应肺。
- 壬水应膀胱，癸水应肾：壬癸同属水，壬为阳水应膀胱，癸为阴水应肾。

此歌诀为传统取象记诵口诀（传统说法）。五行生克也可类比到脏腑关系，如肝木与脾土之间的“木克土”，中医传统称“木乘土”；此处点到即止，不作展开。

## 五行与八卦、方位的贯通

- 五行与八卦相配是跨栏目常用的对应：乾兑属金、震巽属木、坎属水、离属火、坤艮属土（通行说法）。
- 五行与方位：木东、火南、土中、金西、水北；八卦据此各配方位（详见《[八卦基础](/divination/zhouyi/bagua)》页）。
- 命理、中医、风水常借这组对应互相转译：如"东方属木主肝"，就是把方位—五行—脏腑—卦象贯通起来说。
- 干支各自属五行且分阴阳，地支又藏干多气，故论五行强弱时须落到具体干支与藏干上（见《[天干地支](/fate/ganzhi)》）。

## 常见误区

- **数五行个数**：数出「金两个、木三个」就下结论，忽略了天干地支之别与得令失令之差。
- **缺什么补什么**：这是民间最流行的说法，也是命理上最常见的误解。**五行缺的那一行，若是忌神，缺了反而好**；该补的是「用神」，不是「缺的那一行」——补错方向，传统认为反而有害。
- **把五行均衡当好命**：五行俱全、平均分配，在命理上并不等于好；许多有特点的结构（专旺、从格）恰恰以五行严重不均衡为条件。
- **见生就吉、见克就凶**：生克是势，喜忌才分吉凶；日主偏强时，克、泄、耗才是喜。
- **只看五行不看干支**：五行是抽象的「行」，落到盘上必须具体到哪一个天干、哪一个地支、藏干是哪几气——脱离干支谈五行，等于空谈。
- **拿「五行缺 X」推销改名、饰品、方位**：这类话术利用的正是上面两条误解，属应当警惕的情形。
