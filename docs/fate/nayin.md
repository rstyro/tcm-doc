# 纳音

- 纳音是传统术数中把六十甲子各配以一组"五行之音"的说法：六十甲子每相邻两柱合为一组，共三十组，各属一种纳音五行（如"海中金""炉中火"等）。
- "纳音"之名，取"纳其声而应其律"之义——古人把五行与五音（宫商角徵羽）、律吕相配，再由干支纳入音律而定五行，故称纳音（传统说法）。
- 纳音五行与干支的**正五行**（甲木、子水那种直接归属）是两个体系：同一干支既属正五行，又另有纳音五行，二者各有所用，不可混淆。

## 纳音的作用（各体系运用）

- **命理（八字）：** 传统论命有"以年柱纳音为主"的古法（如称某人"年命"为海中金、炉中火），后子平法以日干为主、五行十神论命，纳音退居辅助参考。
- **合婚民俗：** 民间流传"八字合婚看纳音""男木女金不相配"一类的婚配说法，多出自通俗命书与民俗，并非命理主流论法，今人多当作民俗了解。
- **择日与其它术数：** 部分择日、安床、出行体系会参考纳音与方位、时令的配合。
- 需要注意：纳音以"两柱成组"出现，不能单独以某一天干或某一地支论其纳音；论命时纳音多作旁参，不宜代替正五行的旺衰生克判断。

## 纳音与五音律吕（原理简述）

- 传统上以五音（宫、商、角、徵、羽）配五行（土、金、木、火、水），干支按次序纳入律吕而各有其音，故称纳音。
- 具体推法涉及六十律旋相为宫的乐律理论，颇为专门；一般读者掌握"六十甲子两柱一组配三十纳音"的结果即可，不必深究推演细节。
- 现代学者对纳音系统的形成与逻辑也有不同研究，本页按通行表式整理，供查用。

## 学习建议

- 先对照本页纳音表记忆常用者，或借助"甲子乙丑海中金"一类口诀整体诵读。
- 使用要点：先确定是哪两柱成组，再查对应纳音；注意与正五行区分。
- 若用于命理，宜先掌握日主旺衰与十神体系，纳音作补充了解即可，不宜本末倒置。
