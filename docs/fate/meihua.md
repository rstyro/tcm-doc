# 梅花易数

- 梅花易数，相传为北宋邵雍（康节）所传、以“观梅占”而得名的一种易占方法，属传统“以象起卦、以数断事”的简易占卜术。
- 其特点是“万物皆数、数皆成卦”：凡所见字数、声音、方位、时间、器物等皆可转化为卦象，不必借助铜钱，随时随地可占。
- 与六爻的“纳甲装卦、干支生克”体系不同，梅花易数更多运用“先天卦数 + 体用生克 + 卦象比类”断事，入门轻巧而深究无穷。本页仅作知识性整理。

## 起卦方法（举例）

- **时间起卦**：以农历年、月、日、时取数——年支数、月数、日数之和除以 8 取余得上卦，再加时数除以 8 取余得下卦，总数除以 6 取余得动爻。
- **数字起卦**：心中报两数，或取所见两组数，前数为上卦、后数为下卦，总数定动爻；不足八者直接用数，超过八者除八取余。
- **字占**：以字数分上下卦（或笔画数），如“一字占、二字占”各有传统取法。
- 起卦须心诚、所问明确，数字与当下情境相应即可。

## 卦数与卦象（先天八卦）

- 先天八卦配数（通行口诀）：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。
- 配先天数得上下卦后，组合成六十四卦之一；动爻所在之爻为变爻，动则本卦化出变卦。
- 上卦、下卦相重先得“本卦”，据动爻得“变卦”，又可取中间互卦辅助参断。

## 体用生克

- 以动爻所在之卦为“用卦”，不动之卦为“体卦”；体为占者自身（或所主之事），用为所测之环境、对方、事件。
- 生克关系（核心简则）：
    - 用生体：吉，主外有助益、事易成；
    - 体生用：泄气，主费心耗力、事有迟滞；
    - 用克体：凶，主受阻妨碍、宜谨慎；
    - 体克用：主我可制物、事虽费力而可成；
    - 体用比和：吉，主顺遂相合。
- 断卦时尚须结合卦象本身含义（如乾为刚健、坤为顺载、离为明丽、坎为险陷）与所问人事取象，不宜只论生克。

## 外应

- 梅花易数讲究“外应”：起卦或断卦当下，周围环境出现的动静（如声响、来人、物象变化）可作附加取象佐证，为传统“天人相应”思想的体现，属进阶运用。

## 学习建议

- 入门顺序：记熟先天八卦与配数 → 学会时间/数字起卦 → 掌握本卦、变卦、互卦 → 习体用生克 → 再练象意解读与外应。
- 本页为入门导览；梅花易数古籍以《梅花易数》一书为代表，历代注家说法小有出入，宜以通行本为准。
