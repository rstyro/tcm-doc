# 天干地支

- 天干地支（简称"干支"）是传统历法与命理、医卜通用的计时记数符号系统。
- 甲、乙、丙、丁、戊、己、庚、辛、壬、癸 为十天干；
- 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥 为十二地支。
- 干支是理解八字命理、《黄帝内经》运气学说、六爻纳甲、择日风水等众多传统学问共同的"字母表"。本页为干支基础总论。
- 十天干与十二地支各自的**阴阳五行属性**，见《[五行](/fate/wuxing)》页对照表；本页侧重干支组合与关系的排布规律。

## 干支的由来（源流简述）

- 干支纪日、纪年的传统起源很早，甲骨文中已有完整的天干纪日；干支相配成六十甲子以循环纪时，是中国古代历法的重要创造（通行说法）。
- 古人以天干象天之气、地支象地之形：天干主动而地支主静，天干纪天道运行、地支纪地道方位与节气。
- 关于干支的具体起源（是否对应远古十个太阳、十二个月等），学界有各种假说，尚无定论；此处以传统干支体系的功能与用法为主。

## 十天干

- 甲乙丙丁戊己庚辛壬癸，其阴阳五行归属如下（详表见《[五行](/fate/wuxing)》）：
    - 五行属性：甲乙木、丙丁火、戊己土、庚辛金、壬癸水。
    - 阴阳属性：甲丙戊庚壬为阳；乙丁己辛癸为阴。即"同五行分阴阳"。
- 天干之间另有**十干合化**（相合而化）与**相冲**等关系，为命理、中医运气所用：
    - **五合：** 甲己合化土、乙庚合化金、丙辛合化水、丁壬合化木、戊癸合化火（传统说法，合化须有条件）。
    - **相冲（对位相克）：** 甲庚冲、乙辛冲、丙壬冲、丁癸冲（戊己居中不与冲）。
- 十天干尚与方位、季节、脏腑相配（如甲乙东方木主肝胆），用于中医藏象与卦气取象。

## 十二地支

- 子丑寅卯辰巳午未申酉戌亥，五行属性：子亥水、寅卯木、巳午火、申酉金、辰戌丑未土（详表见《[五行](/fate/wuxing)》）。
- 地支兼表**月份、时辰、生肖与方位**：
    - 月份：寅为正月……丑为十二月（夏历建寅）。
    - 时辰：子时约 23:00–01:00，依次类推，两小时为一时辰。
    - 生肖：子鼠、丑牛、寅虎、卯兔、辰龙、巳蛇、午马、未羊、申猴、酉鸡、戌狗、亥猪。
    - 方位：子北、午南、卯东、酉西，四隅为辰巳（东南）等（详见风水相关页）。
- 十二地支之间的关系十分丰富，是命理合婚、六爻取用、择日的重要依据（见下文"地支关系"）。

## 六十甲子

- 天干 10 与地支 12 的最小公倍数为 60，故天干地支依次相配，从"甲子"到"癸亥"共六十对，循环纪年、纪月、纪日、纪时，称"六十甲子"。
- 六十甲子的相配遵循"阳干配阳支、阴干配阴支"的规律，故无"甲丑"一类组合。
- 六十甲子每轮也各配以**纳音五行**（如甲子乙丑海中金），即"纳音"之说，详见《[纳音](/fate/nayin)》页。
- 六十甲子亦为太岁纪年（六十位值年太岁）与某些择日体系的计时基础。

## 地支关系

- 地支间主要有六合、三合、三会、六冲、相刑、六害（穿）、六破等关系，是命理、六爻、择日、风水共用的判断工具。概览如下：

| 关系 | 组合 | 大义 |
| --- | --- | --- |
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 | 亲近、结合、羁绊 |
| 三合局 | 申子辰水、亥卯未木、寅午戌火、巳酉丑金 | 三支成局，力量强 |
| 三会方 | 寅卯辰木、巳午未火、申酉戌金、亥子丑水 | 会成方位旺势，力量最强 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 | 动摇、冲突、变动 |
| 相刑 | 寅巳申、丑戌未、子卯、辰午酉亥自刑 | 暗中损耗、内耗 |
| 六害 | 子未、丑午、寅巳、卯辰、申亥、酉戌 | 暗中干扰、好事多磨 |
| 六破 | 子酉、午卯、辰丑、戌未、寅亥、巳申 | 轻度破损、计划落空 |

- 这些关系并非孤立口诀，须结合干支旺衰与所处环境综合判断。**完整对照表、合化条件、多重关系（如寅亥既合又破、巳申既合又刑又破）以及实例，见《[地支关系：合冲刑害](/fate/dizhi-relation)》专页。**
- 初学者可先记"六合、三合、六冲"三组最重要，其余随具体术数需要渐次掌握。

## 地支藏干

- 每个地支除本气（所主五行）外，还暗藏其他天干之气，命理称"地支藏干"。如子藏癸、丑藏己癸辛、寅藏甲丙戊等。
- 藏干是解读地支内在层次（本气、中气、余气）的依据，八字取用神、论十神强弱时常须透干查支、参看藏干。
- 通行口诀（地支藏干歌）可在八字命理各页的具体论述中看到运用，此处仅说明概念。

## 干支的运用一览（本站交叉参考）

- **命理（八字）：** 年月日时四柱皆以干支表示，见《[八字基础](/fate/bazi)》及命部各篇。
- **历法节气：** 干支纪时与二十四节气结合，是节气查询工具与运气学说的计时基础。
- **医（运气学说）：** 《黄帝内经》五运六气以干支推步（岁运、司天、在泉），见《[黄帝内经](/tcm/huangdi/what)》相关论述。
- **卜（六爻纳甲）：** 装卦纳甲需将天干地支纳入卦爻，见《[六爻](/divination/liuyao)》。
- **相（风水罗盘）：** 罗盘二十四山即由干支与八卦组成，见《[风水](/face/fengshui)》。
- **纳音：** 六十甲子配纳音五行，见《[纳音](/fate/nayin)》。

## 学习建议

- 先记十天干、十二地支的**顺序与阴阳五行属性**（可与《[五行](/fate/wuxing)》对照表并看）。
- 再背六十甲子循环（"甲子乙丑海中金……"一类口诀可辅助记序与纳音）。
- 后学地支六合、三合、六冲三组核心关系，其余关系随具体术数需要再补充。
- 干支是工具而非目的，宜在八字、六爻、风水的实际阅读中反复接触，自然熟习。
