# 用神
- 用神是子平命理（八字命理）里的核心概念之一，指对命局能起关键补救、平衡作用的那一类力量。
- 一张八字排出后，先看日主（日柱天干）的旺衰，再结合整个命局的强弱、寒暖与生克关系，从中选定某个天干、地支或五行作为全盘分析的“枢纽”，这个枢纽就是用神。
- 用神可以落实到具体某一个字，也可以归结为某一五行；实际论命中常以“十神”（正官、七杀、正印、偏印、比肩、劫财、食神、伤官、正财、偏财）的名称来称呼它。
- 确定用神，是从“排八字、看格局”进入“论喜忌、断吉凶”的关键一步：用神一定，才知道哪些力量对命局有益、哪些有害。

## 什么是用神
- 通俗地说，用神就是命局里“最需要的那股力量”。传统说法认为，八字中日主与其余七个字之间普遍存在生克、强弱、寒暖的失衡，取用神的目的就是把这种失衡重新调回相对平衡的状态。
- 取用神时通常会连带讨论一组相对概念：
    - 喜神：帮助用神、与用神同气连枝、对命局有利的力量。
    - 忌神：克制、冲害用神、对命局不利的力量。
    - 另有“仇神、闲神”等进一步细分，本文只作提示、不展开。
- 需要说明：这套“选枢纽、分喜忌”的方法是传统命理的理论框架，属于经验性的归纳说法，并非现代科学意义上的定论。

## 取用神的几种常见思路（传统说法）
- 传统子平取用神有若干常见视角，各流派侧重不同，以下只做入门介绍，每种给一个大意式的例子，不展开排盘过程：
- **扶抑（以平衡日主强弱为主）**
    - 日主过强（身强），取能克制、消耗、泄化它的力量来“抑”，即传统所说的身强喜克、泄、耗。
    - 日主过弱（身弱），取能生助、扶持它的力量来“扶”，即身弱喜生扶。
    - 举例：某命局木气过旺、日主太强，就可能以金（克木）或火（泄木）为用神。
- **调候（以调和寒暖燥湿为主）**
    - 讲究命局与时令的关系，当寒暖燥湿明显偏于一端时，取相应五行来“调候”。
    - 传统说法如：生于寒冬、全局偏寒者喜火暖局，常以丙火一类作调候考虑；生于盛夏、偏于燥热者则喜水润局。此思路为传统理论主张。
- **通关（以化解两行相战为主）**
    - 命局中两股力量直接相冲相克、互不相让时，取能让二者“流通”起来的中间五行化解。
    - 举例：金木相战，可取水通关，使金生水、水生木，把对抗转为连续相生之势。
- **病药（以对症去病为主）**
    - 把命局中最明显的失衡、弊害处看作“病”，能把病治好的那个字或五行就是“药”，即用神。
    - 大意类似对症下药：先找出病在何处，再找对应的药。传统命书对这类思路多有阐发，如《滴天髓》《子平真诠》等均涉及取用与喜忌的讨论（本文只引书名，不作原文摘录）。

## 用神与喜忌
- 用神确定之后，命局中的其他力量便按与用神的关系大致分成两方：
    - 与用神同党、能助其发挥作用的一方，为喜（喜神）；
    - 与用神相背、会削弱或冲坏用神的一方，为忌（忌神）。
- 传统推断岁运（大运、流年）吉凶的思路，就是看某一步运、某一年出现的干支站在哪一边：
    - 生扶用神与喜神、能制住忌神的岁运，传统认为偏吉；
    - 生旺忌神、克害用神的岁运，传统认为偏凶。
- 这只是一个框架性的传统推演思路；实际判断还要结合格局、宫位、十神配置等综合权衡，并非“见到某五行就定吉凶”的简单对应。

## 专旺与从格特例
- 有一类命局，日主或某一五行强旺到“既不能抑、也不便扶”的程度，传统称之为“从格”或“专旺格”。
- 这类格局的取用思路与常规相反：
    - 从强、专旺一类，不逆其旺势，反以所旺之五行为用，讲究顺势。
    - 从弱（弃命从势）一类，不以扶助日主为要，而以所从的财、官等力量为用。
- 另有“化气格”等特殊说法，同样属于取用上的特例。
- 需要特别提醒：专旺、从格的成立条件很严格，各流派认定标准分歧较大，同一个八字可能有人论从、有人论正；本文仅提示存在这类思路，不展开具体操作。

## 提示
- 取用神历来是命理中最有争议的环节之一：不同流派（如传统子平诸家）取法不同，即便同一流派，不同师傅的看法也常有出入，用神定法并非唯一。
- 本页只做术语与框架层面的入门介绍，所述均为传统说法，不承诺任何预测效果，也不代表现代科学结论。
