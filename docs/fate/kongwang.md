# 空亡

四柱排出来，有人会被告知「这一柱落空亡了」。听起来像某个字被抹掉了，其实不是——空亡是六十甲子相配时留下的**结构性剩余**，不是谁判给它的吉凶。

## 一、空亡是怎么来的

六十甲子由十天干与十二地支按固定顺序相配而成，10 与 12 的最小公倍数是 60，所以六十组一循环。详见[天干地支](/fate/ganzhi)与[八字基础](/fate/bazi)。

但排列方式决定了另一件事：每十组为一旬，一旬之内**天干正好用完一轮，地支却只用掉十个**，于是每旬必然余下两个地支无处可配。这两个地支，就是该旬的「空亡」，也称「旬空」。

所以空亡不必当成需要背吉凶的符号——它是一道算术题的必然结果。

规律很直白：**从旬首地支往后数第十、第十一位**。甲子旬自子起算，第十、十一位是戌、亥；甲戌旬自戌起算，第十、十一位是申、酉——依此类推。

## 三、怎么查自己四柱的空亡

**以日柱定旬是主流做法**（亦有以年柱起旬者，各派不一）。步骤只有三步：

1. 看日柱落在哪一旬；
2. 记下该旬所空的两个地支；
3. 四支（年、月、日、时）中凡出现这两个字者，即为落空。

举例：日柱为**甲子**，落在甲子旬，空戌亥。若四支依次为 戌、亥、子、寅，则**年支戌、月支亥**落空，日支子与时支寅不落空。

自己四柱的空亡情况，[八字查询工具](/fate/query/baziQuery)的结果里有对应栏目，可以对着盘核。

## 四、落空了会怎样

传统用法大致分三层，按可靠程度从高到低排：

**其一，作「减力」看，不作「消失」看。** 这是最通行的一条：某支落空只表示该支之力**偏虚**，不等于「有这个字就当没有」。日支落空，不代表配偶宫就此空掉；财星落空，也不等于财路断绝。它在《[八字怎么批](/fate/piming)》里被归为**论断参考**，而非结构必需项。

**其二，按十神性质分吉凶倾向。** 传统有「吉神落空则减吉、凶煞落空则减凶」的说法——[用神](/fate/yongshen)、财官印食这类吉的字落空，被认为成事打折；而煞、刃之类凶的字落空，反被认为减轻。这条属**倾向性说法**，须放回整个命局看，不能凭一字定论。十神含义见《[十神](/fate/shishen)》。

**其三，看「填实」与「冲空」。** 空掉的地支在大运、流年里重新出现，称「填实」；被冲，称「冲空」。传统认为两者都会让该支恢复作用，而究竟吉凶仍看该支本身的喜忌。所以空亡不是终身判词，得放进[大运与流年](/fate/dayun)里逐段看。

**柱位差异**也常被提及：年支空涉祖上与少年、月支空涉父母与事业宫、日支空涉配偶宫、时支空涉子女与晚年。这是一套**宫位说**，各家取用不同，只能当参考坐标，不宜作结论。

## 五、常见误解

- **见空亡就断凶、断无。** 空亡本身不含吉凶，它标的是「力虚」；吉凶要看这个字在命局里扮演什么角色。
- **以为只在日柱论空亡。** 查旬可先日柱、也可年柱，各派不一；而落空的前提是那一支确实出现在四支之中。
- **把空亡算作神煞。** 它不是神煞——神煞是另立名目的一套符号系统，见《[神煞](/fate/shensha)》；空亡是干支自身的结构剩余。
- **忽略填实与冲空。** 只看原局四个字，会漏掉大运流年带来的变化。
- **拿单一符号断具体事。** 「空亡所以破财」「空亡所以婚姻不顺」这类推断，跳过了喜忌与全局，属过度简化。

## 提示

- 空亡的用法各家分歧较大：有主张只作「减力」的，有主张按吉凶分论的，也有主张填实即解、冲空即破的，取舍标准并不统一。
- 本文属干支结构与术语层面的知识整理；具体命例的判断须结合喜忌与全局，不在本文范围。
- 命理内容是传统文化知识的整理介绍，不作预测承诺。
