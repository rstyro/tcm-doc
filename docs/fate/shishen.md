# 十神

- 十神是子平命理（八字命理的主要流派）的专用称谓体系，属于分析术语。
- 它以出生日柱的天干（日干，又称日主、日元）为“我”，将四柱中其余天干以及地支所藏的天干，逐一与“我”比较。
- 比较只取两个维度：五行生克与阴阳异同。由此得到十种名称，合称“十神”。
- 十神包括：比肩、劫财、食神、伤官、偏财、正财、七杀（偏官）、正官、偏印（枭神）、正印。
- 本页整理十神的推算、别名与传统含义，供阅读排盘与命理资料时对照参考。

## 十神的推算原则

- 推算十神以日主为参照，先分五行生克关系，再看阴阳异同。
- 五行生克分为五类：
    - 同我：与日主五行相同。
    - 生我：五行生助日主（如木日主，水为生我）。
    - 我生：日主所生之五行（如木生火）。
    - 克我：五行克制日主（如金克木）。
    - 我克：日主所克之五行（如木克土）。
- 阴阳异同分两类：对象天干与日主阴阳相同，或阴阳相异。
- 两类组合即得十神，传统命名为：
    - 同我：同阴阳为比肩，异阴阳为劫财。
    - 我生：同阴阳为食神，异阴阳为伤官。
    - 克我：异阴阳为正官，同阴阳为七杀（偏官）。
    - 我克：异阴阳为正财，同阴阳为偏财。
    - 生我：异阴阳为正印，同阴阳为偏印（枭神）。
- 可留意的是：官、财、印三组都以“阴阳相异者为正”，故有正官、正财、正印；七杀又称偏官，偏印又称枭神。
- 举例以助理解：设日主为甲木，则见乙木为劫财；见丙、丁分别为食神、伤官；见庚、辛分别为七杀、正官；见戊、己分别为偏财、正财；见壬、癸分别为偏印、正印；见甲为比肩。

## 十神一览

- **比肩**：与日主同五行、同阴阳，如同胞兄弟。传统认为主自身、同辈与自立，命局比肩多者常显独立好强。
- **劫财**：与日主同五行、异阴阳，有“分夺”之意。传统认为主同辈间的竞争与助力并存，多者行动力强，也防因朋友合伙而起破耗。
- **食神**：日主所生、同阴阳。传统列为福神之一，主口福、才艺与福泽；女命亦常以食神论子女。心性宽和乐观。
- **伤官**：日主所生、异阴阳。传统认为主聪明外露、才气与表现欲；多者不喜受拘束、言辞锋利，宜创造表达之途。
- **偏财**：日主所克、同阴阳。传统认为主流动之财与机缘，男命亦常以偏财看父亲；性情多慷慨、善交际。
- **正财**：日主所克、异阴阳。传统认为主正当稳定的财源，重勤俭守成；男命以正财为正妻星。
- **七杀（偏官）**：克日主、同阴阳，气势刚猛。传统认为主威权、魄力、压力与竞争，身强能任者多果断敢为。
- **正官**：克日主、异阴阳。传统认为主贵气、官职、名誉与法纪，如上级之管束与赏识；女命以正官为夫星。
- **偏印（枭神）**：生日主、同阴阳。传统认为主偏门学问与冷静思辨；因会克伤食神，古有“枭神夺食”之说，喜忌须随命局论。
- **正印**：生日主、异阴阳。传统认为主母亲、文书、名誉与荫庇，为生身护佑之神，主慈爱与福荫。

## 十神与六亲

- 传统上十神常与六亲对应，但因男命、女命及各派师承不同，说法略有差异，以下为常见说法。
- 母亲：一般以正印为母；父亲一说以偏财为父（与正印为母相配），亦有以偏印为父的派别。
- 配偶：男命多以正财为妻星，女命多以正官为夫星。
- 子女：常见说法有“女命以食伤为子女”“男命以官杀为子女”，细分如以食神为子、伤官为女，或七杀为子、正官为女，随流派而别。
- 兄弟姊妹与同辈：以比肩、劫财对应。
- 需要说明：六亲对应只是象征性归类，亲属吉凶仍须结合宫位、旺衰与全局来看，不能机械套用（传统说法）。

## 十神与心性事业取向

- 传统命书常以十神多寡归纳心性与事业倾向，以下为经验性概括，仅供参考。
- 正官多者：传统称“官主贵”，多显稳重守纪，适合管理、公职等需秩序与规则的工作。
- 七杀多者：传统称“杀主威”，多显魄力与开创性，传统上联想军警、外科等需决断力的领域。
- 正财多者：勤俭务实，善守成理财；偏财多者：慷慨活络，长于经营、聚人与把握机缘。
- 食神多者：传统称“食主福”，常与美食、艺术、技艺有关；伤官多者：聪明外显，适合创意、设计、表达类工作。
- 正印多者：传统称“印主文”，利文教、文书与学术；偏印多者：宜偏门专精、研究与特殊技能。
- 比肩、劫财多者：一重自立、一重行动，与人合作时均须结合格局论其利弊。

## 提示

- 十神只是八字分析的术语框架之一。同一十神因日主旺衰、格局清浊、所处宫位与大运流年的不同，表现与吉凶可能相差很大。
- 传统论命须以旺衰（可参看十二长生、五行诸页）、月令格局、用神并结合大运流年综合判断，不凭十神多寡单独论断。
