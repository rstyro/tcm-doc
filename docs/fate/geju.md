# 格局

- 子平命理在排出八字原局后，还需对命局作定性分析，其中重要的一步是“定格局”。
- 格局之学，以月令（月支及其所藏之气）与日主（出生日的天干）的关系为主要依据，把千差万别的命局归纳为若干典型结构。
- 传统认为格局反映命局的贵贱层次与结构主次，也是后续取用神、辨喜忌的重要框架之一。

## 什么是格局

- “格”指命局所属的类型。子平传统的主流做法是“以月令取格”：月支为一月节令的提纲所在，故月令又称“提纲”。
- 通行说法是：看月支所藏的主气（本气）是否透出于天干，再以该透干与日主的关系定格；若藏干均不透，也常见直接以本气取格的做法，各派取法并不完全相同。
- 定格局是传统论命的分层手段：先分出大类（常格与特殊结构），再看该结构内部是否纯粹、有力。

## 八格

- 正官格：月令为官星、能成格者，传统视为较端正贵气的格局。
- 七杀格：月令为七杀（偏官），性较刚烈，传统主张须制化得宜方为贵。
- 正财格：月令为正财，主财利与经营之事。
- 偏财格：月令为偏财，亦主财帛，论法与正财有别。
- 正印格：月令为正印，主学识、庇护与内涵。
- 偏印格：月令为偏印（倒食），亦主才学偏艺，须防夺食之弊。
- 食神格：月令为食神，主福气、才艺与表达。
- 伤官格：月令为伤官，主才华外放，传统谓喜泄秀或佩印，须视组合而定。
- 以上即传统所称“八格”，大体按“月令透干”或“月支本气”的通行说法取定；不同派别对透干条件、混杂与否的判断存在差异。
- 羊刃格与建禄格是两类较特殊的结构，有的著作归入外格另论：羊刃格为月支临日主之刃，气势偏旺；建禄格为月支临日主之禄（又称月令建禄），日主有根而月令无官财食伤可取，论法与常格不同。各派归类与取法不一，此处只作简介。

## 外格（变格）

- 除八格等常格之外，历代命书还列有一批特殊结构，统称外格或变格，名目繁多，各家互有出入。
- 从格：当日主极弱、四柱又无根无助，而财、官、食伤等异党势力专旺时，传统认为日主“不得不从”，遂论从格，大致分为两类：
  - 从强者：全局印比一气成势，日主顺势而从旺，如按一方专旺之气论的结构。
  - 从弱者：全局以异党为主，日主从之，常见如从财格、从杀格、从儿格等，分别以财、七杀、食伤为主气。
- 化气格：指天干五合（如甲己合）在化神得令得势、不见克制等条件下论“化”的格局。
- 传统对外格讲究“真从”与“假从”之别：真从者全局气势一体，假从者尚有不服之气，行运判断随之有别。
- 需说明：外格的判定争议在诸格中最大，是否可从、真从假从如何区分，各派有细致规则；本文只作概念介绍，不展开操作细节。

## 成格与破格

- 传统认为格局有成与破之分：所谓“成格”，大致要求结构清纯、主气有力，且有护卫或制化得宜。
- 所谓“破格”，指结构遭到破坏的情形，例如官星被冲伤合去、喜用受损、或官杀混杂而制化失宜等，诸书说法繁复。
- 清纯、混杂、有护卫、受破坏等判断，实际都要回到十神关系与命局整体来看，并非一句术语可以定论。

## 格局与用神的关系

- 格局回答“命局属于哪一类结构”，用神回答“这一结构如何补偏救弊”。
- 通行次序是：先定格局，再据格局与原局的强弱虚实取用神、分喜忌，论大运流年也围绕喜用展开。
- 二者配合使用：同为财格，身强身弱取用不同；同为食神格，透官与不透官论法也不同。

## 提示

- 格局之学体系庞大，派别分歧多。例如《子平真诠》重在按月令讲格局、条理较整，而《滴天髓》更重气势与体用，两书思路有别；本页仅提及书名，不作原文摘引，亦不涉及具体页码。
- 文中所称“传统认为”“通行说法”之处，均指流传较广的概括性说法，具体判定应参照诸家原著，多本对照为宜。
