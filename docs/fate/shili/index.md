# 命盘实例

- 《[八字怎么批](/fate/piming)》把批命的完整流程拆成七步——**排盘 → 立极 → 察旺衰 → 定格 → 取用 → 看组合 → 推岁运**。但步骤表读起来终究抽象，真正难的是「七个环节怎么串到同一张盘上」。
- 本栏目专门用**完整的命盘**把这条流程从头走一遍：每一张盘都按七步逐节推演，把引擎算出的结果与每一步的判据摆在一起，演示 **「怎么推」而不是「推得准不准」**。
- 两张示例同为**辛金日主**，一强一弱、喜忌完全对调，最适合对照着读：

| 示例 | 四柱 | 日主强弱 | 用神 | 看点 |
| --- | --- | --- | --- | --- |
| [实例一：辛金生申月](/fate/shili/example1) | 丁丑　戊申　辛卯　乙未（男） | **偏强** | 火（次水） | 得令得地得势、取格三法各异、命中无火 |
| [实例二：辛金生卯月](/fate/shili/example2) | 戊午　乙卯　辛巳　乙未（女） | **偏弱** | 土金 | 财多身弱、三会火局、取用三法不同向 |

## 两张盘为什么这样选

- **同一日主，强弱相反。** 两例的日元都是辛金，只看这一个字，长像是「一样」的；可一旦比旺衰，实例一金得月令、有强根，实例二却月令耗身、无强根，判若两盘。**旺衰是批命的第一道分水岭**，两例放在一起，这一点就藏不住了。
- **喜忌正好对调。** 同一个「火」，在实例一是制旺金、暖凉局**的用神**；在实例二却是克单薄之身、又助火局**的忌神**。八字里没有「绝对的吉神凶神」，吉凶全随日主而定——这是传统命理最核心也最易被误解的一条。
- **排运走出了两条路。** 实例一是「阴年男命」，实例二是「阳年女命」，按「阳男阴女顺排、阴男阳女逆排」，两条不同来路都归到**逆排**，可顺带记住这条口诀。

## 每个示例怎么读

- 两页都严格按七步走，读的时候可以这样跟：

| 步 | 页面小节 | 该盯住什么 |
| --- | --- | --- |
| 一 | 排盘 | 四柱、藏干、旬空、五行分布——先把「原料」摆齐 |
| 二 | 立极 | 认出日主（日干），后面一切以它为中心 |
| 三 | 察旺衰 | 得令 / 得地 / 得势三项合看，定强弱 |
| 四 | 定格 | 以月支取格，留意各家取法是否一致 |
| 五 | 取用神、分喜忌 | 扶抑 / 调候 / 通关三法是否同向 |
| 六 | 看组合 | 刑冲合害、宫位、十神——把静态的四柱看活 |
| 七 | 推大运流年 | 看岁运引动了原局哪一方，而非孤立看好坏 |

- **每一页都刻意保留了分歧点**：取格各家不同、取用三法不完全同向、宫位论断留有几处虚点。这不是没写清，而是**传统命理本就如此**——它给的是倾向与框架，不是唯一答案。
- 想自己练手，先用[八字查询工具](/fate/query/baziQuery)把自己的生辰排成四柱，再拿这两页的七步，一步一步往上套。

## 说明

- 本栏两个命造均为**教学编制的示例，生辰虚构，非真人**；推算过程取自本站[八字查询工具](/fate/query/baziQuery)的同一套算法，结论为传统术数语言。
- 内容供了解传统文化与命理术语之用，**不构成预测、医疗或现实决策建议**，不承诺任何预测功效。取格、取用、起运折算等环节各派分歧极大，两页所述均取较通行的做法，不代表唯一答案。
