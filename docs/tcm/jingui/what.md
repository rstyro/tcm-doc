# 金匮要略

- 《金匮要略》，全称《金匮要略方论》，是传统医学四大经典之一《伤寒杂病论》的杂病部分。
- 东汉张仲景著《伤寒杂病论》，后世（一般认为宋代林亿等整理校订时）将其分为两书：外感病部分成《伤寒论》，杂病部分则传为《金匮要略》（通行说法）。
- 篇名"金匮"取"藏之金匮、珍重宝贵"之意，"要略"谓其撷取精要、言简义赅。

## 与《伤寒论》的关系

- **同源：** 《伤寒论》与《金匮要略》同出张仲景《伤寒杂病论》，合观才是完整的仲景学术；历来有"伤寒论讲外感、金匮讲杂病"的粗略区分。
- **互补：** 《伤寒论》以六经辨证论外感热病；《金匮要略》以内科杂病为主，兼及妇科、外科等，分篇列证，是脏腑辨证与方证对应的典范。
- 学习路径上，一般建议先研《伤寒论》六经辨证，再入《金匮》杂病各篇（此为本站倪注伤寒论前言的观点，可参《[伤寒论·前言](/tcm/shanghanlun/start)》）。

## 内容与篇目概况

- 《金匮要略》通行本共二十五篇，内容以杂病辨证论治为核心，兼载妇人病等。篇目大致涵盖：
    - **脏腑经络先后病脉证（总纲）**
    - 痉湿暍、百合狐惑阴阳毒、疟病、中风历节、血痹虚劳等病证
    - 肺痿肺痈咳嗽上气、奔豚气、胸痹心痛短气等胸肺病证
    - 腹满寒疝宿食、五脏风寒积聚、痰饮咳嗽、消渴小便利淋等
    - 水气病、黄疸、惊悸吐衄下血胸满瘀血、呕吐哕下利、疮痈肠痈浸淫等
    - 趺蹶手指臂肿转筋阴狐疝蛔虫等杂疗
    - 妇人妊娠病、妇人产后病、妇人杂病
- 历代注家众多，清代尤怡《金匮要略心典》、民国以来各家集注，都是研读的重要参考。

## 学习提示

- 金匮各篇多以"某某病脉证并治"命名，读法与伤寒论条文相似：先明主证、再识病机、后对治方。
- 仲景方药讲究"方证对应"，学习时宜将方剂与证候（病机要点）配对记忆，不必死背条文。
- 通行本末三篇（杂疗方、禽兽鱼虫禁忌并治、果实菜谷禁忌并治）性质与病证方治不同；另有版本把痉湿暍、百合狐惑阴阳毒、疟病等编次前后互异，读他本时留意对照。
- 本站伤寒论前言亦提示：先伤寒、后金匮为较稳妥的进阶次序，可与本页对照阅读。
