# 经络与腧穴

- 经络是中医关于**人体联系通路**的学说：它把脏腑与体表、上下内外连成一张网，气血靠它运行，针刺靠它起作用。
- 《灵枢·第 33 篇·海论》给经络下了最简洁的定义：「夫十二经脉者，内属于府藏，外络于肢节。」——向内连属脏腑，向外网络四肢关节。[见原文](/tcm/huangdi/lingshu/lingshu33)
- 《灵枢·第 10 篇·经脉》则点明它的分量：「经脉者，所以能决死生，处百病，调虚实，不可不通。」[见原文](/tcm/huangdi/lingshu/lingshu10)
- 《灵枢·第 47 篇·本藏》从功能上补了一句：「经脉者，所以行血气而营阴阳，濡筋骨，利关节者也。」
- 需要事先说明：经络的**解剖学实质**至今没有公认结论。学界有神经说、血管说、体液说、筋膜结缔组织说等多种解释，也有一些实验提出了尚未被普遍接受的结论。本页介绍的是传统理论本身，不对其实质下断言。

## 经络系统的构成

- 整个系统按「**经脉**（主干）—**络脉**（分支）—**连属部分**（附着结构）」三层来组织：

| 层次 | 内容 | 说明 |
| --- | --- | --- |
| 经脉·正经 | 十二经脉 | 气血运行的主要通道，左右对称，与脏腑直接配属 |
| 经脉·奇经 | 奇经八脉 | 督、任、冲、带、阴跷、阳跷、阴维、阳维；不拘于脏腑配属，起调节作用 |
| 经脉·附 | 十二经别 | 从十二经脉分出的支脉，加强表里两经与脏腑的深层联系 |
| 络脉 | 十五络脉、浮络、孙络 | 十五络为十二经加任督各一、脾之大络；浮络行于体表，孙络最细密 |
| 连属 | 十二经筋、十二皮部 | 经筋主约束骨骼、司关节活动；皮部把体表按经脉分区 |

## 十二经脉

- **命名规则**：由「手/足」+「阴/阳」+「脏腑名」三段构成，一看名字就知道循行的大致区域与归属脏腑。
    - 手三阴（从胸走手）：手太阴肺经、手少阴心经、手厥阴心包经。
    - 手三阳（从手走头）：手阳明大肠经、手太阳小肠经、手少阳三焦经。
    - 足三阳（从头走足）：足阳明胃经、足太阳膀胱经、足少阳胆经。
    - 足三阴（从足走腹胸）：足太阴脾经、足少阴肾经、足厥阴肝经。
- **走向与交接**有一条便于记的口诀：手之三阴，从胸走手；手之三阳，从手走头；足之三阳，从头走足；足之三阴，从足走腹（胸）。概括起来即「**阴升阳降**」——阴经之气上行，阳经之气下行，如此形成循环。
- **流注次序**（十二经气血依次相传）：
    - 肺 → 大肠 → 胃 → 脾 → 心 → 小肠 → 膀胱 → 肾 → 心包 → 三焦 → 胆 → 肝 → 复归于肺。
    - 一日一夜运行五十周，见《灵枢·第 15 篇·五十营》《第 16 篇·营气》。[见原文](/tcm/huangdi/lingshu/lingshu15)
- **表里配属**：每一脏经与一腑经相配（肺—大肠、心—小肠、心包—三焦、脾—胃、肝—胆、肾—膀胱），互为表里，在生理与病理上相互影响。这条关系是「脏病治腑、腑病治脏」以及「原络配穴」等针法的根据。

## 奇经八脉

- 八条经脉不属于十二正经，也不与脏腑直接配属，故称「奇」。
    - **督脉**：行于身背正中，上头面。总领一身之阳，称「**阳脉之海**」。
    - **任脉**：行于身腹正中，上至咽喉。总任一身之阴，称「**阴脉之海**」，与妊娠关系密切。
    - **冲脉**：与任督同起于胞中，为「十二经之海」，又称「**血海**」，主生殖与月经。
    - **带脉**：环绕腰腹一周，如束带，约束纵行的诸经。
    - **阴跷、阳跷**：主司下肢运动与眼睑开合（「跷」有轻健之意）。
    - **阴维、阳维**：维系联络诸阴经或诸阳经（「维」有维系之意）。
- 奇经八脉的总作用是**沟通、蓄溢与调节**：当十二经脉气血有余时予以蓄藏，不足时予以补充。

## 腧穴

- 腧穴是脏腑经络之气输注于体表的部位，也是针灸、推拿施术的位置。按归属分三类：
    - **十四经穴**：归属于十二经脉与任督二脉的穴位，有固定位置、固定名称与归经，是主体部分。其系统整理始于晋代皇甫谧《针灸甲乙经》，现代通行的标准穴位数为 **361 个**（2006 年国家标准）。
    - **经外奇穴**：有固定位置与名称但未归入十四经的穴位，如太阳、印堂、四缝等。
    - **阿是穴**：无固定位置，以压痛点或反应点为穴，即「以痛为腧」。
- **特定穴**是十四经穴中具有特殊治疗作用与特定称号的一批穴位，针灸配穴多依据它们：
    - **五输穴**：每条经在肘膝以下各有井、荥、输、经、合五穴，配属五行，主治有「井主心下满，荥主身热，输主体重节痛，经主喘咳寒热，合主逆气而泄」之说。
    - **原穴**与**络穴**：原穴为该经原气所留止，络穴为表里两经联络之处；临床上常以「原络配穴」法同用。
    - **俞穴**（背俞，位于背部膀胱经）与**募穴**（位于胸腹部）：前者为脏气输注于背处，后者为脏气汇聚于腹处，合称「俞募配穴」，用于治疗相应脏腑病证。
    - **郄穴**：经脉之气深聚之处，多用于急症与痛证。
    - **八会穴**：脏、腑、气、血、筋、脉、骨、髓八者之精气所会，各有一穴主之。
    - **八脉交会穴**：十二经中通于奇经八脉的八个穴位，上下配合治病。
    - **下合穴**：六腑之气下合于足三阳经的六个穴位。
- 腧穴的定位方法有骨度分寸法、体表标志法、手指同身寸法与简便取穴法，具体做法见站内《[黄帝内经](/tcm/huangdi/what)》相关篇章及针灸专书，此处不展开。

## 经络的作用

- 传统理论把经络的功能概括为四项：
    - **联系脏腑、沟通内外**——把分散的脏腑、形体、官窍连成整体。
    - **运行气血、濡养全身**——气血赖经络输送到各处。
    - **抗御外邪、保卫机体**——卫气循经络布散于体表，邪气入侵时经络首当其冲。
    - **传导感应、调整虚实**——针刺之所以能「调虚实」，理论上即通过经络的感应传导实现。
- 前两项好理解，后两项是**针灸疗法的理论支点**：如果经络不存在传导功能，针刺远端穴位治内脏病就无从解释。现代研究对针刺镇痛的效应积累了不少证据，但对其机制的解释（神经机制、筋膜机制等）仍与经络学说不同。

## 提醒

- 经络的实质尚无公认的解剖学对应。把它当作一套**沿用了两千年的功能分区与联系模型**来理解是稳妥的；宣称已「科学证明经络存在」或「彻底证伪」的说法，都需要打折扣看待。
- **针刺、艾灸、推拿都是医疗行为**。自行在非正规场所接受针刺存在感染、气胸、神经损伤等实际风险；孕妇、出血倾向者、装有心脏起搏器者等尤其要谨慎。请到正规医疗机构就诊。
- 网络上流传的「按压某穴包治某病」「按穴位减肥」一类说法，多无可靠依据，且常与推销绑定。本页只讲理论结构，不提供任何穴位主治的自我诊疗建议。
