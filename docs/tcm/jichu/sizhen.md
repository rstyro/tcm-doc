# 四诊

- 四诊即**望、闻、问、切**四种诊察方法。它不是四个独立的检查项目，而是围着同一个病人从四个方向收集信息，最后必须综合起来看——这就是「**四诊合参**」。
- 《素问·卷二·阴阳应象大论》给出诊法的总原则：「善诊者，察色按脉，先别阴阳。」先分阴阳，再谈细节。
- 《素问·卷三·五藏生成篇》进一步说「能合色脉，可以万全」——望色与切脉要合看，单凭一项容易出错。这一条其实是对「只看脉就开方」与「只看脸色下结论」两种做法的告诫。
- 诊法理论还包含一层自省。《素问·卷二十三》有《疏五过论》《徵四失论》两篇，专门批评医生常犯的五种过失与四种失误，如不问病人社会境遇（「尝贵后贱」「尝富后贫」）就下判断、不知比类奇恒就妄言。这两篇是中医医德与临床规范的重要文献。[见原文](/tcm/huangdi/suwen/suwen23)

## 望诊

- 望诊居四诊之首，古人认为「有诸内，必形诸外」，最直观。主要内容包括：

### 望神

- 神是生命活动的外在表现，望神重在**目光、面色、表情、语言、体态**。分四种情况：
    - **得神**（有神）：目光有神、面色荣润、反应灵敏、气息平稳——正气尚充，病较轻或预后良好。
    - **少神**：精神不振、目光乏神、倦怠乏力——正气不足，多见于轻病或恢复期。
    - **失神**：目光晦暗、精神萎靡、反应迟钝、甚则神昏——正气大伤，病重。
    - **假神**：久病重病之人突然精神转佳、面色泛红、言语不休、欲进饮食——这是阴阳即将离决的危候，古称「回光返照」，须格外警惕。

### 望色

- 主要看面部色泽（「色」为色调，「泽」为荣润程度），五色主病的通行说法如下：

| 面色 | 主病 | 说明 |
| --- | --- | --- |
| 青 | 寒证、痛证、瘀血、惊风 | 寒凝气滞、经脉挛急，或肝风内动 |
| 赤 | 热证 | 实热多满面通红；虚热多两颧潮红 |
| 黄 | 脾虚、湿证 | 萎黄为脾虚，黄胖为湿困，黄疸则目黄身黄 |
| 白 | 虚证、寒证、失血 | 苍白多阳气暴脱或大失血，晄白多阳虚 |
| 黑 | 肾虚、寒证、水饮、瘀血 | 面黑暗淡多肾阳虚，焦黑多肾阴耗竭 |

- 「泽」比「色」更关键：色泽明润者预后多佳，晦暗枯槁者病多重。这一点在古籍中反复强调。

### 望形态、五官与舌

- **形体**：强壮与瘦弱反映体质与虚实；**姿态**：躁动不安多属热证、实证，蜷卧少动多属寒证、虚证。
- **五官**：目（眼神最重要，亦察目色、目形）、鼻、口唇（唇色淡白主虚、青紫主血瘀）、齿龈、咽喉（红肿多热，淡红多虚）。
- **小儿指纹**：三岁以下小儿看食指内侧络脉的浮沉、色泽、长短，以代脉诊。浮沉分表里，红紫辨寒热，淡滞定虚实，三关测轻重。这是四诊中颇具特色的一支。
- **舌诊**是望诊中信息量最大的一项，通常分看舌质与舌苔：
    - **舌质**（舌的本体）：淡白主虚寒或气血不足；红主热；绛（深红）主热入营血；紫暗或有瘀斑主血瘀。舌形有胖大（多脾虚湿盛）、瘦薄（多阴血亏虚）、齿痕、裂纹、芒刺之别；舌态有强硬、痿软、震颤、歪斜（歪斜常与中风相关）之别。
    - **舌苔**（舌面苔状物）：白苔多主表证、寒证；黄苔多主热证；灰黑苔多主热极或寒盛。苔质分厚薄（辨邪之深浅）、润燥（辨津液盈亏）、腻腐（辨湿浊与食积）、剥落（辨胃气与阴伤）。
- 《灵枢·第 49 篇·五色》是望色的专篇；《[伤寒论](/tcm/shanghanlun/start)》中舌诊的运用也值得对照阅读。

## 闻诊

- 闻诊包括**听声音**与**嗅气味**两方面。
- **听声音**：
    - 语声强弱：高亢有力多实证、热证；低微无力多虚证、寒证。
    - 语言异常：**谵语**（语无伦次、声高有力，多属热扰心神之实证）、**郑声**（语言重复、声低无力，多属心气大伤之虚证）、**独语**（自言自语，多见于心气不足或痰浊蒙蔽）。
    - 呼吸：喘（呼吸困难、张口抬肩）、哮（喉中痰鸣如水鸡声）、短气（呼吸急促而微弱）、少气（呼吸微弱、气不足以息）。
    - 咳嗽：声重浊多外感风寒，声低气怯多内伤；干咳少痰多燥，痰多易咳多湿。
    - 呃逆、嗳气、呕吐、太息（叹息）：皆反映气机升降的异常。
- **嗅气味**：口气（口臭多胃热或食积，酸腐多食滞）、汗与体气、痰涕、二便、经带的气味，皆可辅助判断寒热虚实与有无腐坏。

## 问诊

- 问诊是获取病人主观感受的主要途径，也是四诊中信息量最大的一项。明代张介宾在《景岳全书》中列「十问篇」，清代陈修园编成《十问歌》便于传诵，通行歌词为：
    - 「一问寒热二问汗，三问头身四问便，五问饮食六胸腹，七聋八渴俱当辨，九问旧病十问因，再兼服药参机变，妇女尤必问经期，迟速闭崩皆可见，再添片语告儿科，天花麻疹全占验。」
- 几个重点：
    - **问寒热**：恶寒发热并见多属表证（新病初起），但寒不热多属里寒或阳虚，但热不寒多属里热，寒热往来多属半表半里（如少阳病）。
    - **问汗**：无汗见于表寒或津亏；自汗（白昼不因活动而汗出）多气虚、阳虚；盗汗（睡时汗出、醒则汗止）多阴虚；大汗淋漓伴肢冷脉微为亡阳之兆。
    - **问疼痛**：部位定脏腑，性质辨病机——胀痛多气滞，刺痛固定多瘀血，冷痛多寒，灼痛多热，重痛多湿，隐痛多虚，绞痛多实。
    - **问饮食口味**：食欲、食量、口味偏好（口苦多热、口淡多虚、口甜黏腻多湿）、口渴与否及喜冷喜热，皆关脾胃与津液。
    - **问二便**：便秘有热结、气滞、津亏、气虚之别；泄泻有湿盛、脾虚、肾虚之别；尿黄赤多热，清长多寒。
    - **问睡眠**：失眠有实证（如心火、痰热扰神）与虚证（如心脾两虚、阴虚火旺）之别；嗜睡多阳虚或痰湿。
    - **问经带**：月经周期、量、色、质、痛经情况；带下量色质味。女科问诊的必备内容。
- 《灵枢·第 28 篇·口问》记录了大量问诊得来的病状，可与本段对读。[见原文](/tcm/huangdi/lingshu/lingshu28)

## 切诊

- 切诊分**脉诊**与**按诊**两部分，脉诊最受重视也最被神化，这里讲清它的实际内容。

### 脉诊

- **部位**：通行的方法是「**寸口诊法**」——在手腕桡动脉搏动处切脉，分寸、关、尺三部。以掌后高骨（桡骨茎突）定关，关前为寸，关后为尺，左右两手共六部。
    - 六部与脏腑的配属，历代说法有分歧。较通行的一种是：左手寸候心、关候肝、尺候肾；右手寸候肺、关候脾、尺候命门（或候肾）。另有「左候心肝肾、右候肺脾命」等表述，古人于此争论较多，不宜视作定论。
    - 除寸口外，古代还有遍身诊法（《素问·卷六·三部九候论》：上、中、下三部各分天、地、人三候）与张仲景所用的趺阳脉、太溪脉等，今多不习用。[见原文](/tcm/huangdi/suwen/suwen6)
- **方法**：诊脉讲究「平旦」为宜（病人未受饮食活动干扰），医者需「平息」以定己息，一息四至五至为平脉，一般要求候满**五十动**以上，以察有无结代（《灵枢·第 1 篇·九针十二原》有「五十动」之说）。手法有浮取、中取、沉取，合称「举、按、寻」，反复体察脉象的有力无力与层次深浅。
- **正常脉象（平脉）**：三部有脉，一息四至五至，不浮不沉，不迟不数，从容和缓，柔和有力，节律均匀。古人以「有胃（从容和缓）、有神（柔和有力）、有根（尺脉沉取有力）」为标准，并认为它随四时气候与个体差异而略有变化（春弦、夏洪、秋浮、冬沉的倾向）。
- **病脉**：后世归纳为 **28 脉**（一说 24 脉），常用的基本脉象有：
    - 以部位分：**浮**（轻取即得，主表证）；**沉**（重按始得，主里证）。
    - 以至数分：**迟**（一息不足四至，主寒证）；**数**（一息五至以上，主热证）。
    - 以形态分：**滑**（往来流利如珠走盘，主痰、食、实热或妊娠）；**涩**（往来艰涩不畅，主气滞血瘀、精血亏虚）；**弦**（端直以长如按琴弦，主肝胆病、痛证、痰饮）；**紧**（绷急弹指如转索，主寒、痛、宿食）；**洪**（来盛去衰如水波涛，主气分热盛）；**细**（脉细如线，主气血两虚、诸虚劳损）。
    - 以力量分：**虚**（举之无力、按之空虚）；**实**（三部有力）。
- **需要注意**：脉诊是中医中最容易被玄化的一项。实际上，脉象的判别依赖长期的手感训练与大量临床经验，而且同一个脉象在不同医家笔下的描述并不完全统一。流传的「摸脉断胎儿性别」「一搭脉就知道你得了什么病」等说法**没有任何可靠依据**。

### 按诊

- 用手触摸按压病人体表某些部位以了解病情，包括：
    - 按肌肤：察寒热、润燥、肿胀（按之凹陷不起为水肿，随手而起为气胀）、有无皮疹疮疡。
    - 按手足：四肢冷多阳虚，手足心热多阴虚。
    - 按胸腹：了解痞满、肿块、压痛（拒按多实，喜按多虚）。
    - 按腧穴：探查某些穴位有无压痛或反应物，作为脏腑病变的参考。

## 四诊合参与常见误区

- 四诊各有局限：望诊看不到内部感受，闻诊信息有限，问诊可能因病人表述而失真，切诊对手法要求极高。**四诊合参**要求把它们放在一起交叉印证，矛盾时进一步追询，而不是抓一项就下结论。
- 三个常见误区值得记下：
    - **只看脉**。古人早就批评过。《素问·卷二十三·徵四失论》所诟病的失误之一，就是「诊病不问其始，忧患饮食之失节，起居之过度」，只顾切脉。
    - **凭单一表现定证**。舌红未必是热，也可能是正常人；但见一症便断为某证，是初学者最常犯的错。
    - **忽视处境与情志**。《疏五过论》特别指出要问「尝贵后贱」「尝富后贫」这类社会境遇的剧变——这一点在今天依然适用。

## 提醒

- 四诊是一项**需要长期训练与师承的临床技能**，尤其脉诊。文字能传达的是概念与框架，不能传达手感。读过本页不等于会诊病。
- 自我对照网络上的「舌象诊断图」「脉象自测」来给自己下结论，可靠度极低（且舌苔受饮食、光线、拍摄设备影响极大）。据此服药的风险是实实在在的。
- 任何疾病的确诊都应以执业医师的面诊为准。本页只作理论介绍，不构成诊疗建议。
