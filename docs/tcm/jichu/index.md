# 中医基础理论

- 站内医部此前收录的都是**典籍原文**：《黄帝内经》（素问 81 篇、灵枢 81 篇）、《伤寒论》《金匮要略》《本草纲目》《中药学》《方剂学》。源头是够的，但门槛也高——不熟悉「阴阳」「藏象」「经络」这套语言，原文读起来就只是一堆字。
- 本组是后补的**入门层**：按现代中医学教材的通行框架，把《内经》以来的核心概念拆成十余个专题。每个专题都标出它在原典中的出处，读完可以顺着链接直接跳去看原文。
- 阅读前先明确一件事：这里讲的是**中医学自身的理论模型**，属于传统文化与医学史的知识范畴，与现代医学（循证医学）不是同一套话语体系。中医的「肝」「肾」是功能系统的代号，不等于解剖学上的肝脏与肾脏；「心主神明」也不是说思维由心脏产生。
- 本组只做理论梳理，**不构成任何诊断、处方、用药或自我治疗的建议**。身体不适请到正规医疗机构就诊。

## 中医学的两个基本特点

- **整体观念**：认为人体自身是一个整体（脏腑、经络、形体、官窍在生理上相互联系、病理上相互影响），同时人与自然环境、社会环境也是一个整体（四时气候、地理方域、情志境遇都会影响健康）。
    - 向内的一面：「有诸内，必形诸外」——体内的变化会反映到体表，这是望闻问切能成立的前提。
    - 向外的一面：「人与天地相参」——养生与治病都要考虑时令、地域与个体处境，故有因时、因地、因人「三因制宜」之说。
- **辨证论治**：把四诊收集到的症状体征，综合成某个「证」（证候），再据证立法处方。
    - 「病」「证」「症」三者的区别：病是全过程的总称（如伤寒、消渴），证是某一阶段的病理概括（如「脾胃虚寒」），症是单个表现（如腹痛、乏力）。
    - 「同病异治」与「异病同治」由此而来：同一个病在不同阶段证不同，治法就不同；不同的病若证相同，治法可以相同。
    - 需要注意：中医并非一概只辨证不辨病。急症、专病专方时也会以辨病为主，调理体质、疑难杂症时则以辨证为主。

## 理论体系的来路

- **先秦至西汉**：阴阳五行、精气学说等哲学观念渗入医学，医疗经验开始被整理成系统理论。这一过程的结果就是《黄帝内经》。
    - 《[黄帝内经](/tcm/huangdi/what)》分《素问》《灵枢》两部分，各 81 篇，非一时一人之作，一般认为成编于战国至西汉之间，托名黄帝与岐伯、雷公等问答。
    - 《素问》偏重理论（阴阳、藏象、诊法、治则、运气），《灵枢》偏重经络与针法，但两书内容互有交叉。
- **东汉**：理论进一步落到临床。
    - 《难经》以八十一问的形式补充《内经》，对脉学、经络、命门、三焦等有发挥。
    - 张仲景《伤寒杂病论》创立**六经辨证**体系，把理论与方药结合，后世分为《[伤寒论](/tcm/shanghanlun/start)》与《[金匮要略](/tcm/jingui/what)》，被尊为方书之祖。
    - 《神农本草经》总结药物 365 种，按上、中、下三品分类，提出四气五味、七情和合等药学原则，是[本草](/tcm/bencao/yuanxu)一脉的源头。
- **晋唐**：分科趋于完备。王叔和《脉经》整理脉学，皇甫谧《针灸甲乙经》整理腧穴，孙思邈《千金方》集唐以前医方之大成。
- **金元**：学术争鸣，形成流派。刘完素（寒凉）、张从正（攻邪）、李杲（补土）、朱震亨（滋阴）并称金元四大家，各执一说以补前人之偏。
- **明清**：温病学派兴起。吴有性、叶天士、吴鞠通等针对外感热病提出**卫气营血**与**三焦**辨证，弥补了伤寒法论治温病的不足。同时《本草纲目》集药物学之大成。

## 建议的阅读顺序

- 若完全从零开始，按下面这条线走最顺，前四步是后面所有内容的地基：
    1. [阴阳学说](/tcm/jichu/yinyang) —— 先建立最基本的分类语言。
    2. [五行学说](/tcm/jichu/wuxing) —— 再理解五脏之间怎么「连」起来。
    3. [精气血津液神](/tcm/jichu/qixue) —— 弄清在体内流动的到底是什么。
    4. [藏象学说](/tcm/jichu/zangxiang) —— 把功能落到五脏六腑上。
    5. [经络与腧穴](/tcm/jichu/jingluo) —— 理解联系脏腑、运行气血的通路。
    6. [病因与病机](/tcm/jichu/bingyin) —— 知道「怎么病的」。
    7. [四诊](/tcm/jichu/sizhen) → [辨证方法](/tcm/jichu/bianzheng) —— 知道「怎么看出来、怎么归纳」。
    8. [治则与治法](/tcm/jichu/zhize) —— 知道「据此怎么治」。
    9. [体质学说](/tcm/jichu/tizhi) —— 理解为什么同样的病治不同的人要换方。
    10. [五运六气](/tcm/jichu/yunqi) —— 专为《素问》运气七篇而设，偏推演，可放到最后按兴趣读。
- 若只想读懂原典，也可以反过来走：先读《素问》卷一的《上古天真论》《四气调神大论》这两篇（讲养生，最易懂），再回头补本组的概念。

## 关于本组的取材与写法

- 框架主要参照现代中医学统编教材《中医基础理论》的通行章节（阴阳五行、藏象、精气血津液、经络、病因病机、诊法、辨证、治则），并与《黄帝内经》原文互校。
- 凡引用《内经》原文处，均标出篇名与所属卷次，站内按「素问 24 卷 / 灵枢 81 篇」分页，可直接对照阅读。
- 各家学说在细节上分歧不少（如三焦的实质、命门的位置、五行配属的个别条目、六淫与疫疠的关系），本组遇争议处一般注明「另有他说」，不做独断。

## 提醒

- 中医学理论建立在古代对自然与人体的观察之上，其中相当一部分论述以现代科学标准看属于取象比类与推论。了解它的价值在于读懂传统医学的思维方式与典籍原文，而不是用它替代现代诊疗。
- 中医理论讲究临证权衡，同一症状在不同人身上含义可能相反（真寒假热、真热假寒等）。网络上按症状对号入座的「自测」多不可靠，切勿据此自行服药。
- 任何疾病的确诊与用药，均应以执业医师的面诊为准。孕妇、婴幼儿、老年人及有基础疾病者，尤不可自行试用方药与针刺。
