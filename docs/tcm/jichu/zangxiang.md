# 藏象学说

- 「藏象」二字要拆开看：**藏**（zàng）指藏于体内的脏腑，**象**指表现于外的生理病理征象。合起来的意思是——**通过外在的表现，推知内在脏腑的状态**。
- 《灵枢·第 47 篇·本藏》有一句话可以作为本页的题眼：「视其外应，以知其内脏，则知所病矣。」看外面的反应就知道里面的脏腑，进而知道病在哪里。这句话同时解释了整部中医诊断学的可能性前提。[见原文](/tcm/huangdi/lingshu/lingshu47)
- 读藏象学说最容易犯的错，是把中医的脏腑当成解剖器官的旧称。**「心」不等于心脏，「肾」不等于肾脏**：中医的「肾主生殖」「肾主纳气」「肾开窍于耳」，用解剖学的肾脏一个都解释不通。正确的理解是：**中医的脏腑是一组功能系统的代号**，每个代号打包了一串相关的生理功能、体表征象与病理反应。

## 「藏象」的含义

- 《素问·卷三·藏象论》（通行篇名作《六节藏象论》）对「象」有三层用法：
    - **形象**——脏腑的解剖形态。
    - **征象**——脏腑表现于外的生理病理现象。
    - **应象**——脏腑与四时阴阳的相应之象。
- 中医理论的重心在第二、三层。解剖形态虽有记载（《灵枢·第 31 篇·肠胃》《第 32 篇·平人绝谷》对消化道长度容积有相当具体的描述），但并未发展成解剖学，功能推演始终是主线。

## 五脏

- 五脏的共同特点是「**藏精气而不泻**」（《素问·卷三·五藏别论》），即主贮藏精微物质而不直接排泄。各自的功能核心如下：

| 五脏 | 主要功能 | 在体 / 开窍 / 其华 / 志 | 官称 |
| --- | --- | --- | --- |
| 心 | 主血脉、藏神 | 脉 / 舌 / 面 / 喜 | 君主之官 |
| 肺 | 主气司呼吸、主宣发肃降、通调水道、朝百脉 | 皮毛 / 鼻 / 毛 / 悲（忧） | 相傅之官 |
| 脾 | 主运化、主统血、主升清 | 肉 / 口 / 唇 / 思 | 仓廪之官 |
| 肝 | 主疏泄、主藏血 | 筋 / 目 / 爪 / 怒 | 将军之官 |
| 肾 | 藏精、主水、主纳气 | 骨 / 耳 / 发 / 恐 | 作强之官 |

- 表中「官称」出自《素问·卷三·灵兰秘典论》，该篇以朝廷官职比喻十二脏腑的职能，是中医藏象学说最著名的一段：[见原文](/tcm/huangdi/suwen/suwen3)
    - 「心者，君主之官也，神明出焉。」——心为最高主宰，统摄精神意识。
    - 「肺者，相傅之官，治节出焉。」——如宰相辅佐君主，主治理调节。
    - 「肝者，将军之官，谋虑出焉。」——如将军，主谋虑决断与气机条达。
    - 「脾胃者，仓廪之官，五味出焉。」——如粮仓，主受纳运化。
    - 「肾者，作强之官，伎巧出焉。」——主强力与精巧动作，与精力、生殖、技巧相关。
    - 另有膻中（臣使之官，喜乐出焉）、胆（中正之官，决断出焉）、小肠（受盛之官，化物出焉）、大肠（传道之官，变化出焉）、膀胱（州都之官，津液藏焉，气化则能出矣）、三焦（决渎之官，水道出焉）。
- 几处需要细说的：
    - **肺**：主一身之气与呼吸之气；「宣发」是把气与津液向上向外布散，「肃降」是向下向内布散并保持呼吸道的洁净通畅。二者一宣一降，相反相成。肺又「通调水道」，参与水液代谢，故有「肺为水之上源」之说。
    - **脾**：主运化水谷与水湿，为「气血生化之源」，故称「后天之本」。「升清」是把水谷精微上输心肺头目，脾气主升是它的特点（与胃主降相对）。
    - **肝**：「疏泄」指疏通、畅达、升发之性，涉及情志调畅、脾胃运化、胆汁分泌、气血运行、月经与生殖等多方面。肝气郁结是临床极常见的证候，即从此而来。肝又「藏血」，与女子月经关系密切，故有「女子以肝为先天」的说法。
    - **肾**：「藏精」主生长发育与生殖；「主水」司水液代谢的开合；「主纳气」指协助肺保持呼吸深度，故肾虚可见呼多吸少的喘。「肾为先天之本」。
- **命门**的位置与实质是长期争论的话题。《难经》有「左肾右命门」之说，明代张介宾等主张命门为水火之宅、元气之根，另有一派认为命门即肾间动气。此处只作说明，不取一说为定论。

## 六腑

- 六腑的共同特点是「**传化物而不藏**」（《素问·卷三·五藏别论》），即主受纳、传化、排泄，以通为用。
    - **胆**：贮藏并排泄胆汁以助消化；又与「决断」相关（中正之官）。胆与肝相表里。
    - **胃**：受纳并腐熟水谷，主通降，与脾相表里，合称「后天之本」。
    - **小肠**：受盛胃中水谷，进一步化物、分别清浊（「小肠者，受盛之官，化物出焉」），清者上输，浊者下传大肠，水液渗入膀胱。
    - **大肠**：传导糟粕，吸收水分，形成并排出粪便。
    - **膀胱**：贮存与排泄尿液，「气化则能出矣」——强调排尿有赖肾的气化功能。
    - **三焦**：为六腑之一，主通行元气与运行水液，「决渎之官，水道出焉」。其**实质**历来有争议：一说为分布于胸腹腔的脏腑间隙，一说为上、中、下三部分的功能划分，一说为解剖上的体腔。此处并存诸说，不强行统一。三焦的具体讨论见《[经络与腧穴](/tcm/jichu/jingluo)》。

## 奇恒之府

- 《素问·卷三·五藏别论》列出「脑、髓、骨、脉、胆、女子胞」六者，称奇恒之府。
- 「奇恒」意为异于寻常：它们的形质似腑（多为中空有腔），功能却似脏（藏精气而不传化水谷）。
- 中医对脑的论述相对简略，多把神志功能归于心（心藏神）与五脏（五神脏），这是与西医差异较大的一处。现代中医研究对脑的功能有所补充，可视为对传统理论的拓展。

## 脏腑之间的关系

- 五脏六腑不是各管一段，而是通过**表里配属**与五行生克联系起来：
    - 表里配对（脏为里、腑为表）：心—小肠、肺—大肠、脾—胃、肝—胆、肾—膀胱，加心包—三焦。
    - 在五行框架下，五脏之间还有相生相克的复杂牵连（见《[五行学说](/tcm/jichu/wuxing)》），这是中医考虑「治一个脏要顾到另几个脏」的理论依据。
- 举一个常被提到的例子：脾与胃同居中焦而「脾升胃降」，脾气升清、胃气降浊，两者协同才能完成受纳运化。若胃气不降而反上逆，便见恶心呕吐、嗳气；若脾气不升而反下陷，便见久泻、脱肛。这类「升降失常」的表述，是脏腑关系学说的典型运用形式。

## 为什么值得了解

- 藏象学说是中医理论的**中枢**：向上承阴阳五行，向下连着诊法、辨证与治法。不懂藏象，「肝郁脾虚」「心肾不交」「肺肾两虚」这些证候名就无从理解。
- 它同时也是一套**高度系统化的功能描述**。抛开与现代解剖学的对应问题，它在解释症状之间的关联、指导临床综合判断方面，的确形成了一套自足的逻辑。理解它的价值，主要在于读懂传统典籍与这一医学传统的思维方式。

## 提醒

- 再次强调：**中医的脏腑是功能系统的概念，不能与解剖器官互换**。「脾主运化」包含了现代消化系统的部分功能，「肾」更涵盖了泌尿、生殖、内分泌、骨骼、耳等多个方面。混淆两者会导致大量误解，也常被虚假宣传利用。
- 藏象学说中的不少推论源于古代观察与类比，可靠性不一。它作为一套解释模型有自身的一致性与临床应用历史，但不应被视为已证实的生理事实。
- 本页只作理论介绍。脏腑辨证须由执业医师面诊完成，读者不可凭本页判断自己「哪个脏腑虚」并自行调补或用药。身体不适请到正规医疗机构就诊。
