# 治则与治法

- **治则**是治疗疾病的**总原则**（治病求本、扶正祛邪、调整阴阳、三因制宜等）；**治法**是在治则指导下确立的**具体方法**（汗、吐、下、和、温、清、补、消等）。治则是方向，治法是路径。
- 全篇的起点是一句话：《素问·卷二·阴阳应象大论》说「**治病必求于本**」。这个「本」指疾病的根本机理，而不是表面症状。找错了本，药越猛错得越远。
- 《素问·卷二十二·至真要大论》给出了具体的操作纲领：「**谨守病机，各司其属，有者求之，无者求之，盛者责之，虚者责之，必先五胜，疏其血气，令其调达，而致和平。**」——守住病机，分清归属，现有的症状要追究，没有出现的也要预判；盛者责其何以盛，虚者责其何以虚；再疏通血气使之调达，归于平和。[见原文](/tcm/huangdi/suwen/suwen22)

## 治病求本

- 「本」与「标」是一对相对概念，可指病因与症状、正气与邪气、旧病与新病、原发病与继发病等。
- **急则治标，缓则治本**：出现危急症状（如大出血、剧痛、高热神昏）时先解决当务之急，待缓解后再治根本。如大出血当先止血，之后再调治出血的病因。
- **标本兼治**：标本并重时两者同顾。如气虚外感，既解表又益气。
- 《素问·卷十八·标本病传论》是讨论这一问题的专篇。[见原文](/tcm/huangdi/suwen/suwen18)

## 正治与反治

- **正治**（逆治）：逆着证象的性质而治，是最常用的一类。
    - 寒者热之、热者寒之、虚则补之、实则泻之。
    - 适用于病机与表象一致的情况。
- **反治**（从治）：当病情出现与本质相反的假象时，**顺着假象**去用表面相同的药，实质仍是针对本质。四种典型情形：
    - **热因热用**：真寒假热证，用温热药。表面上是「以热治热」。
    - **寒因寒用**：真热假寒证，用寒凉药。
    - **塞因塞用**：真虚假实证（如脾虚所致的腹胀、气虚所致的便秘），用补益药。表面上是「以补治塞」。
    - **通因通用**：真实假虚证（如食积所致的腹泻、瘀血所致的出血），用通利药。表面上是「以通治通」。
- 反治听起来反直觉，但逻辑一致：**治的始终是本质**，只是表面看去与证象同向。它的前提是辨证准确——若把真实的寒证误判为真寒假热而用温药，尚不至于大错；把真热假寒误作真寒假热而用温药，则后果严重。这正是《内经》反复强调「察色按脉，先别阴阳」的原因。

## 扶正与祛邪

- 邪正盛衰是病机最根本的一对关系（见《[病因与病机](/tcm/jichu/bingyin)》），因而治法上也要权衡两者：
    - **扶正**：补益正气，适用于虚证或以虚为主的病证。方法有益气、养血、滋阴、温阳等。
    - **祛邪**：祛除病邪，适用于实证或以实为主的病证。方法有解表、清热、攻下、消导、活血、化痰等。
    - **两者关系**：单纯扶正可能「闭门留寇」（邪未去而补之，反而助邪），单纯祛邪可能「伤及正气」（攻伐太过，正气愈虚）。故常需「**攻补兼施**」，并分清主次与先后——先攻后补、先补后攻或攻补并行，取决于正虚与邪实的轻重缓急。

## 调整阴阳

- 由于阴阳失调是病机总纲，调整阴阳也是治则总纲（详见《[阴阳学说](/tcm/jichu/yinyang)》）。要点有四：
    - **损其偏盛**：阳盛则热，用寒凉以清；阴盛则寒，用温热以散。
    - **补其偏衰**：阳虚者温补，阴虚者滋养。
    - **阴阳互济**：补阳时少佐补阴，补阴时少佐补阳——「阴中求阳，阳中求阴」。
    - **以平为期**：目标是恢复动态平衡，不是把某一方补得越高越好。这一点对今天习惯「缺什么补什么」的人来说尤其值得留意。

## 调理气血与脏腑

- **调理气血**：气虚补气、气滞行气、气逆降气、气陷升提；血虚补血、血瘀活血、血热凉血、出血止血。并顾及气血关系，如补气以摄血、行气以活血。
- **调理脏腑**：按脏腑的生理特性与相互关系立法。例如脾胃同居中焦而脾升胃降，故治胃多用降逆和胃，治脾多用升阳益气；又如肝木克脾土，故治肝郁常兼健脾（「见肝之病，知肝传脾，当先实脾」）。
- 五行生克关系派生出的一批治法名目（滋水涵木、培土生金、抑木扶土、佐金平木等）即由此而来，详见《[五行学说](/tcm/jichu/wuxing)》。

## 三因制宜

- 治疗必须考虑**时、地、人**三个变量，这在《内经》中有明确论述：
    - **因时制宜**：不同季节的治法有别。如夏季腠理疏松，用发汗药宜轻；冬季腠理致密，用药宜重。四时气候的变化见《素问·卷一·四气调神大论》。[见原文](/tcm/huangdi/suwen/suwen1)
    - **因地制宜**：不同地域的常见病与体质不同。如《素问·卷四·异法方宜论》说东方之域「其病皆为痈疡，其治宜砭石」，西方「其病生于内，其治宜毒药」，北方「其病生于内，其治宜灸焫」，南方「其病挛痹，其治宜微针」，中央「其病多痿厥寒热，其治宜导引按跷」。这是「一病而治各不同，皆愈」的道理。[见原文](/tcm/huangdi/suwen/suwen4)
    - **因人制宜**：按年龄、性别、体质、生活习惯施治。老人生机减退，用药宜轻；小儿脏腑娇嫩，忌峻猛攻伐；妇人须考虑经、孕、产、乳（孕期禁用或慎用峻下、破血、滑利之品）。
- 三因制宜的另一面，是反对「一刀切」——同一种病在不同人身上治法可以不同，这正是中医个体化特点的体现。体质差异详见《[体质学说](/tcm/jichu/tizhi)》。

## 八法

- 清代程钟龄在《医学心悟》中把众多治法归纳为「**汗、吐、下、和、温、清、补、消**」八法，成为后世最通行的治法分类：
    - **汗法**：开泄腠理、逐邪外出，用于表证。辛温发汗（风寒）、辛凉解表（风热）皆属之。
    - **吐法**：涌吐痰涎、宿食或毒物，用于邪在上焦且病情急迫者。今临床已少用。
    - **下法**：通便、泻下、逐水，用于里实证（燥屎内结、水饮内停）。有寒下、温下、润下、逐水之别。
    - **和法**：和解调和，用于半表半里或脏腑不和。如和解少阳（小柴胡汤）、调和肝脾。
    - **温法**：温里祛寒，用于里寒证。温中散寒、回阳救逆皆属之。
    - **清法**：清热泻火，用于里热证。清气、清营、凉血、清脏腑热各有所属。
    - **补法**：补益虚损，用于虚证。补气、补血、补阴、补阳皆属之。
    - **消法**：消食导滞、行气活血、化痰利水，用于气、血、痰、食等形成的积滞。特点是渐变缓消，不同于下法的急攻。
- 八法常**配合使用**，如汗下并用、温清并用、攻补兼施。程钟龄本人的提醒是「一法之中，八法备焉」——法度是死的，病是活的。

## 病机十九条

- 《素问·卷二十二·至真要大论》中有一段把症状与病机一一挂钩的条文，后世称「病机十九条」，是中医病机与治则的纲领性文字。原文如下（择要）：
    - 「诸风掉眩，皆属于肝」——凡见动摇、眩晕之类，多责之于肝。
    - 「诸寒收引，皆属于肾」——凡见寒冷、拘挛收缩之类，多责之于肾。
    - 「诸气膹郁，皆属于肺」——凡见气机郁滞、胸闷喘息之类，多责之于肺。
    - 「诸湿肿满，皆属于脾」——凡见水湿、肿胀、胀满之类，多责之于脾。
    - 「诸痛痒疮，皆属于心」——凡见疼痛、瘙痒、疮疡之类，多责之于心。
    - 「诸厥固泄，皆属于下」「诸痿喘呕，皆属于上」——前者指厥逆、二便固泄之症多在下焦，后者指痿、喘、呕吐之症多在上焦。
    - 关于火热者有九条（「皆属于火」或「皆属于热」），是十九条中占比最大的一类，如「诸热瞀瘈，皆属于火」「诸逆冲上，皆属于火」「诸躁狂越，皆属于火」「诸病有声，鼓之如鼓，皆属于热」「诸转反戾，水液浑浊，皆属于热」「诸呕吐酸，暴注下迫，皆属于热」等。
    - 关于寒者一条：「诸病水液，澄澈清冷，皆属于寒。」
- 读这十九条要注意两件事：
    - 「皆」字是**强调倾向**，不是说凡见此症必属此脏。古人用词简练，后人不宜当数学公式来套。
    - 十九条里**没有一条提「虚」「实」的证型**，而是把症状直接系于脏腑或六气——这是《内经》时代的思路特征，后来的辨证体系（八纲、脏腑辨证）是在此基础上逐步细化出来的。

## 提醒

- 治则是**思路层的知识**，不能直接转化为用药。看到「寒者热之」就自行吃热性药、看到「虚则补之」就自行进补，是把原则当处方，风险很大——上一条里说的「真寒假热」「真热假寒」一旦辨错，方向恰好相反。
- 中医的「以平为期」「三因制宜」与现代医学的个体化治疗在思路上有相通之处，但理论依据与证据体系不同，不宜简单互证。
- 中药并非天然无害。常用药中有相当一部分具有肝肾毒性或明确禁忌（如某些含马兜铃酸、乌头碱的药材），与西药同服还可能产生相互作用。**任何处方都应出自执业医师，并在正规医疗机构取药**；本页不构成任何用药建议。
