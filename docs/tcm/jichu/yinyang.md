# 阴阳学说

- 「阴阳」是中医学最基本的一对概念，也是《黄帝内经》讲理的总纲。《素问·阴阳应象大论》开篇即说：「阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始，神明之府也。治病必求于本。」
- 它起初并不是医学概念，而是先秦思想家用来描述自然现象对立两面的工具：向日为阳、背日为阴，进而扩展到天与地、昼与夜、动与静、热与寒。
- 进入医学后，它变成了一套**分类与解释的模型**——把人体结构、生理功能、病理变化乃至药性，都用阴阳两分的方式整理出秩序。《灵枢·阴阳系日月》说得很明白：「阴阳者，有名而无形。」它是给事物贴的标签，不是某种可以取出来的实体。
- 理解阴阳，是读懂后面所有章节的前提；阴阳不清，藏象、经络、诊法、治则都无从谈起。

## 阴阳的基本内容

- 四组关系构成阴阳学说的全部骨架，缺一不可：
    - **对立制约**：阴阳两方性质相反、相互抑制。如寒与热、动与静。就人体而言，阳主温煦推动，阴主凉润宁静，两者互为约束，谁也不能独大。
    - **互根互用**：任何一方都以另一方为存在条件，「孤阴不生，独阳不长」。《素问·阴阳应象大论》说：「阴在内，阳之守也；阳在外，阴之使也。」——阴是阳的守持之基，阳是阴的运使之用。
    - **消长平衡**：两者不是静止的对半，而是此长彼消、此消彼长的动态过程。生理状态下是「阴平阳秘」（《素问·生气通天论》），即一种动态的稳态，而不是绝对均等。
    - **相互转化**：在一定条件下，一方可以变成另一方。《素问·阴阳应象大论》说「重阴必阳，重阳必阴」「寒极生热，热极生寒」，讲的正是这种物极而反。
- 四组关系里，**互根与转化最容易被忽略**，却最要紧。只记住「对立」，容易把阴阳理解成两个敌对的帮派，那样后面的治法就全成了「打压」；临床上「阴中求阳、阳中求阴」的思路，正是从互根来的。

## 怎么分阴阳

- 划分没有固定清单，原则是「**以一对相反的性质作标准**」，看什么场合、比什么。常见的几组：
    - 自然：天为阳、地为阴，昼为阳、夜为阴，春夏为阳、秋冬为阴，动为阳、静为阴。
    - 部位（以人体而论）：上为阳、下为阴，外为阳、内为阴，背为阳、腹为阴，四肢外侧为阳、内侧为阴。
    - 脏腑：六腑为阳、五脏为阴（因腑主传化、藏而不泻者为藏，其性相对内守）。
    - 物质与功能：气为阳、血为阴；卫气为阳、营气为阴；功能活动为阳、精血津液为阴。《素问·阴阳应象大论》概括为「阳化气，阴成形」——推动与转化的属阳，凝聚成形的属阴。
    - 药性：四气（寒凉为阴、温热为阳）与五味（辛甘淡属阳，酸苦咸属阴）皆分阴阳。
- 阴阳还可以再分。《素问·阴阳离合论》说「阴阳者，数之可十，推之可百」，即阴中有阴阳、阳中有阴阳。如就一天而言昼为阳，昼之中上午为阳中之阳、下午为阳中之阴。这是个**可无限细分的相对系统**，不是一张固定的二元清单。

## 在医学中的运用

### 说明生理

- 人体被视为阴阳的对立统一体：物质（精、血、津液）属阴，功能（气化、温煦、推动）属阳。两者互相化生——物质消耗产生功能，功能活动又化生新的物质，如此循环。
- 《素问·生气通天论》特别推重阳气的地位：「阳气者，若天与日，失其所则折寿而不彰。」把阳气比作天上的太阳，说明温煦与推动之力一旦衰败，生机便随之减损。
- 「阴平阳秘，精神乃治；阴阳离决，精气乃绝」——前者是健康的状态描述，后者是说两者若彻底脱钩，生命即告终结。

### 说明病理

- 疾病的基本机理可归纳为**阴阳失调**，常见四种格局：
    - **阴阳偏盛**（实证）：阳偏盛则热，阴偏盛则寒。「阳胜则热，阴胜则寒」；而「阳胜则阴病，阴胜则阳病」——一方过盛必然耗损另一方。
    - **阴阳偏衰**（虚证）：阳偏衰则寒（阳虚不能温煦），阴偏衰则热（阴虚不能制阳而虚热内生）。《素问·调经论》所记「阳虚则外寒，阴虚则内热，阳盛则外热，阴盛则内寒」即此四型。
    - **阴阳互损**：由于互根关系，阴损日久可累及阳（阴损及阳），阳损日久可累及阴（阳损及阴），最终形成阴阳两虚。
    - **阴阳格拒与亡失**：极盛或极衰时可出现「阴阳之气不相顺接」的格拒之象（如真寒假热、真热假寒），以及亡阴、亡阳的危候。
- 需要留意，同一症状的阴阳归属可能完全相反。发热未必属阳盛，也可能是阴虚；畏寒未必属阳虚，也可能是阳郁不达。这正是「辨证」不能照症状对号入座的原因。

### 用于诊断

- 阴阳是诊法的总纲。《素问·阴阳应象大论》说：「善诊者，察色按脉，先别阴阳。」——先分清阴证阳证，再谈细节。
- 具体到望闻问切：望诊中色泽鲜明者为阳、晦暗者为阴；闻诊中声高气粗者为阳、声低气怯者为阴；问诊中发热口渴喜冷为阳、畏寒口不渴喜热为阴；脉诊中浮、数、洪、滑为阳，沉、迟、细、涩为阴。
- 八纲辨证里，表、热、实属阳；里、寒、虚属阴。**阴阳是总纲，表里、寒热、虚实是它的细化**。

### 用于治疗

- 总原则是「**调整阴阳，以平为期**」——把失衡的状态调回动态平衡，而不是一味补或一味泻。
    - 对偏盛者用「泻其有余」：寒者热之、热者寒之，即《素问·至真要大论》的「寒者热之，热者寒之，温者清之，清者温之」。此为**正治**（逆其证象而治）。
    - 对偏衰者用「补其不足」：阳虚者温补其阳，阴虚者滋养其阴。
    - 也有**反治**（从治）：当病情出现假象时，顺其假象而治。如真寒假热，仍用温热药（「热因热用」）；真热假寒，仍用寒凉药（「寒因寒用」）。
- 阴阳互根还派生出两条重要思路：
    - **阳病治阴、阴病治阳**：阳热亢盛而伤阴的，要兼养其阴；阴寒内盛而伤阳的，要兼扶其阳。
    - **阴中求阳、阳中求阴**：补阳时适当配以补阴药，补阴时适当配以补阳药，取「无阴则阳无以化，无阳则阴无以生」之意。这是后世（如张介宾）对《内经》的发展，很有代表性。

## 提醒

- 阴阳是**模型**，不是物质的分类学。它用两个标签把复杂的现象整理成可推理的形式，方便记忆与传承，但不等于它描述的每一组对应关系都能在现代意义上得到验证。
- 使用时要看**比较的对象是什么**。同一个东西，在不同比较里阴阳归属可以颠倒：脏与腑相对，脏为阴；但脏与四肢皮毛相对，脏又属里属阴——必须先明确「跟谁比」。
- 本页只是理论梳理。阴阳辨证是执业医师的临床工作，读者不必也不能凭本页自行判断自己属阴虚还是阳虚，更不可据此选购补药。身体不适请就医。
