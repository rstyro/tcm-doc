# 病因与病机

- 病因讲「**为什么会病**」，病机讲「**病起来之后体内发生了什么**」。两者通常合称「病因病机」，是中医从理论走向临床的中间环节。
- 《素问·卷十七·调经论》说「百病之生，皆有虚实」；《素问·卷九·评热病论》又说「邪之所凑，其气必虚」——**先有正气不足，邪气才能乘虚而入**。这一句是中医病因观的总纲：疾病从来不是外邪单方面造成的，而是「邪正相争」的结果。[见原文](/tcm/huangdi/suwen/suwen9)
- 由此推出一个贯穿全书的判断尺度：**正气存内，邪不可干**（《素问·卷二十·刺法论》遗篇语，见站内卷二十一）。

## 病因的分类

- 病因的分类法经历了三个阶段，了解这个演变有助于读懂不同时代的医书。
    - **《内经》的二分法**：《素问·调经论》说「夫邪之生也，或生于阴，或生于阳。其生于阳者，得之风雨寒暑；其生于阴者，得之饮食居处，阴阳喜怒。」——把病因按性质分归阴阳两端。[见原文](/tcm/huangdi/suwen/suwen17)
    - **张仲景的三条**：《[金匮要略](/tcm/jingui/what)》开篇说「千般疢难，不越三条」——经络受邪入脏腑（内所因）、四肢九窍血脉壅塞（外皮肤所中）、房室金刃虫兽所伤。这是三因说的雏形。
    - **陈无择的三因说**：南宋陈言（字无择）《三因极一病证方论》正式提出——**内因**为七情，**外因**为六淫，**不内外因**为饮食劳倦、跌仆金刃、虫兽所伤。此说沿用至今。
- 需要注意：现代临床并不严格按这套分类判断病因，它更像一个便于检索与教学的框架。下面按通行的几类分述。

## 六淫

- 「六淫」指**风、寒、暑、湿、燥、火**六种外感病邪。
    - 正常的气候变化称「**六气**」，是万物生长的条件，本不致病。当气候异常（太过、不及、非其时而有其气）或人体正气不足、不能适应时，六气才成为致病因素，此时称「**六淫**」（「淫」有过甚之意）。
    - 六淫致病多与季节、地域、居处环境相关，且常**相兼为病**（如风寒、湿热、风寒湿）。
- 六淫各自的致病特点，是中医辨析外感病的主要依据：

| 淫邪 | 主要性质与致病特点 | 常见表现 |
| --- | --- | --- |
| 风 | 轻扬开泄，善行数变，主动，**为百病之长**（诸邪多依附于风而侵入） | 汗出、恶风、游走性疼痛、瘙痒、抽搐、起病急骤变化快 |
| 寒 | 阴邪，易伤阳气；性凝滞（气血凝滞而痛）、收引（筋脉挛缩） | 恶寒、无汗、疼痛、肢体拘急、脉紧 |
| 暑 | 阳邪，其性炎热；升散，易**耗气伤津**；多湿相兼 | 高热、汗多、口渴、乏力（甚则气短）、暑湿并见 |
| 湿 | 重浊、黏滞、趋下；阻遏气机，**易伤脾阳** | 头身沉重、困倦、分泌物秽浊、病程缠绵、下肢症状 |
| 燥 | 干涩，**易伤肺津** | 口鼻干燥、咽干、干咳少痰、皮肤干燥、便秘 |
| 火（热） | 炎上，易伤津耗气；**生风动血**、易致肿疡 | 高热、面赤、烦躁、口渴、出血、抽搐、疮疡红肿 |

- 「风为百病之长」值得单说：风性开泄，能使腠理疏松，其他邪气便借道而入，故风寒、风热、风湿都冠以「风」字。这是六淫中最具统领性的一条。
- 与之相对，「湿性黏滞」是临床最常被体会到的一条：湿邪致病往往病程长、反复难愈，中医形容为「如油入面」。

## 疫疠

- 除六淫之外，还有一类具有**强烈传染性**的致病因素，称「疫疠之气」「疠气」或「乖戾之气」。
- 明代吴有性（又可）在《温疫论》中提出：「夫温疫之为病，非风非寒非暑非湿，乃天地间别有一种异气所感。」——明确指出疫病由一种独立于六淫的致病因子引起，这是中医病因学的一次重要突破，作于 1642 年。
- 疠气的致病特点：传染性强、易于流行、发病急骤、病情危重、一气致一病（一种疠气引起一种疾病）、有物种感受性的差异（「牛病不羊」）。
- 这一理论与现代病原微生物学在**方向上是相通的**，但古代无从观察到具体病原体，只能以「气」名之。站内《[黄帝内经](/tcm/huangdi/what)》卷二十一的《刺法论》《本病论》（遗篇）中也留有对疫病流行的讨论。

## 七情内伤

- 「七情」指喜、怒、忧、思、悲、恐、惊七种情志活动。正常情况下它们是人体的正常反应，**只有当突然、强烈或长期持续时**，才会成为致病因素。
- 七情致病有两大特点：
    - **直接伤及内脏**：怒伤肝、喜伤心、思伤脾、忧伤肺、恐伤肾（《素问·卷二·阴阳应象大论》）。因心主神明，情志所伤首先影响心神，再由心波及他脏。
    - **影响脏腑气机**：《素问·卷十一·举痛论》有一段极精炼的概括——「百病生于气也。**怒则气上，喜则气缓，悲则气消，恐则气下，寒则气收，炅则气泄，惊则气乱，劳则气耗，思则气结**。」（「炅」音 jiǒng，指热）这一组「九气」是中医情志理论的骨架。[见原文](/tcm/huangdi/suwen/suwen11)
- 举例说明「气上」与「气结」的差别：大怒则气机上逆，可见面红目赤、头痛、甚则呕血；思虑过度则气机郁结，可见胸闷、纳呆、腹胀。同样属于情志致病，气机的走向相反，治法也因此不同。
- 七情还多**影响病情进退**：情志舒畅则病易愈，情志抑郁则病难解，故中医历来重视情志调摄在治疗中的作用。

## 饮食、劳逸与病理产物

- **饮食失宜**：过饥（气血生化乏源）、过饱（食积、损伤脾胃）、饮食不洁（肠道寄生虫、食源性疫病）、五味偏嗜（《素问·卷三·五藏生成篇》讲五味过用各伤所喜之脏）。
- **劳逸失度**：过劳包括劳力过度（耗气）、劳神过度（耗伤心血、损伤脾气）、房劳过度（耗伤肾精）；过逸则气血运行不畅、脾胃功能减退，同样致病。故《内经》主张「形劳而不倦」。
- **病理产物性病因**：某些病变过程中产生的物质反过来成为新的致病因素，最常见的是三类：
    - **痰饮**：水液代谢障碍所形成的病理产物。稠厚者为痰，清稀者为饮。痰可随气流行全身，故有「百病多由痰作祟」「怪病多痰」之说。
    - **瘀血**：血液运行障碍所形成的病理产物，又是继发性病因。典型表现是疼痛（刺痛、固定不移）、肿块、出血（血色紫暗有块）、面色唇甲紫暗、肌肤瘀斑。
    - **结石**：多见于胆、肾、膀胱等部位，多因湿热久蕴、煎熬津液而成。

## 病机

- 病机是病变发生、发展与转归的机理。中医讨论病机，通常从下面几个层面切入。

### 邪正盛衰

- 这是**最根本的一对关系**。邪气与正气相争的胜负，决定了疾病的性质（虚证或实证）与转归（好转或恶化）。
    - **实证**：邪气盛而正气未衰，邪正斗争剧烈，表现为亢奋、有余（如高热、腹胀痛拒按、脉实）。
    - **虚证**：正气不足，抗病无力，表现为衰退、不足（如神疲乏力、气短、脉虚）。
    - 病程中可出现**虚实转化**（实证久延伤正转为虚证，虚证复感外邪转为虚实夹杂）、**虚实真假**（真虚假实、真实假虚，如「大实有羸状」「至虚有盛候」）。
- 理解这一层，就理解了中医为什么强调「扶正」与「祛邪」的权衡——治法方向几乎都从这里推出。

### 阴阳失调

- 包括阴阳偏盛、偏衰、互损、格拒与亡失，详见《[阴阳学说](/tcm/jichu/yinyang)》。这是病机总纲。

### 气血失常

- **气的失常**：气虚（推动无力）与气机失调（气滞、气逆、气陷、气闭、气脱）。
- **血的失常**：血虚（濡养不足）、血瘀（运行不畅）、血热（迫血妄行）、出血。
- **气血关系失常**：气滞血瘀、气虚血瘀、气不摄血、气随血脱、气血两虚。这些证候名的构词方式，正是「气为血之帅」等关系（见《[精气血津液神](/tcm/jichu/qixue)》）在病理侧的直接映射。

### 津液代谢失常

- 津液不足（津亏、液脱）与津液输布排泄障碍（水肿、痰饮、湿浊内停）。后者与肺、脾、肾、三焦的功能失调直接相关，故有「诸湿肿满，皆属于脾」（病机十九条之一）之说。

### 内生五邪

- 脏腑功能失调可以产生类似六淫的病理变化，因其起于内而非感于外，故称「内生五邪」：
    - **内风**：肝阳化风、热极生风、阴虚风动、血虚生风。表现多为眩晕、抽搐、震颤、肢体麻木。
    - **内寒**：阳气虚衰，温煦不足。表现为畏寒肢冷、面色苍白、小便清长。
    - **内湿**：脾失健运，水湿内停。表现为困倦、腹胀、便溏、舌苔厚腻。
    - **内燥**：津液或阴血亏耗。表现为口干、皮肤干燥、干咳。
    - **内火（内热）**：阳气过亢或阴液不足，虚火上炎。表现为五心烦热、盗汗（虚火）或面赤、口疮（实火）。
- 内生五邪与六淫在表现上相似而来源不同，中医辨治时特别强调区分——「外风宜散，内风宜息」就是从这个区别来的。

## 提醒

- 「六淫」「七情」是**分类语言**，不是对病因的实证结论。现代医学对多数疾病有更具体的病因认识（病原体、遗传、代谢、环境毒物等），中医的病因分类仍有其辨证价值，但不应被当作病因学的替代。
- 疫疠学说虽与病原微生物学方向相通，推论仍属古代观察层面；流行病发生时请以公共卫生部门的指引与正规医疗机构诊治为准。
- 「痰」「瘀血」等概念在中医理论中有明确所指，但与网络养生内容里泛化使用的「排毒」「湿气重」「血瘀体质」并不等同。按这些流行说法自行服用利湿、活血之品（尤其活血药对孕妇、服用抗凝药者有害），存在实际风险。身体不适请就医。
