# 黄帝内经

- 《黄帝内经》（简称《内经》）是现存最早的中医理论典籍，由《素问》《灵枢》两部分组成，与《难经》《伤寒杂病论》《神农本草经》并称中医「四大经典」。
- 全书以君臣问对的形式写成，托名黄帝与其臣岐伯、雷公等相问答，实际非一时一人之作。
- 它系统建立了中医的阴阳五行、藏象、经络、病因病机、诊法、论治、养生、运气诸学说，被后世尊为「医家之宗」。书中还涉及古代哲学、天文、气象、物候、地理、心理、音律等内容，是了解先秦两汉自然观的重要材料。
- 本站医部把两书**按篇成页**收录：**素问八十一篇编为二十四卷、灵枢八十一篇逐篇成页**，均附白话译文。若想先建立理论框架再读原文，可先看《[中医基础理论](/tcm/jichu/)》一组页。

## 成书与传承

- **非一时一人之作。** 托名黄帝是古书常见的依托之法。现代通行看法是：主体成编于战国至西汉之间，个别篇章可能晚至东汉，是先秦两汉众多医家经验的汇编（此为学界通说，非定论）。
- **书名的来历。** 「内经」是相对于「外经」而言。《汉书·艺文志》著录有《黄帝内经》十八卷，同时另有《黄帝外经》等，后者早已失传。
- **今本与《汉志》卷数相合。** 传世本《素问》《灵枢》各九卷八十一篇，合十八卷，与《汉志》所记相合，故一般认为今本即《汉志》所载之本。
- **素问的运气七篇是后补的。** 素问在六朝时已缺第七卷（仅存篇目）。唐代王冰自称得到「旧藏之卷」，补入后世所称的**运气七篇**（天元纪大论至至真要大论等），并重加编次与注释，今本面貌由此而定。第七十二、七十三两篇（刺法论、本病论）北宋时已亡，今存者为后人补撰，称「遗篇」。
- **灵枢曾长期散佚。** 南宋史崧以家藏本重新校订刊行，才得流传至今，故又称《灵枢经》。因所据版本与校订者不同，灵枢个别篇名、篇序在他本中略有出入。
- **主要注本。** 素问有王冰注、明代马莳《黄帝内经素问注证发微》、张介宾《类经》；灵枢有马莳《灵枢注证发微》、张志聪《灵枢集注》等，都是历代研读的重要参考。其中《类经》把两书内容按主题重编，便于按专题查找，可作对照读物。

## 素问与灵枢的分工

- 两书同属「医经」，内容互为表里，传统上有一个粗略分工：

| | 《素问》 | 《灵枢》 |
| --- | --- | --- |
| 侧重 | **医理** | **针灸与形体** |
| 主要内容 | 阴阳五行、藏象、脉法、病因病机、治则治法、养生、运气 | 经络循行、腧穴、九针形制与刺法、营卫气血的运行 |
| 后世影响 | 中医理论体系的骨架 | 针灸学的源头 |

- 这一分工只是大致倾向，不能当成分界：**《素问》也有刺法诸篇**（刺要论、刺禁论、针解、长刺节论等），**《灵枢》也有大量藏象与诊法内容**（本神、本藏、五色、论疾诊尺等）。
- 所以传统主张「素灵合观」——先读素问立其理，再读灵枢究其形与法；两书对读，才是完整的《内经》。

## 怎么读《内经》

- **先立框架，再入原文。** 内经是问答体的札记，不是教科书，一上来逐篇读容易只见树木。建议先用《[中医基础理论](/tcm/jichu/)》建立阴阳、五行、藏象、经络的框架，再按兴趣挑篇精读。
- **按主题串读。** 同一主题常散在多篇：论脉在脉要精微论、平人气象论、三部九候论；论热病在热论、评热病论、刺热。按主题把散篇串起来，比逐篇推进更有效。
- **素灵对读。** 同一个概念，素问多言其理，灵枢多言其形与法。如同论经络，素问见于经脉别论，灵枢则详于经脉、经别、经筋诸篇。
- **注意层累。** 全书非一时之作，同一问题前后说法偶有出入。这不是「矛盾」而是层累的结果，读到不一致处宜记下，不必强作调和。
- **配合医部其他典籍。** 内经立理，仲景《[伤寒论](/tcm/shanghanlun/start)》《[金匮要略](/tcm/jingui/what)》立方法与方药；本草与方剂则见《[本草纲目](/tcm/bencao/yuanxu)》《[中药学](/tcm/zhongyaoxue/jiebiao)》《[方剂学](/tcm/fangjixue/zonglun-xulun)》。

## 提示

- 本页与本站素问、灵枢各篇均属传统医籍的知识整理，供阅读古籍、了解中医理论源流之用，**不构成医疗建议**。
- 涉及具体病症的诊断与用药，请就医并遵医嘱，勿据文义自行施治。
- 成书年代、篇章真伪、文字校勘等问题学界分歧颇多，本页所述均取较通行的说法。
