# 山·筑基 · 静定原典导读

- **本节定位：** 这一页介绍三部以「静定」为主题的古代文献——《坐忘论》《天隐子》《清静经》——包括它们的作者、成书、结构与版本，以及本站的收录范围与取舍理由。
- 选这三部，是因为它们有一个共同点：**文本独立、以议论为主、不依赖师承即可读通其义理**。传统中谈静定的文字极多，但多数散见于经论，或依附于师承口诀，不适合作为可公开阅读的原典。

## 为什么是这三部

- **《坐忘论》**——次第最系统，七阶层层递进，是理解「静定为何要分步骤」的最好入口。
- **《天隐子》**——篇幅最短，框架最简，且明确主张「渐」，反对「奇诡」，态度最为平实。
- **《清静经》**——不足四百字，纯讲义理，自金元以后是全真道道士的日常功课，流传最广。

三者的关系：**《清静经》给方向，《天隐子》给框架，《坐忘论》给次第。**

## 一、《坐忘论》

- **作者：** 题唐·司马承祯撰。司马承祯（647—735），字子微，号白云子，唐代著名道士，上清派宗师，长期居天台山，曾受唐玄宗召见。著有《天隐子序》《服气精义论》《坐忘论》等。
- ⚠️ **作者异说：** 有学者考证此书的实际作者或为赵坚（一说赵志坚），假托司马承祯之名。此事在学界仍有讨论，本站两说并存，**不强作裁定**。
- **结构：** 序 + 七篇——信敬、断缘、收心、简事、真观、泰定、得道；另有附篇《枢翼》。
- **主旨：** 序中说得很直接——「夫人之所贵者，生也；生之所贵者，道也」。全书回答的是「怎么把散逸在外的心收回来」，并把这件工作分解为七个阶段。
- **梯度逻辑：** 先立信心（信敬）→ 减除外缘（断缘）→ 正式收拾心念（收心）→ 精简事务（简事）→ 以智慧观察（真观）→ 达到无心而定的安定（泰定）→ 与道相合（得道）。**从外部条件一步步走向内在状态，这个次序本身是全书最值得注意的地方。**

## 二、《天隐子》

- **作者与成书：** 主体题「天隐子」撰，序则明确为司马承祯所作。序中说「天隐子，吾不知其何许人」——**连作序者都不知道作者是谁**，可见其托名性质。全书八篇：神仙、易简、渐门、斋戒、安处、存想、坐忘、神解。
- **「渐门」是全书骨架：** 一曰斋戒，二曰安处，三曰存想，四曰坐忘，五曰神解。并强调「人之修真达性，不能顿悟，必须渐而进之，安而行之」——**明确站在「渐修」一边，与主张顿悟的一路相对。**
- **「易简」是全书态度：** 书中说「凡学神仙，先知易简。苟言涉奇诡，适足使人执迷，无所归本，此非吾学也」。这句话值得单独拎出来：**一部修炼文献自己站出来反对「奇诡」，在古代同类著作中并不多见。**

## 三、《太上老君说常清静经》

- **简称：** 《清静经》，全称《太上老君说常清静经》。
- **成书与作者：** 一般认为约成书于唐代，作者不详。旧题葛玄（葛仙公）受经，属托名。南宋《秘目》及《通志·艺文略》著录作一卷。
- **版本：** 今本收入《正统道藏》洞神部本文类，经文不足四百字。
- **结构：** 分上下两章——上章言「人能常清静，天地悉皆归」，讲好清静则得道；下章说众生不得真道皆因有妄心，由妄心而惊神、著物、生贪求、起烦恼，终至「流浪生死，常沉苦海」。
- **义理来源：** 一般认为其说出自隋唐道教的重玄哲学。
- **后世影响：** 金元以后全真道以诵习此经为道士日常必修功课；历代注家甚多，唐末杜光庭、南宋白玉蟾、金元侯善渊、李道纯、王道渊等皆有注本。

## 版本与用字说明

古籍无「标准版本」。以下几处是本站校读时实际遇到的差异，**列出以便读者知情，不作单向裁决**：

| 位置 | 《全唐文》卷九二四本 | 《正统道藏》太玄部本 |
| --- | --- | --- |
| 篇首 | 无独立序，开篇即正文 | 有真静居士序一篇 |
| 信敬篇 | 「夫坐忘者，何所不**忘**哉」 | 「何所不**忌**哉」 |
| 断缘篇 | 「**求**人保己」 | 「**来**人保己」 |
| 收心篇 | 「百神之**师**」 | 「百神之**帅**」 |
| 泰定篇 | 「**尽**俗之极地」 | 「**出**俗之极地」 |
| 得道篇 | 篇末至「被形者则神人也」 | 有完整下文，接「及心者但得慧觉，而身不免谢……」 |
| 附篇 | 无 | 附《枢翼》一篇 |

- 这些差异成分不一：如「不忌／不忘」明显是形近致误，而「尽俗／出俗」「求人／来人」则可能各有传承。**并非所有差异都需要判定对错。**
- 本站正文以**文从字顺、上下文可通**为取舍依据，凡有疑问处随文注明，不悄然改字。用字一律统一为简体，标点统一为现代通行体例。

## 收录原则：哪些收，哪些不收

本站对这三部文献采取**选择性收录**，理由如下：

**收录的：** 议论性、义理性内容——它们可以独立读通，不需要师承讲解，也不会误导读者去「照着做」。

**不收的三类：**

1. **具体操作口诀。** 《坐忘论》的附篇《枢翼》，《天隐子》书末所附的修行跋文（含吐纳、漱咽、叩齿、掩耳、闭息、导引等一整套操作），属于本站《[功法导览](/shan/gongfa)》已立体例所排除的「具体功法步骤、口诀与火候」范围，故不逐条收录。
2. **信仰承诺性的段落。** 《清静经》正文之后所附「仙人葛玄曰」「左玄真人曰」「正一真人曰」三段，内容是「诵持不退，身腾紫云」一类诵经功德的许诺，属信仰宣传而非经文主体，依本站去营销化的约定不予收录。
3. **需要师承印证的次第细节。** 涉及具体火候、气脉运行路线的描述，不作展开。

⚠️ **需要说明的是：以上的「不收」是说明边界，不是删改古籍。** 原文完整文本可自行查阅《正统道藏》太玄部本、《全唐文》卷九二四，或道教研究机构的公开整理本。站点把「为什么不收」写出来，是不希望读者以为被省略的部分无足轻重，更不希望有人因为找不到而另寻野路子。

## 建议的阅读顺序

1. **先读《[清静经](/shan/zhuji/classics/qingjingjing)》**——四百字，先建立对「清静」二字的基本印象。
2. **再读《[天隐子](/shan/zhuji/classics/tianyinzi)》**——五阶框架最简单，最容易看懂「静定为什么要分步骤」。
3. **最后读《[坐忘论](/shan/zhuji/classics/zuowanglun)》**——七阶，最系统，读完之后可以对「收心」这件事有较完整的认识。
4. 全程可配合《[术语辨析](/shan/zhuji/terms)》查阅名词，配合《[静坐答疑](/shan/zhuji/faq)》对照现代人会遇到的实际疑问。

## 三种读法，请自行定位

- **文化读法（推荐）：** 把它当作中国思想史的文献来读，看古人如何描述身心经验、如何组织修养次第。这是本站做这些页面时的立场。
- **修养读法：** 取其「顺其自然、贵在坚持、身心并重」的态度，用于涵养性情。可行，但目标宜保持在「安顿身心」这一层。
- **不作操作手册读：** 这些文本写在千年之前，写作对象、语言习惯、身心观念都与今天不同。**把「安坐收心，离境住无所有」这类原则性语句，直接当作可以照做的步骤，是本站最不建议的一种读法。**
