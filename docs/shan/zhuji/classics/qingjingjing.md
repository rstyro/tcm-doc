# 山·筑基 · 太上老君说常清静经

- 《太上老君说常清静经》，简称《清静经》，是道教中流传最广的短经之一，全篇不足四百字。
- 一般认为约成书于唐代，作者不详，旧题葛玄受经，属托名之说。今本收入《正统道藏》洞神部本文类。
- 全经分上下两章：上章言「人能常清静，天地悉皆归」，说好清静则得道；下章说众生不得真道皆因有妄心，由妄心而惊神、著物、生贪求、起烦恼，终至「流浪生死，常沉苦海」。
- 金元以后，全真道以此经为道士日常必修功课，历代注家甚多，唐末杜光庭、南宋白玉蟾、金元侯善渊、李道纯、王道渊等皆有注本。

## 经文与译文

### 一、道的不可名

> 老君曰：大道无形，生育天地；大道无情，运行日月；大道无名，长养万物。吾不知其名，强名曰道。

**译文**

大道没有形体，却生养了天地；大道没有情意，却推动着日月运行；大道没有名称，却滋养着万物。我不知道该叫它什么，只好勉强称之为「道」。

**简说**

开篇三句，句式几乎一样，落点却在最后一句：**「强名曰道」——这个名字是被迫取的，不是它本来的名字。**

这一点与《道德经》第一章「名可名，非常名」是同一个意思。先承认「说不尽」，再开口说，这是道门言说的一贯分寸。凡是把「道」讲得斩钉截铁、条理分明的，往往已经离开了这个分寸。

### 二、清浊与动静

> 夫道者：有清有浊，有动有静；天清地浊，天动地静；男清女浊，男动女静。降本流末，而生万物。清者浊之源，动者静之基。人能常清静，天地悉皆归。

**译文**

道之中，有清也有浊，有动也有静：天是清的、地是浊的，天是动的、地是静的；阳刚的一面属清、阴柔的一面属浊，阳刚的一面主动、阴柔的一面主静。从本原向下流布，于是生出了万物。清是浊的源头，动是静的根基。人若能常保清静，天地的一切都会归附于他。

**简说**

这一段讲的是一个**相对而言的结构**：清与浊、动与静互为条件，各占一边。

要注意「清者浊之源，动者静之基」两句话里的关系——**不是说清比浊高、静比动好，而是说清浊动静互为根源**。水静止下来，浊物才能沉淀而显出清；事物安静下来，动向才看得清楚。所以「常清静」并不是要消灭动与浊，而是找到那个能让它们各自归位的位置。

至于「男清女浊」是古代阴阳比附的表述方式，属于那个时代的语言习惯，读时不必拘泥于字面的性别对应。

### 三、神好清，而心扰之

> 夫人神好清，而心扰之；人心好静，而欲牵之。常能遣其欲而心自静，澄其心而神自清。自然六欲不生，三毒消灭。所以不能者，为心未澄，欲未遣也。

**译文**

人的神本来是喜好清明的，却被心所搅扰；人的心本来是喜好安静的，却被欲望所牵引。若能常常排遣欲望，心自然就静；澄清这颗心，神自然就清明。这样六种欲望不会生起，三种毒害自然消灭。之所以做不到，是因为心还没有澄清、欲望还没有排遣。

**简说**

这是全经最有名的一段，也是最能说到现代人心坎上的一句：**扰乱的不是外界，是心自己对欲望的响应。**

「神好清，而心扰之」——注意主语的分工：神、心、欲是三个层次。神本身清，心把它搅浑了；心本身静，欲望把它拉开了。这是一条**下行链**。经文给出的方向则是反过来的：**遣欲 → 心静 → 神清**。

「渐次」二字很关键。「遣」不是一次性的动作，是持续的过程。所以经文接下来立刻补了一句清醒的自我批评：「所以不能者，为心未澄，欲未遣也」——做不到，就是因为还没做到，不是别的原因。

### 四、三重观空

> 能遣之者：内观其心，心无其心；外观其形，形无其形；远观其物，物无其物。三者既悟，唯见于空。观空亦空，空无所空；所空既无，无无亦无；无无既无，湛然常寂；寂无所寂，欲岂能生？欲既不生，即是真静。

**译文**

能够排遣欲望的人：向内观察自己的心，发现心并没有一个实在的「心」可得；向外观察自己的形体，发现形体并没有一个实在的「形」可得；再远观外物，发现外物并没有一个实在的「物」可得。这三重看清之后，眼前只剩下一个「空」。再观这个空，连空也是空的；所空掉的既然没有了，「无无」这层也没有了；这层也没有了，便是一片澄澈清明、恒常寂静。连这寂静也没有什么可寂静的，欲望又从何处生起呢？欲望既不生起，便是真正的静。

**简说**

这一段是层层剥落，**连「空」这个落脚处也要拆掉**：空 → 空无所空 → 无无亦无 → 湛然常寂 → 寂无所寂。

这种「一路拆到底」的写法，出自隋唐道教的重玄哲学，与佛教中观论的思想有相通之处。它的用意在于防止一件事：**把「空」当成一个新的东西去抓**。修行者好不容易放下了世间种种，很容易随即执着于「我已看空」——这就把药变成了病。所以经文一路推到底，不留任何可以站的地方。

### 五、得道而实无所得

> 真常应物，真常得性；常应常静，常清静矣。如此清静，渐入真道；既入真道，名为得道；虽名得道，实无所得；为化众生，名为得道。能悟之者，可传圣道。

**译文**

以真常之心应对万物，就能得见真常之性；应事而不失其静，便是常清静了。这样的清静，能渐渐契入真道；既已契入真道，就称之为得道；虽然名为得道，实际上并没有得到什么；只是为了度化众生，才名之曰得道。能够领悟这一层的人，才可以传扬圣道。

**简说**

「虽名得道，实无所得」——这句话是全经的枢纽。

为什么说得道而实无所得？因为得的不是一件东西，而是**去掉了遮蔽**。遮蔽本非实有，去掉它，就谈不上「获得」。这与《道德经》第四十八章「为学日益，为道日损」是同一个方向：**这条路是减法。**

顺带一个提醒：「常应常静」四字值得留意。**清静不是躲开事，是应事之中仍不失其静。** 这一点在《[静定传统对照](/shan/zhuji/compare)》里与儒家理学静坐、二程对静坐之弊的警惕可以对看。

### 六、上士与下士

> 老君曰：上士无争，下士好争；上德不德，下德执德。执着之者，不名道德。

**译文**

老君说：上等的士人不与人争，下等的士人才好争；上德之人不把德行当作一回事，下德之人才紧紧抓着德行不放。凡对某事执着不舍的，就称不上道德了。

**简说**

「上德不德」直接承自《道德经》第三十八章。**真正具备的人不标榜，标榜的人多半不具备。**

末句「执着之者，不名道德」放在这里格外有针对性：**连修道这件事也不要执着**。把「我在修行」当作身份来执守，恰恰是经文一路要拆掉的东西。

### 七、妄心的连锁

> 众生所以不得真道者，为有妄心。既有妄心，即惊其神；既惊其神，即著万物；既著万物，即生贪求；既生贪求，即是烦恼。烦恼妄想，忧苦身心；便遭浊辱，流浪生死；常沉苦海，永失真道。

**译文**

众生之所以不能得道，是因为有一颗虚妄的心。既然有了妄心，就惊扰了本来的神；惊扰了神，就会执着于万物；执着于万物，就生起贪求；生起贪求，便是烦恼。烦恼与妄想使身心忧苦，于是遭受浊辱，在生死中流转漂泊，长久沉沦于苦海，永远失去了真道。

**简说**

这是一条**因果链**，写得极其干净，五步：妄心 → 惊神 → 著物 → 贪求 → 烦恼。

值得注意的是**链条的起点不是外物，是「妄心」**。外物本身并不构成问题，是心先有妄，才一步步走到了烦恼。这个分析方式在今天看来依然有效：让人痛苦的常常不是事情本身，而是对事情的执着。

### 八、结语

> 真常之道，悟者自得；得悟道者，常清静矣。

**译文**

真常之道，领悟的人自然得到；领悟了道的人，便常处清静之中。

**简说**

「悟者自得」——只能自己得，别人代不了。全经到这句话收住，回到开篇的「强名曰道」：**说不尽的东西，只能各自去领会。**

## 全篇串讲

整部经其实只有一条线：

> **道本不可名 → 但清浊动静在其中各安其位 → 神本清、心本静，却被欲望搅动 → 排遣欲望，须层层观空、连空也空 → 于是欲不生而真静 → 名为得道，实无所得。**

贯穿这条线的是一个态度：**减法**。不是往身上添加什么，而是一层层去掉。所以全经没有一处教你「如何做」，只讲「如何不」。这一点与《道德经》第四十八章的「为道日损」完全一致。

读起来会发现它几乎不讲身体——不讲气、不讲丹田、不讲姿势。**《清静经》是纯义理性质的短经**，这正是它可以作为静定原典入门第一篇的原因：先明白方向，再谈方法。

## 本站说明

- **底本与用字：** 正文以通行本为准，参校《正统道藏》洞神部本文类本。各本有小异，如「真常应物」一句，另有传本作「真静应物」；本节取通行本。标点依现代体例统一。
- **关于省略的附录：** 部分流通本在正文之后另有「仙人葛玄曰」「左玄真人曰」「正一真人曰」三段，内容为诵持此经的功德许诺（如「诵持不退，身腾紫云」一类）。**本站不予收录**——它们属信仰宣传性质的附加段落，非经文主体的义理内容，与本站去营销化的整理约定不合。原文完整形态可查阅《正统道藏》本。
- **阅读定位：** 本节属传统文化知识整理。经文中有「得道」「升为天官」等语，是道教自身的宗教表述，本站如实呈现而不加主张，亦不涉任何修法指导。
