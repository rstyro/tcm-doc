# 庄子·应帝王

- **《庄子》内篇第七篇**（全书第七篇）｜原文 8 段、约 1341 字

> 齧缺问于王倪，四问而四不知。齧缺因跃而大喜，行以告蒲衣子。 蒲衣子曰：「而乃今知之乎？有虞氏不及泰氏。有虞氏其犹藏仁以要人，亦得人矣，而未始出于非人。泰氏其卧徐徐，其觉于于。一以己 为马，一以己为牛。其知情信，其德甚真，而未始入于非人。」
>
> 肩吾见狂接舆。狂接舆曰：「日中始何以语女？」肩吾曰：「告我 ：君人者以己出经式义度，人孰敢不听而化诸！」狂接舆曰：「是欺德也。其于治天下也，犹涉海凿河而使蚊负山也。夫圣人之治也，治 外夫？正而后行，确乎能其事者而已矣。且鸟高飞以避矰弋之害，鼷鼠深穴乎神丘之下以避熏凿之患，而曾二虫之无知？」
>
> 天根游于殷阳，至蓼水之上，适遭无名人而问焉，曰：「请问为天 下。」无名人曰：「去！汝鄙人也，何问之不豫也！予方将与造物者 为人，厌则又乘夫莽眇之鸟，以出六极之外，而游无何有之乡，以处 圹埌之野。汝又何帠以治天下感予之心为？」又复问，无名人曰： 「汝游心于淡，合气于漠，顺物自然而无容私焉，而天下治矣。」
>
> 阳子居见老聃，曰：「有人于此，向疾强梁，物彻疏明，学道不倦 ，如是者，可比明王乎？」老聃曰：「是於圣人也，胥易技系，劳形 怵心者也。且也虎豹之文来田，猨狙之便执斄之狗来藉。如是者，可 比明王乎？」阳子居蹴然曰：「敢问明王之治。」老聃曰：「明王之 治：功盖天下而似不自己，化贷万物而民弗恃。有莫举名，使物自喜。 立乎不测，而游于无有者也。」
>
> 郑有神巫曰季咸，知人之死生、存亡、祸福、寿夭，期以岁月旬日 若神。郑人见之，皆弃而走。列子见之而心醉，归，以告壶子，曰： 「始吾以夫子之道为至矣，则又有至焉者矣。」壶子曰：「吾与汝既 其文，未既其实。而固得道与？众雌而无雄，而又奚卵焉！而以道与 世亢，必信，夫故使人得而相汝。尝试与来，以予示之。」
>
> 明日，列子与之见壶子。出而谓列子曰：「嘻！子之先生死矣！弗 活矣！不以旬数矣！吾见怪焉，见湿灰焉。」列子入，泣涕沾襟以告 壶子。壶子曰：「乡吾示之以地文，萌乎不震不正，是殆见吾杜德机 也。尝又与来。」明日，又与之见壶子。出而谓列子曰：「幸矣！子 之先生遇我也，有瘳矣！全然有生矣！吾见其杜权矣！」列子入，以 告壶子。壶子曰：「乡吾示之以天壤，名实不入，而机发于踵。是殆 见吾善者机也。尝又与来。」明日，又与之见壶子。出而谓列子曰： 「子之先生不齐，吾无得而相焉。试齐，且复相之。」列子入，以告 壶子。壶子曰：「吾乡示之以太冲莫胜，是殆见吾衡气机也。鲵桓之審为渊，止水之審为渊，流水之審为渊。渊有九名，此处三焉。尝 又与来。」明日，又与之见壶子。立未定，自失而走。壶子曰：「追 之！」列子追之不及。反，以报壶子曰：「已灭矣，已失矣，吾弗及 已。」壶子曰：「乡吾示之以未始出吾宗。吾与之虚而委蛇，不知其 谁何，因以为弟靡，因以为波流，故逃也。」然后列子自以为未始学 而归。三年不出，为其妻爨，食豕如食人，于事无与亲。雕琢复朴， 块然独以其形立。纷而封哉，一以是终。
>
> 无为名尸，无为谋府，无为事任，无为知主。体尽无穷，而游无朕 。尽其所受乎天而无见得，亦虚而已！至人之用心若镜，不将不迎， 应而不藏，故能胜物而不伤。
>
> 南海之帝为儵北海之帝为忽，中央之帝为浑沌。儵与忽时相与遇于 浑沌之地，浑沌待之甚善。儵与忽谋报浑沌之德，曰：「人皆有七窍 以视听食息此独无有，尝试凿之。」日凿一窍，七日而浑沌死。

## 译文

齧缺向王倪问道，问了四次，王倪四次都说不知道。齧缺因而高兴得跳起来，跑去告诉蒲衣子。蒲衣子说：「你现在才知道吗？有虞氏（舜）比不上泰氏（伏羲）。有虞氏还心怀仁义来笼络人心，虽然也得到人心了，但还没有超脱出『非人』的牵累。泰氏睡觉时安安稳稳，醒来时无思无虑；听任别人把自己当作马，听任别人把自己当作牛。他的心智真实可信，他的德性纯真无伪，从来没有陷入外物的牵累。」

肩吾去见狂接舆。狂接舆问：「日中始对你说了些什么？」肩吾说：「他告诉我：做君主的只要自己制定法度规范，百姓谁敢不听从教化呢！」狂接舆说：「这是欺骗人的德行。用这种办法治理天下，就像要渡过大海去开凿河道、让蚊虫去背负大山一样。圣人治理天下，难道是去管外在的形迹吗？他是先端正自己而后行化，使人人确实能做自己能做的事罢了。况且鸟还要高飞来躲避箭矢的伤害，鼷鼠还要深藏在神坛底下以躲避烟熏挖掘的祸患——你难道还不如这两只小虫聪明吗？」

天根在殷山之南游玩，走到蓼水边上，正好遇到无名人，就问他说：「请问怎样治理天下。」无名人说：「走开！你这个鄙陋的人，怎么问得这么不合时宜！我正打算与造物者结为伴侣，厌烦了就乘上那轻虚的飞鸟，飞出天地四方之外，遨游于一无所有的地方，安处在旷阔无垠的原野。你又何必拿治理天下的话来搅扰我的心呢？」天根又问了一遍，无名人说：「你让心遨游于恬淡之境，让气合于虚寂，顺应事物的自然本性而不掺杂私心，天下就治理好了。」

阳子居去见老聃，说：「假如有这样一个人：办事敏捷、强悍果决，事理通达明澈，学道从不倦怠。这样的人，可以比得上英明的君主吗？」老聃说：「在圣人看来，这种人不过是像供职的小吏、被技艺拴住的人，是劳苦形体、惊扰心神的人。况且虎豹因为身上有花纹才招来猎取，猿猴因为动作便捷才被人从山林中捉来。像这样的人，可以比得上英明的君主吗？」阳子居顿时变了脸色，说：「请问英明的君主是怎样治理的。」老聃说：「英明君主的治理：功盖天下却好像与自己无关，化育万物而百姓并不觉得要依赖他。他使万物各得其所而无法称举他的名，让万物自己欢喜。他立于深不可测之处，而遨游于一无所有之地。」

郑国有个神巫叫季咸，能预知人的死生、存亡、祸福、寿夭，所预言的年月旬日像神一样准。郑国人见了他，都躲开跑掉。列子见了他却醉心倾倒，回来把这事告诉壶子，说：「起初我以为先生的道理是极至了，如今才知道还有更高的。」壶子说：「我教给你的只是名相，还没教你实际。你就以为得道了吗？只有雌而没有雄，怎么能生出卵来呢！你用所学的道去和世人争胜，一定想让人信服，所以人家才能看透你的相。你试着把他带来，让他给我相一相。」

第二天，列子带季咸去见壶子。季咸出来对列子说：「唉！你的先生要死了！活不成了！过不了十天了！我看到怪相了，看到像浸湿的灰一样的东西了。」列子进去，哭得眼泪沾湿了衣襟，把这话告诉壶子。壶子说：「刚才我给他显示的是大地般的形象，生机萌动却不动不正，他大概是看到我闭塞了生机的迹象了。你再带他来。」第二天，又带季咸去见壶子。季咸出来对列子说：「幸运啊！你的先生遇到我了，有救了！完全有生机了！我看到他闭塞之中有了转机！」列子进去，把这话告诉壶子。壶子说：「刚才我给他显示的是天地间的样子，名和实都不进入心中，而生机从脚跟发出。他大概是看到我生机勃发之处了。再带他来。」第二天，又带季咸去见壶子。季咸出来对列子说：「你的先生神态不定，我无法给他看相。让他安定下来，我再给他相。」列子进去，把这话告诉壶子。壶子说：「我刚才给他显示的是太虚的浑然之气，无偏无倚，他大概是看到我气机平衡的样子了。鲸鲵盘桓之处是深渊，静止的水是深渊，流动的水是深渊——深渊有九种名称，我在这里显示了三种。再带他来。」第二天，又带季咸去见壶子。季咸还没站定，就惊慌失色地逃走了。壶子说：「追上他！」列子追他没追上，回来报告壶子说：「已经没影了，已经消逝了，我追不上他了。」壶子说：「刚才我给他显示的是从未出过我的根本。我对他虚与委蛇，他不知我是谁，便把我当作随波逐流之物、当作流水一般，所以逃走了。」此后列子自认为从未学过什么，回到家中，三年不出门。他给妻子烧火做饭，喂猪像喂人一样，对事情不再亲近。把雕琢的心思去掉、回归朴素，像土块一样独立地以自己的形貌存在；在纷纭中守住了本性，就这样终其一生。

不要做名声的躯壳，不要做谋略的府库，不要做事务的承担者，不要做知识的主宰。体察无穷之境而遨游于无迹可寻之处。用尽自己从上天禀受的东西而不自觉得到了什么，不过是虚静而已！至人的用心像镜子一样：不送不迎，如实反映而不藏留，所以能胜过外物而不被外物所伤。

南海的帝王叫儵，北海的帝王叫忽，中央的帝王叫浑沌。儵与忽时常在浑沌的地界相遇，浑沌待他们很好。儵与忽商量着报答浑沌的恩德，说：「人都有七窍用来视听、饮食、呼吸，唯独他没有，我们试着给他凿出来。」于是一天凿一个窍，凿到第七天，浑沌就死了。

## 本篇导读

**《应帝王》是内篇的最后一篇。** 篇名问的是：面对「做帝王」「治天下」这件事，该怎样回应？庄子的答案一路给到最尽头——**不治**。

**前半篇四个故事，一路把「治」往下拆。**

- **齧缺问王倪，四问而四不知**，齧缺反而大喜。为什么喜？因为「不知」在这里不是失败。蒲衣子接着说舜不如伏羲：舜还「藏仁以要人」（心怀仁义去笼络人心），伏羲则听任别人把自己当马当牛，**连「我要对你好」这层意图都没有**。
- **狂接舆斥「经式义度」为「欺德」**：靠君主自定法度去让人听话，等于「涉海凿河而使蚊负山」。他举鸟高飞避箭、鼷鼠深藏避熏——**连鸟兽都懂得不受摆布，人反倒不懂**。
- **无名人被问怎么治天下，第一反应是「去！汝鄙人也」**，因为他正打算与造物者同游、飞出天地之外。被追问不过，才给出一句正经回答：「汝游心于淡，合气于漠，顺物自然而无容私焉，而天下治矣。」
- **老聃说「明王之治」**：「功盖天下而似不自己，化贷万物而民弗恃。」——功绩盖过天下，却像与自己无关；化育万物，而百姓并不觉得要依赖他。「有莫举名，使物自喜」，让人没法称举他的名号，只让万物各自欢喜。

**后半篇两段，是内篇里最要紧的文字之一。**

**季咸相壶子的故事**占了全篇最长的篇幅。神巫季咸能预言生死祸福，准得像神；列子见了心醉，壶子便让他来给自己看相。四次相面，壶子现出四种不同的「相」：一是**地文**（闭塞生机），季咸说他要死了；二是**天壤**（生机从脚跟发出），季咸说有救了；三是**太冲莫胜**（气机平衡无偏），季咸说他神态不定、没法相；第四次，壶子「未始出吾宗」——**根本没有从自己的根本里出来**，虚与委蛇，季咸连他是什么都摸不着，只好逃走。列子由此醒悟自己从未真正学到什么，回家三年不出，给妻子烧火、喂猪如喂人，把雕琢的心去掉，「雕琢复朴，块然独以其形立」。

**紧接着是那句全篇最著名的话：「至人之用心若镜，不将不迎，应而不藏，故能胜物而不伤。」** 心像镜子——不送走什么，也不迎接什么，来什么照什么，照过不留。所以能应对万物而不被万物所伤。**这句话后来成了中国思想里描述「心」的经典比喻**，也是本站《[筑基](/shan/zhuji/)》一路反复会碰到的那个「照」与「不藏」的分寸。

**末尾的浑沌之死，是内篇最沉重的收尾。** 南海之帝儵与北海之帝忽，常在中帝浑沌的地界相遇，浑沌待他们很好。二人商量报恩：「人皆有七窍以视听食息，此独无有，尝试凿之。」一天凿一窍，第七天，浑沌死了。

**这个寓言的锋利之处在于：杀死浑沌的不是恶意，是报恩。** 儵与忽是十足的善意，做的是「让人变成正常人」这件在任何人看来都无可指责的事——而结果恰恰是毁了对方。**「无为」的反面从来不是「胡作非为」，而是「善意的强加」。** 这一层意思，无论用来读政治、读管理，还是读人与人之间，都不过时——也正因如此，庄子把这个故事放在了内篇的最末。

**读完之后可以回看《[逍遥游](/shan/zhuangzi/pian1)》：** 那一篇说「至人无己」，这一篇说「用心若镜」。无己，故无所谓功（无功）；不用自己的好恶去迎送外物，故无所谓名（无名）。内七篇首尾互扣，走的是一条线：**从「无所依待」讲到「不去凿人」。**
