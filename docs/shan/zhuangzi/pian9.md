# 庄子·马蹄

- **《庄子》外篇第二篇**（全书第九篇）｜原文 3 段、约 678 字

> 马，蹄可以践霜雪，毛可以御风寒。龁草饮水，翘足而陆，此马之 真性也。虽有义台路寝，无所用之。及至伯乐，曰：「我善治马。」 烧之，剔之，刻之，雒之。连之以羁絷，编之以皁栈，马之死者十二 三矣！饥之渴之，驰之骤之，整之齐之，前有橛饰之患，而后有鞭筴之威，而马之死者已过半矣！陶者曰：「我善治埴。」圆者中规， 方者中矩。匠人曰：「我善治木。」曲者中钩，直者应绳。夫埴木之 性，岂欲中规矩钩绳哉！然且世世称之曰：「伯乐善治马，而陶匠善 治埴木。」此亦治天下者之过也。
>
> 吾意善治天下者不然。彼民有常性，织而衣，耕而食，是谓同德。 一而不党，命曰天放。故至德之世，其行填填，其视颠颠。当是时也 ，山无蹊隧，泽无舟梁；万物群生，连属其乡；禽兽成群，草木遂长 。是故禽兽可系羁而游，鸟鹊之巢可攀援而闚。夫至德之世，同与禽 兽居，族与万物并。恶乎知君子小人哉！同乎无知，其德不离；同乎 无欲，是谓素朴。素朴而民性得矣。及至圣人，蹩躠为仁，踶跂为义， 而天下始疑矣。澶漫为乐，摘僻为礼，而天下始分矣。故纯朴不残， 孰为牺尊！白玉不毁，孰为珪璋！道德不废，安取仁义！性情不离， 安用礼乐！五色不乱，孰为文采！五声不乱，孰应六律！
>
> 夫残朴以为器，工匠之罪也；毁道德以为仁义，圣人之过也。夫马 陆居则食草饮水，喜则交颈相靡，怒则分背相踶。马知已此矣！夫加 之以衡扼，齐之以月题，而马知介倪闉扼鸷曼诡衔窃辔。故马之知而 能至盗者，伯乐之罪也。夫赫胥氏之时，民居不知所为，行不知所之， 含哺而熙，鼓腹而游。民能已此矣！及至圣人，屈折礼乐以匡天下之 形，县跂仁义以慰天下之心，而民乃始踶跂好知，争归于利，不可止 也。此亦圣人之过也。

## 译文

马，蹄子可以踏霜雪，毛皮可以御风寒。吃草饮水，翘足而跳跃，这是马的真性。即使有高台大殿，对它也没有用处。等到伯乐出现，说：「我善于治马。」于是烧烙它、剪毛它、削蹄它、烙印它。用羁绊络头把它连起来，用马厩木栅把它编排起来，马就死去十分之二三了！又饿它渴它、驱驰它奔跑它、整饬它整齐它，前面有马嚼子装饰的祸患，后面有鞭打竹策的威逼，而马死去的已经过半了！陶匠说：「我善于治黏土。」圆的合于规，方的合于矩。木匠说：「我善于治木材。」弯的合于钩，直的应于绳。那黏土与木材的本性，难道想要合于规矩钩绳吗！然而世世代代都称道说：「伯乐善于治马，陶匠木匠善于治黏土木材。」这也是治天下的人的过错啊。

我料想善于治天下的人不是这样。那百姓有常性，织布而穿衣，耕地而吃饭，这叫做同德。纯一而不偏党，叫做天放。所以在至德之世，人们的行动安详，他们的目光质朴。在那个时候，山上没有小路隧道，水上没有舟船桥梁；万物群生，乡里相连；禽兽成群，草木畅茂。所以禽兽可以牵引着游玩，鸟鹊的巢可以攀上去观看。那至德之世，与禽兽同处，与万物并聚。哪里知道什么君子小人呢！同于无知，他们的德就不离散；同于无欲，这就叫素朴。素朴而百姓的本性就保全了。等到圣人出现，艰难勉强地去行仁，踮脚费力的去行义，天下才开始疑惑了。放纵地制作乐，繁琐地制作礼，天下才开始分裂了。所以完整的朴木不被残破，谁能做出牺尊！白玉不被毁坏，谁能做出珪璋！道德不被废弃，哪里用得着仁义！性情不离散，哪里用得上礼乐！五色不被搅乱，谁能做出文采！五声不被搅乱，谁能应和六律！

残破朴木来制作器具，是工匠的罪过；毁坏道德来制作仁义，是圣人的过错。那马在陆地居住就吃草饮水，高兴时交颈相摩，发怒时背对背相踢。马所知道的就到此为止了！等到给它加上衡轭，用月形的额饰来整齐它，马就知道了侧目、曲颈、猛夺、诡诈地吐掉嚼子、偷偷地咬断辔头。所以马的智巧而至于成盗的，是伯乐的罪过。那赫胥氏的时代，百姓居住不知道要做什么，行走不知道要去哪里，含着食物而嬉戏，鼓着肚子而游玩。百姓的能力就到此为止了！等到圣人出现，曲折身体去行礼拜乐来匡正天下人的形体，高悬踮脚去标举仁义来安慰天下人的心，而百姓才开始踮脚费力地喜好智巧，争着归趋于利，不可止住。这也是圣人的过错啊。

## 本篇导读

**《马蹄》是外篇里最短、也最直白的一篇，只有三段。** 全篇用两个比喻说一件事：**治理本身就是伤害。**

**第一个比喻是「治马」。** 马的本性是「蹄可以践霜雪，毛可以御风寒，龁草饮水，翘足而陆」——吃草、喝水、跳着跑，**「此马之真性也」，至于高台大殿，对它毫无用处**。然后是伯乐上场：「我善治马。」烧、剔、刻、雒，用羁绊连起来，用马厩编起来——**「马之死者十二三矣」**；再饿它渴它、驱它奔它、整它齐它，前面有嚼子的患，后面有鞭策的威——**「而马之死者已过半矣」**。

紧接着一笔横插进来：陶匠说自己善治黏土，木匠说自己善治木材。**「夫埴木之性，岂欲中规矩钩绳哉！」** 黏土和木材的本性，难道想要合于规矩钩绳吗？而世人却世世代代称道「伯乐善治马，陶匠善治埴木」——**「此亦治天下者之过也」。**

**第二个比喻是「至德之世」。** 百姓有常性：织布穿衣、耕地吃饭，「一而不党，命曰天放」。那个时代的样子：山上没有小路、水上没有船桥、禽兽成群、草木畅茂，**「禽兽可系羁而游，鸟鹊之巢可攀援而闚」**——可以牵着禽兽走，可以爬上鸟巢去看。**「同与禽兽居，族与万物并，恶乎知君子小人哉！」**

**这一段是全篇的题旨所在**：那个世代「同乎无知，其德不离；同乎无欲，是谓素朴。素朴而民性得矣」。等到圣人出现，「蹩躠为仁，踶跂为义」——**艰难勉强地去行仁，踮脚费力地去行义，天下才开始疑惑。** 接着四句排比是全篇最有名的：

> 故纯朴不残，孰为牺尊！白玉不毁，孰为珪璋！道德不废，安取仁义！性情不离，安用礼乐！

**「完整的东西不被破坏，哪来的器皿」**——祭器、玉器、仁义、礼乐，全都是从破坏中剪裁出来的东西。

**第三段收回到马身上。** 马在陆地吃草饮水，高兴时交颈相摩，发怒时背对背相踢，「马知已此矣」——马所知道的就到此为止。**等给它套上衡轭、加上额饰，马就学会了侧目、曲颈、猛夺、诡诈地吐掉嚼子、偷偷咬断辔头**——「故马之知而能至盗者，伯乐之罪也」。这一段极精彩：**马并没有变得更聪明，是被人逼出了「坏心眼」。** 接着同样的句式收尾——赫胥氏之民「含哺而熙，鼓腹而游」，「民能已此矣」；等到圣人用礼乐匡正形体、用仁义安慰人心，**「而民乃始踶跂好知，争归于利，不可止也。此亦圣人之过也」**。

**读这一篇要留意一个常被略过的层次：庄子不是说「人本来没有智巧」，而是说「智巧是被治出来的」。** 「马之知而能至盗者，伯乐之罪也」——马学到的那套规避技巧，恰恰是治马术的产物。这一层落到今天的管理、教育、制度设计上，依然锋利。
