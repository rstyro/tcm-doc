# 《庄子》· 南华真经

- 《庄子》是先秦道家最重要的典籍之一，通行本共三十三篇，约八万字，分内篇七、外篇十五、杂篇十一。
- 书中以寓言、重言、卮言为主要表达方式，不取条贯论证，而是借故事、对话与奇诡想象展开思想，文风在中国古籍中极为独特。
- 它与《[道德经](/shan/daodejing/)》并称道家两大根本典籍，同属传统五术之「山」中的玄典一脉，义理定位可参见《[玄典概说](/shan/xuandian)》。

## 其人其书

- 传统上认为庄子名周，战国时宋国蒙地人，曾为漆园吏，与梁惠王、齐宣王同时。其生平记载极少，主要见于《史记·老子韩非列传》，全文不过二百余字，且多存寓言色彩。
- 《庄子》一书并非一人一时之作。内篇风格统一、思想连贯，学界多认为最接近庄子本人的手笔；外篇、杂篇内容杂驳，掺入了后学的发挥，也含有黄老、法家乃至名辩的色彩。
- 因此读《庄子》要先分清「哪一层」：内篇是庄子，外篇杂篇是「庄子学派」。本站各篇导读里对争议篇章都有标注，不作「这就是庄子说的」式论断。

## 篇目与分篇

- **内篇七篇**（一至七）：传统认为出自庄子本人，是全书的思想核心。从《逍遥游》立境界、《齐物论》破是非，到《应帝王》收于治世，七篇有一内在的推进次第。
- **外篇十五篇**（八至二十二）：篇幅较长，议题更分散。其中《骈拇》《马蹄》《胠箧》《在宥》与《天道》部分段落，学界多认为带有黄老或法家色彩，面貌与内篇有明显距离；《秋水》《至乐》《达生》《山木》《知北游》则多有精彩寓言，流传极广。
- **杂篇十一篇**（二十三至三十三）：体例最杂，包含短论、故事集、人物评述。《天下》一篇是全书末篇，也是中国最早的学术史文章。其中《盗跖》《渔父》《说剑》《让王》四篇，古今学者多疑为伪作或晚出（详见各篇导读）。
- 本页各篇导读中，凡属学界有争议的部分都会明确写出，不把后学之作当作庄子的原意使用。

## 核心概念

- **道**：与《道德经》共用同一概念，指万物的本原与运行之理。庄子对「道」的特殊推进在于：它不在高处，而在「蝼蚁」「稊稗」「瓦甓」乃至「屎溺」之中（《[知北游](/shan/zhuangzi/pian22)》）。
- **逍遥**：无待之境。不依赖任何外在条件而自足，故《逍遥游》以「至人无己，神人无功，圣人无名」收束。
- **齐物**：万物在「道」的层面本无差别，是非、大小、生死之别皆因立场而生。《齐物论》是全书理论难度最高的一篇。
- **真人**：理想人格的写照。《大宗师》以「古之真人」一段集中描述，不惧生死、不逆寡、不雄成。
- **心斋与坐忘**：两种修养方法的名称。**心斋**见《人间世》，指「无听之以耳而听之以心，无听之以心而听之以气」的虚静状态；**坐忘**见《大宗师》，指「堕肢体，黜聪明，离形去知，同于大通」。
- **无用之用**：全书反复出现的一个思路。不材之木因其无用而免于斧斤，是全书中极具生活意味的一种安身之道。
- **物化**：万物相互转化的观念，最著名的表达是《齐物论》结尾的庄周梦蝶。

## 版本与流传

- **郭象注本（通行本）**：西晋郭象删定并注解的三十三篇本，是后世一切通行本的祖本。今日所谓「内七、外十五、杂十一」的分篇即由此定型。
- **唐成玄英疏**：在郭象注的基础上作疏解，与郭注合刊，是读《庄子》最常用的旧注组合。
- **明清评点与集解**：明焦竑《庄子翼》、清王先谦《庄子集解》、郭庆藩《庄子集释》等。其中郭庆藩《集释》汇集郭注、成疏及清代各家之说，是传统注疏的集大成之作。
- **现当代整理本**：陈鼓应《庄子今注今译》、刘笑敢《庄子哲学及其演变》等，以现代汉语注解疏通文义，便于初学入门。
- 需要留意的是，**「三十三篇」本身是郭象整理的结果**，不是庄子原书的原貌。《汉书·艺文志》著录《庄子》五十二篇，多出的十九篇已散佚，仅零星见于他书称引。因此本书的「完整」是相对通行本而言的。
- 本站各篇译文与导读为入门对照而自撰，取通行文意，不专主一家之说，也不作版本校勘。

## 阅读路径建议

- **先读内篇，按序读**：七篇有次第。先《[逍遥游](/shan/zhuangzi/pian1)》立起境界，再《[齐物论](/shan/zhuangzi/pian2)》拆掉是非，然后《[养生主](/shan/zhuangzi/pian3)》《[人间世](/shan/zhuangzi/pian4)》讲处世，《[德充符](/shan/zhuangzi/pian5)》《[大宗师](/shan/zhuangzi/pian6)》讲人格，《[应帝王](/shan/zhuangzi/pian7)》收于治世。不必一次读懂，先过一遍语感。
- **外篇挑着读**：《[秋水](/shan/zhuangzi/pian17)》《[至乐](/shan/zhuangzi/pian18)》《[达生](/shan/zhuangzi/pian19)》《[山木](/shan/zhuangzi/pian20)》寓言最集中、最好读，可作入口；《骈拇》《马蹄》《胠箧》是政治批评，读时留意其与内篇的距离。
- **杂篇当故事集读**：《[徐无鬼](/shan/zhuangzi/pian24)》多人物逸事，《[外物](/shan/zhuangzi/pian26)》《[寓言](/shan/zhuangzi/pian27)》含若干名篇，《[天下](/shan/zhuangzi/pian33)》单读亦无妨，它是全书最好的收尾。
- **不要强求「庄子到底主张什么」**：书中同一问题常有相反的说法，这本身是庄子的表达方式。遇到矛盾处，先记下来，不必急着统一。
- **配合旧注读**：《庄子》字义与句读的歧解极多，仅靠白话译文容易失掉层次。遇疑难处翻一下郭注成疏或陈鼓应本，看各家分歧在哪里，往往比得到一个「标准答案」更有用。

- 各篇导读中凡涉及修养、静定之法的内容，只作文献介绍，不构成实践指导。原文中出现的闭气、导引等具体做法，多为古人记述，未必适用于今人，请勿据以自行练习。
