# 庄子·刻意

- **《庄子》外篇第八篇**（全书第十五篇）｜原文 3 段、约 809 字

> 刻意尚行，离世异俗，高论怨诽，为亢而已矣。此山谷之士，非世之人，枯槁赴渊者之所好也。语仁义忠信，恭俭推让，为修而已矣。 此平世之士，教诲之人，游居学者之所好也。语大功，立大名，礼君 臣，正上下，为治而已矣。此朝廷之士，尊主强国之人，致功并兼者 之所好也。就薮泽，处闲旷，钓鱼闲处，无为而已矣。此江海之士， 避世之人，闲暇者之所好也。吹呴呼吸，吐故纳新，熊经鸟申，为寿而已矣。此道引之士，养形之人，彭祖寿考者 之所好也。若夫不刻意而高，无仁义而修，无功名而治，无江海而闲 ，不道引而寿，无不忘也，无不有也。淡然无极而众美从之。此天地 之道，圣人之德也。
>
> 故曰：夫恬惔寂漠，虚无无为，此天地之平而道德之质也。故曰： 圣人休，休焉则平易矣。平易则恬淡矣。平易恬淡，则忧患不能入，邪气不能袭，故其德全而神不亏。故曰：圣人之生也天行，其死也物化 。静而与阴同德，动而与阳同波。不为福先，不为祸始。感而后应， 迫而后动，不得已而后起。去知与故，循天之理。故无天灾，无物累 ，无人非，无鬼责。其生若浮，其死若休。不思虑，不豫谋。光矣而不耀，信矣而不期。其寝不梦，其觉无忧。其神纯粹，其魂不罢。虚 无恬淡，乃合天德。故曰：悲乐者，德之邪也；喜怒者，道之过也； 好恶者，德之失也。故心不忧乐，德之至也；一而不变，静之至也； 无所于忤，虚之至也；不与物交，淡之至也；无所于逆，粹之至也。 故曰：形劳而不休则弊，精用而不已则劳，劳则竭。水之性，不杂则 清，莫动则平；郁闭而不流，亦不能清；天德之象也。故曰：纯粹而不杂，静一而不变，淡而无为，动而以天行，此养神之道也。
>
> 夫有干越之剑者，柙而藏之，不敢用也，宝之至也。精神四达并流 ，无所不极，上际于天，下蟠于地，化育万物，不可为象，其名为同帝。纯素之道，唯神是守。守而勿失，与神为一。一之精通，合于天伦。野语有之曰：「众人重利，廉士重名，贤士尚志，圣人贵精。」 故素也者，谓其无所与杂也；纯也者，谓其不亏其神也。能体纯素，谓之真人。

## 译文

刻意尚行，离世异俗，高谈阔论、怨愤讥刺，只是为了高傲而已。这是山谷之士、非议世俗之人、枯槁赴渊者所喜好的。讲仁义忠信，恭俭推让，只是为了修身而已。这是平世之士、教诲之人、游居学者所喜好的。讲大功、立大名，以礼治君臣、端正上下，只是为了治理而已。这是朝廷之士、尊主强国之人、致功兼并者所喜好的。走向沼泽，处在闲旷，钓鱼闲居，只是为了无为而已。这是江海之士、避世之人、闲暇者所喜好的。吹呴呼吸，吐故纳新，像熊一样悬吊、像鸟一样伸展，只是为了长寿而已。这是导引之士、养形之人、彭祖寿考者所喜好的。至于那不刻意而自高，不修仁义而自修，不求功名而自治，不处江海而自闲，不事导引而自寿，无所不忘，无所不有。淡然无极而众美跟从他。这是天地之道，圣人之德。

所以说：那恬淡寂漠、虚无无为，是天地的平准而道德的实质。所以说：圣人休息，休息了就平易了。平易就恬淡了。平易恬淡，忧患就不能进入，邪气就不能侵袭，所以他的德完备而神不亏损。所以说：圣人的生是依天而行，他的死是随物而化。静时与阴同德，动时与阳同波。不为福先，不为祸始。受感而后回应，被逼而后行动，不得已而后兴起。去掉智巧与故旧，遵循天的理。所以无天灾，无物累，无人非，无鬼责。他的生像浮寄，他的死像休息。不思虑，不预谋。光明而不炫耀，诚信而不期约。他睡觉不做梦，醒来无忧虑。他的神纯粹，他的魂不疲惫。虚无恬淡，才合于天德。所以说：悲乐，是德的邪；喜怒，是道的过；好恶，是德的失。所以心不忧不乐，是德的极致；纯一而不变，是静的极致；无所违逆，是虚的极致；不与物交，是淡的极致；无所违逆，是粹的极致。所以说：形体劳累而不休息就疲敝，精神耗用而不停止就劳苦，劳苦就枯竭。水的本性，不杂就清，不动就平；郁闭而不流，也不能清：这是天德的形象。所以说：纯粹而不杂，静一而不变，淡而无为，动而依天而行，这是养神之道。

那拥有干越之剑的人，用匣子把它藏起来，不敢使用，是宝爱它到了极至。精神四达并流，无所不至，上接于天，下盘于地，化育万物，不可以形像来比拟，它的名字叫「同帝」。纯素的道理，只是守住神。守住而不失，就与神为一。一的精通，合于天伦。俗话说：「众人看重利，廉士看重名，贤士崇尚志，圣人宝爱精。」所以素，是说它没有与别的东西相杂；纯，是说它不亏损它的神。能体察纯素，就叫真人。

## 本篇导读

**《刻意》只有三段，短得像一篇文章的提纲——但它给出了外篇里最完整的一份「养神」纲领。** 篇名「刻意」就是「刻削心志」——**故意把自己磨成某个样子。**

**第一段是一张「士的清单」，六种人一路排下来，一种比一种高，然后一句话全部否定掉：**

- **山谷之士**：刻意尚行、离世异俗、高论怨诽，「为亢而已矣」——只为了高傲；
- **平世之士**：语仁义忠信、恭俭推让，「为修而已矣」；
- **朝廷之士**：语大功、立大名、礼君臣，「为治而已矣」；
- **江海之士**：就薮泽、处闲旷、钓鱼闲处，「无为而已矣」；
- **导引之士**：吹呴呼吸、吐故纳新、**熊经鸟申**，「为寿而已矣」。

**这张清单的高明处在于：它把「隐士」和「导引养生的人」也一并列入，跟他们所鄙视的「朝廷之士」放在同一个平面上。** 五者各有所「为」，因此都还是「刻意」。**而真正高的，是那句「若夫」：**

> 若夫不刻意而高，无仁义而修，无功名而治，无江海而闲，不道引而寿，无不忘也，无不有也。淡然无极而众美从之。

**「不刻意而高」「不道引而寿」——连养生这件事也不必修。** 这一段与内篇《[逍遥游](/shan/zhuangzi/pian1)》「至人无己」是同一路的，而「熊经鸟申」四个字也是中国文献里最早的导引术描述之一（本站《[五禽戏](/shan/wuqinxi)》一页会回指这里）。

**第二段是全篇的正文，讲「养神」。** 关键句是：

- **「其生若浮，其死若休。不思虑，不豫谋。光矣而不耀，信矣而不期。其寝不梦，其觉无忧。」**——睡觉不做梦，醒来无忧虑，这十四个字被后世养生家引了无数遍。
- **「悲乐者，德之邪也；喜怒者，道之过也；好恶者，德之失也。」**——把情绪直接定义为「德的失误」，这是《庄子》里对情绪最严厉的表述，与《[在宥](/shan/zhuangzi/pian11)》「人大喜邪，毗于阳」是一路的。
- **一组「极致」：** 「心不忧乐，德之至也；一而不变，静之至也；无所于忤，虚之至也；不与物交，淡之至也；无所于逆，粹之至也。」
- **「形劳而不休则弊，精用而不已则劳，劳则竭。」**——这是全篇最实用的警告，等于给所有「努力养生」的人画了一条线。
- 水的那句比喻：**「水之性，不杂则清，莫动则平；郁闭而不流，亦不能清。」**——注意后半句：**静不等于不动，郁闭不流的水也是浑的。** 这与《[天道](/shan/zhuangzi/pian13)》「水静则明烛须眉」是同一个意象、更进一层。

**第三段收在「纯素」上，末尾四句一路排下来极漂亮：**

> 众人重利，廉士重名，贤士尚志，圣人贵精。

**「贵精」两字是这一段的核心。「纯」是不亏其神，「素」是无所与杂，而「能体纯素，谓之真人」——「真人」这个词在《[大宗师](/shan/zhuangzi/pian6)》里已经铺陈了一大段，这里给出了它的操作性定义：不亏神、不杂染。**

**这一篇与《[刻意](/shan/zhuangzi/pian15)》同组的《[缮性](/shan/zhuangzi/pian16)》可以连着读**：刻意讲如何不刻意，缮性讲如何不修而修。两篇合起来，是外篇里对「养生—养神」这条线说得最集中的地方。**而它们共同的立场值得记住：连「养生」这件事，庄子都提醒别把它变成新的「刻意」。**
