# 山·食饵

- **概念定位:** 食饵是利用补药、药酒及日常饮食来增强体力、辅助调理身体的方法，属于"山"术中服食养生的一脉。在传统框架里，它借"吃"这一最日常的途径养护身心，与筑基、玄典等向内用功的方法相互配合。
- **药食同源:** 传统观念认为许多食物与药物本出同源，食物可以入药，药材也可以入食，两者之间并无截然界限；所谓"药膳""食疗"，正建立在这一认识之上。

## 源流概述

- 以饮食调养身体的思想在中国出现得很早，一般认为其发展大体经历了这样一个脉络：
    - 先秦时期，宫廷中已设有与饮食保健相关的专职，《周礼》所记的"食医"一职常被视为最早的例证。
    - 汉代以后，食养与药补的观念逐渐进入医学理论，《黄帝内经》中就有不少关于饮食调养的论述。
    - 唐代孙思邈所著《千金要方》对食治相当重视，一般认为其主旨之一是主张先以饮食调理、不效再议用药，这一取向对后世食疗思想影响深远。
    - 相传唐代孟诜撰有《食疗本草》，是较早以食疗为专题的著作；此后药膳与食补的风气大体沿此不断发展。
    - 宋元以降，养生专著增多，饮食调养的内容日益丰富，元代的《饮膳正要》即以宫廷饮膳与食疗养生为主题，常被视为古代营养与食疗文献的代表之一。
    - 明清时期，食疗与烹饪进一步结合，"药膳"逐渐成为民间日常养生的一部分，各类食养方书与本草著作中均多有收录。
- 一般认为食疗重在日常调理、药补偏于对症纠正，二者各有侧重；具体篇卷与主张则应以原书和可靠的学术整理本为准。

## 药食同源与本草传统

- "药食同源"的观念建立在古人对食物性味的认识之上。传统本草学以性（寒、热、温、凉）、味（酸、苦、甘、辛、咸）与归经来描述药物与食物的性质，认为二者遵循同一套性味框架。
- 许多日常食物在《本草纲目》等本草著作中都有记载，既可作为饮食，也具备传统理论中的调养取向，这正是"药膳"得以成立的认识基础。
- 但"药食同源"不等于"食物皆可当药"。传统医学同样强调食性有偏、须因人因时制宜，盲目把食物当药物长期大量食用，在传统观念里同样属于失当。
- 原卫生部曾公布过"药食同源"目录（即可用于保健食品的中药材名单），这是现代管理意义上的界定，与古代"药食同源"的文化观念含义不同，阅读古籍时宜加区分。

## 常见食饵取向举例

- 依传统补益观念的通俗归纳，食饵材料常被大致分为若干取向。以下仅作概念举例，不构成任何处方或用量建议：
    - **补气:** 一般认为与缓解气力不足、易感疲乏等相关，常见如山药、大枣、黄芪、党参之类。
    - **补血:** 在传统观念中与滋养血液、改善面色等相关，常见如红枣、桂圆、当归之类。
    - **滋阴:** 一般认为用于阴液偏亏、体易生燥的调养取向，常见如百合、银耳、枸杞之类。
    - **温阳:** 在传统观念中用于偏于虚寒、畏冷的调养取向，常见如生姜、肉桂、羊肉之类。
- 需要强调，上述归类是传统养生知识的简略概括：同一味材料在不同配伍、不同体质下的取向并不相同，不能望文生义地自行套用。
- 传统观念还讲究"药性归经"与配伍相须相使，单味食饵的作用有限，古人更重视整体的组方与长期的饮食结构，而非依赖某一种"神奇食材"。

## 药酒与膏方

- **药酒:** 以酒为溶剂浸泡药材，是传统食饵的常见形态之一。酒性辛温走窜，被认为有助于药力布散；节日药酒、保健药酒在民间饮食文化中屡见不鲜。
- **膏方:** 将多味药材（常配伍胶类、糖类）熬制成膏，便于长期服用，是秋冬调补的常见剂型，江南一带素有服膏方的习俗。
- 药酒与膏方均属专业调配范畴：酒与药同用会改变药性，膏方用量讲究一人一方，自行泡制或服用存在风险，应在医师、药师指导下进行。

## 服食与四时调养

- 传统养生重视顺应天时，一般认为饮食宜随四时寒热温凉而调整，春夏偏于清淡升发，秋冬则可适当偏向温养收藏。
- 民间流传的"秋冬进补""冬令进补"等说法，正是这种顺时观念落到生活习俗上的体现。
- 在传统养生观念中，进补讲究"虚则补之、以平为期"，并非人人需要进补，更非越补越好；不分体质一味进补，在传统观念里同样被视为禁忌。
- 传统观念还讲究"谷肉果菜，食养尽之"，主张饮食多样、荤素搭配、饥饱有度，把日常均衡饮食放在比"进补"更基础的位置。

## 服食与辟谷

- 传统上"服食"之说有时也与"辟谷"并提——辟谷指在一段时间内减少甚至停止谷食，配合调息静养以求养生。此类做法风险较高，本文不作提倡，仅作概念说明。
- 在道教文化中，辟谷常与"服气""饵药"搭配出现，被视为修炼的辅助手段；其历史源流与具体做法多见于道经与养生文献，门派说法不一。
- 从现代医学角度看，长期禁食或极端限食可能造成营养不良与代谢紊乱，绝非人人适合。任何形式的节食、断食都应在专业指导下进行，切勿仅凭古籍记载自行尝试。
- 传统文献中记载的辟谷人物往往同时配合服食特定药物与导引吐纳，是一种综合性修持，而非简单"不吃饭"，简单模仿极易伤身。

## 注意与禁忌

- 食饵属于传统文化与传统养生知识，不等于现代医学意义上的治疗，不能替代就医和规范用药。
- 药材的配伍、用量、炮制与服用禁忌均有讲究，自行乱服补药、药酒可能带来健康风险；本文不提供任何处方与剂量建议。
- 如需调理身体，请咨询有资质的医师、药师或营养专业人士；孕妇、儿童、老人及慢性病患者尤须谨慎。
- 历史上曾有以金石丹药求长生的风气，因丹药多含铅、汞等有毒物质而伤身甚至致死的记载并不少见。这股风气后来屡受批判，也提醒后人慎待一切"补益""长生"之说。
