# 五术之山

- **所谓:** “山”就是通过食饵、筑基、玄典、拳法、符咒等方法来修炼“肉体”与“精神”，以达充满身心的一种学问，是传统“山、医、命、相、卜”五术之首。
- 与其他四术相比，“医”重在祛病疗疾，“命、相、卜”重在推演与决断吉凶，而“山”所指向的，是人自身身心状态的养护与转化。它不向外求问，而是向内用功，因此常被概括为“修身养性之学”。
- 下文先交代“山”的整体框架与核心理念，再分条展开食饵、筑基、玄典、拳法、符咒五类；具体每一类的细说，可进入对应章节阅读。

## “山”字何意

- 传统注解对“山”字的取义并无统一说法，较常见的解释是取其“不动”“静定”之象：山岳岿然不动，隐喻身心安定、如如不迁的修养状态。
- 也有说法认为“山”指代古人隐居修炼的处所——远离尘嚣的深山是传统语境中修行的理想场所，“山”由此成为修炼之事的代称。
- 无论取哪种解释，其共同指向都在于：安定身心、收敛外驰的精神，从纷扰的日常中抽身，回到自身的修养上来。

## 核心理念

- **精、气、神三宝:** 传统养生观念把“精、气、神”称为人身三宝，认为三者是生命活动的基本要素。山术诸法大体都围绕固精、养气、凝神展开，只是下手处不同：
    - 食饵偏于物质层面的滋养，为身体提供基础；
    - 筑基通过静坐吐纳调养气与神；
    - 玄典从义理上端正心性认知；
    - 拳法以动功强健形骸、流畅气血；
    - 符咒则作用于传统观念中的精神、信仰层面。
- **性命双修:** 传统修炼文化讲究“性命双修”。“性”指心性、精神层面，“命”指形体、气血层面，理想的状态是二者并重、相互促进，而非偏执一端。这一观念把山术诸法贯穿为一个整体。
- **道法自然:** 山术深受道家“道法自然”思想的影响，主张顺应身心本有的节律去调养，反对勉强、速成与刻意强求，这与“无为而无不为”的哲学取向一脉相承。

- 五类并非截然分立：静坐之余辅以动功、读经与静观交替、食养为修持提供身体基础，都是传统中常见的做法。分类只是为了叙述方便，实际修持常是综合运用。
- 一般认为，五类之中以“筑基”与“玄典”最为根本——一在实修、一在明理，其余诸法多围绕二者展开。

## 源流简说

- 山术的思想土壤主要来自先秦的养生传统与道家哲学。先秦文献中已有关于导引、行气、食养、静定的零散记载，如《庄子》所记“熊经鸟申”、行气与坐忘之说，常被视为早期修炼文化的缩影。
- 汉代以后，这类观念与方术、医学、道教渐次交汇。一方面，养生思想进入医学理论，形成食养、导引等医学分支；另一方面，部分内容被道教吸纳，与丹道、符箓等仪式系统结合，成为道教文化的一部分。
- 魏晋以降，随着道教组织的成熟与内丹学的兴起，修炼理论日益系统化。许多山术概念（如“筑基”“百日”“精气神”）经由内丹文献获得更精细的表述，其传承也多依托师徒口传与丹经著述。
- 需要区分的是：先秦的道家义理、传统医学中的养生术、道教宗教文化中的方术，三者渊源相近却各有体系。后世所谓“山术”，常是这些脉络在民间传习中的统称，不宜一概而论。

## 文化定位与理性看待

- 今天研习山术，较合适的定位是把它们作为中国传统养生文化与哲学思想来了解：从中理解古人如何看待身心、自然与修养，借鉴其“顺其自然、贵在坚持、身心并重”等观念。
- 山术中的具体方法牵涉个人体质与身心健康，均应在正规医师、教练或有资质的传承者指导下进行；任何声称“速成”“返老还童”“特异功能”的说法都应警惕。
- 传统修炼文化的价值在于提供了一种关于身心修养的古老智慧，其效用更多落在安顿身心、涵养习惯与开阔文化视野上，不应被神化或作为替代医疗的手段。
