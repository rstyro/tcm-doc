# 修炼功法谱系与典籍导览

- 传统"山"术修炼确有功法流传，但功法体系庞杂、层次有别：有的公开普及、有标准教学，有的依托师承口传，有的则隐于丹经暗语、非文字可尽。
- 本页作为**功法体系导览**：梳理传统功法的谱系脉络、代表典籍与公开学习渠道，帮助读者"知道有哪些、到哪里正规学"。
- 出于安全与负责任考虑，本页**不收录具体功法步骤、口诀与火候**——修炼须有师承印证或正规教学指导，仅凭文字照练易出偏差。

## 功法的三个层次

- 传统功法大体可分三个层次，其公开性、安全性与学习方式各不相同：
    - **公开养生功法：** 以强身健体、调养身心为目的的动功与基础静功，有公开教材与国家/团体标准套路，风险较低，可依正规教学学习。
    - **师承内功：** 需师徒授受、依个人禀赋调整的静功吐纳与门派功法，讲究"口传心授、因材施教"，不宜自学者照书摸索。
    - **秘传口诀与丹道：** 门派内部不轻传的口诀与高阶火候，古籍多隐语（以"龙虎铅汞"等暗喻），非入门者可自行参透。
- 判断一个功法属于哪一层次，可从其**传承背景、教学方式、是否公开教材**三点大致判断。

## 动功类（公开普及为主）

- 动功以肢体运动配合呼吸导引，重在舒展筋骨、流畅气血，是传统功法中公开程度最高的一类：
    - **五禽戏：** 相传由东汉华佗创编，模仿虎、鹿、熊、猿、鸟之态。现代有国家体育总局推广的"健身气功·五禽戏"标准套路。
    - **八段锦：** 流传极广的传统健身功法，分坐式、立式等版本；"健身气功·八段锦"为其现代规范套路。
    - **易筋经：** 传统导引功法，以伸筋拔骨为要；现代有"健身气功·易筋经"标准版本。
    - **六字诀：** 以"嘘、呵、呼、呬、吹、嘻"六字吐音配合呼吸动作的养生功法，亦有"健身气功·六字诀"规范套路。
    - **太极拳：** 兼具技击与养生的拳术，流派众多（陈、杨、武、吴、孙等），广泛用于健身。
- 以上功法的**标准套路**由国家体育总局健身气功管理中心组织编订并公开推广，有权威教学视频与教材，是初学者最安全、最规范的学习入口（详见《[拳法](/shan/quanfa)》）。

## 静功类（筑基相关）

- 静功以静坐、调息、存想为要，是《[筑基](/shan/zhuji)》一脉的核心：
    - **数息、随息、听息：** 以呼吸为系心对象的入静方法，佛教禅修（如安那般那念）与道教静坐中皆有运用。
    - **意守丹田：** 将注意力安放于腹部的传统静坐法，讲究"似守非守、勿忘勿助"。
    - **存想/存思：** 道教上清派传统中以观想身中景象或神真为法的静功，多见于道经描述。
- 静功看似简单，实则涉及意念运用的分寸，不同传承说法差别很大；入门宜在**有经验的老师或正规禅修/静坐课程**指导下进行，避免自行加码。
- 现代语境下，经循证研究支持的 **正念冥想（MBSR）** 等可作为传统静坐的现代对照入门，见《[筑基](/shan/zhuji)》相关段落。

## 内丹体系（以文献导览为主）

- 内丹是传统修炼中最系统也最隐晦的一支，以"精气神"为药物、以"筑基→炼精化气→炼气化神→炼神还虚"为次第，理论深邃、门派众多。
- 重要文献（公开古籍，供了解体系）：
    - **《周易参同契》：** 相传东汉魏伯阳撰，借《周易》讲炼丹之理，被尊为"万古丹经王"，文字古奥、多隐语。
    - **《悟真篇》：** 北宋张伯端（紫阳）撰，以诗词阐发南宗丹法，为内丹重要典籍。
    - **《伍柳仙宗》：** 明伍守阳、清柳华阳合著（伍柳派丹法汇编），在丹经中相对条理清晰，常被作为研习丹道次第的入门书之一。
    - **《道藏》：** 道教典籍总集，内含大量丹道与养生文献，卷帙浩繁，宜在学术指引下查阅。
- 需要特别说明：丹经几乎都以隐喻写成（龙虎、铅汞、婴儿姹女等皆有所指），离开师承讲解极易误读误练。研读丹经应以**学术研究或门派传承的讲解**为前提，切勿自行按字面试验。
- 内丹文献属于修炼文化的理论遗产，其描述的身心体验现代科学尚无统一解释；了解其思想体系的价值在于理解传统文化，而非照方抓药。

## 各派体系一览（导览）

| 谱系 | 代表功法/法门 | 传承特点 | 公开学习程度 |
| --- | --- | --- | --- |
| 健身气功系统 | 五禽戏、八段锦、易筋经、六字诀等 | 国家编订标准套路 | 公开、正规、推荐 |
| 太极拳系统 | 陈/杨/武/吴/孙等流派 | 广泛教学 | 公开（正规拳馆教学） |
| 佛家禅定 | 安那般那念、四念处等 | 依经依师、寺院/禅修营传授 | 半公开（有正规禅修课） |
| 道家静坐/筑基 | 调息、意守、坐忘、心斋 | 师承为主 | 低（需明师指点） |
| 内丹（南北宗门） | 伍柳派、全真内丹等 | 师承秘传为主 | 低（文献公开、火候不传） |

- 上表为粗略归纳，各传统内部差异极大，仅供读者建立"谱系感"，不可视为严谨分类。

## 正规学习渠道建议

- **养生动功：** 首选国家体育总局推广的"健身气功"系列（含公开教材与视频），各城市健身气功站点、老年大学、体育院校多有教学。
- **太极拳：** 选择有资质、有传承脉络的太极拳馆或教练，先学规范套路再求深入。
- **静坐与正念：** 可选择有循证背景的正念课程，或传统寺院/机构的正规禅修课程；警惕以"开悟""出功能"为卖点的商业培训。
- **丹道研读：** 建议从学术角度阅读丹经整理本与易学/道教研究著作，或以门派正规传承者所办的学术讲座为入门，不轻信网络"秘传"。
- 判断一个渠道是否可靠，可留意：是否收费异常高昂、是否鼓吹速成与超常功能、是否阻挠与正规医疗接触、是否有清晰师承与出版教材。

## 重要提醒

- 传统修炼功法属于传统文化知识，不等同于现代医学的健身或治疗方案；身体不适请先就医。
- 凡涉及呼吸、意念的功法，患有严重心脑血管疾病、精神疾病者不宜自行练习；孕妇、老人等特殊人群应遵医嘱。
- 不轻信"速成""返老还童""出特异功能"等宣传；历史上因盲目照书练功而出偏、甚至被夸大宣传误导的教训并不少见。
- 本页仅作体系导览，不提供任何具体功法步骤，具体学习请咨询有资质的正规教学者或医疗机构。
