# 山·拳法

- 拳法是"山"术五类之一，指通过习练武术与导引动功来强健体魄、调养身心的方法，与食饵、筑基、玄典、符咒共同构成传统修炼养生的体系。
- 在中国传统文化中，锻炼身体并不仅限于武术技击，还包括以呼吸吐纳、肢体屈伸为主的养生导引，二者往往相互交融。
- 广义的"拳法"大体涵盖两端：一是以养生为目的的导引动功（如五禽戏、八段锦），二是兼备技击与健身的拳术（如太极拳、形意拳等）；两者在历史上互相渗透，难以截然分开。

## 源流简述

- 导引术一般认为可追溯至先秦时期，是一种以肢体运动配合呼吸吐纳来舒展筋骨、调畅气血的养生方法。
- 《庄子》中即有"熊经鸟申"等模仿动物姿态的表述，相传与早期的导引行气活动有关，可见此类锻炼在先秦已见端倪。
- 长沙马王堆汉墓出土的《导引图》以彩绘形式描绘了多种导引姿态，是研究早期导引术的珍贵实物资料，也印证了导引在秦汉之际已相当普及。
- 此后导引与武术渐次融合，既讲强身健体，也讲攻防技击，逐步演化出丰富的拳种与功法体系。

## 导引与武术的分合

- **导引重于养生:** 导引的核心是肢体运动与呼吸吐纳相配合，目的在于舒展筋骨、流畅气血，一般不涉及攻防对抗。
- **武术兼具技击:** 武术在发展过程中形成了踢打摔拿、器械演练等攻防技术体系，同时各门派又普遍把站桩、导引等作为基本功，用以增强体质、培养劲力。
- 两者长期相互滋养：养生功法为武术提供体能与内壮基础，武术则把导引方法纳入训练体系，形成"内练一口气、外练筋骨皮"的传统观念。
- 汉代以后，随着佛教、道教文化的传入与交融，武术还吸纳了吐纳、禅定等心性功夫，至明清形成"内外兼修"的成熟面貌，内家拳的兴起即为典型。

## 养生功法举例

- 五禽戏——相传由东汉华佗创编，模仿虎、鹿、熊、猿、鸟五种动物的动作来锻炼身体，是较早成套的导引功法。
- 八段锦——流传广泛的传统健身功法，由若干组动作串联而成，讲究柔和缓慢、舒展连贯，常被用作日常锻炼。
- 易筋经——传统导引功法之一，以伸筋拔骨、调息运气为要，多见于武学与养生文献的记载。
- 六字诀——以"嘘、呵、呼、呬、吹、嘻"六种吐音配合呼吸与动作的养生方法，讲究以声导气、以气养脏。
- 太极拳——集技击、导引与吐纳于一体的传统拳术，动作圆活连贯、以意导气，常被用于健身与修身。
- 以上功法仅作常识性介绍，各家各派传承不一、要领有别，此处不展开具体招式。

## 主要拳种谱系（概述）

- 中国武术拳种流派繁多，有"南拳北腿""内家外家"等粗略分类，以下仅列几个流传较广的代表性体系，供了解脉络：
    - **少林拳:** 以河南嵩山少林寺为文化符号，拳械体系庞大，讲究刚猛有力、硬打快攻，被视为"外家"代表的通行说法。
    - **太极拳:** 相传创自明清之际，流派有陈、杨、武、吴、孙等，以松柔圆活、以柔克刚为特色，广泛用于健身。
    - **形意拳:** 以五行拳、十二形为基本内容，动作简朴直进，讲究"整劲"与形意合一。
    - **八卦掌:** 以走转为核心，步法灵活、掌法多变，与形意、太极并称"内家三大拳"（通行说法）。
    - **咏春拳、洪拳等南派拳术:** 流行于岭南一带，结构紧凑、手法密集，各有鲜明地域特色。
- 需要说明，各拳种的起源多依托师徒传承与民间传说，史料未必翔实，"创自某人某地"的说法常常兼有传说成分，宜以学界与武术界的通行整理为准。

## 站桩与内功

- 站桩是武术与传统养生共有的基础功法，以静立姿势配合意念与呼吸进行调整，形似"不动"而内里求整，被视为培养下肢力量与全身整劲的入门功夫。
- 传统武术讲究"内功"，大致指通过呼吸、意念与姿势配合所练就的内在劲力与身体协调，与单纯的外部肌肉力量相对而言。
- 内功的说法玄妙纷杂，现代可用运动科学中的核心力量、身体协调、呼吸节奏等概念部分理解，不必拘泥于神秘化的表述。

## 练功的一般原则

- 松静自然——形体放松、意念安定、动作自然，不强行用力。
- 循序渐进——由易到难、由浅入深，逐步积累，不宜急于求成。
- 呼吸与动作配合——以呼吸引导动作的起落开合，逐步做到呼吸深、匀、细、长。
- 贵在坚持——锻炼重在规律与持之以恒，时断时续难以见效。
- 量力而行——依自身体质与年龄安排强度，以练后精神舒畅、不感过度疲惫为宜。

## 武德与传统观念

- 传统武术文化向来重视"武德"，主张习武以强身、防身、修身为目的，戒恃强凌弱、好勇斗狠，所谓"未曾学艺先学礼、未曾习武先习德"。
- 传统观念把武术视为"修身"的一种途径，认为练武不仅能强筋骨，更能磨练心性，使人沉稳、果毅而有节制。
- 现代习武者更应把武术当作体育与文化来对待，遵守规则、尊重对手，避免以武侠小说式的想象理解武术。

## 注意与禁忌

- 身体不适、患病或处于伤病恢复期时，应先就医诊治，并遵医嘱决定是否锻炼。
- 初学武术或导引者，宜在专业教练或老师的指导下练习，以免动作不当造成损伤。
- 过于疲劳、情绪波动较大或饭前饭后不久，一般不宜进行剧烈锻炼。
- 传统锻炼以强身健体为目的，不可替代现代医疗；如有疾病应及时就医。
