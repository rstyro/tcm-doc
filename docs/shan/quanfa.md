# 山·拳法

- 拳法是"山"术五类之一，指通过习练武术与导引动功来强健体魄、调养身心的方法，与食饵、筑基、玄典、符咒共同构成传统修炼养生的体系。
- 在中国传统文化中，锻炼身体并不仅限于武术技击，还包括以呼吸吐纳、肢体屈伸为主的养生导引，二者往往相互交融。

## 源流简述
- 导引术一般认为可追溯至先秦时期，是一种以肢体运动配合呼吸吐纳来舒展筋骨、调畅气血的养生方法。
- 《庄子》中即有"熊经鸟申"等模仿动物姿态的表述，相传与早期的导引行气活动有关，可见此类锻炼在先秦已见端倪。
- 此后导引与武术渐次融合，既讲强身健体，也讲攻防技击，逐步演化出丰富的拳种与功法体系。

## 养生功法举例
- 五禽戏——相传由东汉华佗创编，模仿虎、鹿、熊、猿、鸟五种动物的动作来锻炼身体，是较早成套的导引功法。
- 八段锦——流传广泛的传统健身功法，由若干组动作串联而成，讲究柔和缓慢、舒展连贯，常被用作日常锻炼。
- 易筋经——传统导引功法之一，以伸筋拔骨、调息运气为要，多见于武学与养生文献的记载。
- 太极拳——集技击、导引与吐纳于一体的传统拳术，动作圆活连贯、以意导气，常被用于健身与修身。
- 以上功法仅作常识性介绍，各家各派传承不一、要领有别，此处不展开具体招式。

## 练功的一般原则
- 松静自然——形体放松、意念安定、动作自然，不强行用力。
- 循序渐进——由易到难、由浅入深，逐步积累，不宜急于求成。
- 呼吸与动作配合——以呼吸引导动作的起落开合，逐步做到呼吸深、匀、细、长。
- 贵在坚持——锻炼重在规律与持之以恒，时断时续难以见效。
- 量力而行——依自身体质与年龄安排强度，以练后精神舒畅、不感过度疲惫为宜。

## 注意与禁忌
- 身体不适、患病或处于伤病恢复期时，应先就医诊治，并遵医嘱决定是否锻炼。
- 初学武术或导引者，宜在专业教练或老师的指导下练习，以免动作不当造成损伤。
- 过于疲劳、情绪波动较大或饭前饭后不久，一般不宜进行剧烈锻炼。
- 传统锻炼以强身健体为目的，不可替代现代医疗；如有疾病应及时就医。
