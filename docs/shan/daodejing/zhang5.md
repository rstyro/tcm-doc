# 第五章 天地不仁

> 天地不仁，以万物为刍狗；圣人不仁，以百姓为刍狗。天地之间，其犹橐龠(tuó yuè)乎！虚而不屈，动而愈出。多言数穷，不如守中。

## 译文

天地没有偏爱，把万物看作草扎的祭品，任其自生自灭；圣人也没有偏爱，把百姓看作草扎的祭品，任其自生自长。天地之间，岂不像一个风箱吗？内部虚空却不会塌陷，越是鼓动，风就越是不断生出。话说多了反而处处碰壁，不如守住内心的虚静。

## 详解

「不仁」不是残忍，是不偏心。天地没有偏爱，把万物看成草扎的祭品（刍狗）——用过了就放下，不特意护着谁；圣人也不偏心，对百姓一视同仁。这话听着冷，细想却是最大的公平：太阳既照好人，也照坏人。

第二层是一个比喻：天地之间像一具风箱（橐龠），里面是空的，可你越鼓动它，风就出的越多。**虚，才有用不完的劲。**

最后一句最要紧：「多言数穷，不如守中」。话说多了、政令烦了，反倒把自己逼进死角；不如守住中间那个空处——少说、少下命令、留余地。带团队、管家庭都一样：规矩越细，破规矩的办法越多。
