# 第五十九章 治人尚啬

> 治人事天，莫若啬（se）。
>
> 夫为啬，是谓早服；早服谓之重积德；重积德，则无不克；无不克，则莫知其极；莫知其极，可以有国；有国之母，可以长久。是谓深根固柢（di），长生久视之道。

## 译文

治理百姓、养护身心，没有比爱惜节俭更好的了。

正因为爱惜节俭，才能及早顺道而行；及早顺道而行，就叫做不断积德；不断积德，就无所不能胜任；无所不能胜任，就没人知道他的极限；没人知道他的极限，就可以保有国家；掌握了治国的根本，就可以长久。这就叫做根扎得深、柢扎得牢，是长生久存的道理。

## 详解

「治人事天，莫若啬」——治理百姓、养护身心，没有比「啬」更好的方式。「啬」不是吝啬，是**爱惜、收敛、不浪费**——对精力、资源、念头都省着用。

第二段是一串连锁推演：能收敛，就叫「早服」（早早地顺应、早早地准备）；早服叫做不断积德；不断积德就无往不胜；无往不胜就没人能测出他的边界；没人能测出边界，就可以承担一个国家；有了治国的根本（国之母），就可以长久。

末句「是谓深根固柢，长生久视之道」——这叫做根扎得深、柢扎得牢，是长久存在的道理。

这一章跟第 48 章是一对：一个讲「日损」，一个讲「啬」，都是把消耗降下来。**从节省开始，才谈得上积累。**
