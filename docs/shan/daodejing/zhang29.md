# 第二十九章 圣人无为

> 将欲取天下而为之，吾见其不得已。天下神器，不可为也。为者败之，执者失之。
>
> 故物或行或随，或歔（xu）或吹，或强或羸（lei），或载或隳（hui）。
>
> 是以圣人去甚，去奢，去泰。

## 译文

想要夺取天下而加以治理，我看是达不到目的的。天下是神妙的存在，不可以强行作为。强行作为的必然失败，把持不放的必然失去。

所以世间万物，有的前行有的后随，有的缓吁有的急吹，有的强健有的羸弱，有的安载有的堕毁。

因此圣人去除极端，去除奢侈，去除过度。

## 详解

「将欲取天下而为之，吾见其不得已」——想拿下天下再按自己的意思去摆弄，我看这是办不成的。

接着一句很重的判断：天下是「神器」，不可以硬来（不可为也）。「为者败之，执者失之」——动手去干的人把它弄坏了，抓得死死的人把它丢掉了。**世间最难的东西，往往越用力越走偏。**

第二段说明原因：物的禀性各不相同——有的前行有的跟随，有的缓有的急，有的强有的弱，有的安稳有的倾颓。既然天生不一样，就不可能用一把尺子量到底。

第三段给做法，三个「去」：「去甚，去奢，去泰」——去掉极端，去掉奢侈，去掉过度。这三条不是戒律，是操作建议：把可能把事做崩的那部分先拿掉。
