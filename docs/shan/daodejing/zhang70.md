# 第七十章 被褐怀玉

> 吾言甚易知，甚易行。天下莫能知，莫能行。言有宗，事有君。夫唯无知，是以不我知。知我者希，则我者贵。是以圣人被褐（he）而怀玉。

## 译文

我的话很容易明白，很容易实行。可是天下没有人能明白，没有人能实行。言论有其主旨，行事有其根据。正因为人们不明白这个道理，所以不了解我。了解我的人越少，效法我的人就越显得可贵。所以圣人身上穿着粗布衣服，怀里却揣着美玉。

## 详解

第一段说得很朴素：「吾言甚易知，甚易行。天下莫能知，莫能行」——我的话很容易懂，很容易做；可天下竟没人懂，没人做。这种话在经典里并不少见，老子说得格外平。

接着讲原因：「言有宗，事有君」——话有它的主旨，事有它的根据。也就是说，不是不懂字面，是不认得那个主旨。所以他又说：「夫唯无知，是以不我知」——正因为人们不认识那个根本，所以不认识我。而「知我者希，则我者贵」——懂我的人少，取法我的人才显珍贵。

末句铸成一个流传极广的形象：「是以圣人被褐而怀玉」——所以圣人穿着粗布衣服，怀里揣着美玉。

**「被褐怀玉」这四个字值得单独记下来**：外面看着寻常，里头有真东西。这也是对全书人格理想的一次总结。
