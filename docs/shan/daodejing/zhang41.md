# 第四十一章 大器晚成

> 上士闻道，勤而行之；中士闻道，若存若亡；下士闻道，大笑之。不笑，不足以为道。故建言有之：
>
> 明道若昧，进道若退，夷道若颣（lei）。
>
> 上德若谷，大白若辱，广德若不足，
>
> 建德若偷，质真若渝（yu）。
>
> 大方无隅（yu）；大器晚成；
>
> 大音希声，大象无形，
>
> 道隐无名。
>
> 夫唯道，善贷（dai）且成。

## 译文

上等资质的人听了道，勤勉地去实行；中等资质的人听了道，半信半疑；下等资质的人听了道，哈哈大笑。不被这种人嘲笑，就不足以成其为道。所以古人立下的话里有这样几句：

光明的道好像暗昧，前进的道好像后退，平坦的道好像崎岖。

崇高的德好像低下的川谷，洁白的好像沾染了污垢，广大的德好像不足，

刚健的德好像懈怠，质朴纯真好像浑浊未定。

最方正的反而没有棱角；最大的器物最后才完成；

最大的声音听不出声响，最大的形象看不见形迹；

道幽隐而没有名称。

只有道，善于辅助万物而使其成就。

## 详解

第一段讲闻道的三种反应：上等的人听了道，努力去做；中等的人听了道，将信将疑，时而记得时而忘掉；下等的人听了道，大笑不止。而「不笑，不足以为道」——不被嘲笑，就不成其为道了。**真道理在当下常常听着不像道理**，因为它跟流行看法拧着。

后面几段是「建言」引的格言，一串「A 若 B」的悖论句：光明的道像是暗昧，前进的道像是后退，平坦的道像是崎岖；崇高的德像低下的山谷，最白净的像含着污垢，宽广的德像不足；刚健的德像懈怠，质朴真实像浑浊变易。

再往下是全书的几处名句：「大方无隅」——最大的方形没有棱角；「大器晚成」——大器要到最后才成；「大音希声」——最大的声音听不见；「大象无形」——最大的形象没有形状。这几句都在说同一件事：**到了极致，反而看不出形迹。**

最后一句「夫唯道，善贷且成」——只有道，善于给予，也善于成就。给出去，才成事。
