# 第七十三章 天网恢恢

> 勇于敢则杀，勇于不敢则活。此两者，或利或害。天之所恶，孰知其故？
>
> 是以圣人犹难之，天之道，不争而善胜，不言而善应，不召而自来，繟（chan）然而善谋。天网恢恢，疏而不失。

## 译文

勇于逞强就会送命，勇于不敢逞强就能存活。这两种勇，一个带来害处，一个带来好处。上天所厌恶的，谁知道其中的缘故呢？

所以圣人还把这件事看作难事。自然的规律是：不争而善于取胜，不言而善于应答，不召唤而自动到来，从容舒缓而善于谋划。天道的大网宽广无边，网眼虽稀疏却不会漏失。

## 详解

「勇于敢则杀，勇于不敢则活」——敢闯敢拼的常常断送自己，敢于「不敢」的反而活得下来。两个「勇」字放在一起，一下子把「勇」分成了两种：一种是逞强，一种是能忍住不逞强。接着一句：这两样，有的有利，有的有害。天所厌恶的，谁知道其中的缘故？

第二段先承认难测：「是以圣人犹难之」——所以连圣人在这件事上也不敢轻率。然后一转，给出天道的四条特性：「不争而善胜，不言而善应，不召而自来，繟然而善谋」——不争却善于取胜，不说却善于回应，不召唤却自然到来，从容舒缓却善于谋划。

末句是流传最广的八个字：「天网恢恢，疏而不失」——天道的大网宽广无边，网眼虽疏，却不会漏掉。**这句话的力量在于「疏」**：它不密，不盯人，可也不漏。
