# 第四十四章 知足不辱

> 名与身孰（shu）亲？身与货孰多？
>
> 得与亡孰病？
>
> 是故，甚爱必大费，多藏必厚亡。
>
> 故知足不辱，知止不殆，可以长久。

## 译文

名声与生命，哪一个更亲近？生命与财货，哪一个更贵重？

得到与失去，哪一个更有害？

所以，过分吝惜必定会造成大的耗费，过多收藏必定会招致惨重的损失。

所以知道满足就不会受辱，知道适可而止就不会遭险，这样才可以长久。

## 详解

四组拷问，把人生的账本摊开：

「名与身孰亲？」名声和身体，哪个更亲近？「身与货孰多？」身体和财货，哪个更多？「得与亡孰病？」得到和失去，哪个更有害？三个问题都没有直接答案，但摆在谁面前，谁心里都会晃一下。

第二段给判断：「甚爱必大费，多藏必厚亡」——爱得太深，消耗一定大；藏得太多，损失一定重。**因为你在乎的东西，就是你被牵制的地方。**

第三段给结论，也是全章最有名的十二个字：「知足不辱，知止不殆，可以长久」。知道满足就不受辱，知道停下就不危险，这样才走得远。

注意「知止」和「知足」是两个动作：知足管欲望，知止管行动。心里够了，脚下才停得住。
