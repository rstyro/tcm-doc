# 第八十一章 善者不辩

> 信言不美，美言不信。
>
> 善者不辩，辩者不善。
>
> 知者不博，博者不知。
>
> 圣人不积，既以为人，己愈有；既以与人，己愈多。天之道，利而不害；圣人之道，为而不争。

## 译文

真实的话不漂亮，漂亮的话不真实。

善良的人不巧辩，巧辩的人不善良。

真懂的人不卖弄广博，卖弄广博的人不是真懂。

圣人不为自己积藏，越是尽力帮助别人，自己反而越充足；越是把东西给予别人，自己反而越丰富。自然的规律，是施利于万物而不加损害；圣人的准则，是有所作为而不与人争。

## 详解

全书的最后一章，用三组对偶收束，句句是全书主题的再次确认。

「信言不美，美言不信」——真实的话不漂亮，漂亮的活不真实。「善者不辩，辩者不善」——好人不巧辩，巧辩的人不好。「知者不博，博者不知」——真懂的人不卖弄广博，卖弄广博的人不真懂。三组都是同一个动作：**把「说得好看」和「确实如此」分开。**

第二段讲给予的悖论：「圣人不积，既以为人，己愈有；既以与人，己愈多」——圣人不为自己积藏，越是为人做事，自己越充实；越是给出去，自己越丰厚。这不是经济学，说的是**能力、信誉、关系这些东西，用一次长一次**。

最后两句总结全书的两条路：「天之道，利而不害；圣人之道，为而不争」——天的运行法则是让万物得益而不加害；圣人的行事法则是去做，但不与人争。八十章讲下来，收在这十六个字上，也算收得稳。
