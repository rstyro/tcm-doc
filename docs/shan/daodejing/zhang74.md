# 第七十四章 民不畏死

> 民不畏死，奈何以死惧之？若使民常畏死，而为奇者，吾得执而杀之，孰敢？
>
> 常有司杀者杀。夫代司杀者杀，是谓代大匠斫（zhuo）。夫代大匠斫者，希有不伤其手矣。

## 译文

百姓连死都不怕，怎么能用死来吓唬他们呢？如果能让百姓一向畏惧死亡，对那些为非作歹的人，我就把他抓来杀掉，谁还敢作乱呢？

但历来有专管杀人的去执行杀戮。代替专管杀人的人去杀，就好比代替高明的木匠去砍木头。代替木匠砍木头的人，很少有不砍伤自己手的。

## 详解

「民不畏死，奈何以死惧之？」——百姓连死都不怕了，你拿死来吓唬他还有什么用。**这是一句反问，问的是刑罚的失效。** 当最重的刑罚都镇不住人的时候，说明问题已经不在刑罚这一头了。

第二段是假设句：如果能让百姓常常畏死，对那些为非作歹的人，我抓来杀了，谁还敢？这句其实是把严刑的幻想推到底，让人自己看出它站不住。

第三段是结论，也是全章最好的比喻：「常有司杀者杀」——总有专管杀伐的那一方在杀（指天道、自然规律）。而「代司杀者杀，是谓代大匠斫」——代替专管杀伐的去杀，就像代替高明的木匠去砍木头。最后一句极准：「夫代大匠斫者，希有不伤其手矣」——替木匠砍木头的人，很少有不砍伤自己手的。

**这一章讲的不是宽刑，是分工**：各归其位，越界代劳，先伤的是自己。
