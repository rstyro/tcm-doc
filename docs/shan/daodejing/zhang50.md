# 第五十章 出生入死

> 出生入死。生之徒十有三；死之徒十有三；人之生，动之死地，亦十有三。夫何故？以其生生之厚。盖闻善摄（she）生者，陆行不遇兕（si）虎，入军不被甲兵。兕无所投其角，虎无所措其爪，兵无所容其刃。夫何故？以其无死地。

## 译文

人从出生到死亡。属于长寿一类的，占十分之三；属于短命一类的，占十分之三；本来可以生存、却自己走向死路的，也占十分之三。这是什么缘故？因为奉养生命过于丰厚。听说善于养护生命的人，在陆上行走不会遇到犀牛猛虎，进入军阵不会受到兵器伤害。犀牛用不上它的角，猛虎用不上它的爪，兵器用不上它的锋刃。这是什么缘故？因为他身上没有可以致死的空隙。

## 详解

「出生入死」四个字，通常被读成「冒着生命危险」，但这里是在讲生死的数据。

活着的人占十分之三，死掉的人占十分之三，而本来活着却自己走向死地的，也占十分之三。为什么？「以其生生之厚」——因为太用力地想活、把养生搞得太厚重。**补得太狠，反倒伤了本**，这一点在今天格外好懂。

后半段是另一种人：「善摄生者」——真正善于养护生命的人，走在陆地上不遇兕虎，进了军队不被兵刃所伤。不是他有神通，是那些凶险的东西找不着他下口的地方：兕的角无处可投，虎的爪无处可落，刀锋无处可入。

末句点明原因：「以其无死地」——因为他身上没有那块「可以死的地方」。**这句话的落点不是长生，是不把自己放到危险的处境里去。**
