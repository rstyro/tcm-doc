# 第六十三章 能成其大

> 为无为，事无事，味无味。大小多少，报怨以德。图难于其易，为大于其细；天下难事，必作于易； 天下大事，必作于细。是以圣人终不为大，故能成其大。夫轻诺必寡信，多易必多难。是以圣人犹难之，故终无难矣。

## 译文

以无为的态度去作为，以不生事的方式去做事，以恬淡无味当作滋味。大生于小，多起于少，用德去回报怨恨。处理难事要从容易处入手，成就大事要从细微处做起；天下的难事，必定是从容易的地方发展起来的；天下的大事，必定是从细微的地方积累而成的。所以圣人始终不自以为大，因此才能成就大事。轻易许诺的人必定很少守信用，把事情看得太容易必定遭遇很多困难。所以圣人总是把事情看得很困难，因此终于没有困难。

## 详解

开篇三个「无」：「为无为，事无事，味无味」——把不妄为当作作为，把不弄事当作办事，把平淡当作滋味。三句都是把动作降下来。

接着一句是异文里最有名的一处：「大小多少，报怨以德」——把小的看成大的，把少的看成多的，用德去回应怨。这一句后来在《论语》里被拿去做过对照，是儒道两家分歧最清楚的接口之一。

第二段是全章最好用的方法论：「图难于其易，为大于其细」——处理难事要从容易处入手，做大事要从细微处起步。接着两句：「天下难事，必作于易；天下大事，必作于细」。所以圣人始终不自居为大，反而能成其大。

第三段提醒反面：「夫轻诺必寡信，多易必多难」——**轻易许诺的人，一定少守信用；把事情看得太容易的人，一定遇到更多难处。** 所以圣人把事情看得难一些，最后反倒没有难事。
