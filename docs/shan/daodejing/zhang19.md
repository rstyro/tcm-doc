# 第十九章 绝圣弃智

> 绝圣弃智，民利百倍；绝仁弃义，民复孝慈；绝巧弃利，盗贼无有。此三者，以为文不足。故令有所属：见素抱朴，少私寡欲。

## 译文

抛弃聪明的智巧，百姓可以得到百倍的好处；抛弃刻意标榜的仁义，百姓就能恢复孝慈的天性；抛弃取巧和贪利，盗贼就会消失。这三条只是文饰，还不足以治理天下。所以要使人有所归属：显现本色，持守质朴，减少私心，降低欲望。

## 详解

这一章接着上一章往下说，给出的是减法方案：

抛弃聪明的智巧，百姓能得到百倍的好处；抛弃刻意标榜的仁义，百姓就能恢复孝慈的天性；抛弃取巧和贪利，盗贼就会消失。

老子不是要人不聪明、不厚道，而是说：**刻意标榜的道德一旦成了评优的指标，就会变成表演。** 用尺子量孝顺，家里就会出现给人看的孝顺。

后面一句很实在：「此三者，以为文不足」——光说这三条还不够，得让人有地方落脚：显现本色（见素），持守质朴（抱朴），减少私心，降低欲望。

两条纲领合起来就是全书的一个核心动作：**做减法。** 与其不断加规则，不如把使人变坏的条件撤掉。
