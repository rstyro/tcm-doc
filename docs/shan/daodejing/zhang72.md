# 第七十二章 自爱不贵

> 民不畏威，则大威至。
>
> 无狎（xia）其所居，无厌其所生。
>
> 夫唯不厌，是以不厌。
>
> 是以圣人自知不自见（xian），自爱不自贵。故去彼取此。

## 译文

当百姓不再害怕统治者的威压时，可怕的祸乱就要到来了。

不要逼迫百姓的居所，不要压榨百姓的生计。

正因为不压榨百姓，所以百姓才不厌弃统治者。

所以圣人有自知之明而不自我表现，爱惜自身而不自命高贵。因此舍弃后者而选取前者。

## 详解

「民不畏威，则大威至」——当百姓不再害怕威严的时候，真正的大威就要来了。**恐惧的失效本身就是信号**：靠威严维持的秩序，一旦威严不好使，秩序就到头了。

第二段两句是劝告：「无狎其所居，无厌其所生」——不要逼迫百姓的居所，不要压榨百姓的生计。给他们留地方住、留活路走。

第三段是一个回环：「夫唯不厌，是以不厌」——正因为你不压迫人，所以才不被厌弃。上句的「厌」是压，下句的「厌」是厌弃，两个意思叠在一起，读起来很有意思。

末段落到圣人的自处：「自知不自见，自爱不自贵」——了解自己但不自我显摆，爱惜自己但不自命高贵。「故去彼取此」——去掉后者，取用前者。

把这两句拎出来就是：**自省可以留，自恋要去掉。**
