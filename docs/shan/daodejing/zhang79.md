# 第七十九章 道与善人

> 和大怨，必有余怨，安可以为善？
>
> 是以圣人执左契（qi），而不责于人。有德司契，无德司彻。
>
> 天道无亲，常与善人。

## 译文

调解深重的怨恨，必定还会留下残余的怨恨，这怎么能算是妥善的办法呢？

所以圣人虽然拿着借据的左半，却并不据此去责求于人。有德的人像持借据的人那样宽厚，无德的人像收税的人那样苛刻。

天道没有偏爱，却常常帮助行善的人。

## 详解

「和大怨，必有余怨，安可以为善？」——调和了大的怨恨，必定还剩下余怨；这怎么算得上妥善呢？

**这句话的洞见在于「余怨」二字**：怨恨一旦结下，就算面上和解，底下还会留一层。所以真正高明的做法不是事后调停，而是别把怨恨结起来——这就接上了第 63 章的「报怨以德」。

第二段用契券作比：「是以圣人执左契，而不责于人」——圣人握着借据的左半（借出的一方留存的那半），却不拿它去向人讨要。「有德司契，无德司彻」——有德的人拿着凭据而不催逼，无德的人才像征赋税一样斤斤计较。

末句「天道无亲，常与善人」——天道没有偏私，却总是站在行善的人那一边。**「无亲」和「常与」并不矛盾**：规则对谁都一样，而按规则办事的人自然得到好处。
