# 第二章 美之为美

> 天下皆知美之为美，斯恶已。皆知善之为善，斯不善矣。故有无相生，难易相成，长短相较，高下相倾，音声相和，前后相随。是以圣人处无为之事，行不言之教。万物作焉而不辞，生而不有，为而不恃，功成而弗居，夫唯弗居，是以不去。

## 译文

天下人都知道美之所以为美，丑的观念也就产生了；都知道善之所以为善，不善的观念也就有了。所以有和无互相生发，难和易互相促成，长和短互相比较，高和下互相依存，音和声互相应和，前和后互相跟随。因此圣人以无为的态度处事，用不言的方式施行教化。听任万物自行生长而不去干预，生养万物而不据为己有，有所作为而不自恃其能，事情成功而不居功。正因为不居功，功绩才不会离他而去。

## 详解

天下人都知道「美」是美，是因为心里已经立了「丑」这把尺子；都知道「善」是善，是因为已经有了「不善」的标准。判断一落地，对立就跟着来。所以有和无互相催生，难和易互相成全，长和短互相显出对方，高和下互相依靠，音和声互相应和，前和后互相跟随——两两相对，谁也离不了谁。

既然事物本来就是这样成对的，做人就不必硬挑一头、把另一头按死。所以圣人做事用「无为」：不硬插一手，顺着事情本来的势去推；教人用「不言」：不靠喊口号，靠把事做成给人看。

末段是一串「不」：让万物自己生长而不去管束，生养万物而不占为己有，出了力也不自恃有功，事情成了也不把功劳揽在怀里。正因为不揽功，功劳反倒跑不掉。

这一章可以当成全书的总纲：**先把对立看清楚，再从对立里退出来，退到那个不争的位置上做事。**
