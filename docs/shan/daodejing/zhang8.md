# 第八章 不争无尤

> 上善若水。水善利万物而不争，处众人之所恶，故几于道。居善地，心善渊，与善仁，言善信，正善治，事善能，动善时。夫唯不争，故无尤。

## 译文

最高的善就像水一样。水善于滋养万物而不与万物相争，停留在众人都厌恶的低处，所以最接近于道。居处善于选择低下之地，心境善于保持深沉，交往善于施予仁爱，言语善于恪守诚信，为政善于治理，做事善于发挥所长，行动善于把握时机。正因为不争，所以没有过失。

## 详解

「上善若水」是全书流传最广的比喻，值得慢读。

水有两个本事：一是利万物，二是往低处走。它滋养一切却不跟谁争高低，还偏要待在众人嫌弃的低洼处——正因如此，它最接近道。

接下来七句把「像水一样」拆成七个动作：居处要选稳的地势，心要沉得住（像深渊），待人要厚道，说话要算数，治理要有条理，办事要用所长，出手要看时机。七件事没有一个讲「赢」，讲的全是**把自己的位置摆对**。

结尾点题：正因为不争，所以没有过失。不是让你放弃争取，是让你别把力气都花在争上——水从不跟石头吵，可最后是它把石头磨圆的。
