# 第四十七章 不行而知

> 不出户，知天下；不窥（kui）牖（you），见天道。其出弥远，其知弥少。是以圣人不行而知，不见而名，不为而成。

## 译文

不出门户，就能知晓天下的事；不望窗外，就能明白自然的规律。向外奔走得越远，所知道的反而越少。所以圣人不远行就能知晓，不亲眼看见就能明辨，不妄自作为就能成功。

## 详解

全章很短，却往往被人误读成「不必出门，就能知道一切」的神秘主义。

先看原文：不出门就能知道天下，不望窗外就能看见天道；走出去越远，知道的反而越少。所以圣人不用走就能知道，不用看就能命名，不用做就能成事。

**关键在「知道什么」**：老子说的不是事实和信息，而是规律。信息当然要走出去才能拿到，可规律不必——规律在自家院子里也能验证：草木的荣枯、人的喜怒、家用的消长，哪一样不是「反者道之动」？反过来，一个人不断往外面跑，拿回一堆消息，却看不出其中的模式，那就是「其出弥远，其知弥少」。

今天的信息环境把这一章的意思放大了：**不是信息不够，是模式看不清。**
