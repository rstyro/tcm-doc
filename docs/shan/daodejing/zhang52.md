# 第五十二章 天下有始

> 天下有始，以为天下母；既得其母，以知其子； 既知其子，复守其母，没身不殆。塞其兑，闭其门，终身不勤；开其兑，济其事，终身不救；见小曰明，守柔曰强。用其光，复归其明，无遗身殃（yang），是为袭常。

## 译文

天下万物都有本始，可以把它看作天下的母体。既然得到了母体，就能认识它的子女；既认识了子女，再回守母体，终身就不会有危险。堵住欲望的孔窍，关上欲望的门户，终身都不会有困扰；打开欲望的孔窍，去应付纷繁的事务，终身都无可救药。能察见细微叫做明，能持守柔弱叫做强。运用外照的光，再回归内在的明，不给自身留下祸殃，这就叫做承袭常道。

## 详解

开篇四句是全章的一条路线图：天下有一个开端，可以当作天下的母体；既然得到了母体，就能知道它生出来的孩子（万物）；既然知道了孩子，再回来守住母体，终身不会有危险。

**注意这个顺序**：不是守住抽象的道就够了，而是先认识具体的事物，再从具体的事物回到它背后的那个根本。先有「子」，才谈得上「守母」。

中间一段讲收心：「塞其兑，闭其门」——堵住嗜欲的孔窍，关上情欲的门户，终身不会受窘；反过来，「开其兑，济其事」，终身不可救。这两句是在讲注意力的分配：**感官全天开着的人，收不回来。**

再往下是四句格言：能看见细微叫「明」，能守住柔弱叫「强」；用它的光，却回到自己的明，不给自身留下祸殃，这就叫「袭常」。
