# 第五十六章 知者不言

> 知者不言，言者不知。
>
> 塞其兑，闭其门，挫其锐，解其纷，和其光，同其尘，是谓玄同。故不可得而亲，不可得而疏；不可得而利，不可得而害；不可得而贵，不可得而贱。故为天下贵。

## 译文

真正懂得的人不多言，夸夸其谈的人并不真懂。

堵住欲望的孔窍，关上欲望的门户，磨去锋芒，化解纠结，收敛光芒，混同尘世，这就叫做玄妙的同一。所以对这样的人，无法去亲近他，也无法去疏远他；无法去利诱他，也无法去伤害他；无法去抬举他，也无法去贬低他。所以他为天下所尊贵。

## 详解

开篇八个字很干脆：「知者不言，言者不知」——真懂的不多说，说个不停的大多没懂。**这话本身不必抠字面，它讲的是「说」和「知」的关系**：知道的人知道话说不全，所以话少；不知道的人以为说完就懂了，所以话多。

第二段是老子的收束术，和第 4 章、第 52 章有交叉：「塞其兑，闭其门，挫其锐，解其纷，和其光，同其尘」——堵住欲望的孔窍，关上取舍的门户，磨去锋芒，解开纠缠，收敛光芒，混同尘世。这六句合起来叫「玄同」——玄妙的同一。

然后是一串「不可得而」：对这样的人，你无法把他拉近，也无法把他推远；无法给他好处，也无法害他；无法抬举他，也无法贬低他。因为他不在那个能被摆动的位置上。**所以天下人推重他。**
