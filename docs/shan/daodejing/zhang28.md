# 第二十八章 知雄守雌

> 知其雄，守其雌（ci），为天下溪。为天下溪，常德不离，复归于婴儿。
>
> 知其白，守其黑，为天下式。为天下式，常德不忒（te），复归于无极。
>
> 知其荣，守其辱。为天下谷。为天下谷，常德乃足，复归于朴（pu）。
>
> 朴散则为器，圣人用之，则为官长，故大制不割。

## 译文

深知什么是雄强，却安守雌柔的位置，甘作天下的溪涧。甘作天下的溪涧，恒常的德就不会离散，回复到婴儿般的状态。

深知什么是明亮，却安守暗昧的位置，甘作天下的范式。甘作天下的范式，恒常的德就不会出差错，回复到无穷无尽的本原。

深知什么是荣耀，却安守卑辱的位置，甘作天下的川谷。甘作天下的川谷，恒常的德才充足，回复到未经雕琢的质朴。

质朴一散，就变成了各种器物；圣人沿用这质朴，就成了百官之长。所以最好的治理是不割裂万物。

## 详解

三段排比，句式一样，意思层层递进。

「知其雄，守其雌，为天下溪」——知道什么是刚强，却守住柔和，做天下的溪谷。溪谷是什么？是众水所归的地方。守柔的结果「常德不离，复归于婴儿」——本有的德不散失，回到婴儿那样纯一的状态。

「知其白，守其黑，为天下式」——明白什么是显赫，却安于暗处，做天下的范式。结果「常德不忒，复归于无极」。

「知其荣，守其辱，为天下谷」——知道什么是荣耀，却守住承受，做天下的空谷。结果「常德乃足，复归于朴」。

注意三段的共同结构：**「知」在前面，「守」在后面。** 不是不知道雄、白、荣，而是知道了却选择守另一头。这跟无能、退缩完全是两回事。

末段「朴散则为器，圣人用之，则为官长，故大制不割」——朴一旦散开就成了器物，圣人用这个道理去管理，所以好的制度不割裂人与事。
