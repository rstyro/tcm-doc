# 第十六章 殁身不殆

> 致虚极，守静笃。万物并作，吾以观复。夫物芸芸，各复归其根。归根曰静，是曰复命。复命曰常，知常曰明。不知常，妄作凶。知常容，容乃公，公乃王，王乃天，天乃道，道乃久，殁身不殆。

## 译文

使心灵虚寂到极点，坚守清静到笃实。万物一齐生长，我从中观察它们的循环往复。万物纷纭繁茂，各自回归到本根。回归本根叫做静，也就是回复本然之性。回复本然之性叫做常，认识常叫做明。不认识常而轻妄行动，就会招致凶险。认识常就能包容一切，能包容就能公正无私，能公正无私就能周遍周全，能周遍周全就合于天，合于天就合于道，合于道就能长久，终身不遭危险。

## 详解

这一章是老子讲修养最完整的一段，可以当功法读。

「致虚极，守静笃」——把心清空到极点，守静守到踏实。空不是发呆，是把杂念、成见、急切先撤走，让事情本来的样子露出来。

接着是观察：万物一齐生长，我从中看它们的循环往复。草木长到极盛会落，水蒸到天上会成雨——万物纷纭繁茂，最后各自回归本根。回归本根叫做「静」，也叫「复命」（回复本来的样子）。回复本然叫做「常」（恒常的规律），认识到「常」叫做「明」（明白）。

反面一句很硬：「不知常，妄作凶」——不识规律，硬来，招祸。

正面是一串推演：能包容→就能公正→就能周全→就能合于天→合于道→就能长久，终身不遭危险。**这条路是从「装得下」开始的**：容不下不同意见，公正就无从谈起。
