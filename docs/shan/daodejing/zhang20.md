# 第二十章 独异于人

> 绝学无忧。唯之与阿，相去几何？善之与恶，相去若何？人之所畏，不可不畏。荒兮其未央哉！众人熙熙，如享太牢，如春登台；我独泊兮其未兆，如婴儿之未孩。傫傫兮若无所归！众人皆有余，而我独若遗。我愚人之心也哉，沌沌兮！
>
> 俗人昭昭，我独昏昏。俗人察察，我独闷闷。澹兮其若海，飂兮若无止。众人皆有以，而我独顽且鄙。我独异于人，而贵食母。

## 译文

绝弃那些浮华的学问，就没有忧愁。恭敬地应一声「唯」和随便应一声「阿」，相差多少？美好与丑恶，又相差多少？别人所畏惧的，自己也不能不有所畏惧。这风气茫茫，好像没有尽头。众人都兴高采烈，像去赴丰盛的宴席，像春天登台远眺；唯独我淡泊安静，无动于衷，像婴儿还不会发出笑声。疲倦闲散啊，好像无处可归。众人都富足有余，唯独我像什么都匮乏。我真是愚人的心肠啊，浑浑沌沌。

世俗之人都那么光耀自炫，唯独我昏昏昧昧；世俗之人都那么精明细察，唯独我懵懵懂懂。恬淡啊像大海一样沉静，飘荡啊像没有止境。众人都各有所长，唯独我又笨拙又鄙陋。我偏偏与众人不同，因为我看重那养育万物的根本。

## 详解

这一章有点像老子的自画像，语气罕见地带着情绪。

开篇「绝学无忧」：放下那些浮华的学问，反而没有忧愁。接着拿两声应答作比——恭敬地应一声「唯」和随便应一声「阿」，差多少？美好和丑恶，又差多少？差距往往只在一层薄薄的评判上。别人所畏惧的，你也得有所畏惧，这风气茫茫，像没有尽头。

中间是全章最动人的一段：众人都兴高采烈，像去赴盛宴、像春天登台远望；唯独我淡泊安静，无动于衷，像还不会笑的婴儿。疲倦闲散啊，好像无处可归。众人都富足有余，唯独我像缺了什么。我的心真是愚人的心肠啊，浑浑沌沌。

第二段对比更狠：世人光耀自炫，我昏昏昧昧；世人精明细察，我懵懵懂懂；恬淡啊像大海那样沉静，飘荡啊像没有止境。众人都各有所长，唯独我又笨又陋。

最后一句才把底露出来：「我独异于人，而贵食母」——我偏偏与众人不同，因为我看重那养育万物的根本。**表面上的「不如人」，是因为取法的标准不一样。**
