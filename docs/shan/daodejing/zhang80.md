# 第八十章 小国寡民

> 小国寡民。使有什（shi）伯之器而不用。使民重死而不远徙（xi）。虽有舟舆（yu），无所乘之； 虽有甲兵，无所陈之。使民复结绳而用之。甘其食，美其服，安其居，乐其俗。邻国相望，鸡犬之声相闻，民至老死不相往来。

## 译文

国土小些，百姓少些。即使有各种器械也用不上。让百姓看重生命而不轻易迁徙远方。虽然有船只车辆，却没有必要去乘坐；虽然有铠甲兵器，却没有机会去陈列。让百姓回到结绳记事的淳朴状态。百姓觉得自己的饮食甘美，觉得自己的衣服漂亮，安于自己的居所，乐于自己的风俗。邻国之间相互望得见，鸡鸣狗叫的声音相互听得到，而百姓直到老死也不互相往来。

## 详解

这一章是老子笔下的理想社会，画面感极强，也最常被误解。

「小国寡民」——国土小一点，人口少一点。接着是一串「有而不用」：使百姓有各种器具却不轻易使用；使百姓看重生命而不向远处迁徙；虽然有船有车，却不怎么去乘坐；虽然有铠甲兵器，却没有地方陈列。

然后两句更有意思：「使民复结绳而用之」——让百姓回到结绳记事那样的简朴方式；「甘其食，美其服，安其居，乐其俗」——觉得自家的饮食甘美，衣服美好，居所安稳，风俗可乐。**这四句不是讲物质水平，是讲「不比较」**：没有对照，所以自己手里的就够好。

最后「邻国相望，鸡犬之声相闻，民至老死不相往来」——邻国互相望得见，鸡犬之声互相听得到，百姓到老死也不互相往来。

读这一章不必当作政治纲领，它更像一把尺子：**用来量「我们为了便利，付出了多少安宁」。**
