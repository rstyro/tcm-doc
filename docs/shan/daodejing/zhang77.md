# 第七十七章 不欲见贤

> 天之道，其犹张弓欤（yu）？高者抑（yi）之，下者举之；有余者损之，不足者补之；天之道，损有余而补不足；人之道则不然，损不足以奉有余。
>
> 孰能有余以奉天下？唯有道者。
>
> 是以圣人为而不恃，功成而不处，其不欲见贤。

## 译文

自然的规律，岂不就像张弓射箭吗？高了就把它压低，低了就把它抬高；拉得过满的就减少一些，不足的就补足一些。自然的规律，是减损有余的来补足不足的；人世的法则却不是这样，而是减损不足的来供奉有余的。

谁能把自己多余的拿出来奉献给天下呢？只有得道的人。

所以圣人有所作为而不自恃其能，事情成功而不居功，他不愿显露自己的贤能。

## 详解

开篇用张弓作比：「天之道，其犹张弓欤？」张弓的要点是：高了就按低一点，低了就抬高一点；拉过了就减一些，不够就补一些。所以「天之道，损有余而补不足」——天道是减损有余的，补足不足的。

接着一句犀利的对比：「人之道则不然，损不足以奉有余」——人间的做法恰恰相反，是从不足的人那里取来，供奉给已经有余的人。**这两句是全书对现实的批评里最重的一处**，说得很平，分量很足。

第二段一个反问：「孰能有余以奉天下？」——谁能把自己有余的拿出来给天下？答案是「唯有道者」。

末段讲这中间的分寸：「是以圣人为而不恃，功成而不处」——圣人做了事不自恃有功，事情成了也不居其位。原因是一句「其不欲见贤」——**他不想让人看见自己贤能。** 一露贤名，这套有余补不足的机制就变成了一场表演。
