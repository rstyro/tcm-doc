# 第七十五章 无以生为

> 民之饥，以其上食税之多，是以饥。
>
> 民之难治，以其上之有为，是以难治。
>
> 民之轻死，以其上求生之厚，是以轻死。
>
> 夫唯无以生为者，是贤于贵生。

## 译文

百姓之所以饥饿，是因为统治者吞食的赋税太多，所以才饥饿。

百姓之所以难以治理，是因为统治者妄自作为，所以才难以治理。

百姓之所以轻生冒死，是因为统治者奉养自己太过丰厚，所以百姓才轻生冒死。

只有不刻意去求取丰厚生活的人，才胜过那些一味贵养生命的人。

## 详解

这一章是三段并列的因果，句式完全一样，指向也完全一样。

「民之饥，以其上食税之多，是以饥」——百姓挨饿，是因为上面收的税太多。**注意主语的落点**：不是百姓懒，是上面取太多。

「民之难治，以其上之有为，是以难治」——百姓难治，是因为上面爱折腾。

「民之轻死，以其上求生之厚，是以轻死」——百姓不把死当回事，是因为上面求生求得太厚，把民力耗尽了。

三段下来是一条链：取多→贪难→拼命；有为→民乱；厚养己→民不惜命。**三个症状，一个病根——上方。** 这也回应了第 74 章：民不畏死，不是民的问题。

末句给出方向：「夫唯无以生为者，是贤于贵生」——只有不把养生、养己当回事的人，才胜过那些过分看重自己生命的人。
