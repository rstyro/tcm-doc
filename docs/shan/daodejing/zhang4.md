# 第四章 象帝之先

> 道冲，而用之或不盈。渊兮似万物之宗。挫其锐，解其纷，和其光，同其尘。湛兮似或存，吾不知谁之子，象帝之先。

## 译文

道是虚空的，用它却不会穷竭。它深不可测，像是万物的宗主。它磨去锋芒，化解纠结，收敛光芒，混同尘世。它幽隐得似有似无，我不知道它是从哪里产生的，似乎在天帝出现之前就已经存在了。

## 详解

道是空廓的（冲），可怎么用都用不完；它深得望不到底，像是万物的祖宗。

接着四句「挫其锐，解其纷，和其光，同其尘」——磨掉棱角，解开纠缠，收敛光芒，混同尘世。这既是老子给「道」画的自画像，也是给人画的修行图：真有分量的人不扎眼、不摆姿态，能在人群里待得住。

它隐隐约约像是存在着，说它没有它又在起作用；我不知道它是谁生的，只知道它比天帝还早。

日常可用的地方就一条：**把锋芒收一点，把心结解一点，别老想着让别人看见自己发光。** 低一档活着，反而立得住。
