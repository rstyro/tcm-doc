# 第十二章 圣人为腹

> 五色令人目盲；五音令人耳聋；五味令人口爽；驰骋畋猎，令人心发狂；难得之货，令人行妨。是以圣人为腹不为目。故去彼取此。

## 译文

缤纷的色彩使人眼睛昏花，繁复的音声使人耳朵失聪，丰盛的滋味使人口味败坏，纵马打猎使人心神狂躁，稀有难得的财物使人行为受到妨害。所以圣人只求安饱而不逐声色。因此舍弃后者而选取前者。

## 详解

五色看多了眼花，五音听多了耳背，五味吃重了口舌失灵，纵马打猎让人心神发狂，难得的东西让人动歪心（行妨）。

老子不是反对感官享乐，而是提醒：**过度刺激会把感官本身用坏。** 尝慣了重口味，青菜就吃不出甜；天天刷快节奏的东西，读书就读不进去了。

所以「圣人为腹不为目」——求个温饱踏实，不追求看得花哨。「去彼取此」就是取舍两个字：舍掉那些让你眩目的，留下那些真正养人的。

换成今天的话：少刷一点、少吃重口一点、少追热点一点，日子反而更清楚。
