# 第三十三章 知人者智

> 知人者智，自知者明。
>
> 胜人者有力，自胜者强。
>
> 知足者富，强行者有志。
>
> 不失其所者久，死而不亡者寿。

## 译文

了解别人是聪明，了解自己才是明达。

战胜别人是有力量，战胜自己才是刚强。

知道满足的人富有，努力不懈的人有志向。

不丧失自己根基的人能够长久，身死而精神不朽的人才算长寿。

## 详解

四组对照，把人一层层往内推：

「知人者智，自知者明」——能看透别人是聪明，能看透自己才是明白。这和第 24 章的「自见者不明」一正一反：向外看的叫智，向内看的叫明。

「胜人者有力，自胜者强」——打赢别人靠的是力气，管得住自己才叫强。同样的词，一个给外部的胜负，一个给内部的交战。

「知足者富，强行者有志」——**知道满足的人，是真的富有**；坚持往前走的人，是有志向的人。富有不在账户余额，在心里那个「够了」。

「不失其所者久，死而不亡者寿」——不丢掉自己位置的人能长久；人死了而被忘记才算真死，有人记得的，叫「寿」。

四条读下来，是一份向内做功夫的清单。
