# 第十八章 道亡有义

> 大道废，有仁义；智慧出，有大伪；六亲不和，有孝慈；国家昏乱，有忠臣。

## 译文

大道被废弃了，才有人提倡仁义；聪明的智巧出现了，才有严重的虚伪；家庭亲属不和睦了，才显出孝慈；国家昏乱动荡了，才显出忠臣。

## 详解

全章只四句，句句是反话：

大道被废弃了，才有人提倡仁义；聪明的智巧出现了，才有严重的虚伪；家庭亲属不和睦了，才显出孝慈；国家昏乱动荡了，才显出忠臣。

老子的意思不是反对仁义孝慈，而是提醒人们看清**症状和病根**：当「孝顺」被反复表扬时，说明平常的关注已经稀薄；当「诚信」要写进红头文件时，说明它已经稀缺了。

所以读这一章要会拐个弯：别急着夸那些被表彰的美德，先看看是什么环境把它们逼成了稀罕物。这个视角放到任何组织里都好用——**越是天天被强调的东西，往往越是缺的。**
