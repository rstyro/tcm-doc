# 第二十一章 惟道是从

> 孔德之容，惟道是从。道之为物，惟恍惟惚。惚兮恍兮，其中有象；恍兮惚兮，其中有物。窈兮冥兮，其中有精。其精甚真，其中有信。自今及古，其名不去，以阅众甫。吾何以知众甫之状哉！以此。

## 译文

大德的表现，完全随顺于道。道这个东西，恍恍惚惚。惚惚恍恍啊，其中却有形象；恍恍惚惚啊，其中却有实物。它幽深晦暗啊，其中却有精质；这精质非常真实，其中有可以验证的信实。从今天上溯到古代，它的名字一直不曾消失，凭它可以审视万物的初始。我怎么知道万物初始的情形呢？就是凭这个。

## 详解

「孔德之容，惟道是从」——大德的样子，完全随顺于道。道是内容，德是它在你身上的呈现。

接着描述道的存在方式：恍恍惚惚。惚惚恍恍之中有形象，恍恍惚惚之中有实物；幽深晦暗之中有精质，这精质很真实，里面有可以验证的信实。

这一段的好处在于它讲清了「看不见但可信」的依据：不是凭感觉，是**能反复验证**。看不见的规律，总会在具体事物上留下痕迹，有痕迹就能检验。

末句「自今及古，其名不去，以阅众甫」——从今天上溯到古代，它的名字一直没消失，凭它可以审视万物的初始。我怎么知道万物初始的情形？就是凭这个。
