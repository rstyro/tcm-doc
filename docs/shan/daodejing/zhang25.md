# 第二十五章 道法自然

> 有物混成，先天地生。寂（ji）兮寥（liao）兮，独立而不改，周行而不殆（dai），可以为天地母。吾不知其名，字之曰道，强为之名曰大。大曰逝，逝曰远，远曰反。
>
> 故道大，天大，地大，王亦大。域中有四大，而王居其一焉。
>
> 人法地，地法天，天法道，道法自然。

## 译文

有一个混然一体的东西，在天地形成之前就已存在。它无声无形，独立长存而不改变，循环运行而不止息，可以看作天地的根本。我不知道它的名字，勉强称它为「道」，再勉强给它起名叫「大」。大就意味着流逝，流逝就意味着遥远，遥远就意味着返回。

所以道大、天大、地大、王也大。宇宙之中有四种大，而王居其中之一。

人取法地，地取法天，天取法道，道取法它自己的本然。

## 详解

「有物混成，先天地生」——有一个浑然一体的东西，在天地之前就存在了。老子在这里罕见地正面描述道的来历：它寂静无声、空虚无形，独立长存而不改变，循环运行而不停歇，可以看作天地的母体。

接着是老子式的「命名困难」：我不知道它叫什么，只好给它取个字叫「道」，勉强形容它叫「大」。大就意味着往远处走（逝），越走越远（远），走到极处又返回来（反）。**「反」是关键词**：不是抽身而去，而是走远之后的回归——昼夜、四季、潮汐都是这个节奏。

第二段从道拉到人间：道大、天大、地大、王也大，宇宙中有四大，王是其中之一。这句话在先秦是相当抬举人的——人不是天地的奴仆，而是同一个序列里的成员。

最后一句是全书的名句「人法地，地法天，天法道，道法自然」。四层递进，终点不是「道」，而是「自然」——**道取法的最终对象是它自己的本然**，不是谁的命令。所以「道法自然」不是叫你回归山野，而是叫你按事物本来的样子办事。
