# 第三十二章 知止不殆

> 道常无名，朴虽小，天下莫能臣也。侯王若能守之，万物将自宾（bin）。
>
> 天地相合，以降甘露，民莫之令而自均。
>
> 始制有名，名亦既有，夫亦将知止，知止可以不殆。
>
> 譬（pi）道之在天下，犹川谷之于江海。

## 译文

道永远没有名称。它像未经雕琢的原木那样质朴微小，天下却没有谁能支配它。侯王如果能持守它，万物将会自动归从。

天地之气相合，降下甘露，没有人命令百姓，百姓自然就均平。

万物兴作之初就有了名称，名称既已有了，就该知道适可而止；知道适可而止，就可以避免危险。

道存在于天下，就好像江海是川谷的归宿一样。

## 详解

「道常无名，朴虽小，天下莫能臣也」——道永远没有名字，它像未经雕琢的木头那样质朴微小，可天下没有谁能支配它。

接着讲效验：侯王如果能守住它，万物自然归附。天地之气相合，降下甘露，不用谁下命令，百姓自然均平。这里说的是一种「不需要强推」的秩序。

第三段是全章最有用的一句：「始制有名，名亦既有，夫亦将知止，知止可以不殆」。制度一建立就有了名分和分工，名分一定下来，就要知道界限在哪——**知道该停在哪里，才不会出事。** 定规矩重要，知道规矩的边界同样重要。

末句一个比喻：道存在于天下，就像江海是川谷的归宿。
