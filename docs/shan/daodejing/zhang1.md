# 第一章 天地之始

> 道可道，非常道；名可名，非常名。无，名天地之始；有，名万物之母。故常无，欲以观其妙；常有，欲以观其徼。此两者，同出而异名，同谓之玄。玄之又玄，众妙之门。

## 译文

可以用言语说出来的道，就不是恒常不变的道；可以用名称叫出来的名，就不是恒常不变的名。「无」，是天地初生的本始；「有」，是万物生养的母体。所以要常从「无」处着眼，去体会道的微妙；常从「有」处着眼，去观察道的边际。这两者同出一源而名称不同，都可以称为幽深。幽深之中再幽深，正是一切奥妙的门径。

## 详解

「道」要是能被一句话讲完，它就不是那个恒常的道了。这跟「我说了你就该懂」是两回事：我们每个人都站在自己的十字路口，你说往东，他说往西，各自都有道理，可这些道理都从各自的经验和常识里长出来。经验有边界，常识有局限，所以道说不尽——能说出口的，只是它的一个切面。就像没人见过风的样子，可风一动，草伏树摇，民风、作风、家风都攒着千钧之力：这就是道，你能说出它，却说不出它的全部。

「名」也一样。「手机」这个词并不等于任何一台真实的手机，它只是个共用的标签。标签好用，但把标签当成实物，就容易走偏。

接着老子给了两把钥匙：「无」指天地还没分化的那个本始，「有」指万物已经长出来的母体。所以看道要分两路走——常从「无」这头看，看它幽微难言的妙处；常从「有」这头看，看它落实成具体事物后的形迹边际。这两头是一个源头，只是叫法不同，都叫做「玄」；玄里再套一层玄，就是一切奥妙的门。

落到日用：既要看事物「有」的一面——能兑现的成果、数字、器物；也要留一份对「无」的敬意——那些还没成型、还没名字的余地。只认「有」，容易把工具当目的；只谈「无」，又成了空谈。
