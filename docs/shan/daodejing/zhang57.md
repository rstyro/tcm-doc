# 第五十七章 以正治国

> 以正治国，以奇用兵，以无事取天下。吾何以知其然哉？以此。
>
> 天下多忌讳（hui），而民弥贫；民多利器，国家滋（zi）昏；人多伎（ji）巧，奇物滋起；法令滋彰，盗贼多有。
>
> 故圣人云：“我无为而民自化；我好静而民自正；我无事而民自富；我无欲而民自朴。”

## 译文

用正道治理国家，用奇谋用兵作战，用不生事的方式取得天下。我凭什么知道是这样的呢？就凭以下这些。

天下的禁忌越多，百姓就越贫穷；民间的利器越多，国家就越昏乱；人们的技巧越多，邪门的东西就越层出不穷；法令越森严，盗贼反而越多。

所以圣人说：「我无为，百姓自然归化；我好静，百姓自然端正；我不生事，百姓自然富足；我没有贪欲，百姓自然质朴。」

## 详解

开篇三个「以」立纲领：以正道治国，以奇谋用兵，以不折腾取天下。三种场景三种手法，**这就点出老子并不是一概反对手段**，他只是反对在治国和养民上用手段。

第二段是一串因果：天下禁令越多，百姓越贫困；民间利器越多，国家越昏乱；人的技巧越花，邪门东西越冒出来；法令越森严，盗贼反而越多。这四句说的都是**管制与反抗的同步增长**。

第三段用圣人的话给出替代方案，四个「我…而民…」：「我无为而民自化；我好静而民自正；我无事而民自富；我无欲而民自朴」——我先退一步，百姓自然长起来。

这一章常被拿来讨论治理，其实放到带孩子、带团队上也准：**你的动作做了多少，对方就自己长多少；你替他做完了，他就不用长了。**
