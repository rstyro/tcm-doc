# 第二十六章 静为躁君

> 重为轻根，静为躁君。
>
> 是以君子终日行不离辎（zi）重。虽有荣观，燕处超然。奈何万乘之主，而以身轻天下？
>
> 轻则失本，躁则失君。

## 译文

厚重是轻浮的根基，静定是躁动的主宰。

所以君子整天行走，也不离开载着辎重的车辆。即使有华美的景观可看，也安然处之而不动心。为什么拥有万辆兵车的大国之君，却要以自身的轻率去治理天下呢？

轻率就会失去根基，躁动就会失去主宰。

## 详解

开篇两句是格言式的判断：「重为轻根，静为躁君」——厚重是轻浮的根基，静定是躁动的主宰。

接着拿出行作比：君子整天赶路，却不离开辎重（装行李粮草的车）。车马走得再快，粮草得跟着；人跑得再远，底盘得稳。下一句「虽有荣观，燕处超然」——就算沿途有热闹的景致，他也安然处之，不被牵着停下来。

然后是一个锐利的反问：「奈何万乘之主，而以身轻天下？」一国的君主，怎么能拿自己的轻率去对待天下？**位置越高，轻率的代价越大。**

最后两句回到判断：「轻则失本，躁则失君」——轻浮就丢掉了根本，躁动就丢掉了主宰。这一章读起来像给急性子写的处方。
