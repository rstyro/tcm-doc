# 第十章 长而不宰

> 载营魄抱一，能无离乎？专气致柔，能婴儿乎？涤除玄览，能如疵乎？爱国治民，能无为乎？天门开阖，能为雌乎？明白四达，能无知乎？生之畜之，生而不有，为而不恃，长而不宰，是谓玄德。

## 译文

让形体与精神合抱为一，能够不分离吗？聚敛气息达到柔和，能够像婴儿那样吗？洗去心中的尘垢而深观内照，能够没有瑕疵吗？爱护百姓治理国家，能够不用智谋机巧吗？感官与外物接触开合，能够保持柔静守雌吗？通达事理无所不明，能够不自恃聪明吗？生养万物、畜养万物，生养而不占有，作为而不自恃，使其成长而不加主宰，这就叫做深远的德。

## 详解

一连六个反问，是全章的骨架：

身与心能不能不劈成两半？气息能不能柔到像婴儿？能不能把心里的尘擦净、照见自己而没瑕疵？管人管事能不能不逞机巧？跟外界打交道，能不能守得住那份柔静的接纳？什么都懂，能不能不摆出一副什么都懂的样子？

六问其实是一件事：**能不能「一」，能不能不用力。** 不是让你什么都不干，是别把力气花在「显得能干」上。

末段「生之畜之，生而不有，为而不恃，长而不宰」——生养而不占有，用力而不自恃，任其成长而不去主宰，这才叫「玄德」。养孩子、带团队都适用：给资源、给空间，别攥在手里；攥得越紧，长出来的东西越歪。
