# 第四十八章 为道日损

> 为学日益，为道日损。损之又损，以至于无为。
>
> 无为而无不为。取天下常以无事，及其有事，不足以取天下。

## 译文

求学的人，知识一天天增加；求道的人，欲念一天天减少。减少再减少，一直达到无为的境界。

顺任自然而无为，反而没有什么做不成。治理天下常常靠不生事扰民，如果政令烦苛、不断生事，就不足以治理天下了。

## 详解

「为学日益，为道日损」——做学问是每天增加，修道是每天减少。这两句常被对立起来讲，其实讲的是两种不同的活动：**知识的积累做加法，认识的提升做减法。**

接着是「损之又损，以至于无为」——减了再减，减到不再妄为。减掉的不是知识，是成见、是想当然、是多余的动作。第二步则是「无为而无不为」——不妄为，反而没有做不成的事。

末段落到治国：「取天下常以无事，及其有事，不足以取天下」——取天下常常靠不折腾，到了折腾不休的时候，就取不了了。

放在个人身上也一样：日程排得越满，越办不成要紧的事；把不必要的事删掉，真正重要的那件才有空间长大。
