# 第六十九章 哀者胜矣

> 用兵有言：“吾不敢为主而为客，不敢进寸而退尺。” 是谓行（xing）无行（xing），攘（rang）无臂，扔无敌，执无兵。
>
> 祸莫大于轻敌，轻敌几丧吾宝。
>
> 故抗兵相加，哀者胜矣。

## 译文

用兵的人有这样的话：「我不敢主动挑起战端，而宁可采取守势；不敢前进一寸，而宁可后退一尺。」这就叫做摆开没有阵势的阵势，举起没有臂膀的手臂，面对没有敌人的敌人，握着没有兵器的兵器。

祸患没有比轻敌更大的了，轻敌几乎要丧失我的法宝。

所以两军实力相当而对阵时，怀着悲悯的一方会取胜。

## 详解

开篇引用兵法格言：「吾不敢为主而为客，不敢进寸而退尺」——我不敢主动挑起战事，宁可做应战的一方；不敢向前进一寸，宁可向后退一尺。

接着四句「无」，把锋芒全收掉：「行无行，攘无臂，扔无敌，执无兵」——摆阵像没阵，捋袖像没胳膊，迎敌像没敌人，拿兵器像没兵器。**这不是示弱，是把「对方的眼睛」也一并撤掉。** 不摆阵、不张势，对方就找不到打击的着力点。

第二段一句极重要的判断：「祸莫大于轻敌，轻敌几丧吾宝」——最大的祸就是轻敌，轻敌几乎要丢掉我的宝贝（就是第 67 章那三宝之首的「慈」）。

末句收尾：「故抗兵相加，哀者胜矣」——两军相当的时候，怀着悲悯的一方得胜。**哀不是伤感，是不把杀人当乐事的那种凝重。**
