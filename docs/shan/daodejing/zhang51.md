# 第五十一章 道生德畜

> 道生之，德畜之，物形之，势成之。
>
> 是以万物莫不尊道而贵德。
>
> 道之尊，德之贵，夫莫之命而常自然。
>
> 故道生之，德畜之，长之育之，亭之毒之，养之覆之。生而不有，为而不恃，长而不宰。是谓玄德。

## 译文

道生成万物，德蓄养万物，形体使万物各具其状，环境使万物各自成就。

所以万物没有不尊崇道而珍贵德的。

道之所以被尊崇，德之所以被珍贵，就在于它们从不加以干涉，而永远顺任自然。

所以道生成万物，德蓄养万物，使它们生长、发育，使它们结果、成熟，使它们得到养护和庇荫。生养万物而不占有，作为而不自恃，使其成长而不加主宰，这就叫做深远的德。

## 详解

这一章讲万物是怎么来的，四个动作排下来：「道生之，德畜之，物形之，势成之」——道生出它，德蓄养它，物质赋予它形体，环境造就它的完成。四个环节缺一不可，**把「生」和「成」分开说，是这一章最要紧的地方**：种下去只是开始，养起来、长成形、遇对时机才叫成。

所以万物没有不尊崇道、珍视德的。而道和德的可贵，恰在于它们「莫之命而常自然」——没有谁下命令，它们本来就是那样，所以不需要谁去颁个奖。

末段又见那三个「不」：生养它，但生而不占有；有所作为，但不自恃有功；让它长大，但不加主宰。这就叫「玄德」。

这一章拿来理解「怎么带人」特别合适：生（给机会）、畜（给资源）、形（给舞台）、成（给时机），然后不占有、不居功、不控制。
