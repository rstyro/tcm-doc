# 第三十七章 道恒无为

> 道常无为而无不为，侯王若能守之，万物将自化。化而欲作，吾将镇之以无名之朴。无名之朴，夫亦将不欲。不欲以静，天下将自定。

## 译文

道永远顺任自然而不妄为，却又没有什么不是它所为。侯王如果能持守它，万物将会自行化育。化育中若有贪欲萌动，我就用道的质朴去镇服它。用道的质朴去镇服，就不会产生贪欲。没有贪欲就归于宁静，天下自然就安定了。

## 详解

这一章是「道经」部分的收束，也是全书对「无为」最完整的一次表述。

「道常无为而无不为」——道永远不刻意作为，却又没有什么不是它成就的。前一句讲它的姿态，后一句讲它的效果。侯王如果能守住它，万物自然演化。**注意：老子从不说「无为」等于「什么都不干」，他说的是一种不硬插手的作为方式。**

第二段讲失控时刻怎么处理：变化之中如果有人起了贪欲、想动手，我就用「无名之朴」去镇住它。所谓「无名之朴」，就是回到质朴无名、不做分别的那个状态。欲望一起，先别急着满足它，也别急着打压它，而是把它放回那个没有名目的本然里。

最后一句：不起贪欲就静下来，天下自然安定。**很多乱子不是解决了才停的，是不再喂它才停的。**
