# 第四十五章 大成若缺

> 大成若缺，其用不弊。
>
> 大盈若冲，其用不穷。
>
> 大直若屈，大巧若拙，大辩若讷（ne）。躁胜寒，静胜热。清静为天下正。

## 译文

最完满的东西好像有欠缺，但它的作用不会衰败。

最充盈的东西好像空虚，但它的作用不会穷尽。

最正直的好像弯曲，最灵巧的好像笨拙，最善辩的好像木讷。躁动可以驱散寒冷，安静可以克服暑热。清静才是天下的正道。

## 详解

第一段全是「看似有缺，其实不亏」的例子。

「大成若缺，其用不弊」——最完美的东西好像有缺憾，可它的作用不会败坏。「大盈若冲，其用不穷」——最充盈的好像很空，可它的作用不会穷尽。**说的是「留有余地」的智慧**：一个产品做到 100 分的同时把扩展性做没了，其实还是亏了。

第二段三句连着来：「大直若屈，大巧若拙，大辩若讷」——最直的好像弯着，最巧的好像笨拙，最善辩的好像嘴笨。真本事的人不靠技巧炫技，因为**炫技会让对方把注意力放到技巧上，而不是内容上**。

最后一句：「躁胜寒，静胜热。清静为天下正」。躁动能驱寒，安静能降热；那么清静，才是天下的正。前面讲「大若」，最后落到「清静」上——这是一句方法论：**遇到过热或过冷的局面，先调自己的温度。**
