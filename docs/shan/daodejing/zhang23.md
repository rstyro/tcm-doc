# 第二十三章 道亦乐得

> 希言自然。
>
> 故飘风不终朝，骤雨不终日。孰为此者？天地。天地尚不能久，而况于人乎？故从事于道者，同于道；德者，同于德；失者，同于失。同于道者，道亦乐得之；同于德者，德亦乐得之；同于失者，失亦乐得之。
>
> 信不足焉，有不信焉。

## 译文

少发号令，才是合乎自然的。

所以狂风刮不了一早晨，暴雨下不了一整天。谁使它们这样的？是天地。天地尚且不能使这种猛烈状态持久，何况人呢？所以从事于道的人，就与道相同；从事于德的人，就与德相同；失道失德的人，就与失相同。与道相同的人，道也乐于接纳他；与德相同的人，德也乐于接纳他；与失相同的人，失也乐于接纳他。

诚信不足，自然就得不到信任。

## 详解

开篇三字「希言自然」——少说话，才合乎自然。这一句统领全章。

接着用天气作比：狂风刮不了一早上，暴雨下不了一整天。谁让它们这样？天地。天地的暴烈尚且不能持久，何况人呢？**靠拼命、靠发狠做出来的事，通常撑不久。**

中间一段讲「同类相召」：做事合乎道的人，就与道同在；修养德行的人，就与德同在；失掉分寸的人，就与过失同在。你往哪边靠，哪边就接纳你——道乐于得之，德乐于得之，失也乐于得之。这话听着朴素，其实是因果：**长期的行为会把你引到那个结果上去。**

末句「信不足焉，有不信焉」又一次出现，是提醒：先问问自己可信不可信，再怪别人信不信你。
