# 第六十一章 大者宜下

> 大国者下流，天下之交，天下之牝，牝常以静胜牡，以静为下。故大国以下小国，则取小国；小国以下大国，则取大国。故或下以取，或下而取。大国不过欲兼畜人，小国不过欲入事人。夫两者各得其所欲，大者宜为下。

## 译文

大国要像江河的下游一样，处在天下交汇之处，做天下的雌柔。雌柔常以安静胜过雄强，因为它安静而居下。所以大国以谦下对待小国，就能取得小国的归附；小国以谦下对待大国，就能取得大国的容纳。所以有的谦下而取得别人，有的谦下而被别人接纳。大国不过是想畜养人，小国不过是想侍奉人。要使两者都各得其所愿，大国更应当谦下。

## 详解

这一章讲大国怎么摆位置，比喻用得很实在。

「大国者下流」——大国要像江河的下游。下游是什么地方？是天下交汇之处（天下之交），也是「天下之牝」——天下最柔静的一头。接着一句：「牝常以静胜牡，以静为下」——雌性常以静定胜过雄性，因为它静、它在下。

然后是一组对偶的推演：大国对小国谦下，就能取得小国的归附；小国对大国谦下，就能被大国接纳。所以有的是谦下而取得，有的是谦下而被接纳。大国的诉求不过是兼容畜养别人，小国的诉求不过是加入并服务别人。两边都得到想得的。

末句「大者宜为下」——**越是大的那一方，越应该处在下面。** 这话跟第 66 章江海为王是同一个道理：位置够大，姿态就得越低，否则两边接不上。
