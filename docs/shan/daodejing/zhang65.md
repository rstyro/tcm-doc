# 第六十五章 善为道者

> 古之善为道者，非以明民，将以愚之。
>
> 民之难治，以其智多。故以智治国，国之贼；不以智治国，国之福。
>
> 知此两者亦稽（qi）式。常知稽式，是谓玄德。玄德深矣远矣，与物反矣！然后乃至大顺。

## 译文

古时善于以道治国的人，不是用道去教百姓变得机巧，而是引导百姓归于淳朴。

百姓之所以难以治理，是因为智巧太多。所以用智巧去治理国家，是国家的祸害；不用智巧去治理国家，是国家的福气。

懂得这两者的差别，也就是懂得了法则。常守这个法则，就叫做深远的德。深远的德深不可测、远不可及，与一般事物的取向相反！然后才能达到最大的顺遂。

## 详解

「古之善为道者，非以明民，将以愚之」——古时善于行道的，不是拿道理去教人机巧，而是使人归于朴厚。「愚」在这里是质朴，不是愚笨，读的时候要按住这个分界。

第二段给理由：「民之难治，以其智多」——百姓难治，是因为心思太多、机巧太盛。所以「以智治国，国之贼；不以智治国，国之福」——用机巧去治，是国家的祸害；不用机巧去治，是国家的福气。

第三段讲两条路的自觉：「知此两者亦稽式」——懂得这两种方式的差别，就是一个法式、一条准则。常守这个准则，就叫做「玄德」。而玄德「深矣远矣，与物反矣」——它深、它远，跟一般事物的方向是反的（不以机巧取胜），然后才到达最大的顺。

**这一章最容易误读，务必读准**：老子反对的是机巧的治理方式，不是主张让百姓蒙昧。
