# 第六章 玄牝之门

> 谷神不死，是谓玄牝。玄牝之门，是谓天地根。绵绵若存，用之不勤。

## 译文

虚空中的神妙作用永不消亡，这叫做玄妙的母体。玄妙母体的门户，就是天地的根源。它连绵不绝地存在着，发挥作用却从不费力。

## 详解

这一章只用一组比喻，说得极省，却是全书讲「生养」的起点。

先说「谷神」。「谷」是山谷——空的地方，两山之间一凹下去，水就往里聚，草木就从那长出来。所以「谷」在这里是虚而能受的意思，加上一个「神」，指的是那种虚空中生发万物的作用。它「不死」，不是指某个实体长存，而是说这种生发的能力不会消失（老子紧接着就说它「绵绵若存」，仿佛有、又不落实为某个东西）。

「玄牝」是玄妙的母体，母体的门户就是天地的根。句子里用「门」这个字很有意思：门是通路，不是东西——道不是在某个地方的某个物，而是万物得以出来的那条通路。

「用之不勤」三字最该记住。「勤」在这里是劳、是竭的意思：它绵绵不绝地供给，而且供给的过程本身不费力。这和第 4 章的「用之或不盈」、第 5 章的「动而愈出」是同一个意思的三种说法。

落到日用上：**别把产出的成果当全部，要看住那个能持续产出的源头。** 水要有源才长流，人要有根才不至于枯。不折腾、不断根、细水长流——这就是本章最朴素的落点，也是养生、养家、养事业共用的那一句话。
