# 第三十四章 不自为大

> 大道泛兮，其可左右。万物恃（shi）之而生而不辞，功成不名有，衣养万物而不为主。常无欲，可名于小；万物归焉而不为主，可名为大。以其终不自为大，故能成其大。

## 译文

大道广泛流布，左右上下无处不在。万物依赖它生长，它却不推辞；成就了万物，却不占有名声；养育万物，却不做它们的主宰。它永远没有私欲，可以称它为「小」；万物归附于它，它却不做主宰，可以称它为「大」。正因为它始终不自以为大，所以才能成就它的伟大。

## 详解

「大道泛兮，其可左右」——大道像大水漫流，左边右边哪边都到得了。它不挑地方，也没有固定方向。

下面几句是道的性格：万物依靠它生长，它却不推辞（不辞）；事情成了，也不把功劳归给自己（不名有）；养育万物却不去支配（不为主）。它「常无欲」，所以可以叫它「小」；万物都归附它而它仍不主宰，所以又可以叫它「大」。

最后一句点题：「以其终不自为大，故能成其大」——正因为始终不把自己撑大，所以能成就它的伟大。

这一章和第 7 章、第 66 章是同一个道理的不同说法：**不抢占，才不会被剥夺；不自居，位置反而稳。**
