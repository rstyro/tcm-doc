# 第五十三章 盗竽非道

> 使我介然有知，行于大道，唯施是畏。
>
> 大道甚夷，而民好径。朝甚除，田甚芜，仓甚虚；服文采，带利剑，厌饮食，财货有余，是为盗夸。非道也哉！

## 译文

假使我稍微有点认识，行走在大道上，就怕走上邪路。

大道十分平坦，可人们偏偏喜欢走捷径。朝政非常败坏，农田非常荒芜，仓库非常空虚；却还穿着华丽的衣服，佩带锋利的宝剑，饱食精美的饮食，搜刮多余的财货，这就叫做强盗头子的排场。这哪里合于大道啊！

## 详解

「使我介然有知，行于大道，唯施是畏」——假使我有那么一点真知，走在平坦的大道上，最怕的就是走偏（施）。

第二段是全章最锋利的部分，先立一个强烈的反差：大道非常平坦（大道甚夷），可百姓偏偏喜欢走小路（而民好径）。然后是一串并置的画面：朝廷很整洁，田地却荒芜，仓廪却空虚；有人穿着华美的衣服，佩着锋利的宝剑，吃腻了精美的饮食，财货多得放不下。

老子给这些人的判词是「是为盗夸」——这叫盗贼的夸耀。「非道也哉」——这哪里是道啊！

**这一章的核心是一个识别方法：看一个系统里钱和资源被用在哪头。** 宫殿修得漂亮而仓廪空空、衣服佩剑齐整而田地荒芜，就不用再问它好不好了。
