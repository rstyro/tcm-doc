# 第三十八章 上德不德

> 上德不德，是以有德；下德不失德，是以无德。
>
> 上德无为，而无以为；下德为之，而有以为。
>
> 上仁为之，而无以为；上义为之，而有以为；
>
> 上礼为之，而莫之应，则攘（rang）臂而扔之。
>
> 故失道而后德，失德而后仁，失仁而后义，失义而后礼。
>
> 夫礼者，忠信之薄（bo），而乱之首；
>
> 前识者，道之华，而愚（yu）之始。是以大丈夫处其厚，不居其薄；处其实，不居其华。故去彼取此。

## 译文

上德的人不自恃有德，所以才有德；下德的人刻意不失德，所以反而没有德。

上德的人顺任自然而不妄为，而且无意于作为；下德的人有所作为，而且是有意作为。

上仁的人有所作为，却无意于作为；上义的人有所作为，而且是有意作为。

上礼的人有所作为，如果得不到回应，就捋起袖子强拉人来遵从。

所以，失去了道才去讲德，失去了德才去讲仁，失去了仁才去讲义，失去了义才去讲礼。

礼这个东西，是忠信淡薄的产物，是祸乱的开端。

所谓先见之明，不过是道的浮华，是愚昧的开始。因此大丈夫立身于敦厚，不居于浅薄；立身于实在，不居于浮华。所以舍弃后者而选取前者。

## 详解

这一章是「德经」的开篇，讲的是「德」的层级。

上德的人不刻意表现德，所以真有德；下德的人生怕丢了德，反倒没有德。上德顺任自然而不自恃有心作为，下德则处处有心为之。

往上再排一层：上仁有所作为但不带目的；上义有所作为且带着目的；上礼有所作为，如果没人响应，就捋起袖子去强拉人（攘臂而扔之）。到「礼」这一步，已经需要强制了。

接着是全章的骨句：「失道而后德，失德而后仁，失仁而后义，失义而后礼」。**一条从自然到强制的下坡路**：最自然的状态是道，道丢了才讲德，德丢了才讲仁，仁丢了才讲义，义丢了才靠礼来撑。

所以「礼者，忠信之薄，而乱之首」——礼是忠信不足的产物，也是祸乱的开端。这话不是叫人不要礼，而是提醒：**当一件事只能靠制度硬拉的时候，说明里面已经不认它了。**

最后一句给做法：「大丈夫处其厚，不居其薄；处其实，不居其华。故去彼取此」——站在厚实的那头，不站在轻薄的那头；要果实，不要花。
