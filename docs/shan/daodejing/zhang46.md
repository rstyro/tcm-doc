# 第四十六章 知足常足

> 天下有道，却走马以粪。天下无道，戎（rong）马生于郊。
>
> 祸莫大于不知足；咎（jiu）莫大于欲得。故知足之足，常足矣。

## 译文

天下有道的时候，把善跑的战马退还给农夫去耕田施肥；天下无道的时候，怀胎的母马也被征去作战，只能在战地生产。

祸患没有比不知足更大的，过失没有比贪得无厌更重的。所以懂得满足于已经有的满足，就永远满足了。

## 详解

「天下有道，却走马以粪；天下无道，戎马生于郊」——天下有道的时候，退下战马去耕田施肥；天下无道的时候，怀胎的母马都被拉去打仗，只能在战地生产。两幅画面，一个指标：**看资源被用在哪里，就知道天下在什么状态。**

第二段给判断，也是全书的金句：「祸莫大于不知足；咎莫大于欲得」——没有比不知足更大的祸，没有比贪得更大的错。接着一句「故知足之足，常足矣」——由知足而来的满足，才是长久的满足。

这里要留意老子的分寸：他不是叫你压制欲望，而是指出「不知足」是一种会自己长大的病。今天有了就想要明天，明天到手又盯着后天，人就永远在缺口里活着。

把「知足」用到事上，也是把边界感找回来：知道自己要什么，才知道什么可以不要。
