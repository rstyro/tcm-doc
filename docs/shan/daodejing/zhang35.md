# 第三十五章 执道乐往

> 执大象，天下往。往而不害，安平泰。
>
> 乐（yue）与饵（er），过客止。道之出口。淡乎其无味，视之不足见，听之不足闻，用之不足既。

## 译文

把握住大道这一根本法象，天下人就会归往。归往而不互相妨害，于是安宁平和。

音乐与美食，能使过路的人停下脚步。而道说出来，却平淡无味，看它看不见，听它听不到，可是用它却用不完。

## 详解

「执大象，天下往」——守住那最大的「象」（也就是道），天下人自然归往。接着是结果：往而不害，安、平、泰。人聚过来而不受伤害，于是安宁、均平、通达。**能聚人的从来不是好处多，而是不受害。**

第二段有个漂亮的对比：「乐与饵，过客止」——音乐和美食，能把过路的人留住，但只能留一会儿。**道呢？「道之出口，淡乎其无味」**——摆出来平平淡淡，看它不值得看，听它不值得听，可用起来却用不完（用之不足既）。

这话放进今天也说得很准：刺激性的东西来得快去得也快，平淡的东西才撑得住长线。选行业、选合伙人、选生活节奏，都适用。
