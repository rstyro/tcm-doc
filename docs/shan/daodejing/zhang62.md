# 第六十二章 万物之奥

> 道者万物之奥，善人之宝，不善人之所保。美言可以市，尊行可以加人。人之不善，何弃之有？故立天子，置三公，虽有拱璧以先驷（si）马，不如坐进此道。古之所以贵此道者何？不曰：求以得，有罪以免邪！故为天下贵。

## 译文

道是万物的庇荫，是善人的珍宝，也是不善之人赖以保全的所在。美好的言辞可以换来交易，尊贵的行为可以见重于人。人即使不善，道又何必舍弃他呢？所以拥立天子、设置三公，虽然有拱璧在前、驷马随后的厚礼，也不如安坐而进献这个道。古人之所以看重这个道，是为什么呢？不就是因为：求它就能得到，有罪也能因此免去吗！所以它为天下所尊贵。

## 详解

「道者万物之奥」——道是万物的庇荫、深藏之处。「善人之宝，不善人之所保」——它是善人的珍宝，也是不善人的依靠。**注意后半句**：道不是只属于好人的，这为后面几句铺了路。

「美言可以市，尊行可以加人」——漂亮的言辞可以换来交易，尊贵的行为可以抬高一个人。「人之不善，何弃之有？」——人有了不善，何必就要抛弃他呢？

再往下讲世俗的权衡：立天子、置三公，就算有拱璧在先、驷马随后这样的厚礼，也不如安静地进献这个道。为什么古人这么看重它？「不曰：求以得，有罪以免邪」——不就是因为：求就能得到，有罪也能免除吗？所以它为天下所贵。

这一章的好处在于它把道的另一面说清了：**它不只是高处的道理，也是低处的救济。**
