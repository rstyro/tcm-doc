# 第三十章 以道佐主

> 以道佐（zuo）人主者，不以兵强天下，其事好还。师之所处，荆（jing）棘（ji）生焉。大军之后，必有凶年。
>
> 善有果而已，不敢以取强。果而勿矜，果而勿伐，果而勿骄。果而不得已，果而勿强。
>
> 物壮则老，是谓不道，不道早已。

## 译文

用道辅佐君主的人，不靠兵力逞强于天下，用兵这种事很容易反过来报应到自己身上。军队所到之处，荆棘丛生。大战之后，必定是荒年。

善于用兵的只求达到目的而已，不敢凭兵力去逞强。达到目的而不自矜，达到目的而不夸耀，达到目的而不骄傲，达到目的只是出于不得已，达到目的而不逞强。

事物壮盛了就会走向衰老，这就叫做不合于道，不合于道很快就会消亡。

## 详解

这一章谈用兵，态度很明确：别想靠武力逞强。

以道辅助君主的人，不靠兵力逞强于天下，因为**这种事会回报到自己身上**（其事好还）。接着两句是现场描写：军队驻过的地方，荆棘丛生；大战之后，必有荒年。这不用多解释，读过历史的人都懂。

第二段给了分寸：「善有果而已，不敢以取强」——把事情做成、达到目的就够了，不敢凭着武力去逞强。然后是四个「果而勿」：做成了不自高、不夸耀、不骄傲、不逞强；因为这一切本就是不得已才做的。

第三段一句总结：「物壮则老，是谓不道，不道早已」——事物壮盛到极点就开始衰老，这就是不合于道；不合于道的，很快就结束。**极盛就是下坡的起点**，这个判断贯穿全书。
