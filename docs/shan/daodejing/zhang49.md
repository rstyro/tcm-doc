# 第四十九章 善者吾善

> 圣人常无心，以百姓之心为心。
>
> 善者吾善之，不善者吾亦善之，德善；
>
> 信者吾信之，不信者，吾亦信之。德信。
>
> 圣人在天下，歙（xi）歙；为天下，浑其心。圣人皆孩之。

## 译文

圣人没有自己固执的成见，以百姓的心意为自己的心意。

善良的人，我善待他；不善良的人，我也善待他，这样就得到了善。

守信的人，我信任他；不守信的人，我也信任他，这样就得到了信。

圣人在天下，收敛自己的意欲；治理天下，使人心归于浑厚质朴。百姓都像孩童一样看待他。

## 详解

开篇一句立住全章：「圣人常无心，以百姓之心为心」——有道的人没有自己固定的私意，把百姓的心意当作自己的心意。

接着两句常被误读，要贴在原文上读：「善者吾善之，不善者吾亦善之，德善」。善良的人我善待他，不善良的人我也善待他，于是得到了真正的善。「信者吾信之，不信者吾亦信之，德信」——守信的人我信任他，不守信的人我也信任他，于是得到了真正的信。

**这不是无原则的糊涂。** 老子的着眼点是「德」的传导：你按什么方式对人，就会把对方调成什么样的人。只善待善待你的人，善就成了一场交易；对不善良的人也留一份善意，才有可能把它变成善良。

末段讲圣人在天下怎么待人：收敛自己的锋芒（歙歙），让心浑厚包容（浑其心），把百姓都当成孩子来待。不是俯视，是不设类。
