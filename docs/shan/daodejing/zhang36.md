# 第三十六章 欲歙固张

> 将欲歙（xi）之，必固张之；将欲弱之，必固强之；将欲废之，必固兴之；将欲夺之，必固与之。是谓微明，
>
> 柔弱胜刚强。鱼不可脱于渊，国之利器不可以示人。

## 译文

将要收敛它，必定先让它张开；将要削弱它，必定先让它强盛；将要废弃它，必定先让它兴起；将要夺取它，必定先给予它。这叫做幽微的明。

柔弱能够胜过刚强。鱼不能离开深水，国家的利器不可以随便展示于人。

## 详解

第一段四组，句式相同，讲的是一种普遍的运转规律：将要收敛的，必定先张开；将要削弱的，必定先强化；将要废弃的，必定先兴起；将要夺取的，必定先给予。老子把这叫做「微明」——在细微处就能看出来的明白。

**读这一段要当心**：它常被当成权谋术，其实老子讲的是自然规律，不是操作手册。月亮圆了就要缺，果子熟了就要落，人在极盛时最听不进劝——这些都是「必固」的样子。真要用，用在观察上，不是用在算计上。

第二段两句收束：柔弱胜过刚强；鱼离不开深渊，国家的利器不可以随便亮给人看。前一句讲力量的样子，后一句讲分寸——**底牌亮出来，就不再是底牌了。**
