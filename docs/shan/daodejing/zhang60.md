# 第六十章 以道治国

> 治大国，若烹（peng）小鲜。
>
> 以道莅（li）天下，其鬼不神；非其鬼不神，其神不伤人；非其神不伤人，圣人亦不伤人。夫两不相伤，故德交归焉。

## 译文

治理大国，就像煎小鱼一样，不能翻搅太多。

用道来君临天下，鬼怪就不再灵验；不是鬼怪不灵验，而是它的灵验伤不了人；不但它伤不了人，圣人也不伤害人。两者都不互相伤害，所以德就交互归聚到一起了。

## 详解

开篇六字，是全书的千古名句之一：「治大国，若烹小鲜」——治理大国，像煎小鱼。煎小鱼不能多翻，一翻就碎。**这比喻讲的就是「别老折腾」**：政策反复、朝令夕改，百姓就散了。

第二段讲效果：以道治理天下，鬼就不灵验了；不是鬼不灵，是它的作用伤不到人；不只是鬼伤不到人，圣人也不伤人。两边都不伤人，所以「德交归焉」——德行交相归附到一处。

这一段用的是当时的鬼神话语，字面不必深究，意思很实在：**治理得当的标志是各方都不必互相伤害。** 上有不折腾的政令，下有不作乱的心思，两下不再互相消耗，这就是最好的状态。
