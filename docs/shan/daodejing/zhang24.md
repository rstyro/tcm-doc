# 第二十四章 自是不彰

> 企者不立，跨者不行，自见者不明，自是者不彰，自伐者无功，自矜（jin）者不长。
>
> 其在道也，曰：余（yu）食赘（zhui）行。物或恶（wu）之，故有道者不处。

## 译文

踮起脚跟想站得高，反而站不稳；迈开大步想走得快，反而走不远；自我表现的人不明达，自以为是的人不彰显，自我夸耀的人没有功劳，自高自大的人不能长久。

从道的角度看，这些可以说是剩饭赘瘤。人们大都厌恶它们，所以有道的人不这样做。

## 详解

第一段五句，全是「过头就翻车」的例子：踮起脚想站得更高，反而站不稳；跨大步想跑得更快，反而走不远；只看自己，反而不明白；自以为是，反而不显明；自我夸耀，反而没有功劳；自高自大，反而当不了头。

注意这里的逻辑：这些行为本身都不算坏，坏在「过了」。踮脚是努力，可踮脚站不久；自夸是自信，可自夸让人不看你的活。

第二段给这些行为下了个判词：「余食赘行」——吃剩的饭、多余的肉瘤。这比喻不留情面：**过度的自我表现不是加分项，而是身上多长出来的一块。** 所以有道的人不这么活。

这一章和第 22 章是一对：一个说怎么做，一个说别怎么做。
