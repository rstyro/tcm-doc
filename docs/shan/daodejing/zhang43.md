# 第四十三章 不言之教

> 天下之至柔，驰骋天下之至坚。无有入无间，吾是以知无为之有益。
>
> 不言之教，无为之益，天下希及之。

## 译文

天下最柔弱的东西，能够驰骋穿行于天下最坚硬的东西之中。没有形体的东西能够进入没有间隙的地方，我因此知道无为是有益的。

不言的教化，无为的益处，天下很少有人能够做到。

## 详解

「天下之至柔，驰骋天下之至坚」——天下最柔软的东西，能在最坚硬的东西里穿行。水穿石、风蚀崖、话入心，都是这个道理。

「无有入无间」——没有形体的东西，能进入没有缝隙的地方。这句话讲的是渗透力：**硬碰硬要拼消耗，无形的东西却能直接进去。** 人的习惯、观念、氛围，都是这样渗进去的。

末句「不言之教，无为之益，天下希及之」——不用言语的教化、不妄为的益处，天下很少有人能做到。老子在这里不是说教不了，而是说这两种办法**难在反人性**：人本能地想说服、想动手，恰恰这两样最费力也最不管用。
