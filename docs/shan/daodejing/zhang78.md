# 第七十八章 柔之胜刚

> 天下莫柔弱于水，而攻坚强者莫之能胜，以其无以易之。弱之胜强，柔之胜刚，天下莫不知，莫能行。是以圣人云：“受国之垢（gou），是谓社稷（ji）主；受国不祥，是为天下王。”
>
> 正言若反。

## 译文

天下没有比水更柔弱的了，可是攻击坚强的东西，没有什么能胜过水，因为没有什么可以改变它的这种特性。弱能胜强，柔能胜刚，天下没有人不知道，却没有人能实行。所以圣人说：「承担一国的屈辱，才能称为国家的君主；承担一国的灾祸，才能成为天下的君王。」

正话听起来像是反话。

## 详解

「天下莫柔弱于水，而攻坚强者莫之能胜」——天下没有比水更柔弱的，可攻击坚硬强大的东西，没有能胜过水的。为什么？「以其无以易之」——因为没有什么能替代它这种办法。

接着是全章的核心判断：「弱之胜强，柔之胜刚，天下莫不知，莫能行」——柔能胜刚、弱能胜强，这个道理天下没人不懂，可没人做得到。**这十二个字是全书少见的感慨语气**：不是道理难懂，是难以照做。

第三段用圣人的话作结：「受国之垢，是谓社稷主；受国不祥，是为天下王」——能承受国家的屈辱，才配做社稷之主；能承担国家的灾祸，才配做天下之君。末句「正言若反」四字给全章定性——**正面的道理，听起来常常像反话。**
