# 第六十六章 莫能与争

> 江海之所以能为百谷王者，以其善下之，故能为百谷王。是以欲上民，必以言下之；欲先民，必以身后之。是以圣人处上，而民不重；处前，而民不害。是以天下乐推而不厌。以其不争，故天下莫能与之争。

## 译文

江海之所以能成为百川汇归之王，是因为它善于处在低下的位置，所以能成为百川之王。因此，要想居于民众之上，必须用言辞表示谦下；要想居于民众之先，必须把自身放在后面。所以圣人居于上位，而百姓不感到负担；居于人前，而百姓不感到妨害。因此天下人乐于推戴他而不厌弃他。正因为他不与人争，所以天下没有谁能与他相争。

## 详解

全章就一个比喻，讲得极为清楚。

江海之所以能成为百谷之王，是因为它善于处在低下的位置（以其善下之），所以能成为百川的归处。

接着把这个道理推到人身上：要想居于人上，必须言辞谦下；要想走在人前，必须把自己放在人后。所以圣人处在上面，百姓不觉得是负担；走在前面，百姓不觉得被妨害。因此天下人乐意推举他而不厌弃他。

末句是全书的名句：「以其不争，故天下莫能与之争」——正因为他不争，所以天下没有谁能跟他争。

**注意这一章讲的不是姿态，而是结构**：低处才能聚水，谦下才能聚人。先占位的人常有，能守住位子的人少；守不住的原因往往不是能力不够，是挡住了别人的路。
