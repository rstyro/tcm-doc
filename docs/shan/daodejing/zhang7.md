# 第七章 天长地久

> 天长地久。天地所以能长且久者，以其不自生，故能长生。是以圣人后其身而身先，外其身而身存。非以其无私邪？故能成其私。

## 译文

天地长久存在。天地之所以能够长久，是因为它们不为自己而生，所以能够长存。因此圣人把自己放在后面，反而能占先；把自身置之度外，反而能保全自身。不正是因为他无私吗？所以反而能成全他自己。

## 详解

天地为什么能长久？因为它们不为自己而活（不自生）：阳光不挑对象照，雨水不挑地方下。正因为不经营自己，反倒长存。

接着顺势推出处世之道：圣人把自己往后放，反而被推到前面；把自身置之度外，反而保全了自己。听起来像话术，其实是机制——**你不抢，就没人急着跟你抢；你不上台，就没人想着把你赶下台。**

「非以其无私邪？故能成其私」：不是他真没有自己，而是他不把「自己」顶在每件事的最前面，所以最后成全了自己。

这句常被误读成功利算计的套路，其实它是一种取舍：在短期得失上让一步，换长期的位置。
