# 第五十八章 福祸相倚

> 其政闷闷，其民淳淳；其政察察，其民缺缺。祸兮福之所倚， 福兮祸之所伏。孰知其极？其无正也。正复为奇（ji），善复为妖。人之迷，其日固久。是以圣人方而不割，廉而不刿（gui），直而不肆，光而不耀。

## 译文

政令宽厚不清明，百姓反而淳朴；政令严苛明察，百姓反而狡黠。灾祸里靠着福气，福气里藏着灾祸。谁能知道究竟是哪一头呢？其中并没有定准。正的可以变成邪的，善的可以变成恶的。人们的迷惑，由来已经很久了。所以圣人方正而不割伤人，有棱角而不刺伤人，直率而不放肆，明亮而不炫目。

## 详解

开篇一组对照：「其政闷闷，其民淳淳；其政察察，其民缺缺」——政令宽厚含糊，百姓反而淳厚；政令精明苛细，百姓反而狡黠有怨。**管得越细，钻空子的办法越多。**

接着是全书的千古名句：「祸兮福之所倚，福兮祸之所伏」——祸是福所倚靠的地方，福是祸所潜伏的地方。谁能知道它的究竟？其实没有定准（其无正也）。正可能再变成奇，善可能再变成妖。

但老子没有停在相对主义上，他给了一个位置：「人之迷，其日固久」。世人在这上面糊涂已经很久了。那么圣人怎么做？四句「而不」：「方而不割，廉而不刿，直而不肆，光而不耀」——方正而不割伤人，有棱角而不刺伤人，直率而不放肆，有光而不刺眼。

**所以这一章真正教的是分寸**：任何好品质都有它的过度形态，而过度形态就是祸。
