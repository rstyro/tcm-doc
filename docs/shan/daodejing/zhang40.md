# 第四十章 无中生有

> 反者，道之动；弱者，道之用。
>
> 天下万物生于有，有生于无。

## 译文

向相反的方向运动，是道的运行方式；保持柔弱，是道的作用方式。

天下万物生于「有」，「有」生于「无」。

## 详解

全章只有两句，却是全书最要紧的两句之一。

「反者，道之动」——向相反的方向运动，是道的运行方式。注意是「反」不是「返」的单一意思：既包含「返回」，也包含「反转」。树叶落回根、白天转入夜、强势走向衰弱，都是同一件事在起作用。**所以看事情别只看当下这一头，要顺着它的去向看。**

「弱者，道之用在」——柔弱，是道的功用所在。这里说的是方式：道总是在弱的地方、不起眼的地方起作用，水磨石头、风吹山形、时间改人，都不是靠硬来。

「天下万物生于有，有生于无」——万物从「有」里生出来，而「有」从「无」里生出来。有形的世界有一个无形的源头。

这一章可以当全书的方法论：看到盛想到衰，看到强想到弱，看到终点想到返回。
