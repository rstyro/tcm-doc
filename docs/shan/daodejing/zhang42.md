# 第四十二章 物损而益

> 道生一，一生二，二生三，三生万物。万物负阴而抱阳，冲气以为和。
>
> 人之所恶，唯孤、寡、不穀，而王公以为称。
>
> 故物或损之而益，或益之而损。
>
> 人之所教，我亦教之。强梁者不得其死，吾将以为教父。

## 译文

道产生了一，一产生了二，二产生了三，三产生了万物。万物都背负着阴而怀抱着阳，阴阳二气交冲而生成和谐。

人们所厌恶的，就是「孤」「寡」「不穀」，而王公却用它们来称呼自己。

所以万物有时减损它反而使它增益，有时增益它反而使它减损。

别人用来教导人的道理，我也用它来教导人：逞强霸道的人往往不得善终。我要把这句话当作施教的根本。

## 详解

开篇是全书的宇宙生成论：「道生一，一生二，二生三，三生万物」。一是浑然未分，二是分化为阴阳，三是阴阳交感而生出第三态，由此推演出万物。**这一句最常见的用法，是解释「复杂性来自简单的重复」。**

接着一句描述万物的结构：「万物负阴而抱阳，冲气以为和」——万物背靠阴而面抱阳，阴阳二气激荡而成和气。所以万物都不是纯的，都靠两股力量撑着。「和」不是消灭了矛盾，是矛盾处在一个还能运转的状态。

第二段有个耐人寻味的观察：人人厌恶的就是「孤」「寡」「不穀」这类贱称，而王公却拿它们自称。**主动接下最不好的名，反而坐得稳**，这和第 39 章是同一个道理。

第三段两句实用判断：事物有时减损反而增益，有时增益反而受损。第四段收尾很重：「强梁者不得其死」——逞强蛮横的人，往往不得善终；老子说，我要把这条当成教人的根本。
