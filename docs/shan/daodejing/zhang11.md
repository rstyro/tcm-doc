# 第十一章 无之为用

> 三十辐共一毂，当其无，有车之用。埏埴以为器，当其无，有器之用。凿户牖以为室，当其无，有室之用；故有之以为利，无之以为用。

## 译文

三十根辐条共用一个车毂，正因为车毂中间是空的，才有车的作用。和泥制作器皿，正因为器皿中间是空的，才有器皿的作用。开凿门窗建造房屋，正因为门窗和室内是空的，才有房屋的作用。所以「有」带来便利，「无」发挥作用。

## 详解

三个例子，说的都是同一件事。

三十根辐条聚到一个车毂上，正因为中间那个孔是空的，车才能走；和泥做陶器，正因为中间是空的，器皿才能盛东西；开出门窗盖房子，正因为四壁之间是空的，房子才住得进人。

有形的部分带来便利（「有之以为利」），真正发挥作用的是那块空的地方（「无之以为用」）。一间屋子塞满柜子，人反而进不去；一张时间表排满的人，做不成事。

所以留空不是浪费，**留空就是留功能**。这一章和第 1 章的「有无」是一套：先看见对立，再用好那个容易被忽略的一头。
