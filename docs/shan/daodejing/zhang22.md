# 第二十二章 圣人抱一

> 曲则全，枉则直，洼（wa）则盈，敝则新，少则得，多则惑。
>
> 是以圣人抱一为天下式。不自见（xian），故明；不自是，故彰（zhang）；不自伐，故有功；不自矜（jin），故长。
>
> 夫唯不争，故天下莫能与之争。古之所谓“曲则全”者，岂虚言哉！诚全而归之。

## 译文

委曲反而能保全，屈就反而能伸直，低洼反而能充盈，破旧反而能更新，少取反而能获得，贪多反而迷惑。

所以圣人持守这一原则，作为天下的范式。不自我表现，反而明达；不自以为是，反而彰显；不自我夸耀，反而有功；不自高自大，反而能长久。

正因为不与人争，所以天下没有人能与他相争。古人所说的「曲则全」，怎么会是空话呢！它确实能让人保全而归于大道。

## 详解

第一段六句，讲的是一种普遍的反转：「曲则全，枉则直，洼则盈，敝则新，少则得，多则惑」。受得住委曲才能保全，肯弯一下才能伸直，低洼处才能蓄满水，旧了才有更新的机会，要得少反有所得，贪得多反倒糊涂。

第二段是处世四不：「不自见，故明；不自是，故彰；不自伐，故有功；不自矜，故长」。不自我表现反而明白，不自以为是反而声名显，不自我夸耀反而有功劳，不自高自大反而能领导别人。四句都是一个意思——**把「我」从台前撤走，事情就看得清、做得成。**

第三段收尾：「夫唯不争，故天下莫能与之争。」这不是让你退出竞争，是让你别把竞争放在明处：古话说的「曲则全」，哪是空话呢，它确实能让人保全。

这一章适合贴在办公桌上，尤其适合刚带团队的人。
