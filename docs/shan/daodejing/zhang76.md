# 第七十六章 强大处下

> 人之生也柔弱，其死也坚强。
>
> 万物草木之生也柔脆，其死也枯槁（gao）。
>
> 故坚强者死之徒，柔弱者生之徒。
>
> 是以兵强则不胜，木强则折。
>
> 强大处下，柔弱处上。

## 译文

人活着的时候身体是柔软的，死了以后就变得僵硬。

万物草木活着的时候枝叶是柔脆的，死了以后就变得干枯。

所以坚硬强横的东西属于死亡的一类，柔软柔弱的东西属于生存的一类。

因此军队逞强就不能取胜，树木强壮就会遭到砍伐。

凡是强大的，反而居于下位；凡是柔弱的，反而居于上位。

## 详解

第一段两组对比，说的是同一个道理：人活着的时候身体柔软，死了就僵硬；草木活着的时候柔嫩，死了就干枯。第二段直接下判断：「故坚强者死之徒，柔弱者生之徒」——坚硬属于死亡那一类，柔弱属于生命那一类。

**这个判断很有力，因为它把「柔」和「刚」从道德层面挪到了生命层面**：柔不是弱点，是还在生长的标志；刚不是强大，是已经定了形、动不了的状态。

第三段举两个例子：「兵强则不胜」——军队一味逞强就不能取胜；「木强则折」——树木长得太硬就容易折断。

末句是本章的落点：「强大处下，柔弱处上」——强大的处在下位，柔弱的处在上位。这一章与第 78 章连读，柔胜刚的意思就完整了。
