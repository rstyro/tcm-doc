# 第六十八章 不争之德

> 善为士者不武，善战者不怒，善胜敌者不与，善用人者为之下。是谓不争之德，是谓用人之力，是谓配天之极。

## 译文

善于做将帅的不逞勇武，善于作战的不轻易发怒，善于战胜敌人的不与敌人正面硬拼，善于用人的对人谦下。这叫做不争的德，这叫做善于借用他人的力量，这叫做符合天道的最高准则。

## 详解

四句「善…者不…」，讲的都是同一个作风。

「善为士者不武」——善于做将帅的不逞勇武；「善战者不怒」——善于作战的不被激怒；「善胜敌者不与」——善于胜敌的不与对方正面纠缠；「善用人者为之下」——善于用人的对下面的人谦下。

这四句放在一起，讲的是**把情绪从决策里拿出去**。不武、不怒、不与，都是不被对方的动作牵住；为之下，则是把人的力气引出来。

后面三句给这批话定性：「是谓不争之德，是谓用人之力，是谓配天之极」——这叫做不争的德，叫做善用别人的力气，叫做与天道相配的极致。

尤其「用人之力」四字点得最好：**真正的本事不是自己出力，是让别人的力朝着一个方向使。**
