# 《道德经》· 老子

- 《道德经》，又称《老子》，是先秦道家最重要的典籍，全文约五千言，通行本分为八十一章。
- 全书集中讨论「道」与「德」，由此展开自然、无为、柔弱、知足等一系列命题，是理解道家思想最基本的文本。
- 它与《庄子》（《南华经》）并称道家两大根本典籍，同属传统五术之「山」中的玄典一脉，义理定位可参见《[玄典](/shan/xuandian)》。

## 作者与成书

- 传统上认为作者是春秋末期的老子（相传名李耳，字聃），曾为周王室守藏室之史。司马迁《史记·老子韩非列传》中已并载数说，其人其书的争议自汉代延续至今。
- 一般认为，《道德经》并非一时一人之手写定，而是经历了一个积累与整理的过程：其思想大体形成于春秋末至战国前期，文字则在流传中逐步定型。书中多韵语、多用格言体，也是这一成书方式的痕迹。

## 版本与流传

- **通行本（王弼本）**：分八十一章，「道经」在前（一至三十七章）、「德经」在后（三十八至八十一章），是后世最通行的章序与文本。本站所录即依此章序。
- **马王堆帛书本**：1973 年长沙马王堆三号汉墓出土，有甲、乙两种抄本，为「德经在前、道经在后」，文字与通行本多有出入，可见早期文本的面貌与本子差异。
- **郭店楚简本**：1993 年湖北荆门郭店一号楚墓出土，是现存最早的节抄本，文字总量远少于五千言，内容与通行本不完全重合。
- 三种本子的差异，是校勘与思想史研究的重要材料；对一般读者而言，通行本的分章与文气最为连贯，宜作入门底本。

## 核心概念

- **道**：被描述为天地万物的本原与运行法则，无形无名，不可用言语完全言说，故有「道可道，非常道」之说。
- **德**：万物得之于道而自具的禀性与功能，「道」是体，「德」是用，二者在书中常并提。
- **自然**：事物本然如此的样子，主张顺任其理而不强加干预。
- **无为**：并非无所作为，而是不妄为、不生事、不以私意强行干预；书中将它与治国、处世、养身诸层面相连。
- **柔弱胜刚强**：以退为进、以柔克刚、以静制动，警惕过度欲望与过度作为带来的反效果。

## 历代注本

- 汉代河上公章句偏于从养生与治身角度作解；魏王弼注则以义理思辨见长，二者是流传最广的两大注解传统。
- 此后注家代不乏人：唐有傅奕、成玄英，宋有苏辙《老子解》，明有焦竑《老子翼》，清有王夫之《老子衍》等，取径各不相同。
- 现当代通行整理本有陈鼓应《老子注译及评介》、刘笑敢《老子古今》等，以现代汉语注解疏通文义，便于初学入门。本站各章译文与详解为入门对照而自撰，取通行文意，不专主一家之说。

## 阅读路径建议

- **先通读**：八十一章篇幅不长，可先一气读毕，感受全书的格言体与整体语调，不必急于逐句求解。
- **再对照**：回头逐章细读，把「道」「德」「无为」「自然」等关键词出现的位置串起来，看其在不同语境中的用法。
- **参看注本**：遇到疑难章句，可对照王弼注等旧注与现代整理本，留意各家分歧所在；书中许多章句本就有多种读法，不必强求一说。
- **结合语境**：书中不少内容针对当时的政治与人生处境而发，了解春秋战国的背景，有助于理解「无为而治」「小国寡民」之类命题的针对性。

## 本站说明

- 逐章原文：自〈[第一章 天地之始](/shan/daodejing/zhang1)〉至〈[第八十一章 善者不辩](/shan/daodejing/zhang81)〉，一章一页，侧栏按「道经」「德经」分列。
- 合订本：《[八十一章合订](/shan/daodejing/full)》，一页通读全书。
- 每章分「译文」与「详解」两层：**译文**为逐段白话直译，与原文段落一一对应，只求疏通文意；**详解**为通俗展开，先点章旨再逐句疏说，兼用日常事例佐证，供初学参照。
- 原文以通行本（王弼本）章序与文字为准，标点作了统一整理，生僻字随文标注读音。
- 异文一律从通行本，凡与流行别本不同者，主要有以下六处：第十一章「凿户牖以为室」；第十五章「俨兮其若客」；第三十九、四十二章「不穀」；第六十三章「报怨以德」；第六十九章「行无行」（「行」读 xíng）；第七十六章「木强则折」。
- 章题（如「天地之始」）为便于检索所加，非原书所有。
- 本站译文与详解为便于入门而自撰，意在疏通文意，未必与某一家注本完全相同；遇有疑难，仍以原文与旧注为准。
