# 第十七章 功成事遂

> 太上，下知有之；其次，亲而誉之；其次，畏之；其次，侮之。信不足焉，有不信焉。悠兮其贵言。功成事遂，百姓皆谓“我自然”。

## 译文

最好的统治者，百姓只知道有他存在；次一等的，百姓亲近他、赞美他；再次一等的，百姓畏惧他；最差的，百姓轻侮他。统治者的诚信不足，百姓自然就不信任他。最好的统治者悠闲从容，很少发号施令。事情办成了，百姓都说：「我们本来就是这样的。」

## 详解

这一章讲管理者与下面人的关系，四个层级排得很清楚：

最好的统治者，百姓只知道有他存在——他不刷存在感，不折腾，事情却办成了；次一等的，百姓亲近他、赞美他，说明他确实做了很多好事，也留下了痕迹；再次一等的，百姓怕他；最差的，百姓轻侮他。

紧接着一句因果：「信不足焉，有不信焉」——你说话不算数，下面自然不信你。失信在先，抱怨在后，别把顺序搞反。

最后是对理想状态的描写：处事悠闲从容，很少发号施令；事情办成了，百姓都说「我们本来就是这样的」（我自然）。**功劳不显于己，成果归于大家**，这是相当高的管理境界。
