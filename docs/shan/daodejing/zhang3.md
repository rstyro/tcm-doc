# 第三章 圣人之治

> 不尚贤，使民不争；不贵难得之货，使民不为盗；不见可欲，使民心不乱。
>
> 是以圣人之治，虚其心，实其腹，弱其志，强其骨，常使民无知无欲，使夫智者不敢为也。为无为，则无不为。

## 译文

不推崇贤能之名，使民众不去争逐；不看重稀有难得的财物，使民众不去偷盗；不显露可以引发欲望的东西，使民众的心不被扰乱。

所以圣人治理天下，是使人心虚空、肚腹充实，削弱人的争胜之志，强健人的筋骨体魄，常使民众没有巧诈的心智和多余的欲望，使那些自逞聪明的人不敢妄为。以无为的方式去做，反而没有什么做不成。

## 详解

这一章讲治民之方，落点却很实在：别去人为地制造争夺。

不刻意抬高「贤」的名头，百姓就不会挤破头去争那个名；不把稀罕物件炒成天价，百姓就不必去偷去抢；不把撩人的东西摆到眼前，人心就不会乱。这三条说的是同一件事——**贪欲不是天生的，多半是被挑起来的**。

第二段是正面做法：圣人治理天下，是让人心里空出地方，少一些算计和妄念；把肚子填饱、筋骨练结实；把好勇斗狠的心气降下来。让人不玩弄机巧、不生多余的念头，那些自以为聪明的人也就没机会兴风作浪。最后一句「为无为，则无不为」——按不妄为的方式去做，反而没什么做不成。

放到今天看，这是**环境设计**的思路：与其天天讲道德，不如先把诱人作恶的口子堵上。管住源头，比事后罚人省力得多。
