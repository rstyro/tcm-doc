# 第七十一章 知不知上

> 知，不知，上；不知，知，病。夫唯病病，是以不病。圣人不病，以其病病。是以不病。

## 译文

知道自己有所不知，这是高明的；不知道却自以为知道，这是毛病。正因为把这种毛病当作毛病，所以才没有毛病。圣人没有这种毛病，因为他把这种毛病当作毛病。所以才没有毛病。

## 详解

全章只有几句，句式却拧得厉害，值得慢读。

「知，不知，上」——知道自己有所不知，这是上等的。「不知，知，病」——不知道自己有所不知（甚至以为自己都懂），这是毛病。

后面两句是关键的方法：「夫唯病病，是以不病」——正因为把这种毛病当成毛病来治，所以才没有这个毛病。最后一句再补一遍：「圣人不病，以其病病。是以不病」——圣人之所以没有这种毛病，是因为他把这毛病当毛病看，所以没有。

**这一章讲的是「可修正性」。** 人不可能事事都懂，真正的分界不在懂得多少，在于知不知道自己不懂。知道，就能补；不知道，连补的门都找不到。

它和第 33 章「自知者明」、第 56 章「知者不言」是同一路数：全书把「知」的落点始终放在自己身上。
