# 第十三章 宠辱两忘

> 宠辱若惊，贵大患若身。何谓宠辱若惊？宠为下，得之若惊，失之若惊，是谓宠辱若惊。何谓贵大患若身？吾所以有大患者，为吾有身，及吾无身，吾有何患？故贵以身为天下，若可寄天下；爱以身为天下，若可托天下。

## 译文

受宠和受辱都像受到惊吓，把大患看得与自身一样重要。什么叫做宠辱若惊？受宠是卑下的，得到它时惊喜不安，失去它时惊惶不安，这就叫宠辱若惊。什么叫做贵大患若身？我之所以有大患，是因为我有这个身体；如果我没有这个身体，我还有什么祸患呢？所以，肯以重视自身的态度去对待天下的人，才可以把天下寄托给他；肯以爱惜自身的态度去对待天下的人，才可以把天下交托给他。

## 详解

开头八个字是全章的题眼：「宠辱若惊，贵大患若身」。

什么叫「宠辱若惊」？受宠本身就是件低下的事——因为你的高兴与难过都攥在别人手里。得到时惊喜不安，失去时惊惶不安，一上一下都在惊。今天被表扬就飘，明天被批评就塌，这是被人牵着走的状态。

什么叫「贵大患若身」？我之所以有大的祸患，是因为我把这副身体看得太重。这里的「身」不只是身体，更是那个「我」——我的面子、我的名声、我的得失。**把「我」放得越小，能伤到你的东西就越少。**

末段是推演：肯用重视自身的态度去对待天下的人，天下才可以托付给他；肯用爱惜自身的态度去对待天下的人，天下才可以交给他。注意这里说的是「以身为天下」——把对待自己的那份郑重，拿来对待天下，而不是把天下拿来养自己。
