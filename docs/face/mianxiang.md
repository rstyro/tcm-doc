# 相·面相

- 面相，是传统"相术"中人相（人相又分为面相与手相两大类）的一个分支，指通过观察面部五官的形态、气色与纹理，来推断人的性格、健康与运势的传统相术体系。
- 传统说法认为"相由心生"、面部可反映一个人的心性与际遇，据此形成了一套以"三停""五官""十二宫"等为框架的观察方法。这类说法属于传统文化中的方术观念，各家体系并不一致，并无现代科学实证支持。

## 面相的基本框架

- 传统面相学把面部看作一个整体，再按部位、层次分别观察，较通行的框架包括三停、五官与十二宫等。以下介绍均属传统相书中的通行说法，具体细节各家多有出入。

### 三停

- 三停指把面部从发际到下巴纵向分为三段，传统说法以各段分别对应人生的不同阶段：
    - 上停：从发际到眉间，传统说法认为主早年运势与先天禀赋。
    - 中停：从眉间到鼻准（鼻尖），传统说法认为主中年运势与事业成败。
    - 下停：从鼻准到下巴（地阁），传统说法认为主晚年运势与家业根基。
- 各段起止的界线在不同相书中略有出入，但"分三段对应人生阶段"的观察思路大体一致。
- 传统上讲究三停"匀称"为贵，上停过短或下停过促等都被认为有所偏；这类评价属于相书中的审美化语言，读者了解其思路即可。

### 五官

- 五官指眉、耳、口、鼻、目（眼）五者。传统相书为五官各配一个"官"名，意谓各主一面，较通行的说法是：
    - 眉为"保寿官"：传统说法认为与寿命有关，也主兄弟情谊。
    - 耳为"采听官"：传统说法认为主听闻与聪慧。
    - 口为"出纳官"：传统说法认为主言语与饮食。
    - 鼻为"审辨官"：传统说法认为主嗅觉，亦引申为判断取舍。
    - 目为"监察官"：传统说法认为主观察，也关联心性善恶。
- 另有五官与宫位相互牵合的说法，可见各家归类并不严格统一，此处仅取较通行的一说。
- 传统相书对每一官还讲究"相"——如目贵清朗有神、鼻贵挺直有肉、耳贵轮廓分明等，皆以"端正、精神、均衡"为美的总体取向，与日常审美经验多有重合。

### 十二宫

- "十二宫"是传统相法把面部划分出的十二个观察区位的说法，各宫主事不同。需说明的是，宫位名称与位置在历代各家划分并不一致，以下为较通行的一种说法，逐宫介绍：
    - 命宫：位于两眉之间（印堂），传统说法认为主一生总体的际遇起伏。
    - 财帛宫：指鼻准（鼻头），传统说法认为主财帛聚散。
    - 兄弟宫：指两眉部位，传统说法认为主兄弟姐妹与同辈助力。
    - 夫妻宫：指眼角（鱼尾）处，传统说法认为主婚姻感情。
    - 子女宫：指眼下卧蚕部位，传统说法认为主子嗣与晚辈。
    - 疾厄宫：指鼻梁根部（山根），传统说法认为主疾病灾厄。
    - 迁移宫：指额头两侧靠近发际处，传统说法认为主外出、迁徙与变动。
    - 奴仆宫：指下巴（地阁）一带，传统说法认为主下属、部众与社交。
    - 官禄宫：指额头正中，传统说法认为主事业、功名与仕途。
    - 田宅宫：指上眼皮（眉与眼之间），传统说法认为主家宅田产。
    - 福德宫：指眉尾上方的部位，传统说法认为主福分与享受。
    - 相貌宫：指整个面部的形貌与气色配合，可视作对前述各宫的总评。
- 另有以"父母宫"（额角日月角一带）列入十二宫的版本，这正是各家划分不一的体现。

### 十三部位与流年

- 除三停、五官、十二宫外，传统相书还以"十三部位"把面部自上而下细分为更多点位（如天中、天庭、司空、中正、印堂等），每一部位各有主事与吉凶说法。
- 所谓"流年"，指传统说法把人生各年龄段与面部不同部位对应起来，认为某处气色形态的变化预示相应年龄段的际遇。
- 这类细分体系在不同相书中名目繁复、差异极大，多属相术内部的专业口诀，非相术研究者了解其存在与思路即可，本页不逐一罗列。

## 源流与典籍

- 相人之术的源头一般认为可追溯至先秦两汉，"相人"之说在史书中偶有记载；至汉代，相术已与人物品评、择人任事的社会风气结合。
- 魏晋南北朝时期，受人物品藻风气影响，以骨相、神采论人的做法流行于士人之间；相术理论也随之丰富。
- 唐宋以后，相书大量出现，且常托名古代名人以增其重，如托名麻衣道者的《麻衣相法》、托名袁珙（柳庄）的《柳庄相法》、汇辑性的《神相全编》等，都是流传较广的相书（托名与否属学术考证范围，此处从通行说法）。
- 需要说明：这些相书的具体成书年代、真实作者多有争议，且内容庞杂、互相抄传、矛盾颇多，宜以学术整理本或民俗研究著作作为了解入口，不宜迷信任何单本。

## 气色的观察

- 传统相术除观察静态的形貌外，还很重视"气色"，即面部呈现的颜色与光泽，认为气色会随季节、境遇与身体状况而变化。
- 传统相书多以五行配五色（青、赤、黄、白、黑）并各附吉凶含义，如"面黄主喜""面赤主口舌"一类的说法。此类对应同样是各家经验之谈，说法参差，不宜当作定论。
- 客观而言，面色变化反映的多是真实的身体状态；若自己或家人气色长期异常且伴随不适，应及早前往医院检查，以现代医学诊断为准。

## 面相与中医望诊的异同

- 传统医学"望诊"同样重视面部观察：中医望面色、望神，把面部不同区域与脏腑联系起来（如"鼻为脾胃之候"一类说法），用于辅助辨证。
- 与相术的区别在于：中医望诊服务于疾病诊断与辨证论治，属于医学理论体系；相术则把面部观察用于推演性格与命运，属于方术体系。
- 两者在历史上相互渗透（相书常借用医学术语，医家亦批评相术），但观察对象的重叠不等于方法与结论相同。身体是否健康，应以医学检查与医师判断为准。

## 从文化视角看面相

- "相由心生"是民间流传很广的说法，大意是长期的心性修养会渐渐流露于面相神态之中。这更多是一种人生经验与文化观念的沉淀，属于主观性较强的传统观念。
- 从历史文化看，面相学是传统"相术"的一部分，与古人"观物取象"的思维一脉相承，也曾用于人物品评、择人任事等社会场合，可视为中国传统命理文化中的一种观察学说。
- 现代社会中，一个人的神情气质确实可能受性格、经历与健康影响，但这与相书中"某形主某运"的机械对应有本质区别；了解面相宜取其"重修养、重精神"的文化提示，而不必信奉其吉凶断言。

## 注意与禁忌

- 面相之说不能用于诊断疾病或判定命运，如有健康疑问请务必咨询医生。
- 以貌取人、因相断言他人命运，无论从现代观念还是传统"相不轻断"的告诫看都失之轻率；了解相术应以文化知识为限。
- 本文按传统文化知识整理的面貌加以介绍，供读者了解其说法体系。

## 延伸阅读

- 相书（学术整理本）：《麻衣相法》《柳庄相法》《神相全编》等流传较广，建议选择有校注、附导读的现代整理版本阅读。
- 民俗与学术研究：关于相术文化史、命相民俗的人类学与社会史论著，可提供比相书本身更客观的视角。
