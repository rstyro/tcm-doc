# 五术之相

- 所谓「相」，一般包括**印相、名相、人相、家相、墓相（风水）**等数种，是一类通过观察事物的外在形相来推断吉凶的方法。
- 印相——观看人的印章，据以论定命运。印在中国古代是权力的凭证，故此术有其制度上的由头。
- 名相——以人的姓名或店铺名称为对象，用「五格剖象」等方法，并结合命理推断吉凶。
- 人相——分面相与手相两大类，通过观察面部、手部的形貌、纹线与气色，推知吉凶乃至病理。
- 家相——即阳宅风水，观察住宅的格局与坐向，推断居住者的吉凶。
- 墓相——即阴宅风水，主张通过择地安葬祖先以荫庇后代。
- 总之，「相」是对眼睛所见的形相作观察，以求趋吉避凶的一类方术。它的共同方法是**「观物取象」**——从可见之形推及不可见之理。

## 「相」字何意

- 「相」在古汉语中有「察看、审察」之义（如「相地」「相马」「相人」），引申为对事物外在形态的观察与判断。传统相术之「相」，正取此义。
- 与「山」之修身心、「医」之治疾病不同，「相」的观察对象是**可见之形**：人的面貌体态、姓名的文字、印章的形制、住宅与墓地的地形格局，都属「形相」的范围。
- 传统思维认为「有诸内必形诸外」，外在形态是内在状态的一种显现，故可由形观神、由象知理。这套「观物取象」的思路，是相术各分支共同的方法论基础。
- 需要提醒：**「相」是五术中最依赖直观、也最容易被话术包装的一门**。因为它面对的是人人可见的对象（长相、名字、房子），任何人都能参与议论，也就特别容易出现「越讲越玄」的情况。本站的处理办法是：把「传统说了什么」与「它是否成立」分开写。

- 上述五类中，印相如今已较少流行，主要留存于传统说法与古籍记载；名相、人相、风水在民间流传较广，相关的说法与书籍也更多。
- 五类之外，古代相书还论**体相**（身形、骨架、行坐姿态）与**音相**（语声、笑声高低清浊），《神相全编》有专门篇章论「行」「坐」「卧」「语」。这两类今日已少见系统整理，本站暂未单列，姑志于此。

## 核心理念

- **由形及理**：传统相术相信外在形貌、格局与人的性格、际遇之间存在某种对应关系，观察「形」可以推知「理」。
- **心相相应**：民间常说的「相由心生」认为心性会逐渐显现在神态面貌上。这一条与其余几条性质不同——它说的其实是**长期情绪与习惯会影响神情气质**，属于人生经验的沉淀，也常被现代心理学以「表情习惯」的方式讨论；但它并不支持「容貌决定命运」。
- **天人相应**：风水一脉把环境（地形、方位、水流）与人的吉凶祸福联系起来，体现「天人合一」的传统宇宙观。
- 需要说明：这些理念属于传统文化中的观念体系，不同流派说法互有出入，**并无现代科学实证支持**；作为文化知识了解其框架即可。

## 与医、命的关系

- **与医的关系**：传统医学（尤其「望诊」）也观察面色、形体、舌象，但目的是诊察疾病；相术观察的目的则在推演性格与运势。二者观察对象有重叠，方法与宗旨不同，不宜混为一谈。具体辨析见《[相·面相](/face/mianxiang)》中「与中医望诊的异同」一节。
- **与命的关系**：传统相术常与八字命理互相参看，形成「相命」合流的民间实践。本站把命理内容归入「命」部，可参见《[八字](/fate/bazi)》等篇。
- **与卜的关系**：卜是「以当下之事起卦而问」，相是「观已见之形而论」，一者求问于卦，一者取象于形，方法不同。可参见「卜」部各篇。

## 源流简说

- 相术的思想可追溯至先秦：「相马」「相地」等技艺当时已见记载，以相貌论人贵贱的「相人」之术在《左传》中已有实例。
- 汉魏以后，相术与人物品评风气结合，渐成体系；唐宋以降相书渐多（敦煌写本相书是现存最早的实物文献），明清时期流传更广，并吸收五行、中医脏腑等观念，形成内容丰富而流派众多的面貌。
- 与符咒类似，相术在历史上亦属「方术」之列，正统儒家多持批评态度——荀子《非相》即是最早的系统批判。历代典籍中既有传承也有限禁的记载，其社会地位始终存在争议。
- 这一脉络的详细梳理（各时代的代表人物、典籍与流派）见《[相术源流与流派](/face/history)》；各部相书的题名、年代争议与读法见《[相术原典导读](/face/classics)》。

## 文化定位与理性看待

- 今天了解「相」，较合适的定位是把它作为中国传统民俗与文化观念来认识：相术反映了古人观察世界、理解人与环境关系的思维习惯，也承载了民间趋吉避凶的心理。
- 其中部分观察与生活常识、医学经验存在交集（如**面色反映身体状况**、**住宅朝向影响采光通风**），可作参考；而将形貌、姓名、环境直接断言吉凶祸福的部分，则属于传统说法与民俗信仰，各派出入很大，不可作为事实依据。
- 特别要警惕三类情形：
    - **以相取人**。用面相、手相判断他人品性能力，在招聘、婚配、用人等场合会造成实际的不公与伤害。
    - **以相敛财**。以「相格有亏」「不化解必有祸」施压，推销改运物品、法事、课程，是常见的套路。
    - **以相代医**。把「气色不好」当作诊断结论，延误正规就医。
- 健康问题请咨询医生，重大事务决策请依据事实与专业意见；了解相术宜取知性、开放而审慎的态度。
