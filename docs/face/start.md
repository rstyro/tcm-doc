# 五术之相

- 所谓"相"，一般包括"印相、名相、人相、家相、墓相（风水）"等五种，以观察存在于现象界形相的一种方术。
- 印相——就是观看人的印章，以取定命运的方法。印在中国，以前是权力的凭证。
- 名相——是以人的姓名或店铺的名称，通过五格剖相，同时运用命理等结合来推断吉凶发展的一种方法。
- 人相——又分为面相与手相两大类，通过观察面、手部的纹线与气色而了知人吉凶、病理的一种方法。
- 家相——也就是阳宅的风水，以观察其格局，进行分析来推断对人类所居住的吉凶的一种方术。
- 墓相（风水）——也就是阴宅，以通过选地安葬祖先，而达到对后代子孙荫庇的一种方术。
- 总之，"相"是对眼睛所看到的物体作观察，以达趋吉避凶的一种方法。

## "相"字何意

- "相"在古汉语中有"察看、审察"之义（如"相地""相马"），引申为对事物外在形态的观察与判断。传统相术之"相"，正取此义——观察现象界可见的形貌，推及其背后的趋势与吉凶。
- 与"山"之修身心、"医"之治疾病不同，"相"的观察对象是"可见之形"：人的面貌体态、姓名的文字、印章的形制、住宅与墓地的地形格局，皆属"形相"的范围。
- 传统思维认为"有诸内必形诸外"，外在形态是内在状态的一种显现，故可由形观神、由象知理。这一"观物取象"的思维，是理解相术各分支共同的方法论基础。

## 核心理念

- **由形及理:** 传统相术相信外在形貌、格局与人的性格、际遇之间存在某种对应关系，观察"形"可以推知"理"。
- **心相相应:** 民间常说的"相由心生"认为心性会逐渐显现在神态面貌上；这更多是一种人生经验的沉淀，强调修心养性对气质的影响。
- **天人相应:** 风水一脉则把环境（地形、方位、水流）与人的吉凶福祸联系起来，体现"天人合一"的传统宇宙观。
- 需要说明：这些理念属于传统文化中的观念体系，不同流派说法互有出入，并无现代科学实证支持；作为文化知识了解其框架即可。

## 与医、命的关系

- **与医的关系：** 传统医学（尤其"望诊"）也观察面色、形体、舌象等，但目的在诊察疾病；相术观察的目的则在推演性格与运势。二者观察对象有重叠，方法与宗旨不同，不宜混为一谈。
- **与命的关系：** 传统相术常与八字命理等互相参看，形成"相命"合流的民间实践；本书将其归入"相"部，命理相关内容可参见"命"部各篇。

## 源流简说

- 相术的思想可追溯至先秦，"相马""相地"等技艺在当时已见记载；以相貌论人贵贱的"相人"之术，在先秦两汉文献中亦偶见其说。
- 汉魏以后，相术与人物品评风气结合，渐成体系；唐宋以降相书渐多，明清时期流传更广，并吸收五行、中医脏腑等观念，形成内容丰富而流派众多的面貌。
- 与符咒类似，相术在历史上亦属"方术"之列，正统儒家多持批评态度，历代典籍中既有传承也有限禁的记载，其社会地位始终存在争议。
- 上述为文化史层面的概述，具体书目、年代的考据超出本页范围，读者可按兴趣参见文末延伸文献。

## 文化定位与理性看待

- 今天了解"相"，较合适的定位是把它们作为中国传统民俗与文化观念来认识：相术反映了古人观察世界、理解人与环境关系的思维习惯，也承载了民间趋吉避凶的心理。
- 其中部分观察（如面色反映身体状况、住宅朝向采光通风是否宜居）与生活常识、医学经验存在交集，可作参考；而将形貌、姓名、环境直接断言吉凶祸福的部分，则属于传统说法与民俗信仰，各派出入很大，不可作为事实依据。
- 健康问题请咨询医生，重大事务决策请依据事实与专业意见；了解相术宜取知性、开放而审慎的态度。
