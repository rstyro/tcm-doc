# 相术源流与流派

- 相术是「五术」中「相」这一门的总称，指通过观察人的形貌、气色、声音、举止，乃至姓名、印章、居所环境，来推断其性情、命运的方法体系。
- 它在中国有**两千余年可考的记载**：先秦已见相人之例，汉魏趋于理论化，唐宋出现成套典籍，明清集大成并渗入民间日常。这一门之所以能延续如此之久，既因为它满足了人们对「识人」与「预知」的双重需求，也因为它的判断标准极其模糊、极难被证伪。
- 读这一门的历史，有个好处：**能看清哪些说法是古老的、哪些是后起的、哪些其实是近现代才编出来的**。今天网上流传的不少「古法」，其实出自民国甚至更晚的书坊。辨清源流，是理性看待相术的第一步。

## 一、先秦：相人的早期记载

- 相术的萌芽与先秦的**人物品评**传统分不开。在官僚选拔尚未制度化的时代，「看一个人像不像有出息」是一种实用的社会技能，相人者因此受到重视。
- 最早的记载见于《左传》。《左传·文公元年》载周天子派内史叔服参加鲁国的葬礼，「公孙敖闻其能相人也，见其二子焉」，叔服看了说「谷也食子，难也收子。谷也丰下，必有后于鲁国」——从下巴丰满推出后代昌盛，这是现存最早的相人实例之一。
- 《左传》另有「姑布子卿相赵无恤」的记载：姑布子卿为赵简子诸子看相，认为地位低下的无恤「此真将军矣」，后来无恤果然继位，即赵襄子。这类记载的共同点是**事后追述**——相术的灵验故事大多写在结果已知之后。
- 与此同时，批判相术的声音也已出现。荀子在《非相》篇中说得极为直白：
    - 「相人，古之人无有也，学者不道也。」——相人之术，古人没有，学者不讲。
    - 「故相形不如论心，论心不如择术。形不胜心，心不胜术。」——与其看形貌，不如论心术。
    - 「形相虽恶而心术善，无害为君子也；形相虽善而心术恶，无害为小人也。」——形貌与德行并无必然联系。
- 荀子这一篇是中国思想史上最早、也最系统的相术批判文献，其逻辑至今难以反驳。读相术史时把它放在手边，会清醒得多。

## 二、汉魏：理论化与第一次兴盛

- 汉代相术大盛，并且开始**寻找理论依据**。
- 《史记·淮阴侯列传》载蒯通劝韩信自立，说「相君之面，不过封侯，又危不安；相君之背，贵乃不可言」——借相术之辞行政治游说之实。这一例很能说明问题：**相术在史书中常是政治表达的工具**，而不是单纯的预测技术。
- 汉初有女相者**许负**，相传曾为薄姬看相，断言其「当生天子」。《史记·外戚世家》载此事。许负在后世相书中被奉为祖师之一。
- 东汉**王充**在《论衡》中专立《骨相》篇，为相术作理论辩护：人禀气于天，形见于体，故「案骨节之法，察皮肤之理，以审人之性命」，可以推知其贵贱寿夭。王充的本意是用「气禀」一元论反对天人感应，但客观上为骨相说提供了哲学基础。
- 三国时期，相术进入正史的《方技传》。《三国志·魏书》载**朱建平**善相，曾为曹丕、曹植等多人看相；**管辂**亦以相人、卜筮闻名。
- 这一时期的特点是：相术有了「骨相」「气色」等初步概念，且与当时流行的**相法（形法）之学**、阴阳五行学说结合，开始形成体系。

## 三、唐宋：体系成形与典籍涌现

- 唐代相术在民间与宫廷都相当流行，最著名的人物是**袁天纲**（后世多写作袁天罡）。相传他曾为武则天看相，断言其「龙瞳凤颈，极贵验也」。他与李淳风的名字后来被附会到《推背图》上，但《推背图》的实际成书年代远晚于二人。
- 敦煌藏经洞出土了一批**唐代写本相书**残卷（如伯希和编号 P.2572 等），内容涵盖五官、气色、手足、行走姿态的吉凶判断。这是现存最早的相术实物文献，价值极高——**此前关于唐宋相术的认识多来自后世转述，敦煌写本提供了第一手材料**。
- 五代至宋初，出现了相术史上最关键的两个托名人物：
    - **麻衣道者**：相传为五代宋初僧人，陈抟之师，被奉为「麻衣相法」的祖师。今本《麻衣神相》实际成书大约在宋元之间，并非麻衣本人所作。
    - **陈抟**（希夷先生）：宋初著名隐士，后世相书多托名于他，如《神相全编》题「宋陈抟秘传」。
- 宋代书目著录了一批相书，如《月波洞中记》（托名老子）、《玉管照神局》（题南唐宋齐丘撰）、《太清神鉴》（题王朴撰）。**这些书的真实成书年代多有争议，题名与实际作者往往无关**，这是研读相术古籍时首先要过的关。
- 宋代相术还有一个社会背景：科举制度成熟后，「读书能否出头」成了普遍焦虑，相术因此获得了新的市场——相「功名」成为相术的主要生意之一。

## 四、明清：集大成与名家

- 明代是相术的**集成期**，也是相术典籍大量刊刻的时期。
    - **袁珙**（号柳庄居士）：明初相术名家，《明史·袁珙传》载其为燕王朱棣看相，称「龙行虎步，日角插天，太平天子也」。此说在靖难之役后被广为传述。今传《柳庄相法》托其名。
    - **袁忠彻**：袁珙之子，亦以相术名于世，编订《神相全编》。
    - **《神相全编》**：十二卷，题为宋陈抟秘传、明袁忠彻订正，是相术的集大成之作。今天所见相术术语——十三部位、十二宫、五官、五行形相——大多通过此书定型。
- 清代相术进一步世俗化。
    - **《相理衡真》**：清陈钊撰，十卷，体系较完整。
    - **《冰鉴》**：坊间传为曾国藩所撰，讲「神骨、刚柔、容貌、情态」等识人之法。**学界一般认为是清末民初书坊辑录托名**，并非曾国藩手笔，其中不少内容取自《神相全编》等旧籍。这一点需要特别注意，因为它常被当作「曾国藩的识人术」来宣传。
- 明清相术的一个新特点是**与风水、命理合流**：一个术士往往兼营看相、算命、择日、看宅，服务对象也从士大夫扩展到普通市民。相术由此从「术」变成了一门生意。

## 五、近现代：西学影响与商业变形

- 清末民初，西方的**掌纹学（chiromancy）**经由日本传入中国，与中国固有的手相说法混合，形成了今天常见的手相体系（生命线、智慧线、感情线「三大主线」的提法，其实主要来自西方而非中国古法）。
- 民国时期出现了大量相术出版物，命相馆在大城市颇为常见。相术从「术」转向「行业」。
- 近几十年，相术以新的形态回流：**电脑算命、面相评分 App、AI 看相**。技术外壳变了，判断逻辑与「模糊断言 + 事后印证」的结构其实没变。
- 需要留意一个现象：**今天网上流传的许多「古法相术口诀」，实际出处是民国或当代的通俗读物**。凡见到「古人云」却查不到确切出处的说法，宜先存疑。

## 六、主要流派（传统说法）

- 相术内部的流派划分，历代并无统一标准，以下是较为通行的说法：

| 流派 | 主张与特点 | 代表典籍/人物 |
| --- | --- | --- |
| 麻衣派 | 以《麻衣神相》为宗，重五官、十二宫、十三部位，体系最完整，流传最广 | 托名麻衣道者 |
| 神相派 | 以「神」为第一，认为神气重于形貌，「得神者昌，失神者亡」 | 《神相全编》诸论 |
| 骨相派 | 重骨骼结构，认为骨格定终身贵贱 | 《论衡·骨相》、后世骨相诸说 |
| 形貌派 | 重形体、五行形相、面型分类 | 五行形相说 |
| 文士派（识人术） | 不重吉凶祸福，而重「识人」，讲气质、情态、格局 | 《冰鉴》一类 |
| 江湖派 | 口诀化、快断、重现场观察与话术，兼用试探 | 口传，多见于市井相馆 |

- 需要说明：这几派并非壁垒分明的组织，很多术士兼采诸说。所谓「派」更多是后人对不同侧重的归纳。
- 判断一本相书或一位术士的路数，可看他的切入点：**先看骨、先看神、还是先看气色**；重「定命」还是重「识人」；断语是终身定性还是随时可变。这三点基本能定位其归属。

## 八、关于「应验」的说明

- 相术史上记载了大量「应验」的案例，但需要注意它们的**共同结构**：
    - **事后记录**。绝大多数的灵验故事，都写在结果已知之后。事前留下明确、可核验的书面预言的例子，几乎找不到。
    - **选择性流传**。成功的案例被反复转述，失败的案例无人记录。这是典型的幸存者偏差。
    - **表述模糊**。断语往往一句多解，事后总能把结果套进去。
    - **表述可调**。相术内部有大量「例外条款」（如「相不独论」「有心相改相」），使任何反例都能被解释掉，因而难以证伪。
- 荀子两千多年前的判断，与现代方法论的结论一致：**形貌与人的品行、能力、命运之间，没有可靠的对应关系**。相术作为文化现象值得了解，作为判断他人的依据则极不可靠——尤其当它被用于招聘、婚配、用人决策时，会造成实际的不公。
