# 相术原典导读

- 相术类的古籍有一个共同特点：**托名普遍、成书年代难以确考、版本繁杂**。几乎每一部重要相书都挂在一个响亮的名字下面——麻衣道者、陈抟、郭璞、黄帝——而实际作者与成书年代多不可考。
- 因此本页的写法与站内其他典籍页不同：不逐句整理原文，而是**逐部介绍其题名、时代争议、主要内容与价值**，供读者知道「有哪些书、可信到什么程度、值得怎么读」。
- 需要先立一个参照：**荀子的《非相》是相术文献的对照面**。读过它，再读任何相书，都会自带一层辨别力。

## 一、相术的批判文献（先读这两篇）

### 《荀子·非相》

- 战国荀况撰，是现存最早、最系统的相术批判文献。
- 核心论点有三：其一，相人之术「古之人无有也，学者不道也」，即没有可靠的传统依据；其二，形貌与心术无关，「形相虽恶而心术善，无害为君子也；形相虽善而心术恶，无害为小人也」；其三，应重「心」与「术」而非「形」，「相形不如论心，论心不如择术」。
- 它还举了反例：卫灵公的臣子公孙吕「身长七尺，面长三尺」，相貌极丑却名动天下；楚国的孙叔敖「突秃长左」，却使楚国称霸。这些例子直接否定了「形貌定命」。
- **读法建议**：这一篇篇幅很短，宜先读，再读相书。它提供的不是结论，而是一个提问的角度。

### 《论衡·骨相篇》

- 东汉王充撰。这一篇的立场与《非相》相反，是**为骨相论辩护**的代表。
- 王充的主张是：人禀气而生，气有厚薄，故形见于体；「案骨节之法，察皮肤之理，以审人之性命」，可以据形推知贵贱寿夭。他举了大量历史人物为例，如刘邦「隆准而龙颜」、项羽「重瞳」等。
- 但要注意王充的**理论动机**。他写《论衡》的主旨是反对天人感应与谶纬迷信，用「禀气」这种自然主义的解释取代「天意」；骨相说在他那里是「自然决定论」的一部分，而非神秘主义。这一点常被后世相书引用时模糊掉。
- 结果上，这一篇客观上为骨相说提供了哲学基础，后世相书论「骨格定终身」，源头多可追溯到它。

## 二、唐宋相书（现存较早的一批）

### 敦煌写本相书

- 20 世纪初在敦煌藏经洞发现的唐代写本相书残卷（如伯希和编号 P.2572、P.3492 等，斯坦因也有收藏），是**现存最早的相术实物文献**。
- 内容包括五官、气色、手足、行走姿态的吉凶判断，还保留了当时相书的分类体例（如「相眉」「相眼」「相鼻」各自成篇）。
- 它的价值在于：此前学界关于唐宋相术的认识多来自后世转述，敦煌写本提供了第一手材料，可以校正许多流传已久的说法。**这是研究中国相术史最重要的材料，没有之一。**

### 《月波洞中记》

- 《宋史·艺文志》著录，托名老子（一说唐任逍遥撰）。内容以论「神气」「骨法」为主。
- 原书久佚，今本为《四库全书》从《永乐大典》中辑出的残本。四库馆臣在提要中已指出其文字「多后人增窜」。

### 《玉管照神局》

- 题南唐宋齐丘撰，《宋史·艺文志》著录，《四库全书》收入子部术数类。
- 内容兼论形貌、气色、神气，并附有图说，是较早的图文并重的相书。

### 《太清神鉴》

- 题「王朴撰」。王朴是后周世宗时的名臣，但此书是否真出其手，学界普遍存疑，一般认为是宋人托名。
- 六卷，论形神、气色、骨法、部位，体系相对完整，是宋代相书中的代表作。

### 《麻衣神相》（《麻衣相法》）

- 相术史上影响最大的一部书，托名五代宋初的**麻衣道者**（相传为陈抟之师）。
- 成书年代学界一般认为在**宋元之间**，并非麻衣本人所作；今传本又经明清人增补，其中不少内容（尤其插图与断语）是后来加上去的。
- 主要内容包括：十三部位与流年、十二宫、五官、五行形相、气色、以及大量断语口诀。今天通行的相术术语，大多出自此书及其衍生的《神相全编》。
- **读法建议**：这是最容易上手的一部（术语集中、结构清晰），但也是最容易被当成「权威古法」的一部。读时应清楚：它的体系是层累形成的，不是某个宋代高僧的一次性发明。

## 三、明清相书（集成与世俗化）

### 《神相全编》

- 十二卷，题「宋陈抟秘传、明袁忠彻订正」。实际是明代相书的集大成之作，汇集了此前历代相书的主要内容。
- 结构上分论神、论形、论部位、论气色、论情态等，并配有大量插图与歌诀。相术从零散口诀到系统教材的转变，主要通过这部书完成。
- **研读相术，若要选一部「代表作」，一般选它**——不是因为它最古，而是因为它最全、最有代表性，且能够反映相术在明代的成熟形态。
- 需要注意：书中夹杂的「女相」「奴相」等内容，带有强烈的时代偏见与阶层歧视，阅读时应有意识地区分「历史材料」与「可接受的观点」。

### 《柳庄相法》

- 托名明初相术名家**袁珙**（号柳庄居士）。《明史·袁珙传》载其为燕王朱棣看相，称「龙行虎步，日角插天，太平天子也」。
- 今传本的成书情况复杂，一般认为经后人增补，未必反映袁珙本人的相法。
- 内容偏重实用断语，江湖气息较浓，与《神相全编》的系统性不同。

### 《相理衡真》

- 清陈钊撰，十卷。清代相书的代表作，体例比明代相书整齐，论述也较有条理。
- 它试图给相术建立一套「理」，讲「相由心生、相随心转」，主张相术不仅是断吉凶，更在于劝人向善。这种「劝善」的取向是清代相术的一个特点——**面对儒家的批评，相术通过自我道德化来争取合法性**。

### 《冰鉴》

- 坊间盛传为曾国藩所撰，讲「神骨、刚柔、容貌、情态、须眉、声音、气色」等识人之法，影响极广。
- **学界一般认为是清末民初书坊辑录托名**，并非曾国藩手笔；其中不少内容取自《神相全编》等旧籍，另有部分来自同时代的通俗读物。
- 它的流行说明了一件事：**相术在近现代是靠「名人背书」维持影响力的**。曾国藩、刘伯温、诸葛亮等名字被反复借用，本身就是一种营销。
- 读法上，可把它当作民国通俗相术的样本，而不是「曾氏家学」。

## 四、风水类典籍

- 风水是「相」的一个分支（家相、墓相），其典籍体系与面相、手相不同，自成脉络：

| 典籍 | 题名 | 说明 |
| --- | --- | --- |
| 《葬书》（《葬经》） | 托名晋郭璞 | 阴宅理论的奠基之作，实际成书约在唐宋之间；提出「乘生气」「藏风得水」等核心概念 |
| 《宅经》（《黄帝宅经》） | 托名黄帝 | 阳宅理论的早期文献，实际成书不早于唐；《四库全书》收入 |
| 《阳宅十书》 | 明王君荣辑 | 阳宅理论的汇编，图文并重 |
| 《阳宅三要》 | 清（旧题赵九峰） | 以「门、主、灶」为阳宅三要，影响极大 |
| 《地理五诀》 | 清赵九峰 | 以「龙、穴、砂、水、向」五者为纲，是形法派（峦头派）的代表作 |
| 《八宅明镜》 | 旧题唐杨筠松 | 八宅法的代表作，实际成书在明清之间；东西四宅、游年九星之说由此通行 |
| 《沈氏玄空学》 | 清末沈竹礽 | 玄空飞星法的近代重要著作，三元九运、飞星排盘之说多据此书 |

- 需要说明：《四库全书》把《宅经》《葬书》收入子部术数类，但四库馆臣在提要中**同时提出了批评**。他们一方面承认其中「亦有可取」（如《葬书》对地形水势的部分观察），另一方面明确指出后世相沿的许多说法是「术家附会」。
- 四库馆臣对术数类的总评很值得一读，大意是：术数之兴多在秦汉以后，其旨不出阴阳五行、生克制化，实为《易》的支派而杂以他说。**这是清代官方学者对术数的定调：渊源有自，但不宜尽信。**

## 五、读这类古籍的几点提醒

- **先辨托名**。看一部相书的题名，不要先信作者，而要先查书目著录与学界考证。凡题「黄帝」「郭璞」「麻衣」「陈抟」「刘伯温」「曾国藩」者，几乎都需要打问号。
- **再辨成书年代**。同一部书可能有宋本、明刻本、清刻本、民国石印本多个系统，内容差别可以很大。引用时应注明所据版本。
- **分清「文献记录」与「事实判断」**。书中说「某相主贵」，是在记录一种传统说法；这不等于该说法成立。本页介绍的是前者。
- **留意自我辩护的语言**。相术与风水典籍中大量出现「心善则吉」「德厚者福」一类说法。这类内容一方面有劝人向善的价值，另一方面也使任何反例都能被解释掉——**难以证伪正是它们能长期存续的重要原因**。
- **不要用于判断他人**。用于择业、婚配、用人等决策时，形貌判断会造成实际伤害，且没有证据支持。
