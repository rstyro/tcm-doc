# 相·手相

- 手相，是传统"相术"中人相（人相又分为面相与手相两大类）的一个分支，指通过观察手掌的纹线、掌型与手指形态，来推断人的性格与运势的传统相术体系。
- 手相观察的传统源远流长，东方与西方各有流传。本文所述以较通行的传统说法为主，各家说法并不一致，也无现代科学实证支持。

## 手相研究的基本对象

- 传统手相观察的内容大体可分为纹线与掌型两部分：纹线又分主线与次要线，掌型则涉及掌形与指形。
- 除了看纹、看形，传统手相也讲究观察手掌的气色、软硬、厚薄与温度，认为可反映体质与精神状况；此类说法同样流派出入很大，属经验性归纳。

### 三大主线

- 传统手相较通行的说法，把掌上三条横向主纹合称"三大主线"，名称在不同相书与派别中并不统一（旧时亦以"天纹、人纹、地纹"称呼）。较通行的称呼与说法如下：
    - 生命线：自虎口（拇指与食指之间）向手腕方向环绕拇指的弧线，传统说法认为主体质与精力的强弱。
    - 智慧线（又称头脑线）：自虎口横过掌心通向对侧的横线，传统说法认为主思维、判断与处事方式。
    - 感情线（又称天纹）：自小指下方伸向食指方向的上方横线，传统说法认为主情感倾向与婚姻缘分。
- 需要说明：三大主线只是传统相书对常见掌纹的归纳，各线的起止、长短因人而异，各家解读亦常互相矛盾，并无统一标准。
- 一些手相读物喜欢把"生命线长短"直接说成"寿命长短"，这在各派中其实并非通行结论——传统说法多认为生命线反映的是体质精力的大致趋势而非精确寿命，读者勿被简化说法误导。

### 次要线与其他掌纹

- 除三大主线外，传统手相还常观察若干较细的纹线，常见的有：
    - 事业线（命运线）：自腕部向中指方向延伸的纵线，传统说法认为主事业发展，此线并非人人清晰可见。
    - 婚姻线：小指根部下方的短线，传统说法认为主感情与婚姻状况。
- 此外还有太阳线、健康线、金星带等更多名目，各派称谓与含义纷繁，此处不再展开。
- 传统上认为掌纹会随年龄与生活状态缓慢变化，因此"看手相"讲究在适当的时机观察，同一只手不同时期的纹路未必完全一致；这一说法也使手相带有"动态"的性质。

## 掌型与指型的传统划分

- 传统手相也注重观察手掌与手指的整体形态，掌型划分的说法很多，常见的有：
    - 按五行划分：金、木、水、火、土五种掌型，各配以相应的性格特征描述。
    - 按形状划分：如方形掌、尖形掌、铲形掌等，亦各附说法。
- 指型方面，传统说法常观察手指的长短粗细、指节是否分明、拇指的形态位置等，并与性格作粗略对应。
- 这类掌型分类在东西方手相及不同相书中版本极多，相互并不统一，多属后人归纳的说法，仅作传统文化知识了解即可。
- 还有一种较流行的通俗说法把掌型分为"实际型、艺术型、哲理型、直觉型、运动型"等（源自西方手相的"七型"传统），与五行分法思路不同，可对照了解其多样性。

## 手相与中医"手诊"的辨析

- 传统中医在诊断中确会观察手部（如指甲色泽、掌色、指腹形态等），作为望诊的一部分辅助判断气血状况。
- 但中医手部观察服务于辨证论治，有其理论体系与诊断目的；与流行"手相"把纹路对应性格命运的做法并不相同，不宜混为一谈。
- 若手掌、指甲出现明显异常（颜色改变、痣体变化、溃疡不愈、皮肤增厚脱屑等），应就医检查，切勿以"手相""手诊"自行判断而延误诊治。

## 左右手的主次

- 关于应以哪只手为主，传统说法常见者有以下几种：
    - "男左女右"的说法在民间流传较广，但并非所有流派都采信。
    - 有说法认为"左手主先天禀赋，右手主后天际遇"，也有版本相反，或主张两手同参。
- 这些说法彼此出入很大，并无公认标准，读者了解不同说法即可。
- 西方手相传统则常以"惯用手主后天发展、非惯用手主先天潜质"来区分左右，与东方"男左女右"思路又不同，可见此类规则多为文化习惯而非客观规律。

## 从文化视角看手相

- 手相与面相并称，同属传统"人相"乃至命理文化的一部分，反映了古人由形体观察推及性格、际遇的思维习惯，在民俗与文化史上自有其位置。
- 从传播角度看，手相因"观察对象随身可得、无需生辰"而格外通俗，古今中外都易于流行；这也是它说法版本最多、最不统一的原因之一。
- 客观地看，手掌纹线在个体间差异极大，且会随年龄与皮肤状态变化；并无证据表明纹线与性格、命运之间存在确定关联。
- 特别说明：手相属于传统方术文化，不能作为医学诊断的依据。若手掌或指甲出现颜色、纹路、形态的明显异常（如色素痣变化、溃疡久不愈合等），请及时就医，以专业医疗检查为准。

## 延伸阅读

- 传统相书：面相相关著作中常兼含手相内容（如《麻衣相法》系统文献），可参阅其手部章节；另有近代流传的各种手相讲义，版本驳杂，宜谨慎选择。
- 学术研究：从文化史、民俗学角度研究相术与手相信仰的论著，可提供较客观的分析框架。
- 科普对照：若对手部与健康的关系感兴趣，可阅读现代医学关于皮肤、指甲表现的科普资料，以正规医疗机构发布的信息为准。
