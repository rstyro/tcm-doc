# 相·风水

- 风水，传统上又称堪舆、地理、相地之术，是研究居住环境与墓葬环境的选址、布局以趋吉避凶的一门传统学问。
- 在"相"的五类（印相、名相、人相、家相、墓相）中，风水大体对应两大类：阳宅（家相）——研究住宅与聚落的选址布局；阴宅（墓相）——研究墓地的选址安葬。
- 风水属于传统"相地"传统的延续，观察的对象是地形、方位、水流、建筑与人的关系，其中既有环境经验的积累，也有浓厚的民俗信仰成分。

## 源流概述

- 传统说法认为，风水的源头可追溯至先秦时期的相地传统，即观察土地形势以定居住之宜的实践，最初与选择城址、住宅基址等实用需求相关。
- 汉晋以后，这类相地实践逐渐发展为"堪舆"之学，出现"堪天舆地"的说法，并逐步融入阴阳、五行、卦气等观念，成为一套体系化的传统学问。
- 后世风水流派渐多，各有师承与典籍，说法不一、主张各异，已难以用单一理论概括。
- 需说明：风水典籍版本流传复杂，各书成书年代与作者多有争议，此处不涉及具体篇目页码的考据。

## 核心概念（传统说法）

- **"气"与藏风聚气：** 传统说法认为环境中有一种"气"的流转，理想的选址应能"藏风聚气"，即地形上能避强风、聚生气。
- **"龙、砂、穴、水、向"：** 传统峦头（形势）一派观察地形的一套名词框架：
    - **龙：** 指山势脉络的走向与起伏。
    - **砂：** 指穴场周围环抱的小山丘、地形。
    - **穴：** 指被认为适合落葬或建房的具体位置。
    - **水：** 指水流、水口的形态与方位。
    - **向：** 指建筑或墓穴的朝向。
- **理气各派：** 另有以方位、时间数理推算吉凶的一类流派，较常听到的名称如八宅派（按宅主命卦分东西四宅）、玄空派（以九宫飞星配时间方位论吉凶）等。
- 需要说明：风水流派繁多、说法不一，各派对同一名词的定义、断法常互有出入，此处仅作名词层面的客观介绍，不代表某种流派为定论。

## 阳宅：居住环境（家相）

- 传统说法关注阳宅的诸多方面，常见条目如：坐向方位、大门位置、采光通风、厅堂房间的布局、动线走向、宅周环境等。
- 从现代宜居的角度看，其中不少讲究与环境科学常识相通，例如：
    - 重视朝向与采光，可对应冬日向阳、室内明亮的需求；
    - 重视通风与气流，可对应室内空气流通、避免潮湿的要求；
    - 重视"门路动线"顺畅，与日常起居动线合理、生活便利相通；
    - 重视宅周地形水流，与规避水患、滑坡等风险的经验一致。
- 这些合理成分是传统居住经验的一部分，可作文化知识参考，不必依附于吉凶断言。

## 阴宅：墓葬环境（墓相）

- 传统观念认为，为祖先选择墓地的位置与朝向会影响其后代子孙的运势，故有"荫庇后人"的说法。
- 传统阴宅看重山势环绕、水流有情、来龙去脉等，其观念体系与阳宅大体同源而更强调地形格局。
- 需说明：阴宅影响子孙运势之说属于传统民俗观念，流派众多、说法不一，并无现代科学依据；了解其观念与习俗即可，不宜据此安排实际事务。

## 现代理性视角

- 从现代视角看，风水可视为一种传统文化遗产与民俗现象：它记录了古人对居住环境的选择经验与审美偏好，也承载了民间对吉凶祸福的心理寄托。
- 其中偏重环境宜居的部分（朝向、采光、通风、避害）与科学常识相通，值得以经验总结的态度看待。
- 而涉及吉凶应验、荫庇子孙等断言，则属于信仰与习俗层面，各家说法不一，不可作为可验证的事实或操作指引。
- 了解风水，宜以客观、知性的态度将其作为传统文化知识来读，取其宜居经验，明其民俗属性，而不宜迷信其断语、轻信所谓的"改运布置"。
