# 相·风水

- 风水，传统上又称堪舆、地理、相地之术，是研究居住环境与墓葬环境的选址、布局以趋吉避凶的一门传统学问。
- 在"相"的五类（印相、名相、人相、家相、墓相）中，风水大体对应两大类：阳宅（家相）——研究住宅与聚落的选址布局；阴宅（墓相）——研究墓地的选址安葬。
- 风水属于传统"相地"传统的延续，观察的对象是地形、方位、水流、建筑与人的关系，其中既有环境经验的积累，也有浓厚的民俗信仰成分。

## "堪舆"释义

- "风水"别名"堪舆"。传统训释中，"堪"常解为天道、高处，"舆"解为地道、低处，合指仰观天象、俯察地形的相地之学。
- 又有"地理"之名，取"大地之理"之意；但此"地理"与今日作为科学的地理学含义不同，阅读古籍时宜加区分。
- 以"风水"名之，则源于传统说法"藏风聚气、得水为上"的概括——风与水被视为影响聚气生机的两大关键因素。
- 无论何种名称，其共同指向都是：通过观察自然环境的形势格局，为居住或墓葬选择"吉"的位置与朝向。

## 源流概述

- 传统说法认为，风水的源头可追溯至先秦时期的相地传统，即观察土地形势以定居住之宜的实践，最初与选择城址、住宅基址等实用需求相关。
- 汉晋以后，这类相地实践逐渐发展为"堪舆"之学，出现"堪天舆地"的说法，并逐步融入阴阳、五行、卦气等观念，成为一套体系化的传统学问。
- 魏晋南北朝时期，墓葬风水（阴宅）观念随着世家大族的厚葬风气而流行，相关文献与传说渐多。
- 唐宋以降，风水流派分化，形成"形势"（峦头）与"理气"两大宗趣，各自著书立说；明清时期风水术在民间十分流行，也始终伴随着争议与批评。
- 需说明：风水典籍版本流传复杂，各书成书年代与作者多有争议，此处不涉及具体篇目页码的考据。

## 两大流派（传统说法）

- 风水内部流派繁多，但大体可分两大宗趣：
    - **形势派（峦头）：** 重在看山川形势的走向与格局，讲究"龙、砂、穴、水、向"的配合，认为地形本身即蕴含吉凶信息。此派多用于山地丘陵环境的择址。
    - **理气派：** 重在以方位、时间配合数理推算吉凶，讲究坐向、元运、卦气等，有"八宅""玄空飞星"等多种名目。此派在平原地带与城市住宅中应用较多。
- 实际运用中两派常相互参照，并非截然对立；各派对同一地点、同一住宅的论断因方法不同而常有出入，这正是"风水先生各说各话"现象的原因。
- 了解风水时宜先把握"形势+理气"这一总框架，再谈具体名目，不易迷失于繁琐术语。

## 核心概念（传统说法）

- **"气"与藏风聚气：** 传统说法认为环境中有一种"气"的流转，理想的选址应能"藏风聚气"，即地形上能避强风、聚生气。
- **"龙、砂、穴、水、向"：** 传统峦头（形势）一派观察地形的一套名词框架：
    - **龙：** 指山势脉络的走向与起伏。
    - **砂：** 指穴场周围环抱的小山丘、地形。
    - **穴：** 指被认为适合落葬或建房的具体位置。
    - **水：** 指水流、水口的形态与方位。
    - **向：** 指建筑或墓穴的朝向。
- **理气各派：** 另有以方位、时间数理推算吉凶的一类流派，较常听到的名称如八宅派（按宅主命卦分东西四宅）、玄空派（以九宫飞星配时间方位论吉凶）等。
- **罗盘与二十四山：** 风水师勘察常用罗盘（罗经），盘面上以天干地支、八卦将方位细分为二十四等分（二十四山），用以确定坐向与理气推算；罗盘是风水文化中最具标识性的工具之一。
- 需要说明：风水流派繁多、说法不一，各派对同一名词的定义、断法常互有出入，此处仅作名词层面的客观介绍，不代表某种流派为定论。

## 阳宅：居住环境（家相）

- 传统说法关注阳宅的诸多方面，常见条目如：坐向方位、大门位置、采光通风、厅堂房间的布局、动线走向、宅周环境等。
- 传统阳宅理论还讲究"形局完整"：主张住宅方正、布局均衡、明堂（门前空地）开阔，忌讳缺角、直冲、逼窄等格局。
- 从现代宜居的角度看，其中不少讲究与环境科学常识相通，例如：
    - 重视朝向与采光，可对应冬日向阳、室内明亮的需求；
    - 重视通风与气流，可对应室内空气流通、避免潮湿的要求；
    - 重视"门路动线"顺畅，与日常起居动线合理、生活便利相通；
    - 重视宅周地形水流，与规避水患、滑坡等风险的经验一致。
- 现代建筑与室内设计中，采光、通风、动线、朝向本就是科学设计的基本考量；传统风水在这些方面积累的经验，与合理设计原则常有重合。
- 这些合理成分是传统居住经验的一部分，可作文化知识参考，不必依附于吉凶断言。

## 阴宅：墓葬环境（墓相）

- 传统观念认为，为祖先选择墓地的位置与朝向会影响其后代子孙的运势，故有"荫庇后人"的说法。
- 传统阴宅看重山势环绕、水流有情、来龙去脉等，其观念体系与阳宅大体同源而更强调地形格局。
- 阴宅风水的流行与古代宗法观念、孝道文化、慎终追远的风俗密切相关：选一块"好地"安葬先人，被看作尽孝与泽被后人的方式。
- 需说明：阴宅影响子孙运势之说属于传统民俗观念，流派众多、说法不一，并无现代科学依据；了解其观念与习俗即可，不宜据此安排实际事务。
- 现代视角下，安葬选址真正值得考虑的，是法律法规、土地规划、生态环保与对逝者的尊重，而非风水断语。

## 风水与古代城市规划

- 传统风水观念对古代城市与村落选址影响深远：依山傍水、坐北朝南、背风向阳等原则，在众多古城镇的选址中都能看到影子。
- 从现代视角看，这类选址逻辑常常与气候、水源、防御、交通等实际需求相合——古人未必经由科学推导，却在长期实践中沉淀出与宜居经验相通的取向。
- 因此，研究风水在今天的一个重要价值，是作为理解古人环境观与聚落营建智慧的窗口，而不仅是吉凶学说本身。

## 现代理性视角

- 从现代视角看，风水可视为一种传统文化遗产与民俗现象：它记录了古人对居住环境的选择经验与审美偏好，也承载了民间对吉凶祸福的心理寄托。
- 其中偏重环境宜居的部分（朝向、采光、通风、避害）与科学常识相通，值得以经验总结的态度看待。
- 而涉及吉凶应验、荫庇子孙等断言，则属于信仰与习俗层面，各家说法不一，不可作为可验证的事实或操作指引。
- 近年还出现过把风水包装成"环境心理学""高维科学"的商业话术，需警惕以科学之名贩卖吉凶断言的做法。
- 了解风水，宜以客观、知性的态度将其作为传统文化知识来读，取其宜居经验，明其民俗属性，而不宜迷信其断语、轻信所谓的"改运布置"。

## 延伸阅读

- 传统文献：葬书类（托名郭璞的《葬书》流传最广，成书年代有争议）、形法与理气各家著作；版本复杂，建议选学术整理本。
- 学术研究：从建筑史、聚落地理、民俗学角度研究风水的现代论著，比风水原典更适合作为客观了解入口。
- 现代科普：室内采光、通风、人体工学等居住环境科学资料，可作为理解"风水宜居成分"的科学参照。
